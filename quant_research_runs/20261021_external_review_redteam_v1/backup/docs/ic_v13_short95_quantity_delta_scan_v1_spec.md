# IC v1.3卖95% Put张数与初始Delta口径补测 V1

预注册日期：2026-09-17。研究专用；不修改生产规则、日报、账本或交易状态。

## 研究问题

第六层完整组合中的卖Put采用等名义本金：卖出510500 Put的标的名义等于被替代的固定核心IC名义。该口径不是Delta补足。本轮在相同完整IC组合中，使用每轮开仓前一交易日可知的挂牌Delta重新定义数量，比较等名义、初始0.5 Delta和初始1.0 Delta压力档。

## 固定规则

- 完整IC v1.3组合固定为第六层口径：固定核心0.5倍、现行动量0.5倍、估值0.5/1.0的0.5倍网格、核心/动量买Put、季度T-3期货链。
- 核心Put使用3倍盈利兑现；动量Put不兑现；所有买Put仍为约3个月、95%目标行权价并按目标Delta配量。
- 卖Put仍为估值0/1档、原IC 1.3执行动量许可、M+1、95%、绝对IV严格大于37.5%、权利金衰减60%后最多提前滚动一次；不加入卖方MOM120。
- 路由仍只替代固定核心0.5倍IC及核心Put。动量IC、动量Put和网格不变；IC不卖Call。
- 实物交割ETF转IC、季度链恢复及整轮扣费回本退出保持第六层状态日期。提高数量只线性放大该轮卖Put、交割ETF和恢复IC的经济敞口；不改变准入和退出日期。

## 数量档位

- `q1_notional`：等名义本金，数量倍数1.0；这是第六层当前研究候选。
- `q_delta05`：每轮按前一交易日挂牌合约绝对Delta反推`0.50 / abs(delta)`倍等名义数量，使每1倍IC口径初始短Put绝对Delta约0.5。
- `q_delta10_stress`：按`1.00 / abs(delta)`倍等名义数量，使每1倍IC口径初始短Put绝对Delta约1.0，仅作压力档。
- 完整组合中被替代的固定核心是0.5倍，因此上述两档对组合的初始绝对Delta贡献约为0.25和0.50。
- 真实层Delta使用开仓前一交易日交易所挂牌链字段；理论层使用前一交易日收盘的现货、利率、股息率、波动率及目标到期日计算Black-Scholes Put Delta。禁止使用执行日收盘Delta反推开盘数量。
- 数量允许连续值，以隔离经济敞口；另输出真实入场对应的每1张IC及0.5倍固定核心510500 Put张数。整数账户约束留待后续。

## 对照组

- `baseline`：完整当前组合，无卖Put、无盈利兑现。
- `profit3x_only`：只有核心Put三倍盈利兑现。
- 每个数量档分别输出`short95_only`和`joint3x`。
- `q1_notional`必须逐日复现第六层对应候选。

## 成本与资金

- 所有510500 Put单边5BP；IC期货单边1BP；现金年化3%。
- 正常固定核心0.5倍IC保留15%缓冲。卖Put、待交割和恢复IC阶段的固定核心缓冲按该轮数量倍数线性放大为`15% × quantity_scale`。
- 若完整组合现金权重低于0，候选标记为资金不可行。为观察压力路径可保留不含强平和借款利息的诊断收益，但不得晋级。
- 不加入动态期权保证金、强平、税费、盘口容量、整数张数或额外融资成本。

## 判定

- 真实挂牌层2022-09-19至2026-08-14；理论延展层2015-04-16至2026-08-14，严格分开。
- 输出全样本及10/5/3/1年年化、波动、Sharpe、最大回撤，并列出年度收益、入场Delta、数量倍数、真实张数与最小现金权重。
- `q_delta05`只有在真实与理论两层均资金可行、联合方案年化不低于`q1_notional`、Sharpe不低于其0.05以上、最大回撤绝对值恶化不超过1个百分点时，才保留为更高数量研究候选。
- `q_delta10_stress`只作压力测试，不因收益提高自动晋级。真实事件稀少、结果集中于个别周期或负现金均须明确披露。
