# 中证500固定估值因子结构 v3.1 数值纠正版预注册规格

- 版本：`ic_fixed_valuation_factor_structure_v3_1`
- 预注册日期：2026-08-18
- 父规格：`docs/ic_fixed_valuation_factor_structure_v3_spec.md`
- 父规格 SHA-256：`ea3095a489ea03d7021730cf931ace31b44b6b2435131ea3f18486c93a52cf6a`

## 纠正原因

v3 正式输出后，测试发现加权经验分布的累计浮点和在少数最高观测上达到 `1.000000000000001`，导致严格 `[0,1]` 完整性检查为假。偏差仅为机器精度，不改变排序、门槛状态、结构选择或任何经济结论，但 v3 的 `all_normalized_scores_in_unit_interval=false`，因此不能作为最终通过版本，且其首次正式输出目录不得覆盖。

## 唯一允许的改动

在每个基础风险分量和每个结构的经验分布映射后执行：

`score = clip(score, 0.0, 1.0)`

除此以外，v3 父规格的输入、样本、五类候选结构、7.5/10/12 年时间权重、0.600—0.900 状态探针、195 个候选、975 行窗口扫描、历史时点审计、纯结构选择规则、禁止使用未来收益和研究边界全部原样继承，不得修改。

## 冻结输入

继续使用 v3 父规格第 2 节的全部冻结输入与 SHA-256；另冻结父规格本身。正式程序仍须逐一验证所有上游输入。

## 纠正验收

1. 日度和月度全部基础风险分量及结构标准化风险严格位于 `[0,1]`；
2. v3.1 与 v3 的所有结构原始分、标准化分之最大绝对差不超过 `2e-15`；
3. v3.1 与 v3 的结构选择、当前状态、门槛布尔状态及历史时点结论完全相同；
4. `integrity_checks.json` 中所有完整性布尔值为真；
5. 正式输出写入新目录 `outputs/ic_fixed_valuation_factor_structure_v3_1/`，不得覆盖 v3。

本纠正版仍为 `RESEARCH_ONLY_NOT_LIVE_APPROVED`，不选择实盘门槛。
