# IM + MO Call 5%威胁救援最大历史代理检验 v26 预注册规格

冻结日期：2026-08-19（Asia/Shanghai）  
状态：发布前指数回算 + 合成Call长期诊断；不是真实IM/MO；未批准实盘。

## 1. 研究问题

在不改变v25r2的5%救援参数、正常入场门槛和PE20/60状态机的前提下，把检验期从现有2015-04-16—2026-08-14理论期权模型向前扩展，判断“受威胁向上向后移仓”是否只在2026年两次真实事件中偶然有效。

本版只研究卖Call子系统的增量，不重建2007—2015年不存在的IM、MO、IM贴水或主线Put。底仓统一使用1倍中证1000官方全收益指数代理，附加月滚成本和70%余额现金收益。正式真实证据仍以v25r2的2022-07-22以后官方IM/MO为准；本版所有结论均为长期方向诊断。

## 2. 最大可测边界与数据

- 中证1000官方价格指数`000852`及全收益指数`H00852`回算序列：2005-01-01—2026-08-14；
- 官方滚动PE回算序列：同源2005年起；指数正式发布日期为2014-10-17，之前必须标记`prepublication_backcast`；
- 中债10年国债收益率：2007-01-04起；
- 50ETF QVIX：2015-02-09起，原模型完成60日预热后的可用起点为2015-04-16；
- 新增长期诊断起点取全部必需字段完整的首个交易日，预期为2007-01-04，结束为2026-08-14。

价格和全收益指数是官方回算数据，但2007—2014年并非当时可交易、可观察的中证1000产品；不得把该区间描述为真实历史交易。

## 3. 2015年前IV代理敏感性

2015-04-16以后完全使用冻结模型的`QIVX50 × 中证1000/50ETF 60日实现波动率比`，必须与v25r2上游`sigma_close`逐日一致。

2015-04-16以前没有期权IV，使用严格滞后的中证1000价格指数60日实现波动率`RV60`乘固定IV/RV倍数。倍数不按策略收益选择，而是冻结为2015-04-16—2026-08-14现有模型`implied_sigma / RV60`经验分布的三个分位：

- P25：`0.9984611590392641`；
- P50：`1.1352106814268557`；
- P75：`1.2692067075266782`。

这些分位使用2015年后的信息回填早期，只能用于结构敏感性，不是因果可交易IV。只有三个场景方向一致时，才可称为不依赖单一IV假设。

## 4. 估值状态与候选

PE状态使用最大回算历史：从2005年首个非空官方滚动PE开始，T日只使用`[max(2005起点,T-10年),T]`内观测计算弱经验分位；`<=20%`进入低估修复态，直到`>=60%`退出。状态从普通态开始。该PE路径在2014-10-17以前是发布前回算诊断。

每个IV场景同批运行：

- 基线：PE20/60 + 文章期限—虚值率阶梯 + 正常入场IV26，不含救援；
- 候选：完全相同，但增加v25r2的5%救援。

正常态阶梯为30—60天/最低15%虚值、61—90天/20%、91—120天/25%；低估修复态只允许30—60天/25%。空仓每日检查，正常开仓IV须不低于26%。

## 5. 固定5%救援

- 每日T日收盘先检查`旧Call行权价/指数收盘-1 <= 5%`；
- 救援取严格晚于旧到期日的第一个模型挂牌月；
- 新行权价精确等于旧行权价`×1.05`；
- 救援豁免IV26，T日冻结、T+1收盘理论价执行；
- 连续最多5次，第6次仍受威胁则买回并暂停至下一月度评估；没有下一挂牌月时同样买回暂停；
- 不含TP80、分批止盈、急跌向内移仓、风险度扩仓或参数优化。

## 6. 代理底仓、成本与收益

- 1倍中证1000官方全收益指数日收益代理滚IM方向收益，不含历史贴水；
- 每月模型到期日计底仓双边2bp，首日单边1bp；
- 每1倍指数名义卖1倍Call篮子，等价于真实1张IM对应2张MO；Call每边1bp，救援换仓2bp；
- 70%资本上限减去Call保证金后的余额按净年化3%计息；
- 不含Put、买卖价差、冲击成本、盘中跳空、涨跌停或真实挂牌流动性。

## 7. 必报结果与判定

每个IV场景必须报告full/10Y/5Y/3Y/1Y CAGR与MaxDD、逐年结果、Call损益/成本/持仓日、最大与95分位Delta、最大保证金、救援次数、止损次数和最大连续救援次数。另报告2007—2015前QIVX段及2015年至今段的增量。

长期方向支持条件要求P25/P50/P75三个场景全部满足：

- 救援相对同场景基线full和10Y CAGR落后不超过1个百分点，5Y/3Y/1Y落后不超过3个百分点；
- 最大Call Delta至少下降10个百分点；
- 至少发生5次救援；
- 最终待执行动作、资本穿透和全部审计错误为0。

全部满足记为`extended_proxy_directionally_supported_across_iv_assumptions`；部分满足记为`iv_assumption_sensitive`；全部不满足记为`extended_proxy_not_supported`。无论结果如何都不得晋升实盘，也不得反选IV倍数或5%参数。
