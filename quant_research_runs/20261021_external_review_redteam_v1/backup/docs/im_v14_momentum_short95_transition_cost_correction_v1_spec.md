# IM v1.4 动量腿卖Put切换成本修正复测 v1

日期：2026-09-18  
状态：研究预注册；不修改生产、日报、账本或交易状态。

## 问题

IM v1.3 动量腿转卖Put测试的 `compose_dual` 在动量腿切入卖Put、以及卖Put结束后恢复IM期货的边界日，将该动量期货腿的换手成本置为零。该处理不改变卖Put本身的收益或成本，但遗漏了被替换期货腿的平仓和恢复交易成本。

这不是 IC 中将真实开盘价覆盖为收盘价的加载链问题：IM 本测试明确采用月度收盘成交，且原始 IM 期权报价链未被该 IC 加载器覆盖。

## 固定口径

- 复用 IM v1.3 的真实挂牌层和理论延展层、同一 95% M+1 MO Put、IV 严格高于 35%、q3、三倍兑现、估值/MOM120/早展期规则。
- 复用固定核心腿、动量腿和双腿四组对照。
- 保持 IM 的月度收盘执行口径；不将结果改写为开盘成交。
- 仅修正动量期货腿的边界换手：按相邻交易日的实际持有单位差额计入既有单边期货成本。卖Put状态机、期权价格和数量均不变。

## 判定

报告修正前后 `both_q3 - fixed_only_q3` 的全样本年化、Sharpe、最大回撤及逐日差异；若真实挂牌层仍不满足原门槛，维持拒绝动量腿转卖Put。该复测只校正成本，不构成生产晋级。
