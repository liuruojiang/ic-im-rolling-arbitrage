# IM 固定估值网格 2015 模型代理高入场阈值扫描 v20 预注册规格

冻结日期：2026-08-23（Asia/Shanghai）  
状态：预注册模型代理研究；未批准实盘。

## 1. 研究问题

用户要求把 IM 网格高入场阈值扫描扩展到 2015 年开始的模型代理样本。本版沿用 v19 已冻结的对角扫描：入场 `1.35—2.10`、步长 `0.05`，退出阈值恒等于入场阈值加 `0.40`，并与不加网格和当前 `0.85/1.25` 网格同批比较。

本版不修改 `notes/mainline_registry.md`、V1/V2 冻结规范、首次正式输出或任何实盘接口。

## 2. 模型代理边界

- 样本：2015-04-16—2026-08-14。
- 2015—2022 年不是真实 IM/MO 可执行历史；使用中证1000全收益指数构造的模型 IM 单位、理论 MO Put、模型 D10/IV26/5% 救援 Call 与重建估值。
- 正式代理来源：`outputs/im_put_grid_call_final_audit_v1/daily_candidates.csv.gz` 模型层。
- 无网格基准：`core_put_call_d10_threat5`，即固定1倍模型IM + V1三张上限Put + 模型Call救援，不含网格。
- 当前网格参照：`full_put_grid_call`，即同一模型核心加 `0.85/1.25` 网格。
- 这条代理链的 Put 上限为3张，不是当前 V2 的4张上限；因此结果只能回答网格状态与模型收益敏感性，不能称为当前 V2 的2015实盘回测。

## 3. 候选与执行

- `no_grid`：网格仓恒为0。
- `current_L0.85_H1.25`：当前网格参照，必须逐日复现正式 `full_put_grid_call` 模型路径。
- 高阈值候选：入场 `1.35—2.10`，步长 `0.05`，共16点；退出 `1.75—2.50`。
- 估值分数为 `unbounded_median_knot`；T日收盘确认，T+1模型指数开盘执行。
- 网格状态只有0/1两档；持有时总模型IM名义为2倍；网格仓不增加Put或Call覆盖。

## 4. 收益、成本与资金

- 模型开盘单位按前一日中证1000全收益指数单位乘以价格指数开盘/前收比例构造；结算单位使用全收益指数收盘。
- 网格开平每边1bp；持有期间跟随底仓换月，网格换月双边2bp。
- 每1倍模型IM按30%保证金/风险缓冲；剩余现金扣除模型Put市值与模型Call保证金后按净年化3%计息。
- Put和Call逐日损益、成本、持仓市值与Call保证金继承正式无网格模型核心，不随网格仓放大。
- 不计盘口价差、冲击、容量、涨跌停无法成交、动态保证金上调、税费；上市前理论期权没有真实成交量或可执行性证明。

## 5. 输出指标

每个候选输出 full、last_10y、last_5y、last_3y、last_1y：CAGR、年化波动、Sharpe、MaxDD，以及相对 `no_grid` 的CAGR差和MaxDD差。

同时输出入场/退出次数、完成周期、入场年份数、持有天数、持有比例、期末状态、网格成本、30%口径日终穿透与开仓早盘资金代理穿透。

本版只做描述性模型敏感性分析。任何候选最多进入观察名单；不得依据模型代理直接修改当前 V2 网格或解释为交易建议。

## 6. 强制完整性检查

1. `no_grid` 必须逐日复现正式模型 `core_put_call_d10_threat5`，现金收益最大误差不超过 `1e-12`。
2. `current_L0.85_H1.25` 必须逐日复现正式模型 `full_put_grid_call` 的网格状态、网格收益、成本、总IM单位和现金收益，最大误差不超过 `1e-12`。
3. 16个高阈值候选、当前网格参照和不加网格基准全部存在，日期唯一。
4. 信号日严格早于执行日；模型开盘、结算与前结算单位均为正。
5. 总IM单位只允许1或2；收益乘法成本、现金利息与净值复算误差不超过 `1e-12`。
6. 资金穿透是候选风险结果，必须逐候选保存；不得通过删日或改变资金口径使候选通过。
7. 首次正式输出不得覆盖；参数扫描工件必须通过 `complete --strict`。
