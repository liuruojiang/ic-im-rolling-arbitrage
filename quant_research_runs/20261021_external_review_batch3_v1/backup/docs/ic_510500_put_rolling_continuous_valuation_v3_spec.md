# IC + 510500 Put 滚动连续估值保护 v3 预注册规格

- 版本：`ic_510500_put_rolling_continuous_valuation_v3`
- 预注册日期：2026-08-16
- 状态：研究回测；未获准实盘；不得解释为交易建议或接入自动/人工下单
- 上一版：`ic_510500_put_full_cycle_valuation_v2`

## 1. 研究问题与版本边界

v2证明两类标准均不合格：相似历史硬切档在真正保护的日期高度依赖历史起点；固定2007—2014分布和固定四因子门槛又在最近5年完全失去区分度。

v3只测试一层新假设：**用固定长度、因果滚动的估值分布形成连续风险分数，再把风险分数线性映射为0%—100%的保护比例。** 固定长度窗口使边界随市场结构缓慢更新，但不依赖回测从哪一天开始；连续映射避免0/50/100三档在边界附近陡峭跳变。

本版不改变IC展期、资金口径、Put期限、模型虚值度或实际合约筛选，不加入趋势、暴跌、波动率择时，也不扫描期权执行参数。

## 3. 因果滚动风险分数

每个评估日 `T` 收盘后：

1. 从完整月度状态中取 `[T-W年, T]` 的月末历史，`W` 为8、10或12年；下界和上界均包含。
2. 历史月数不得少于96。2015年开始时10/12年窗因完整数据仅从2007年起，实际使用全部可得且不少于96个月的历史；不得向2007年前伪造估值。
3. 将T日PB映射为历史右侧经验分位风险；将ERP、过去一年股息贡献映射为反向经验分位风险。经验分位固定为`searchsorted(side="right")/N`，只使用T日及以前数据。
4. `ERP=1/聚合滚动PE-10年国债收益率`。为避免PE在“直接PE”和ERP中重复计权，主经济风险分数为：

   `economic_risk = 25% × PB风险 + 50% × ERP风险 + 25% × 股息贡献风险`

5. PE风险仍输出审计，但不进入主经济分数。
6. 结构对照只增加一个等权四因子候选：PE、PB、ERP、股息风险各25%；它不参与主候选晋升。

## 4. 连续保护映射与参数网格

对起始风险 `L`、满保护风险 `H`：

`raw_target = clip((risk_score-L)/(H-L), 0, 1)`

为适配实际合约数量并避免微小日波动触发连续交易，目标比例用明确的十进制四舍五入量化到10%：

`target = floor(raw_target × 10 + 0.5) / 10`

目标取值为0%、10%、…、100%。不再增加滞后确认或暴跌条件；目标档位变化后下一交易日开盘立即调整。

主经济分数预注册完整网格：

- 滚动窗：`8 / 10 / 12`年；
- 映射：`L/H = 0.40/0.80、0.50/0.90、0.60/0.90`；
- 共9个候选：`econ_w08_l40_h80`等稳定标签。

结构对照：`equal4_w10_l50_h90`。

基准：`no_put`、`always_50`、`always_100`。总计13条规则、模型和实际两层共26个候选。不得在看到收益后补充0.45、0.55、其他权重、其他窗口或保护地板。

## 5. 交易、成本与资金口径

1. IC基线沿用冻结逐月到期展期净收益和每边1bp成本。
2. 日评：T日收盘形成目标，T+1交易日开盘执行；首日仅允许用前一交易日完成状态初始化。
3. Put固定当月合约。模型Put固定入场时85%虚值度，使用冻结Black-Scholes/QVIX代理；实际Put使用目标月份内有正开盘价且成交量大于0的最低行权价。
4. Put满保护每边成本1bp，按实际目标比例变化量缩放；到期后若目标仍大于0，按同一规则续开。
5. 100% IC名义多头，不放大方向杠杆；30%作为保证金及缓冲，70%现金按年化3%计息，Put市值占用从70%现金中扣除、下限为0。
6. 用户资本口径以`cash_ret/cash_ann_return/cash_max_dd`为主；不含现金的期货+Put口径同时输出。
7. 实际期权仍是第三方日线开收盘和成交量，不是官方结算价或可执行买卖盘；模型期权不冒充历史成交。

## 6. 必须输出的比较

每个候选必须输出：

- 全样本、最近10年、5年、3年、1年的年化收益、年化波动、Sharpe、最大回撤；真实层不足10/5年时正式表显示N/A，参数扫描副本保留`window_available=false`的全可得样本数值以满足严格产物格式；
- 开发期和留出期同样指标；
- 逐年指标；
- 相对同层`no_put`的年化差和回撤改善；
- 平均/最大保护比例、保护日、切换次数、Put市值占用、成本、交易次数及实际报价陈旧/延期；
- 风险分数及PB/ERP/股息/PE分位逐日审计；
- 8/10/12年相邻窗口在相同映射下的保护日Jaccard、条件于至少一方保护的目标完全一致率、目标平均绝对差；
- 模型和实际同区间的方向比较、永久保护非空验证、事件集中度及当前研究状态。

## 7. 预注册判断标准

### 7.1 单候选防御标准

主经济候选必须同时满足：

1. 开发期：含现金最大回撤相对无Put改善至少3个百分点，含现金CAGR不得落后超过1个百分点；
2. 留出期：含现金最大回撤相对无Put改善至少3个百分点，含现金CAGR不得落后超过1个百分点；
3. 五个强制窗口中，最大回撤至少改善3个窗口；全样本/10年/5年CAGR落后不得超过1个百分点，3年/1年不得超过3个百分点；
4. 模型层和实际层各至少20个保护日；实际层永久保护必须产生真实头寸；
5. 不与无Put逐日完全相同。

### 7.2 邻域与信号稳定性

通过单候选标准还不够：

- 同一映射下，8/10/12年至少两个相邻窗口候选也必须通过单候选标准；
- 通过的相邻窗口之间，保护日Jaccard至少60%，条件于保护并集的目标平均绝对差不超过20个百分点；
- 映射参数的相邻候选不能全部失败。只有一个孤立最优点时标为`peak_only`，不得晋升。

### 7.3 选择与决定

- 若多个候选全部通过，选择平均保护比例最低者作为观察线；若相差不超过1个百分点，优先10年窗口和中间映射0.50/0.90。
- v3即使通过也最多决定为`watchlist`，因为2015—2022仍是模型Put，不能直接批准实盘。
- 若网格执行完整、数据与引擎有效但无人通过，决定为`keep_default`、稳定性`reject`；不允许用运行后新阈值追救。
- 若基线、数据、模型或产物完整性失败，决定为`rerun_required`。

## 8. 完整性与失败条件

- 冻结规格SHA-256不匹配、正式输出已存在、输入哈希变化、无Put与冻结IC不精确一致：立即失败；
- 风险历史少于96个月、使用T日以后状态/收益率、常规执行日不晚于评估日：立即失败；
- 候选缺失、重复日期、收益缺失或日收益`<=-100%`：立即失败；
- 永久50%/100%模型或实际候选没有Put头寸：立即失败；
- 首次正式输出`outputs/ic_510500_put_rolling_continuous_valuation_v3/`不得覆盖；后续改变任何权重、窗口、映射、量化步长或执行假设必须新版本预注册。
