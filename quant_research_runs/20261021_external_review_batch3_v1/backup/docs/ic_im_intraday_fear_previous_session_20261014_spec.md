# IC/IM 盘中恐慌指数上一交易日沿用规范

2026-10-14 用户明确授权：“如果有实时的恐慌数据就用，没有就沿用昨天的。”本规范中的“昨天”定义为信号日之前的最近实际交易所 session。授权自本次变更后的盘中查询生效，不回写此前信号、收盘账本或历史绩效。

## 输入与时点

- 盘中优先使用合格的当日恐慌指数；只有当日尚未发布时，才沿用正式交易日历计算的上一 session 的合格读数。不得使用更早值，不因长假自然日间隔增加而拒绝正确上一 session。
- 复用现有网页与 CSV 的日期、数值一致性、有限值、范围、来源及 SHA-256 检查。沿用值须有上一 session 收盘后更新的证据；页面更新时间与数据日分别保留。
- 采集完成时钟须为信号日且严格早于北京时间 15:00；HTTP 开始与完成分别记录，跨过截止不形成新的沿用盘中信号。
- 正式日历缺失、不覆盖或信号日休市时不得推定上一 session。当日值和上一 session 合格值均缺失时，网格和完整总期货目标未确认，其他已核验腿单列。
- 收盘确认、收盘后“实时信号”查询以及历史正式回放继续要求原有当日/历史同日数据门禁；沿用状态不得进入收盘账本。

## 身份与输出

盘中输入口径修订为 `ic_im_intraday_fear_previous_session_20261014_v1`；沿用状态为 `intraday_previous_session`。输出必须同时保留 `fear_data_date`、`fear_previous_exchange_date`、`fear_latest_available_date`、`fear_page_data_date`、采集/更新时间、来源 URL、CSV SHA-256、`fear_fallback_applied` 和 `fear_fallback_reason`。沿用原因只允许 `same_day_not_published`。

报告明确写“沿用上一交易日 YYYY-MM-DD（当日未发布；盘中预估）”，不能把沿用日期改成信号日，也不能声称收盘确认。盘中目标仍是待收盘确认后形成的下一实际交易日研究目标，不代表成交或下单。

策略 fix11 BUILD/RULE/DELIVERY、schema 4/r1 及历史生效边界保持原身份。网格估值线、恐慌≤25进入/≥50退出、0.5倍数量、首次入场来源冻结和退出不重入规则保持原计算；本次只明确已获授权的盘中数据输入选择。所有 Put、Call、季度展期和其他策略规则保持原口径。
