# IM估值频率 × MO Put期限 v4：运行后独立审计

审计日期：2026-08-16  
研究状态：`watchlist`；稳定性标签：`data_sensitive`；未获准实盘

## 1. 口径边界

- 本版比较的是“滚动目标期限”：`front`为执行日最近未到期月份，`2m`/`3m`为实际到期日最接近估值日后2/3个自然月的月份。
- 估值目标张数不变且目标月份不变时不交易；目标月份改变时换Put。因此本版`3m`是冻结v2的月度滚动3个月期限，不是v3“一张Put持有至到期、覆盖约三次IM换月”的口径。
- 月、周、日评均为T收盘计算、下一共同交易日开盘执行。提高评估频率不等于每日换Put。

## 2. 独立数值核验

- 正式样本为2022-07-22至2026-08-14，共986个共同交易日；日期唯一。
- 18组候选的Put损益、IM成本、Put成本及现金收益逐日重算，净收益和现金收益最大绝对误差均为`3.21e-16`；累计净值最大误差为`4.18e-14`。
- 全样本CAGR和MaxDD独立重算后，与正式指标最大绝对误差分别为`7.36e-15`和`4.44e-15`。
- `monthly_3m_binary`与冻结v2的净收益、加现金收益逐日最大差分别为`9.97e-17`和`9.94e-17`。
- 50个月评状态的预测中位数与冻结v2最大差为`9.02e-17`，二档信号完全一致；月末日度重建的PE、PB、ERP、后视股息与冻结月度状态最大差低于`1e-16`。
- 991条交易审计记录中，常规执行均严格晚于估值日；无重复候选执行日；所有买入均满足`open>0、volume>0、open_interest>0`，逐笔费用等式最大误差`2.71e-20`。
- 全网格共有8个延迟候选日：周评3个月三档1日、日评前月三档1日、日评3个月二档1日、日评3个月三档5日；周评2个月两条候选均无延迟。

## 3. 频率结论（固定3个月期限）

| 档位 | 月评 CAGR / MaxDD | 周评 CAGR / MaxDD | 日评 CAGR / MaxDD |
|---|---:|---:|---:|
| 二档 | 13.87% / -30.07% | 13.95% / -28.87% | 11.79% / -31.83% |
| 三档 | 13.62% / -30.12% | 13.84% / -28.69% | 11.64% / -31.79% |

- 周评3个月只带来轻微改善；日评3个月同时降低收益并加深回撤。
- 二档的评估次数/状态切换为月评`50/9`、周评`209/12`、日评`986/16`；三档为`50/11`、`209/17`、`986/29`。日评增加的不是同等比例的信息，而是更容易在估值边界附近反复改变状态及目标月份。
- 二档3个月Put累计费用为月评0.70%、周评0.87%、日评0.99%。但日评落后不能只归因于费用：Put逐日损益简单合计由月评`+2.06%`、周评`+2.54%`降为日评`-4.45%`，主要问题是信号时点和合约路径。

## 4. 期限结论（固定月评）

| 档位 | 前月 CAGR / MaxDD | 2个月 CAGR / MaxDD | 3个月 CAGR / MaxDD |
|---|---:|---:|---:|
| 二档 | 12.92% / -33.81% | 14.55% / -31.58% | 13.87% / -30.07% |
| 三档 | 12.73% / -33.96% | 14.28% / -31.73% | 13.62% / -30.12% |

- 前月Put的保护最弱，收益与无Put接近，但MaxDD只从-35.96%改善到约-34%。
- 2个月Put在月评下收益最高；3个月Put的全样本收益略低，但MaxDD更浅，呈现“2个月偏收益、3个月偏回撤”的权衡。
- 月评二档前月/2个月/3个月的最近1年结果分别为`22.60%/-19.56%`、`26.08%/-16.35%`、`21.48%/-20.27%`；短窗口对2个月期尤其有利，不能当作长期稳定证据。

- 但优势集中：周评2个月二档相对月评3个月二档的净对数优势中，2024-02-02单日贡献42.62%，前5个正贡献日合计相当于净优势的93.17%；其余负贡献抵消了部分正贡献。

- 周评2个月二档共有47个交易事件，Put累计费用0.81%，无延迟；这不是因忽略交易成本而得到的领先，但官方开盘价仍不代表盘口可承载成交量。

## 6. 判定

周评2个月Put是本轮值得继续纸面跟踪的候选，但不替换冻结月评3个月二档基线。原因是IM/MO可用历史只有约4年，10年和5年指标均为N/A，且领先对少数日期和2024—2025行情路径敏感。参数扫描决定为`watchlist`，稳定性为`data_sensitive`；下一步若继续，应做冻结规则的前瞻纸面跟踪，或另立版本比较2个月Put“滚动目标期限”与“持有到期覆盖两次IM换月”，不得在v4内追调阈值。
