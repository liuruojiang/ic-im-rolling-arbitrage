# 50%裸滚IM + 50%动量IM：逐袖同比例动态Put v3

日期：2026-08-23  
状态：用户纠正后的预注册研究规格；未批准实盘

## 研究目标

按两条资本袖分别配置同一套正常IM Put规则：固定存在的50%裸滚IM袖配置50%的动态Put；动量袖持有多少IM，就同比例配置多少动态Put。组合Put最多4张，整体保护Delta约为1，不允许出现v2错误路径中Put规模相对底仓放大的情况。

## 底仓结构

- 裸滚袖：50%资本，始终持有0.5倍滚IM；
- 动量袖：50%资本，沿用`MA35 / Mom18 / W2.5`，50% Abs20 OFF + 50%静态`Abs20 > 0`；
- 动量袖内部权重`momentum_weight`为0、0.5或1，因此该袖实际IM名义为0、0.25或0.5倍；
- 组合总IM名义为`0.5 + 0.5 × momentum_weight`，即0.5、0.75或1倍。

## Put规则与逐袖数量

先由原IM V2规则得到每1倍IM的目标`q_t ∈ {0,1,2,3,4}`：

- 绝对估值轴`2.45 / 2.50 / 2.60`对应1/2/3张；
- 57个月滚动相对估值轴`75% / 85% / 90% / 92.5%`对应1/2/3/4张；
- 两轴取较高目标；中证1000全收益指数`MOM120 < 0`时最低4张；上限4张；
- 约3个月期限、95%目标行权价，T日收盘信号、T+1交易日收盘执行，月度期限重置。

随后按袖缩放：

- 裸滚袖Put：`q_bare = 0.5 × q_t`，最高2张；
- 动量袖Put：`q_momentum = 0.5 × momentum_weight × q_t`，最高2张；
- 合计Put：`q_total = q_bare + q_momentum = total_im_units × q_t`，最高4张；
- 逐日强制验证上述恒等式，且`q_total <= 4`；
- 张数为单位净资产归一化数量，实际组合需按资本规模做整数合约映射。

## 收益与资本重组

- 原V2每1倍IM的Put损益、费用、市值和名义均乘`total_im_units`；
- 裸滚袖与动量袖的Put组件分别按各自缩放系数保存，并验证相加等于组合组件；
- 底仓非现金净收益加组合Put损益后乘组合Put费用；
- Put市值从组合现金权重扣除，不得出现负现金；
- 每1倍IM使用30%保证金及缓冲，其余现金按净年化3%计息；
- Call和网格关闭。

## 数据与共同样本

- 沿用已审计的`im_roll50_momentum50_fullcycle_put_v1/v2`理论与真实Put组件；
- 2015-04-16至2022-07-21为理论Put和上市前平均贴水代理；
- 2022-07-22至2026-08-14为冻结真实IM/MO；
- 2018-06-18因理论Put模型缺失，所有比较路径共同删除；
- 价格指数不复权，MOM120使用中证1000全收益指数，Asia/Shanghai交易日历。

## 正式比较

- `no_put`：不加Put；
- `sleeve_matched_dynamic_put`：本版唯一主路径，逐袖同比例动态Put；
- v1半规模与v2整套Put只保留为历史错误/诊断证据，不作为本版候选。

输出全样本、10年、5年、3年、1年的年化收益、最大回撤、波动率、Sharpe和期末净值；另输出理论/真实分层、年度表现、回撤峰谷、袖级张数与资本审计。

## 结论边界

- 上市前平均贴水为未来信息回填，Put为理论定价，不能视为真实可执行历史；
- 真实MO为冻结收盘路径，未计盘口价差、冲击、收盘容量、动态保证金、价格限制和整数张数误差；
- 本版纠正研究口径，不修改当前IM V2生产主线，不代表最新交易信号或交易授权。
