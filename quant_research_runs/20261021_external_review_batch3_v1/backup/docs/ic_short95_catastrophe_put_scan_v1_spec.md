# IC M+1 卖95% Put保留灾难保护扫描 v1（预注册）

## Research Question

在上一层保留的 IC M+1、绝对 IV 严格大于37.5%、卖95% Put、权利金衰减60%后最多提前滚动一次的混合路由中，检验卖 Put 期间同步持有深度虚值多头 Put 能否改善尾部风险。

## Frozen Baseline

- 对照一：滚动 IC + 现行102%核心 Put。
- 对照二：M+1 卖95% Put 路由，不带灾难保护。
- 卖 Put 准入保持估值0/1档与原 IC 1.3 执行动量许可；不重新引入已取消的 IC MOM120。
- 卖 Put、IC和核心 Put 同步切换；实物交割 ETF→IC 及 IC 回本退出保持原状态机。
- IC 主线不含 Call；本层不修改生产或冻结主线。

## Candidate Grid

- `none`：不买灾难保护 Put。
- `90%`、`85%`、`80%`：按前一交易日510500收盘价的目标比例，选择与卖出腿同到期、最接近目标行权价且低于卖出腿行权价的挂牌 Put；数量与卖出腿相同。

## Execution and State Rules

- T日收盘形成信号，T+1开盘同步卖95% Put并买灾难保护 Put。
- 真实层两腿都必须有正开盘价与正成交量；保护腿不可执行时整组不得开仓，禁止退化成裸卖 Put。
- 持有期若保护腿当日无成交记录，沿用上一可得收盘价估值并单列陈旧估值天数；任何开仓、平仓或换月仍必须有当日可成交开盘价。
- 60%权利金衰减滚动时，旧卖出腿与旧保护腿在同一T+1开盘同步平仓，新卖出腿与新保护腿同步移至紧接下一个实际挂牌月份；新腿重新通过原 IC 1.3 准入。
- 到期按两腿内在价值结算；卖出腿实物交割后，保护腿已同步到期，不改变 ETF→IC 与回本退出。
- 每一笔510500 Put买卖均按标的名义单边5BP计费；ETF与IC单边1BP；每1倍期货使用30%保证金/缓冲，现金年化3%。

## Data Layers

- 真实层：2022-09-19至2026-08-14的真实510500 Put、ETF与IC数据。
- 理论层：2015-04-16至2026-08-14的理论510500 Put延展与历史IC；不得解释为真实可成交历史。

## Outputs and Diagnostics

- 全样本、10年、5年、3年、1年：年化收益、波动率、Sharpe、最大回撤。
- 路由周期数、保护腿不可执行拒绝数、提前滚动数、实物交割数、保护腿到期实际赔付次数、最差周期损益。
- 保存逐日收益、信号、周期、事件与执行状态机。

## Pre-registered Decision Rule

保护候选只有同时满足以下条件才可保留为下一步研究候选：

1. 真实层和理论层全样本最大回撤相对裸卖 Put均不得恶化超过0.50个百分点；
2. 两层全样本年化收益损失均不超过1.50个百分点；
3. 至少一个可比层的最差卖 Put周期损益改善；若样本内保护腿从未产生正到期赔付，标记“尾部效果未识别”，不得据此证明有效；
4. 至少两个相邻保护档方向一致，单点最优不晋级。

即使通过，也仅为研究候选，不自动替换1.3版本或生成交易建议。

## Known Limitations

- 真实挂牌历史短，卖 Put 持有期未必覆盖极端下跌。
- 理论层依赖 Black-Scholes 与历史输入，无真实买卖价差、冲击、容量、动态保证金、强平、税费或整数张数约束。
- 真实保护腿按挂牌行权价就近选择，实际比例可能偏离80%/85%/90%。
