# IM M+1卖95% Put相对IV扫描 v1：运行后审计

## 结论

相对IV暂不替换绝对`IV>35%`。`504日/80%分位`是唯一同时在真实层和理论层改善Full Sharpe与最大回撤的候选，但它未通过预注册的真实CAGR容忍门槛，且相邻70%和90%档不形成连续平台，因此只保留研究观察，不晋级1.3版本。

## 核心比较

| 候选 | 真实 CAGR / Sharpe / MaxDD | 理论 CAGR / Sharpe / MaxDD | 周期数（真实/理论） |
|---|---|---|---:|
| 绝对IV>35% | 20.44% / 1.226 / -16.20% | 16.83% / 1.123 / -16.71% | 3 / 10 |

| 504日/80% | 19.52% / 1.328 / -14.31% | 18.32% / 1.197 / -16.03% | 8 / 11 |

`504日/80%`相对绝对IV基线：

- 真实CAGR下降0.92个百分点，超过预注册允许的0.50个百分点；Sharpe提高0.102，MaxDD改善1.90个百分点。
- 理论CAGR提高1.49个百分点，Sharpe提高0.074，MaxDD改善0.67个百分点。
- 最近3年真实CAGR几乎相同（32.14% vs 32.23%），Sharpe提高（1.862 vs 1.667），MaxDD改善1.90个百分点；最近1年真实CAGR提高4.28个百分点，但该窗口样本更短。
- 真实卖Put周期从3个增加至8个，理论从10个增加至11个；这不是等频率替换，相对IV会在绝对IV不足35%但处于自身历史高位时更早、更频繁进入卖Put。

## 完整性与限制

- 本次绝对IV基线与上一轮统一修正后的M+1输出逐日收益最大误差：真实和理论均为`9.974659986866641e-17`，低于`1e-12`门槛。
- 相对分位只使用T日前的历史IV；窗口不足60个有效观测时关闭入场，未用未来数据回填。
- 真实层仅约四年，且最佳候选只有8个周期；理论层仍是Black-Scholes代理，不是可成交MO历史。
- 未纳入真实买卖价差、冲击、容量、动态保证金、强平、税费和整数合约约束。
