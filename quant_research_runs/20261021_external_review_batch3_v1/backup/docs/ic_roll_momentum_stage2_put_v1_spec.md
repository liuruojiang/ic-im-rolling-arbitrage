# IC 分层研究第二层：50:50 底座叠加动态 Put v1（预注册）

## 研究目标

固定第一层 `50% 裸滚 IC + 50% 动量门控 IC`，只增加当前 IC V2 动态 Put，比较：

1. `roll50_momentum50_no_put`：不加 Put 的第一层基线；
2. `put_bare50_only`：Put 只保护固定裸滚 50% 袖；
3. `put_both_sleeves`：固定裸滚袖始终保护，动量袖按当日实际 IC 名义同步保护。

Call 与网格继续关闭；不调动量参数、组合比例、Put 估值阈值、期限或成本。

## 固定底座

- 第一层正式输出：`outputs/ic_roll_momentum_stage1_v1/daily_nav.csv.gz`。
- 中证500动量：`MA110 / Mom24 / W2`，50% `Abs20 OFF` + 50% `Abs20 > 0`。
- 动量目标只允许 `0 / 0.5 / 1.0`；组合总 IC 名义为 `0.5 / 0.75 / 1.0`。
- 期货、现金、保证金和交易成本完全继承第一层：单边 1bp、每 1 倍 IC 30% 保证金/缓冲、剩余现金净年化 3%。

## 固定 Put 规则

- 采用当前冻结 IC V2：中证500无界估值分数 `1.90 / 1.95 / 2.00 / 2.05` 对应每 1 倍受保护 IC 的目标绝对 Delta `25% / 50% / 75% / 100%`。
- 中证500全收益指数 `MOM120 < 0` 时，目标绝对 Delta 最低 `50%`。
- 估值目标与动量下限取较大值、不相加；每个完整受保护袖内部的目标为 `0 / 25% / 50% / 75% / 100%`，最高 100%。
- 510500ETF Put；执行日加 3 个日历月为目标，取最近实际挂牌到期月；目标行权价约为 ETF 的 95%；随 IC 月换重置，不持有到期，不做每日 Delta 再平衡。
- 信号 T 日收盘评估，T+1 共同交易日收盘执行。

## 袖子与目标 Delta

令 `d_v2[t]` 为 T+1 执行后的 V2 每 1 倍 IC 目标 Delta，`w[t]` 为第一层已按 T+1 落地的动量 IC 权重：

- `put_bare50_only`：组合目标 Delta = `0.5 × d_v2[t]`；
- `put_both_sleeves`：组合目标 Delta = `(0.5 + 0.5 × w[t]) × d_v2[t]`。

“50%”仅为资本袖规模，不是把动态 Put 固定成半张或固定 0.5 倍。目标 Delta 变化（包括动量袖启停）必须进入原期权执行引擎，按理论单位或真实整数张数重新开仓、退出、换月或调仓，并计入相应 Put 成本；禁止事后把完整 Put 日收益机械乘比例来代替执行。

## 数据分层与拼接

- 2015-04-16—2022-09-16：`model` 层。期货底座为真实 IC 月度滚动；Put 使用 QVIX、Black-Scholes 和冻结执行规则构造的理论 510500 Put，不冒充真实期权成交。
- 2022-09-19—2026-08-14：`real` 层。期货继续使用官方 IC，Put 使用真实 510500ETF 期权收盘价、实际挂牌合约与整数张数。
- 全周期路径在 2022-09-19 切换为真实层；重叠期仅用于校验，不在同一日混合两层收益。

## 收益与现金

- 第一层 50:50 的期货净收益保持不变；Put 损益、Put 成本及 Put 市值占用在其上逐日叠加。
- Put 成本按冻结引擎的单边比例成本计入；真实层保留整数合约离散性。
- 现金权重 = 第一层组合现金权重 - Put 市值占用；不得低于 0。现金继续按净年化 3% 计息。
- 无 Put 路径必须逐日精确复现第一层 `roll50_momentum50_ic_ret`。

## 报告与验证

- 报告全周期、最近 10 年、5 年、3 年、1 年的年化收益、年化波动、最大回撤、Calmar、平均 IC 名义、Put 成本与最大现金占用。
- 验证 V2 原始目标只含 0/25%/50%/75%/100%，负 MOM120 下限、100% 上限和 T+1 时序均成立。
- 验证两条 Put 路径的目标恒等式、模型/真实切换日期、日期一对一、现金恒等式、无缺失与无单日收益小于等于 -100%。
- 另保存逐日路径、Put 调仓事件、目标计划、分年度指标、输入哈希、验证和运行清单。

## 研究边界

- 本层回答“Put 只保护裸滚袖，还是连动量袖一起保护”这一项；不同时测试 Call 或网格。
- 理论 Put 段对波动率模型敏感；真实 Put 段不足 10 年。全周期结论必须同时披露该限制。
- 结果仅为研究候选，不修改冻结 IC/IM V2 主线、Poe 或实盘配置。
