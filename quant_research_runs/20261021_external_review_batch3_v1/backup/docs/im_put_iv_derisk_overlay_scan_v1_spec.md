# IM 高隐波停买 Put / 核心降仓研究预注册 v1

预注册时间：2026-08-25（Asia/Shanghai）  
状态：研究候选；不改写 `ic_im_system_mainlines_v2`，未批准实盘。

## 1. 研究问题

检验中证1000滚动 IM 系统中，当拟买入的 MO Put 隐含波动率较高时，停止持有 Put 并降低固定核心 IM 仓位，能否在相同真实数据、执行时点和成本口径下，比冻结 v2 主线获得更好的收益/回撤权衡。

## 2. 权威基线与不变项

- 权威基线：`outputs/ic_im_system_mainlines_v2/` 中的真实 IM 路径 `IM_4tier_q750_850_900_925_mom4`。
- Put 原始目标、3个月目标期限、95%目标行权价、T收盘评估/T+1收盘执行均继承 v2。
- 固定估值网格保持独立，不随核心降仓同比缩放；网格仓原本不受 Put 保护。
- Call 仍只对应固定核心 IM；核心被缩放时，Call 的损益、成本、保证金和覆盖同比缩放，避免把候选解释为裸卖 Call。
- 绩效仍按每1倍 IM 30%保证金/缓冲和剩余现金净年化3%核算。15%只保留为未由经纪商独立验证的操作可行性口径。
- IC 不在本实验范围内；不得加入 Call。

## 3. 波动率信号

- 每个 T 日使用当日收盘前可见的真实 CFFEX MO Put 链，按冻结规则确定目标到期月，并选择最接近 `行权价/活跃IM收盘=95%` 且收盘价、成交量、持仓量均有效的 Put。
- 用该 Put 的真实收盘价、中证1000价格指数收盘、实际到期日、冻结市场构造中的10年国债收益率和过去一年股息贡献，反解 Black-Scholes Put 隐含波动率。
- 信号必须来自 T 日，仓位与 Put 目标在下一共同交易日收盘执行。首个真实 MO 上市日若不存在前一日可计算信号，保持 v2 基线，不用同日数据回填。
- 无法得到有效报价或隐含波动率时必须失败关闭，不得用未来值或事后插值替代。

## 4. 候选规则

若 v2 原始 Put 目标大于0且 `IV_T > threshold`：

1. T+1 收盘 Put 目标设为0；已有 Put 按正式执行函数退出。
2. T+1 收盘固定核心 IM 目标权重设为：

   `core_scale = max(min_core_scale, threshold / IV_T)`

否则 Put 目标和固定核心 IM 权重均保持 v2（`core_scale=1`）。核心降仓在 T+1 收盘执行，执行日当日收益仍按执行前权重计算，次日起使用新权重。

扫描网格：

- `threshold`: `25% / 30% / 35% / 40%`
- `min_core_scale`: `25% / 50% / 75%`
- 同批包含冻结 v2 基线。

不加入滞后带、波动率平滑、连续若干日确认或二次止损；这些若需要必须新版本预注册。

## 5. 成本与可执行时点

- 原 Put、Call、期货滚动和网格成本沿用冻结路径。
- 固定核心 IM 权重每次变化增加 `1bp × |权重变化|` 的单边期货成本。
- 当 Call 在变化前后任一日存在时，再增加 `1bp × |权重变化|` 的 Call 篮子缩放成本。
- 不计买卖价差、收盘冲击、涨跌停无法成交、盘口容量、动态保证金上调和税费；这些是推广前阻断项。
- 分数权重是组合归一化研究口径；真实整数 IM/MO 合约的最小账户规模和取整误差不在本次收益曲线内，必须单列为限制。

## 6. 验证与报告

- 用正式加载器和正式 `run_real_normal_close` 重新运行冻结 v2 Put 目标，并要求 Put 日路径与冻结 v2 最大绝对误差不超过 `1e-12`。
- 所有候选使用同一真实数据区间，报告 Full、10Y、5Y、3Y、1Y；历史不足时保留机器可审计的可用样本计算，但用户报告必须标记 N/A 及原因。
- 最低指标：CAGR、年化波动、repo Sharpe、MaxDD、平均核心权重、降仓天数、Put成本、期货/Call额外换手成本、现金权重与资金占用。
- 检查 T/T+1 因果、IV缺失、未来数据、Put目标一致性、Call覆盖缩放、收益恒等式和日收益不低于-100%。

## 7. 预先决策门槛

本轮真实 MO 历史不足5年，因此无论结果如何都不得直接修改冻结主线或解释为实盘授权。

候选只有同时满足以下条件才进入后续 `watchlist`：

1. 至少两个相邻阈值/最低仓位组合形成平台，而非单点最优。
2. Full CAGR 不低于基线超过1个百分点，Full Sharpe不低于基线。
3. Full MaxDD至少改善1个百分点；近3年和近1年 MaxDD 均不得恶化超过1个百分点。
4. Put累计交易成本至少减少25%，且无资金占用或完整性违规。

若不满足则 `keep_default`；若数据、IV或基线一致性失败则 `rerun_required`。即使进入 `watchlist`，仍需更长真实历史、不同波动率定义、阈值宽度证据与整数合约可执行性测试后，才能讨论新版本主线。
