# 中证1000有限窗口与分位阶梯扩展扫描 v7 预注册规格

冻结日期：2026-08-19  
研究状态：估值本体参数平台研究；未批准实盘

## 1. 研究问题

v6证明有限滚动窗口能恢复当前分辨率，但只比较48/60/72个月和两组分位，不足以识别连续平台。用户进一步确认本层应保留的经济语义：

1. 2022—2024年处于熊市，估值整体低是合理的，不应强制保护档位非0；
2. 2025年是估值修复期，连续分位应比2022—2024年抬升，但不应长时间落在极端高估档；
3. 2026年出现一定高估，应进入非0档，但不以“当前档位越高越好”为目标。

本版扩展滚动窗口和分位阶梯，但只能从满足上述年代语义的**二维连续平台**中选中心。不读取IM、MO、Put、贴水或策略后续收益选参。

## 2. 冻结数据与基础定义

- 数据只使用v3冻结的中证1000估值状态：2015-10-19至2026-08-17，2,634个日度观测和131个月度观测。
- 基础分数为`unbounded_median_knot`：PB、ERP、过去一年已实现股息贡献三项固定经济压力的二取三中位数。
- 绝对轴不变：`2.45/2.50/2.60 -> 1/2/3档`。
- 对自然月`M`，相对轴只使用日期严格早于`M`首日的月末分数，取最近N个观测；不满N个月则不启用。
- 分位门槛使用NumPy `method="linear"`，当月锁定；边界`>=`进入更高档。
- 双轴档位为`max(absolute_tier, relative_tier)`。

## 3. 冻结参数网格

### 3.1 窗口

`36—84个月，步长3个月`，共17个窗口：

`36, 39, 42, 45, 48, 51, 54, 57, 60, 63, 66, 69, 72, 75, 78, 81, 84`。

36—42个月为可能过度自适应的短窗诊断，78—84个月为可能残留旧中枢的长窗诊断；两端均不事前排除。

### 3.2 分位阶梯

固定四组等距阶梯，从宽松到严格：

- `q700_800_900`：70% / 80% / 90%；
- `q725_825_925`：72.5% / 82.5% / 92.5%；
- `q750_850_950`：75% / 85% / 95%；
- `q775_875_975`：77.5% / 87.5% / 97.5%。

共68个双轴执行候选，并输出68个相对轴诊断候选和`absolute_v3`基线，总计137个状态序列。

## 4. 连续滚动分位

为避免只用0/1/2/3档选窗口，对每个窗口另计算当日基础分数在上月及以前N个月末样本中的弱ECDF分位：

`rolling_percentile = count(window_score <= current_score) / N`。

连续分位只用于窗口的年代语义检验，不改变线性插值分档门槛。

## 5. 窗口年代语义门槛

每个窗口必须同时满足：

1. 2022—2024年已校准日占比不低于75%，2025和2026年已校准日占比均为100%；
2. 2022—2024年连续分位中位数不高于55%，90%分位不高于80%；
3. 2025年中位分位比2022—2024年中位数至少高10个百分点，且不高于75%；
4. 2026年中位分位不低于70%，并比2025年中位数至少高10个百分点；
5. 2026-08-17当前分位在70%—95%之间，排除仍未识别高估的长窗和把当前定义为极端尾部的过短窗。

窗口语义通过不等于分档参数通过。

## 6. 双轴分档候选门槛

一个`dual_wN_ladder`候选必须同时满足：

1. 对应N月窗口已通过第5节年代语义；
2. 2022—2024年非0档日不高于10%，累计2档不高于5%，3档不高于2%；
3. 2025年日度平均档位不高于1.00，非0档不高于50%，3档不高于10%；
4. 2026年非0档不低于50%，3档不高于30%，至少有1个非0月末事件；
5. 2026-08-17当前最终档位只能是1或2，不允许0档或3档；
6. 2022至今日度年化切换不超过24次；
7. 三个月度门槛的环比绝对变化中位数均不超过0.05，95%分位均不超过0.25，最大值均不超过0.75。

这些门槛只衡量年代语义、分档稳定和当前不极端，不包含任何策略绩效。

## 7. 二维连续平台与选择

### 7.1 平台定义

将通过第6节的双轴候选放在`17个窗口 × 4个阶梯`网格上，使用上下左右四邻接定义连通分量。可晋升平台必须：

- 至少包含6个通过单元格；
- 至少横跨3个不同窗口；
- 至少横跨2个相邻分位阶梯；
- 不得只由最短36月或最长84月边界单线构成。

如果有多个合格平台，按以下事前顺序选择：

1. 单元格数最多；
2. 覆盖窗口数最多；
3. 覆盖分位阶梯数最多；
4. 包含v6中心`60月 + 75/85/95`者优先；
5. 仍并列时，选更长窗和更严格阶梯的平台。

### 7.2 平台中心

在选中的连通平台内，先选四邻接通过邻居数最多的单元格；再按与平台窗口中位数、阶梯中位序号的曼哈顿距离最小选择。仍并列时：

1. 与`60月 + 75/85/95`距离更近者优先；
2. 再并列，选更长窗；
3. 再并列，选更严格阶梯。

选中中心必须在同阶梯下同时有左右相邻窗口通过，且在同窗口下至少有一个相邻阶梯通过；否则该平台只能进入观察。

## 8. 决策

- 存在合格二维平台且中心局部支持通过：`freeze_window_ladder_platform_center_for_next_put_layer / wide_stable`；
- 有至少3个通过单元格，但无合格平台或中心支持失败：`watchlist_window_ladder_ridge / peak_only`；
- 通过单元格少于3个：`no_window_ladder_candidate / reject`。

即使冻结中心，也只是下一层MO Put回测的估值输入，不是实盘保护指令。本次年代语义包含用户对2022—2026年的事后盘面判断，因此是语义校准，不是独立样本外验证。

## 9. 强制产物和审计

除参数网格、连通平台和当前状态外，必须输出：

- 所有137个状态序列的全样本、近10年、5年、3年、1年档位指标；
- 中证1000价格指数同窗年化收益和MaxDD背景，不参与选择；
- 每个窗口的2022—2024/2025/2026连续分位诊断；
- 所有通过/失败单元格的分项门槛、平台ID、邻居数、当前档位和选择排名；
- 选中中心与左/右窗口、宽/严阶梯确认线的逐日一致率、Kappa和Jaccard；
- 月度门槛的最大输入日期严格早于有效月，完整N个样本，相邻月只滚入/滚出各1个；
- 历史截断重算误差0、v3绝对档位奇偶误差0、双轴`max`恒等式误差0。

本版不含交易、费用、滑点、保证金、现金收益、Put或流动性假设。
