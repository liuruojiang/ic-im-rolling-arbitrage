# IM高IV卖Put与核心Put三倍兑现联合复测 v1

预注册日期：2026-09-16。研究专用，不修改1.3正式规则、生产代码、账本或信号。

## 固定口径

- 使用已纠正的月度IMC、2015早期估值恢复、当前估值/MOM120防抖核心Put准入。
- 高IV路由固定为：估值0/1档、MOM120非负、目标MO Put自身IV严格大于35%，卖M+1的95% Put。
- 卖Put权利金衰减60%后，下一交易日开盘最多提前滚动一次至紧接下月，并重新检查准入。
- 路由执行日开盘同步退出IM和核心Put；卖Put、现金、交割恢复阶段暂停Call，恢复IMC后重新走原Call准入。
- 核心Put三倍兑现固定为：T日收盘达到实际入场权利金3倍，T+1收盘兑现并按当日102%、约3个月重新建仓；月度维护优先。
- 若高IV路由与三倍兑现发生冲突，高IV路由优先：核心Put在T+1开盘退出，不得在同日收盘重复兑现或重建。
- MO Put买卖成本单边5BP（往返约1‰）；期货与原Call沿用各自现有成本。每1倍期货保留30%缓冲，现金年化3%。
- 真实挂牌历史与理论延展严格分层；理论层不解释为可成交历史。

## 四组候选

1. `baseline`：现行IMC＋核心Put＋Call，不启用两项增强。
2. `short95_only`：只启用高IV卖Put路由。
3. `profit3x_only`：只启用核心Put三倍兑现。
4. `joint`：两项同时启用，按上述冲突优先级运行同一逐日状态机。

## 判定

联合版只有在以下条件全部满足时才保留为下一阶段研究候选：

1. 真实期与理论延展期全样本年化均不低于两个单项候选中的较高者；
2. 两层最大回撤均不得比两个单项中的较差者再恶化超过1个百分点；
3. 高IV路由日核心Put同步退出，不存在同日重复兑现/重复建仓；
4. 保存路由周期、三倍兑现次数、冲突次数、成本及逐日结果。

即使通过，也只表示固定核心模块的联合候选通过，不自动修改完整1.3组合或生产规则。
