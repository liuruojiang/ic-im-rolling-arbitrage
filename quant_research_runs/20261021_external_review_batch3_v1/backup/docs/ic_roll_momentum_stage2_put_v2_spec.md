# IC第二层v2：动量袖Put去MOM120下限

日期：2026-08-23  
状态：预注册规则消融研究；未批准实盘

## 研究问题

固定`50%裸滚IC + 50%动量门控IC`，检验动量袖Put中的`MOM120 < 0`最低50% Delta是否与动量门控重复。裸滚袖继续使用完整IC V2 Put；只有动量袖删除MOM120下限，改为纯估值Put。

## 固定底仓

- 裸滚袖始终持有0.5倍IC。
- 动量袖资本占50%，中证500信号固定`MA110 / Mom24 / W2`，50% Abs20 OFF + 50%静态`Abs20 > 0`；实际IC名义为0/0.25/0.5倍。
- 期货、换月、1bp单边成本、30%保证金缓冲和3%现金收益完全继承第一层与第二层v1。

## Put目标

- `d_full`：完整IC V2。估值分数1.90/1.95/2.00/2.05对应25%/50%/75%/100% Delta；`MOM120 < 0`时最低50%；上限100%。
- `d_valuation`：只按估值四档决定，不使用MOM120下限。
- 裸滚袖目标：`0.5 × d_full`。
- 动量袖目标：`0.5 × momentum_weight × d_valuation`。
- 新组合目标：两袖相加；必须进入原理论/真实Put执行引擎重新交易并计费，禁止事后缩放收益。

## 比较路径

1. `roll50_momentum50_no_put`。
2. `put_bare50_only`：仅裸滚袖完整V2 Put。
3. `put_both_sleeves`：第二层v1旧路径，两袖均完整V2 Put。
4. `put_momentum_valuation_only`：本轮新路径。

Call与网格关闭；期限、95%目标行权价、T日信号/T+1共同交易日收盘执行、换月和费用不变。
