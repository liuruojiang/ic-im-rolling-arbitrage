# IM 固定估值网格 2015 模型代理平均贴水扫描 v21 预注册规格

冻结日期：2026-08-23（Asia/Shanghai）  
状态：预注册平均贴水情景研究；未批准实盘。

## 1. 研究问题

在 v20 的 2015 模型代理网格扫描上，加入现有审计口径测得的 IM 平均毛贴水，重新比较不加网格、当前 `0.85/1.25` 与入场 `1.35—2.10`（步长 `0.05`、退出=入场+`0.40`）的回报、回撤和资金约束。

本版是独立 v21 情景，不覆盖 v20、V1/V2 冻结规范、首次正式输出或实盘接口。

## 2. 平均贴水口径

- 取自 `outputs/im_roll50_momentum50_fullcycle_proxy_v1/data_manifest.json`：2022-07-22—2026-08-21 共991个交易日，IM毛收益相对中证1000价格指数收益的几何平均基差。
- 固定日度毛基差为 `0.00038985993765572324`，几何年化为 `10.321159572014937%`。
- v21 为直接回答“按平均贴水率计算”的敏感性情景，在 2015-04-16—2026-08-14 每个模型交易日统一使用该固定日度基差；因此不仅上市前含未来信息回填，上市后也用固定均值代替真实波动基差。
- 固定1倍模型IM底仓的日收益按 `(1+模型方向收益)*(1+固定日度基差)-1` 计算。
- 网格增量仓也获得同一贴水：基差按 `overlay_held_before` 计入。买入日从开盘建仓，不计前一收盘至当日开盘基差；卖出日持有至开盘，计入该闭合持有区间的一次日度平均基差。这样每个完整开平周期的基差日数与持仓的收盘到收盘区间数一致。
- Put、Call损益和覆盖数量不因贴水放大。

## 3. 模型、执行和成本

- 复用 v20 正式模型来源 `outputs/im_put_grid_call_final_audit_v1/daily_candidates.csv.gz` 的 `core_put_call_d10_threat5` 组件和 v15 网格状态机。
- 样本为2015-04-16—2026-08-14；2015—2022不是可执行IM/MO历史，Put上限仍为V1的3张，不是当前V2的4张。
- T日收盘信号、T+1模型指数开盘成交；网格开平每边1bp，持仓换月双边2bp。
- 每1倍IM按30%保证金/缓冲；剩余现金扣除Put市值与Call保证金后按净年化3%计息。
- 不计盘口价差、冲击、容量、涨跌停无法成交、动态保证金上调和税费。

## 4. 比较与输出

- 同批候选：`no_grid`、`current_L0.85_H1.25`、16个高入场阈值候选。
- 每个候选输出 full、10Y、5Y、3Y、1Y 的 CAGR、年化波动、Sharpe、MaxDD。
- 同时报告相对 v21 `no_grid` 以及相同候选 v20“不计贴水”路径的差值。
- 输出网格周期、持有比例、贴水贡献、成本、30%口径日终与开仓早盘资金穿透。

## 5. 强制完整性检查

1. v21 的网格状态、方向收益、成本和期权组件必须逐日复现 v20，相应最大误差不超过 `1e-12`；唯一新增收益来源是冻结平均贴水。
2. 底仓贴水复算、网格贴水复算、总收益乘法成本、现金利息与净值复算误差不超过 `1e-12`。
3. 18个候选、每候选2,756行、日期唯一；信号严格早于执行日。
4. 总IM单位只允许1或2；资金穿透按原口径保留，不得通过删日或改变资金口径消除。
5. 参数扫描工件必须完成 `complete --strict` 审计。

## 6. 结论边界

固定10.32%年化毛贴水抹平了真实基差波动，并把上市后均值回填到2015年，含明显前视信息。本版只能回答平均贴水情景敏感性，不得用于晋升参数、修改当前V2或解释为下单建议。
