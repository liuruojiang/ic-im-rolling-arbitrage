# IM 新动态估值三档 MO Put v10 预注册规格

冻结日期：2026-08-19  
研究状态：Put 第一层；仅研究，未批准实盘

## 1. 研究问题

`im_valuation_window_ladder_scan_v7`已在不读取IM、MO、Put和后续收益的前提下，冻结中证1000估值中心为`57个月滚动窗口 + 75%/85%/95%分位阶梯`。本版只检验该估值档位直接映射为MO Put数量后，是否能在同执行口径下改善滚IM的回撤，并量化2026年日度跨档造成的真实调仓、成本和反复调整损失。

本版不加入MOM120、网格、卖Call、滞后、缓冲带或持有期规则。旧`固定1.75 OR MOM120`只作为历史纸面首选参照，不参与新估值候选选择。

## 2. 冻结估值输入

- 主候选：`dual_w57_q750_850_950`。
- 相对轴：只用上月及以前最近57个月末的基础分数，按75%/85%/95%线性分位得到0/1/2/3档；门槛每月锁定。
- 绝对轴：v3固定`2.45/2.50/2.60 -> 1/2/3档`。
- 最终档位：`max(absolute_tier, relative_tier)`。
- 日度估值状态来自v7冻结正式产物，不重算、不改变阈值。
- 估值档位在T日收盘确认，下一共同交易日收盘调整Put。

## 3. Put工具与仓位映射

- 固定使用`3个月目标到期 + 95%目标行权价 + 月滚退出`结构，沿用v9的真实合约选择、理论定价和生命周期逻辑。
- 信号持续时，Put随目标月份变化月度换仓；档位下降时立即减仓，档位归0时立即退出，不持有到期。
- 每1份IM对应：0档0张、1档1张、2档2张、3档3张MO Put。
- 由于IM乘数200元/点、MO乘数100元/点，1/2/3张MO分别是IM的50%/100%/150%期权名义；实际Delta保护随虚值程度、期限和波动率变化，不把它机械表述为固定25%/50%/75%。

## 4. 冻结候选

### 4.1 执行候选

1. `no_put`：滚IM，无Put；
2. `v7_dual_w57_q750_850_950`：正式中心；
3. `v7_dual_w54_q750_850_950`：同阶梯短窗确认；
4. `v7_dual_w60_q750_850_950`：同阶梯长窗确认；
5. `v7_dual_w57_q725_825_925`：同窗口宽阶梯确认；
6. `v7_dual_w57_q775_875_975`：同窗口严阶梯确认；
7. `v7_relative_w57_q750_850_950`：相对轴单独分解诊断；
8. `v7_absolute_v3`：绝对轴单独分解诊断；
9. `legacy_fixed175_or_mom120`：旧纸面首选历史参照。

除`no_put`外，全部使用相同的三个月95%月换Put工具。正式宽度只看主候选及四条v7确认线；两个分解项和旧规则不参与宽度判定。

### 4.2 成本敏感性

- 正式成本沿用v9：IM基线含既有展期/交易成本；每张MO每边成本为IM完整名义的0.5bp；30%保证金/缓冲，70%现金净年化3%，Put市值从可计息现金扣除。
- 在同一逐日路径上另报Put交易成本2倍和5倍敏感性，但不据压力成本反向优化参数。
- 无买卖价、收盘VWAP和盘口深度数据；真实合约必须当日close、volume和open interest均为正。收盘价不等于容量证明。

## 5. 数据层与证据边界

### 5.1 模型层

- 2015-04-16至2026-08-14，沿用v9冻结的中证1000全收益基线和理论Put市场。
- v7估值状态始于2015-10-19；此前新估值候选为0张Put，不回填未知状态。
- 模型层不是历史IM/MO，不含上市前真实贴水，仅用于长周期方向和参数宽度诊断。

### 5.2 真实层

- 2022-07-22至2026-08-14，使用冻结中金所IM/MO日行情。
- IM基线、活动合约、结算盯市、MO收盘成交与结算盯市全部沿用v9。
- 真实层10年和5年因上市历史不足必须显示N/A。

## 6. 预注册判定

主候选相对同层`no_put`必须满足：

1. 模型层全样本MaxDD改善，且五个强制窗口中至少三个改善；
2. 真实层全样本MaxDD改善，且全样本/3年/1年三个可用窗口中至少两个改善；
3. 全/10年/5年年化损失不超过1个百分点，3年/1年不超过3个百分点；若全样本MaxDD改善至少8个百分点，可按公共流程接受更宽收益损失，但必须逐窗列示；
4. 四条确认线中，至少一条同阶梯窗口邻线和一条同窗口分位邻线，在模型与真实层呈现相同的全样本回撤改善方向，且不出现明显孤点反转；
5. 真实层必须有非零Put持仓和至少两段独立保护事件，否则标记`not_testable/data_sensitive`；
6. 必须报告2026年状态切换、实际交易事件、买卖腿、加仓/减仓/换月次数。若实际调整年化超过24次，或2倍成本即逆转候选相对收益结论，不得晋升，最多标记`cost_sensitive`观察。

只有同时通过上述规则，才可`carry_to_momentum_layer`；否则为`valuation_only_not_sufficient`或`not_testable`。无论结果如何，本版均不得接入实盘。

## 7. 强制产物与完整性

- 全样本、10年、5年、3年、1年的年化收益、MaxDD及相对no-Put差值；
- 逐年收益与MaxDD；
- 日度收益、Put持仓、Put市值占用、Put损益和成本；
- 所有真实交易腿、成交合约、收盘价、成交量、持仓量及价格奇偶审计；
- 候选暴露、保护事件、档位切换、调仓类型和2026年换手审计；
- 1倍/2倍/5倍Put成本敏感性；
- v9 no-Put逐日奇偶误差不超过`1e-14`；旧规则与v9同名候选逐日奇偶误差不超过`1e-14`；
- T日估值不得在T日收盘成交，执行日必须严格晚于估值日；目标数量必须等于最近已执行估值档位；
- 正式目录首次写入，不得覆盖。

## 8. 正式产物

- 入口：`im_mo_adaptive_valuation_tier_put_v10.py`
- 测试：`test_im_mo_adaptive_valuation_tier_put_v10.py`
- 首次正式输出：`outputs/im_mo_adaptive_valuation_tier_put_v10/`
- 参数工件：由`quant-param-scan`在正式运行前初始化的新目录。
