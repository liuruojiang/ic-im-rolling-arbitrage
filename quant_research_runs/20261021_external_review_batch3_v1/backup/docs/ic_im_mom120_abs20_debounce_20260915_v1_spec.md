生效信号日：2026-09-16（Asia/Shanghai）。状态：用户批准的研究信号规则更新；不构成账户下单授权。

## 范围

- IC、IM核心 Put：MOM120 小于 0 时立即启用原有动量保护下限；一旦启用，只有连续两个交易日的 MOM120 都严格大于 +1% 才解除。估值档仍与该下限取较高值。
- IC、IM动量袖：Score 规则、成交量过滤、极热门过滤及 IC 的 6% NAV 防御均保持不变。Abs20 小于等于 0 时立即从满仓信号降至半仓；只有连续两个交易日的 Abs20 都严格大于 +1% 才恢复满仓。
- IC 不新增 Call；IM 的网格、Call、Put 行权价、月度维护及动量 Put 数量规则不变。

## 日期与状态

- 2026-09-15 及之前的账本与已发送日报按旧规则保留，不回写、不重算。
- 生效日后按连续交易日序列计算；阈值相等（+1%）不算满足恢复条件。
- 防抖仅延迟风险恢复，不延迟 MOM120 或 Abs20 转负时的降风险。

## 证据边界

研究扫描表明 Abs20 两日 +1% 候选显著减少严格少于三日的短段；IC/IM MOM120候选保留真实与模型样本限制。该发布是用户批准的前瞻研究规则，不把历史代理或期权回放解释为实盘收益保证。
