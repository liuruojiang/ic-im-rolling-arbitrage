# IM + MO 每日D10 5%救援Call研究主线 v1

记录日期：2026-08-19（Asia/Shanghai）  
状态：用户确认的研究主线；未批准实盘。

## 冻结决定

用户在完整审阅v27后明确接受5%救援真实全样本相对无救援线约1.1285个百分点的CAGR损失，并选择其降低Call尾部Delta、保证金峰值和组合回撤的特征。该决定属于风险—收益偏好覆盖，不改写v27的机械门槛失败。

后续IM卖Call研究主线固定为：

- 只覆盖固定1倍滚IM底仓，每1张IM卖2张MO Call；不覆盖新增网格仓；
- 空仓时每日收盘按当前IM月度周期的前月选择最接近0.10 Delta的虚值Call，合约自身IV不低于26%才在T+1官方收盘开仓；
- 月度节点只刷新当前期限，不把策略降为月评；
- 已有Call每日检查`旧行权价/中证1000价格指数收盘-1`，不高于5%即在T+1官方收盘买回旧Call，并卖出严格更晚的最近挂牌到期日、行权价至少提高5%的Call；
- 救援豁免IV26，连续最多5次；第6次或无更晚有效合约时买回并暂停，至下一IM月度评估节点重新允许每日开仓；
- 不含PE估值门控、文章期限—虚值率阶梯、TP80、分批止盈、急跌向内移仓或风险度扩仓。

## 证据与边界

v27真实样本2022-07-22—2026-08-14：无救援/救援全样本为18.39%/-16.33%与17.27%/-14.98%；最大Call Delta从86.94%降至69.11%，最大Call保证金从25.96%降至25.05%，成功救援11次。模型层成功救援39次，最大Call Delta从99.99%降至70.40%。
