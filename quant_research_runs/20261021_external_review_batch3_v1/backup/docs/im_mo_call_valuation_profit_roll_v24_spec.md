# IM + MO Call PE估值滞回 × 盈利80%提前展期 v24 预注册规格

冻结日期：2026-08-19（Asia/Shanghai）  
状态：官方MO短样本机制验证；未批准实盘。

## 1. 研究问题与边界

在v23每日检查、文章期限—虚值率阶梯和PE20%/60%滞回已经冻结的基础上，只增加一个机制：已卖Call的T日官方收盘价不高于本轮实际卖出成交收盘价的20%时，若当前估值状态下存在到期日晚于旧Call、同时满足原选约规则且自身IV不低于26%的合约，则冻结旧仓买回与远月新仓卖出，于T+1官方收盘整体移仓。

本版回答两个独立问题：

1. 没有估值滞回时，文章期限阶梯加TP80是否优于同路径不提前展期；
2. 有PE20/60滞回时，文章期限阶梯加TP80是否优于v23正式PE线。

本版不加入40%/60%分批止盈、受威胁向上向后移仓、急跌向内移仓、85%/95%风险度扩缩仓、MOM、网格或发布前PE回溯诊断。任何结果只能归因于盈利80%提前展期及其与正式PE状态的交互。

## 2. 基准与候选

- 底仓：冻结的1倍滚IM + `reconstructed_valmom_floor3`三个月95% Put；
- 参照：v20无Call、v20月评D10+IV26、v22每日D10+IV26；
- v23同路径控制A0：`article_ladder_iv26_daily`，无估值、无TP80；
- v23正式估值B0：`article_pe20_60_hysteresis_iv26_daily`，PE20/60、无TP80；
- 新候选A1：`article_ladder_iv26_daily_tp80`，无估值、加TP80；
- 新候选B1：`article_pe20_60_hysteresis_iv26_daily_tp80`，PE20/60、加TP80。

正式增量判断以B1对B0为主；A1对A0用于识别TP80本身是否有效；`(B1-B0)-(A1-A0)`只作交互归因，不用于反选。每1张IM固定卖2张MO Call，只覆盖固定底仓，不按可用资金扩张数量。

模型层为2015-04-16—2026-08-14连续期权近似；真实层为2022-07-22—2026-08-14官方IM/MO收盘与结算。正式结论只看官方真实层，模型只作长期方向诊断。

## 3. 完整继承的v23规则

- PE使用中证1000官方`official_rolling_pe`，估值历史不早于指数发布日期2014-10-17；
- T日使用截至T日最长十年、早期扩展历史的弱经验分位；
- 分位`<=20%`进入低估修复态，直到`>=60%`才退出；
- 低估修复态只允许DTE 30—60、最低虚值25%；
- 普通态依次寻找30—60/15%、61—90/20%、91—120/25%；
- 空仓每日收盘检查，所选合约自身IV须`>=26%`；
- 月度事件日只有当现有Call到期日不晚于该事件`current_expiry`时才正常重选，否则保持远月仓位；
- T日冻结具体合约，T+1官方收盘成交；不可交易时顺延冻结动作，不用未来信息重选；
- 层内排序、成交量/持仓量要求、模型连续行权价、成本、保证金和现金收益均与v23相同。

## 4. TP80提前展期

每天收盘在没有月度换仓、没有待执行动作且已有Call时计算：

`remaining_price_ratio = T日旧Call官方收盘价 / 本轮旧Call实际卖出成交收盘价`。

当比例`<=0.20`时：

1. 只保留实际到期日晚于旧Call到期日的合约；
2. 按T日当前估值状态使用完整v23层级：低估修复态只有30—60天/25%，普通态为30—60天/15%、61—90天/20%、91—120天/25%；
3. 从第一层存在合格合约的层中，按虚值超额最小、DTE距中点最小、持仓量和成交量由高到低、到期日、行权价、合约代码排序；
4. 只有新合约T日自身IV`>=26%`才冻结移仓；否则持有旧Call并在下一交易日重新检查；
5. T+1按同一冻结合约买回旧仓、卖出新仓；新仓成交后以实际卖出收盘价重置TP80基准。

不要求新到期月恰好比旧仓远一个自然月，也不允许选择到期日相同但行权价更高的合约。TP80不限制单周期次数；实际次数和连续展期必须完整报告。若月度事件与TP80同日，月度事件优先；若月度事件只产生`monthly_keep_far`，当日不再重复发TP80信号。

## 5. 成本与资本

- 2张MO Call篮子每边成本1bp；TP80买回旧仓并卖出新仓合计2bp；
- Call保证金、Put市值、70%可用现金上限和余额净年化3%收益继承v23；
- 任一日Put市值加Call保证金超过70%记为资本穿透；
- 不模拟买卖价差、冲击成本、涨跌停或盘中成交，官方真实层仍是收盘可成交近似。

## 6. 必报结果与审计

1. 模型full/10Y/5Y/3Y/1Y与真实full/10Y/5Y/3Y/1Y；不足窗口显示N/A；
2. A0/A1、B0/B1逐窗口CAGR、MaxDD、收益差和MaxDD改善；
3. 真实逐年、2022部分年度、2024-09-18—10-08、2025和2026YTD；
4. 两条TP80候选的信号数、无合格远月数、IV不足数、实际展期数、触发比例、旧/新到期日、行权价、IV、Delta和成交价；
5. 是否出现连续多次提前展期、是否提前锁定低行权价、相对无TP线的持仓天数、Call损益、成本和保证金变化；
6. v23五条正式参照逐日奇偶、收益/现金恒等式、T/T+1因果、冻结合约、剩余价格比例、远月严格递增、当前估值状态层级、IV26、官方收盘和资本穿透审计。

## 7. 预注册判定

B1相对B0的正式通过条件：

- 真实full和3Y CAGR均不低于B0，1Y落后不超过0.5个百分点；
- 真实full MaxDD不比B0加深超过2个百分点；
- 2024-09-18—10-08收益不比B0低超过1个百分点；
- 实际真实TP80展期至少2次；
- 资本穿透和最终未执行计划为0，全部审计通过。

A1对A0使用相同门槛独立判定，但不影响B1正式结论。

- B1通过：`valuation_tp80_supported_real_short_sample`；
- B1不通过而A1通过：`tp80_without_valuation_only`；
- 两条都不通过：`tp80_not_supported`；
- 只有组合B1相对无Call或D10较好、但B1对B0不通过：`combined_level_not_incremental`。

任一结果最高只能进入官方MO短样本观察池，不获准实盘。不得因结果改变20%、26%、PE20/60或期限—虚值率规则。
