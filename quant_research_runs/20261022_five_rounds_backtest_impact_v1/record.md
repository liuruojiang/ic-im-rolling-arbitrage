# 五轮补丁对历史回测的影响审计

日期：2026-10-22。结论：**已冻结的历史结果没有被改写，原独立研究引擎重跑结果一致；但调用现行生产选约模块的完整账户历史重跑会被日历门槛拦住。因此，不能将五轮修补概括为“对所有历史回测均无影响”。**

本次只读审计，没有修生产代码、更新历史输入、续写正式账本或部署。已读主线登记表、系统冻结规范及首次输出记录。核对链覆盖专家修复、第三轮复查及来源验证、第四轮、第五轮，并向前使用 2026-10-21 首次外审前的完整备份定位归因；没有只检查第五轮的单文件差异。

绩效页的数据是截至 2026-08-14 的旧 v1.3/r6 冻结历史；IM 旧历史仍被标为已撤回有效绩效资格，本次仅通过显式历史审计开关读取。独立研究引擎是各自冻结的早期 v1.4 口径。上述零差异**不意味着这些旧曲线已代表当前 fix11 全部规则**。

实际阻断的调用链是：

`20261016_put_execution_repairs_v1/run_history.py → listed.load_account_inputs → build_fix9_ic_lifecycle → native_fix4_seller_lifecycle_v1.roll_candidate → formal._v14_ic_short_put_candidate → _require_official_exchange_calendar`。

现行运行在约 2.30 秒后抛出：

```text
CalendarCoverageError: new IC short Put expiry需要2024年官方交易日历，但脚本仅覆盖2026年
```

原失败及堆栈保存在 `execution_history_after/receipt.json`，没有将它改成通过。外审前对照运行耗时约 134.61 秒并完整复现旧结果；独立 IC、IM 引擎分别耗时约 24.39、141.59 秒。所有六个主工作进程及七个选约版本探针均离线运行，没有发出行情请求。

归因已定位到 `20261021_external_review_batch3_v1/source_delta.patch`：该补丁给最近月期货、IC 重置／持仓配量、独立 IM Put 及卖 Put 候选等路径添加严格年度核验。**该兼容性阻断在五轮专家修补的起点已经存在，不是第五轮新增。** 后续“模型日期可作诊断”的处理仅在显式诊断上下文中生效；旧研究脚本直接调用选约函数，不在该上下文中，因此仍然严格拒绝。第五轮唯一生产修改是原始 HTTP 回放歧义检查，不是收益计算修订。

静态与实际运行证据互相印证：根目录原独立 IC/IM 研究入口的本地依赖闭包分别有 73、71 个模块，没有本次改动的生产模块；实际重跑结果也一致。较新的完整账户研究则通过研究子目录动态导入生产模块，不能用根目录 import 搜索的无交集替它作保证。`build_v14_full_nav_to_20260918.py` 也直接引用生产模块，其历史取数及选约重跑需独立验证；本次未重跑其行情续接，不能对它宣称收益差为零。

外审前至现行源码的结构比较确认：嵌入收益及基准数据、`FROZEN`、动量参数／生效边界、BS／IV、估值分数、IC/IM 目标数学函数、动量和保护下限函数一致；季度换仓模块字节也相同。这不代表整套状态机行为一致。候选准入、未核验输入的处理、RETRY、网格完整性、持久化资格和回放证据要求确有变化，会影响缺证据场景能否形成正式信号或推进账本。

本次完整账户入口自身按旧规范显式固定一份历史 policy，审计没有将它替换成现行 policy。这次对照证明“旧入口加载现行生产适配器会中断”，不证明“现行全部状态机在完整历史上的收益变化为零”。旧脚本部分内部 `formal_producer_sha256` 按固定 ROOT 读取磁盘文件；本次实际加载版本以各 `receipt.json` 的 `loaded_bot_path`、`loaded_bot_sha256` 和 `loaded_local_sources` 为准，避免把旧模块加载过程误记成当前模块执行。

应单列一个历史重跑兼容性修复：为历史研究提供可追溯的 2022—2025 年交易日历及日期／身份适配，保留生产严格门槛和冻结输出，使用新版本目录重建目标及完整账户，再比较日期、合约、数量、成本和逐日 NAV。不能靠删除门槛、跳过失败日、把失败的 Put 数量置零或让旧曲线换上新版本标签来结案。只补 2027 年日历不能解决此次历史阻断。历史日历补齐后若维护或到期日期改变，收益也可能改变，必须再实测。

原研究的局限继续保留：理论账户并非真实成交；IC 合约成员为历史重建；Fear 为后下载快照；10-16 的 IM 普通买 Put 每臂仍有 4 笔既有 sticky-IV 开盘代理。零差异没有消除这些限制，也没有完成从当前正式 builder、全量真实证据到完整历史账本的端到端验收。

证据入口：`audit_plan.md`、`inventory.json`、`comparison.json`、`financial_source_bindings.json`、`protection_after.json`，以及各独立运行目录的 `receipt.json`。源码、原始输入和前后工件均有哈希绑定；当前完整账户重跑的收益差记为 `null`，原因是入口被阻断，不记为 0。
