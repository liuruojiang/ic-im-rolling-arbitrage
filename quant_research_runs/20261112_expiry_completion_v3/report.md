# 到期日来源接入与多智能体对抗审计

日期：2026-11-12。结论：本轮本地代码修订、完整回归及四路独立对抗审计完成，五项已确认问题均已修复关闭。外部资料仍有两项未取得，见末节；本结论不声称它们已经核验。

## 完成的接入

SSE 正常 510500 月链已实际调用完整主表接口，以证券 ID、交易合约、实际行权价及 `EXPIRE_DATE / EXERCISE_DATE / END_DATE` 三字段交叉核验模型到期日，交收日不充当到期日。仅一致陈旧主表可转原有独立新浪回退；混合日期、未来日期或已知冲突均明确拒绝。

新日采集与回放以 2026-11-12 为采用边界，新增原始 `ic.expiry` 证据，逐个月份和市场日匹配链与来源。SSE 保存真实主表 payload；新浪保存挂牌证券集合和完整详情报文，实际字段46决定到期日。读取、加载就绪及采集完整性不能只信链的 attrs、role 名或内容哈希。旧日原包保留原合同，不补抓当前数据。

新浪未消费的陈旧 A/M 行继续保留，实际消费某合约时仍按其原始时刻检查新鲜度。总体时刻必须等于原始 M 合约详情的最大时刻，A 行不能刷新 M 链；未来时刻仍拒绝。捕获会话出现同键不同证明时，即使外层捕获异常，也会留下未解决的正式失败，不能重新获得合格封存或持久化资格。

CFFEX 已增加独立算术实现，对第三个星期五及非交易日顺延规则作一致性复核。此项共享已采用的交易日输入，属于法律规则与日历的推导复核，**不等同于独立逐合约月度公告或主数据到期字段**。来源检索正文和直接访问失败分别保存，不把检索正文称为 HTTP 原响应字节。
