# IM 新动态估值 + MOM120最低保护 v12 运行后审计

日期：2026-08-19  
状态：第二层完成；存在强观察线，但没有候选通过预注册晋级门槛；未批准实盘

## 结论

- MOM120确实补上了v11估值单独保护遗漏的2022—2024低估熊市。真实IM/MO层中，`估值档位 + MOM120最低2张`把全样本MaxDD从`-34.88%`降至`-16.34%`，CAGR从`15.25%`提高到`16.69%`；最低3张为`16.99% / -16.35%`。
- 但正式决定仍为`no_mom120_floor_candidate/reject`。原因不是Put成本或真实样本表现差，而是所有候选都违反了事前冻结的“相对估值单独线，各窗口收益损失不得超过常规容忍”规则；3张组合线的模型全样本MaxDD改善`2.9882pp`，又比风险优先门槛`3.00pp`少`0.0118pp`。
- 不事后放松门槛，也不把任何线晋升为主线。经济上最值得保留的是`valmom_center_floor2`均衡观察线和`valmom_center_floor3`防御观察线；若要改变“以短窗收益门槛否定显著回撤改善”的效用偏好，必须在新版本中预注册，不能改写v12。

## 策略定义

- 估值沿用v7冻结中心：过去57个月、75%/85%/95%分位，最终档位取动态相对轴与固定绝对轴较高者，映射为0/1/2/3张MO Put。
- MOM120为中证1000全收益指数相对120个交易日前的绝对收益；`MOM120<=0`时，分别要求至少1/2/3张Put。
- 组合目标为`max(估值档位, MOM120最低张数)`，不是两者相加。
- 每1份IM对应1/2/3张MO约为0.5/1.0/1.5倍指数名义Put数量；实际保护还取决于Put Delta。
- Put固定为目标三个月、目标95%行权价、按月退出；不是持有到期。信号在T日收盘确认，下一共同交易日收盘成交。

## 为什么没有正式候选

1. 三条组合线相对no-Put都通过收益容忍，真实层也都显著改善回撤。
2. 事前规则还要求相对“估值单独中心”通过常规收益容忍。模型近1年中，组合最低1/2/3张分别落后`3.27/3.96/5.40pp`，均超过近1年最多落后`3pp`的门槛。因此三条组合线核心经济门槛全部失败。
3. 风险优先门槛要求模型/真实全样本MaxDD至少改善`3pp/8pp`。组合1/2/3张实际为模型`1.47/2.40/2.988pp`、真实`10.83/18.53/18.53pp`；3张只在模型门槛上差`0.0118pp`，仍按失败处理。
4. 四条估值窗口/分位邻线在每个floor都与中心同方向，参数宽度不是失败原因。2倍Put成本下各组合相对no-Put全样本年化仍为正，成本符号也不是失败原因。

## 收益—回撤交换

- 真实2024年，组合最低2/3张相对no-Put分别多`12.76/17.96pp`收益，年度MaxDD均改善`13.51pp`；说明MOM保护确实覆盖了熊市后段。
- 真实2025年，MOM120滞后退出使两条线相对no-Put分别少`13.19/19.40pp`收益，年度MaxDD并未改善。这是更高floor的主要代价：保护下跌，也可能在急速修复期继续消耗权利金。
- 真实2026截至8月14日，组合最低2/3张相对no-Put分别多`7.56/11.60pp`收益，MaxDD改善`9.55/11.28pp`；但这段同时受到新估值档位的额外保护，不能把全部优势归因于MOM。
- 5倍Put手续费压力下，组合最低2张真实全样本CAGR为`15.30%`，仍略高于no-Put的`15.25%`；最低3张降至`15.02%`。盘口价差、收盘冲击和容量仍未计入。

## 估值的增量与换手

- 相对同floor纯MOM，组合最低2张在模型全样本提高`0.93pp` CAGR并改善`1.28pp` MaxDD；真实提高`0.17pp` CAGR、MaxDD相同。最低3张在模型提高`1.37pp` CAGR并改善`2.79pp` MaxDD；真实提高`0.31pp` CAGR、MaxDD相同。
- 真实样本中，估值对组合目标产生110个覆盖日，主要集中于2026；它改善近期路径，但没有进一步改变真实全样本最深回撤。
- 组合最低2/3张真实最近一年非月换信号调整年化为`19.70/20.74`次，低于预注册24次上限；另有正常月换。全样本保护段均为26段。
