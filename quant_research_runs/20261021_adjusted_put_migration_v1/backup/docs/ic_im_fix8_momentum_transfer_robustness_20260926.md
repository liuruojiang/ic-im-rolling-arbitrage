# IC/IM fix8 动量参数、择时与核心配比联合稳健性测试

日期：2026-09-26。性质：**研究型历史反事实**，不改变正式策略、日报、账本或实盘授权。研究身份为 v1.4-r1 fix8，核心卖 Put 持续展期且按既定 0.5 核心名义额，IM 不卖 Call，买 Put 3 倍兑现；期货指定季度展期仍在指定日收盘。各路径使用同一历史窗口、行情、费用及选约规则。这里的“正式”指当前规则作为对照，不代表历史上确实逐日发布过这些净值。

## 结论先行

1. **目前没有证据支持把 IM 的动量 0.5 整体转给核心。** 完整历史账户中，IM 50/50 年化 29.34%、最大回撤 −12.71%；100/0 为 25.73%、−19.94%。贴水保留减半时分别为 25.42%/−13.22% 和 20.63%/−20.82%。预设的 Mom16 与 Mom16×关闭过热过滤压力也未让 100/0 的回撤优于 50/50。
2. **IC 是收益—回撤取舍，不是单向改进。** 从 50/50 提高核心到 100/0，年化 32.30%→34.52%，但最大回撤 −9.99%→−17.63%；贴水减半时 28.79%/−10.42%→29.43%/−18.58%。若特别重视回撤，IC 的核心加权在这段历史里不占优；若偏好更高历史年化，则要明确承担更深的回撤。
3. **动量规则有参数风险，但历史择时价值也真实存在于该模型中。** 与预先固定的 0.25 或 0.5 动量敞口相比，当前动态规则在 IC/IM 两个完整账户均有更好的收益—回撤组合。IM Mom16、MA45、关闭过热过滤分别使 50/50 年化和/或回撤变差；不过临近阈值 140/160、关闭量能过滤影响较小，不能据此称为全面失效。
4. **保持 fix8 的 50/50 正式权重，不自动晋级新配比。** 本次复用了以往参与选参的历史，不能称独立样本外证明。冻结后应前向观察参数相对表现、贴水水平及最大回撤的变化，再讨论是否降低动量占比。

## 范围、来源与可比性

IC：2022-09-19—2026-08-13，共 945 个交易日；IM：2022-07-22—2026-08-14，共 986 个交易日。5 年与 10 年窗口不足，明确为 N/A。A 股股指多头项目中证500/1000 的指数 `close` 与本项目相同日期的 `close` 最大差仅 `1.82e−12`，成交量差为 0；但同执行日的目标权重 IC 有 36/944 日、IM 有 37/985 日不同，且 A 股项目是指数收盘模型账户，本项目是期货/期权完整账户。因此只转移待测参数，**没有移植该项目的绩效结论**。

账户费用为期货名义额 0.01%、期权名义额 0.05%，闲置现金年息 3%；绩效研究每 1 倍期货按 30% 保证金/风险缓冲建模，不能当作经纪商实际保证金。卖 Put 15% 是另一个现金储备约束。价格与执行时钟沿用前次已对齐的 fix8 研究账户，普通买 Put 的 T+1 开盘中 IM 正式基准有 4 笔缺原始开盘期权报价而使用当日现货开盘和前收盘隐波估计的模型价格；这些并非实盘成交证明。

## 对抗性核查与重要发现

- 正式 50/50 研究路径与前次 fix8 固定卖方账户逐日 NAV、现金、费用及事件同一；IC 5,744 条事件、IM 6,707 条事件，日账户最大绝对误差 `7.45e−9` 元。共 78 条候选路径审计 **PASS**，从逐日净值独立复算年化与最大回撤；逐日权益=现金+期权+ETF价值、收益、累计费用、日历、现金不为负、无 Call 交易、100/0 无动量成交均通过。共核查 9,532 个期货成交价对应原始合约报价或已标注的前收盘替代；卖方固定名义额跨权重不漂移；IM 100/0 跨所选动量参数的净值逐日完全一致。
- IC 100/0 **不等于完全摆脱动量参数**：除卖 Put 准入外，IC 核心买 Put 和动量买 Put 共用总 Delta 选约及整数数量拆分，改变 Mom24→26 会让部分核心买 Put 目标数改变。正式卖方规则下 IC 100/0 年化 34.52%→34.16%，最大回撤同为 −17.63%；只锁定卖方生命周期的诊断为 34.41%/−17.63%，剩余差异正来自其他共享目标/账户传导。不能把该诊断称为纯粹的“只改期货动量”。
- 真实行情和挂牌合约不等于真实成交。本回放含模型价格、分数期货/期权数量、现金和保证金假设；未做券商成交/实际保证金核验，也未据此修改正式交易权重。历次研究使用过相同历史，最近三年/一年只是分段稳健性检查，不是独立样本外认证。

## 后续判定门槛

保持当前正式 50/50。若以后要降低动量，先冻结候选如 60/40 与正式 50/50 的前向影子路径，持续记录两腿信号、贴水、实际或可执行报价、风险暴露及滚动回撤；重新评估时同时报告净年化、最大回撤、近一年、卖 Put 路由和 IC 共用买 Put 的传导。没有前向证据，不以本轮历史小幅优势自动升级。
