# IM 网格独立买 Put：MOM120负值两张、其他按估值 v1

状态：预注册研究；不修改正式研究信号、账本或实际交易。

## 研究问题

网格额外 IM 仓位持有期间，增加独立 MO Put 是否改善组合风险收益。

## 网格 Put 规则

1. 仅在网格仓实际持有时配置；网格平仓则该独立 Put 同步退出。
2. T日收盘生成网格状态、MOM120与估值档位，T日IM收盘的102%确定目标行权价；T+1执行。
3. `MOM120 < 0` 时，网格 Put目标为2张；否则目标数量等于当日估值档位（0/1/2/3）。不相加。
4. 期限为约三个月、月度维护；网格 Put 为独立腿，不改变核心或动量 Put的数量规则。

## 首层比较

- 对照：既有核心和动量 Put、网格 IM保留，网格 Put为0；Call关闭。
- 候选：对照加上述独立网格 Put。
- 两条路径使用相同数据、期货/Put成本、30%期货缓冲、3%现金和日期索引；同时报告模型期与真实MO期。
- 真实MO额外加入 `T日选约/T日收盘价代理`：同一合约的T日官方收盘价计入T+1结算路径，用以衡量T+1开盘/收盘价格风险；该路径不是可成交假设，不能作为实盘执行结果。

## 边界

- 本层不把此前“2张核心/动量Put”研究结论自动晋级到本测试；核心与动量 Put保留已发布组合的数量逻辑，隔离网格 Put的边际影响。
