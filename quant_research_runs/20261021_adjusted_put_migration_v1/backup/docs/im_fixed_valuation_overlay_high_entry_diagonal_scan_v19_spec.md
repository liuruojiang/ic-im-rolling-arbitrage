# IM 固定估值网格高入场阈值对角扫描 v19 预注册规格

冻结日期：2026-08-23（Asia/Shanghai）  
状态：预注册研究；未批准实盘。

## 1. 研究问题

当前 IM V2 固定估值网格使用入场 `0.85`、退出 `1.25`。用户要求从入场阈值 `1.35` 起按 `0.05` 步长扫描，并与不加网格比较回报和回撤。

由于候选入场阈值已经高于当前退出阈值，本版预先固定保留当前迟滞宽度 `0.40`：每个候选的退出阈值等于入场阈值加 `0.40`。本版只做研究比较，不修改 `notes/mainline_registry.md`、V1/V2 冻结规范、首次正式输出或任何实盘接口。

## 2. 基准与候选

- 核心基准 `no_grid`：固定 1 倍滚 IM，保留当前 IM V2 的 0—4 张动态 MO Put 与原有 D10/IV26/5% 救援 Call，仅把新增网格仓设为 0。
- 当前主线参照 `current_L0.85_H1.25`：同一批重算当前网格，必须与 V2 正式逐日输出奇偶一致。
- 高阈值候选：入场 `1.35—2.10`，步长 `0.05`，共 16 点；退出始终为入场加 `0.40`，即 `1.75—2.50`。
- 网格状态只有 0/1 两档；持有时组合 IM 总名义为 2 倍；新增仓不增加 Put 或 Call 覆盖。

不得在看到结果后补点、删点、改变步长、改变迟滞宽度或反选退出阈值。

## 3. 当前 V2 实现锚点

- 当前主线权威：`notes/mainline_registry.md`、`docs/ic_im_system_mainlines_v2_spec.md`、`outputs/ic_im_system_mainlines_v2/`。
- 当前 V2 IM 重算入口：`freeze_ic_im_system_mainlines_v2.run_im`。
- 网格真实执行函数：`im_fixed_valuation_overlay_entry_exit_scan_v15.simulate_overlay`。
- 市场构造：复用 v15 的 `load_sources -> build_real_market`；不得复制或简化状态机、真实开盘、成交量、换月或成本逻辑。
- 当前网格 `0.85/1.25` 的新增仓收益、状态、交易成本和总 IM 单位必须与 V2 正式输出逐日核对。

## 4. 数据、执行与资金口径

- 只报告真实 IM/MO 可执行样本：2022-07-22—2026-08-14；不足 5 年和 10 年，因此 `last_5y`、`last_10y` 只能代表全部可得真实样本，不构成独立长窗口证据。
- 估值分数为 `unbounded_median_knot`；T 日收盘确认，T+1 活跃 IM 官方开盘执行。
- 新增仓开平每边 1bp；持有期间跟随底仓换月，新增仓换月双边 2bp。
- 每 1 倍 IM 按 30% 保证金/风险缓冲；剩余现金扣除当前 V2 Put 市值与 Call 保证金后按净年化 3%计息。
- Put 与 Call 的逐日损益、成本、持仓市值和 Call 保证金完整继承同日当前 V2 重算结果；不随网格仓放大。
- 官方开盘价和历史成交量用于可执行性审计，但不代表未来容量或成交冲击保证。

## 5. 输出指标与比较

每个候选同批输出：

- full、last_10y、last_5y、last_3y、last_1y 的年化收益、年化波动、Sharpe、最大回撤；
- 相对 `no_grid` 的年化收益差和最大回撤差；
- 入场次数、完成周期、入场年份数、持有天数、持有比例、期末状态；
- 新增仓交易与换月成本合计。

本版是描述性扫描，不预注册收益最大化的晋升门槛。任何候选最多进入观察名单；若收益改善集中于少数年份、最大回撤明显恶化或相邻点不连续，决定必须保留 `keep_current_research_mainline`。

## 6. 强制完整性检查

1. 当前 V2 IM 官方调用链重算成功，并与 `outputs/ic_im_system_mainlines_v2/daily_candidates.csv.gz` 的当前 IM V2 逐日现金收益一致，最大误差不超过 `1e-12`。
2. 同批 `0.85/1.25` 网格状态、网格收益、网格成本和总 IM 单位与当前 V2 正式输出逐日一致，最大误差不超过 `1e-12`。
3. `no_grid` 的网格持仓、网格收益和网格成本全部为 0，总 IM 单位恒为 1。
4. 每个候选日期唯一，信号日严格早于执行日，真实执行开盘和成交量均为正。
5. 每个候选总 IM 单位只允许 1 或 2；现金权重不得小于 0。
6. 收益乘法成本恒等式、现金利息恒等式和净值复算误差不超过 `1e-12`。
7. 16 个高阈值候选、当前网格参照和不加网格基准必须全部存在；首次正式输出不得覆盖。
