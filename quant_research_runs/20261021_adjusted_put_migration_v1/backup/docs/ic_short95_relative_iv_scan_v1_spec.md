# IC M+1卖95% Put相对IV入场扫描 v1（预注册）

## Research Question

在已确认的IC混合路由中，将卖Put的绝对`IV > 37.5%`首次入场条件替换为因果滚动IV分位，检验相对IV能否在不同波动率阶段提供更稳定的入场尺度。

## Frozen Strategy Rules

- M+1卖95% 510500 Put；权利金衰减60%后最多提前滚动一次至紧接下一个实际挂牌月份。
- 新腿重新通过估值0/1档与原IC 1.3执行动量许可；不重新引入已取消的IC MOM120。
- 卖Put、IC与核心Put同步切换；实物交割后的ETF→IC、IC月度展期及整轮扣费回本退出保持不变。
- 不加入灾难保护Put；上一层已拒绝该增强项。IC不含Call。
- 不修改生产、日报、账本或冻结主线。

## Relative-IV Definition

- 每个T日使用当日收盘可得的M+1、约95%行权价510500 Put隐含波动率。
- 与T日以前、同一信号序列最近`W`个有效交易日IV比较；分位定义为`历史IV <= 当日IV`的比例。
- 历史窗口不包含当天，不使用未来数据；不足60个有效历史观测时相对IV无效并关闭卖Put入场。
- 只改变首次入场的高IV判定。已经进入卖Put周期后，仍由60%权利金衰减、到期、实物交割和回本状态机管理，不因IV分位回落提前退出。
- 严格使用`relative_iv_percentile > Q`，边界相等不触发。

## Candidate Grid

- 绝对基线：`IV > 37.5%`。
- 相对窗口：`W = 126 / 252 / 504`个交易日。
- 入场分位：`Q = 70% / 80% / 90%`。
- 共1条绝对基线与9条相对IV候选。

## Data and Execution

- 真实层：2022-09-19至2026-08-14的真实510500 Put、ETF与IC。
- 理论层：2015-04-16至2026-08-14的理论510500 Put延展与历史IC，不解释为可成交期权历史。
- T日收盘计算准入，T+1开盘执行；每笔510500 Put买卖按标的名义单边5BP，ETF与IC单边1BP。
- 每1倍期货保留30%保证金/缓冲；现金年化3%。

## Diagnostics

- 每个候选保存原始IV、因果相对分位、历史观测数、入场许可、路由周期、实物交割及提前滚动次数。
- 报告full、10Y、5Y、3Y、1Y的年化收益、波动率、仓库口径Sharpe与最大回撤；真实历史不足的窗口明确N/A。
- 绝对IV基线必须与上一轮M+1、5BP输出逐日收益误差不超过`1e-12`。

## Pre-registered Decision Rule

相对IV只有同时满足以下条件才可保留为研究候选：

1. 真实层与理论层全样本Sharpe均不低于绝对IV37.5%基线；
2. 两层全样本最大回撤均不得恶化超过0.50个百分点；
3. 两层全样本CAGR均不得低于绝对基线超过0.50个百分点；
4. 同一窗口至少两个相邻分位通过前三项，或同一分位至少两个相邻窗口通过前三项；禁止单一峰值晋级；
5. 候选真实层至少产生3个完整卖Put周期，理论层至少产生8个完整周期。

通过也只代表研究候选，不自动替换1.3版本或生成交易建议。

## Limitations

- 分位窗口把期限结构、波动率偏斜和制度变化压缩为单一历史排名。
- 60个有效观测的热身期关闭入场；理论样本早期不是完整相对IV策略历史。
- 真实挂牌历史短；理论层依赖Black-Scholes输入。
- 未纳入真实买卖价差、动态冲击、容量、动态保证金、强平、税费或整数张数约束。
