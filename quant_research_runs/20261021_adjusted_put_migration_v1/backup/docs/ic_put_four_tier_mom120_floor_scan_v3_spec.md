# IC Put 四档估值下MOM120保底Delta扫描 v3（预注册）

- 版本：`ic_put_four_tier_mom120_floor_scan_v3`
- 日期：2026-08-20（Asia/Shanghai）
- 性质：研究参数扫描；不修改冻结主线及v2首次正式输出。

## 1. 研究问题

在IC Put四档估值规则下，当中证500全收益指数120交易日绝对动量`MOM120<0`时，最低目标绝对Delta是否仍应维持25%，还是应取消或提高。

## 2. 固定组件

- 固定1倍滚IC、`0.375/1.000`估值网格、网格仓不加Put、IC不含Call。
- 510500 ETF Put、三个月目标期限、95%目标行权价、实际挂牌月份、随IC月换重置、T收盘评估/T+1共同交易日收盘执行均不变。
- 估值目标和MOM120保底取较大值，不相加。
- 每1倍期货30%保证金/缓冲，剩余现金年化3%。

## 3. 候选网格

为避免结论依赖单一估值阶梯，同时验证两套已预注册四档：

1. `conservative`：`1.90/2.00/2.05/2.10 → 25%/50%/75%/100%`；
2. `wide`：`1.90/1.95/2.00/2.05 → 25%/50%/75%/100%`。

每套阶梯扫描`MOM120<0`时最低目标绝对Delta：`0%/25%/50%/75%/100%`。另含冻结三档25%保底基准，在同批运行中做逐日一致性核对。共11个候选。

## 4. 数据与完整性

- 真实样本：2022-09-19至2026-08-14。
- 样本中`MOM120<0`共445个交易日，`MOM120==0`为0个交易日；严格`<0`与旧`<=0`在该样本内无差异。
- 报告`full/last_10y/last_5y/last_3y/last_1y`；较长窗口截到真实样本起点。
- 冻结基准`real_grid_only`逐日收益最大绝对误差不得超过`1e-12`。
- 审计动量负值天数、保底实际绑定天数、目标100%天数、Put张数、实际有效Delta、成本、交易次数、最大Put市值占用及最低原始现金权重。

## 5. 判定规则

每套四档阶梯以25%保底为内部基准。

- 更高保底进入替换观察需同时满足：全样本最大回撤改善至少1个百分点；年化收益下降不超过2个百分点；Sharpe不低于25%保底；近3年与近1年不能同时在收益和回撤上均劣于25%保底；最低原始现金权重不低于0。
- 取消保底（0%）进入替换观察需同时满足：全样本最大回撤恶化不超过0.5个百分点；年化收益及Sharpe均不低于25%保底；近期窗口不能同时劣化。
- 若同一替代方向不能在两套估值阶梯上得到支持，则保留25%保底并标记参数依赖。

## 6. 成本与限制

- 继承正式IC、网格和510500 Put成本。
- 排除买卖价差、收盘冲击、涨跌停未成交、盘口容量、动态保证金上调和税费。
- 目标Delta不是持仓期间的硬上限；实际有效Delta会受整数张取整和期权Delta变化影响，本版必须单列报告。
