# 人民币账户 V8.0-A / ICIM v1.3-r6 权重扫描 v1

状态：预注册研究；不修改任何底层策略、研究信号、Poe、Gmail、远端发布或交易配置。

## 1. 研究问题

用户人民币账户计划为 1500 万元，当前参考配置为 40% V8.0-A、60% ICIM。检验在 ICIM 内部固定 IC/IM 各半时，是否有足够、稳定的真实历史证据把 ICIM 占比进一步提高。

## 2. 冻结输入

- V8.0-A：复用 `outputs/a_v80_ic_im_v2_50_50_20260901/daily_returns.csv` 中已经通过正式入口对账的 `V80_A` 日收益；不得重新解释旧 30% 目标波动率版本为当前 A。
- IC v1.3-r6：`outputs/ic_im_mainline_v1_3_r6_fixed_performance/ic_daily.csv.gz`，只使用 `data_layer=real`。
- IM v1.3-r6：`outputs/ic_im_mainline_v1_3_r6_fixed_performance/im_daily_real.csv.gz` 中 `core_plus_momentum_independent_replay`。
- 三条序列按共同交易日内连接，不前向填充；共同样本预计自 2022-09-19 至 2026-08-14。

## 3. 候选与基准

- ICIM 内部固定 IC 50% / IM 50%。
- 扫描 A 0% 至 100%，步长 1%；ICIM 为剩余权重。
- 当前基准：A 40% / ICIM 60%，即 A 40% / IC 30% / IM 30%。
- 用户问题重点：ICIM 65%、70%、75%、80% 是否相对 60% 有稳定改善。

## 4. 组合和执行口径

- 主结果使用每日固定目标权重线性合成，以便与既有 V2 权重扫描完全同口径。
- 月度首个共同交易日恢复目标权重作为敏感性；不额外收取跨策略划转成本。
- A、IC、IM 底层收益已包含各自正式成本、现金层和执行时点；ICIM 继续使用每 1 倍期货 30% 保证金/缓冲绩效口径。
- 不模拟涨跌停、额外冲击、临时保证金上调、期权盘口容量和实际账户整数映射。

## 5. 指标与窗口

- 报告 Full / 10Y / 5Y / 3Y / 1Y 的 CAGR、年化波动、仓库口径 Sharpe、MaxDD 和 Calmar。
- 真实共同历史不足 5 年，因此 5Y/10Y 必须标记 N/A；不得用理论期权或旧 V2 路径补齐。
- 同时报相关性、风险贡献、每日权重与月度再平衡敏感性。

## 6. 决策规则

- 不以单点最高值决定权重，优先寻找 Full/3Y/1Y 邻近连续的低遗憾平台。
- 若提高 ICIM 后仅有孤立峰值，或相对 60% 基准的 Sharpe 改善低于 0.01 且 MaxDD 改善低于 1 个百分点，则不认为有足够证据提高。
- 候选若在任一正式窗口令 MaxDD 恶化超过 1 个百分点，或 CAGR 降低超过 0.50 个百分点，不建议提高。
- 无论结果如何，本轮只形成研究结论；任何资金配置或发布变更需要用户另行确认。

## 7. 完整性检查

1. A 日收益必须与既有已验证输入逐日零差异。
2. IC/IM 各自从 r6 输入重算的 Full 指标必须与 r6 固定输出一致；组合只取共同真实样本。
3. A40/ICIM60 必须在同批次作为基准；全部候选权重和严格等于 1。
4. 所有候选日收益有限且大于 -100%；无未来数据、无日期重复、无前向填充。
