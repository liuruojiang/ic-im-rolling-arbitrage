# IM高IV卖95% Put期限统一复测 v1

预注册日期：2026-09-16。研究专用，不修改1.3正式规则或生产账本。

## 固定规则

- 使用下午统一修正后的IM月度核心路径：裸IMC基线一致性、T+1开盘定仓、指派后下一交易日开盘转IM、入场日损益不重复、2015早期估值认证恢复。
- 卖Put准入固定为估值0/1档、MOM120非负、目标合约自身IV严格大于35%；卖95% Put。
- 当前核心102% Put在卖Put路由执行的同一T+1开盘退出；权利金衰减60%后，下一交易日开盘最多提前滚动一次，并重新检查原准入。
- 正常IM阶段运行原IM D10/IV26 Call；切入卖Put时同步买回Call；卖Put、指派和回本阶段暂停Call；恢复普通IM后重新走原Call准入。
- 单边名义成本1bp、每1倍期货30%缓冲、现金年化3%。真实挂牌与理论延展严格分层。

## 唯一扫描变量

- `front10`：优先入场当月合约；若从执行日至实际到期不足10个交易日或无合格合约，使用M+1。
- `m1`：入场月份的下一个日历月。
- `m2`：入场月份后的第二个月。
- `m3`：入场月份后的第三个月，仅用于衔接旧扫描审计。

目标月份内选择最接近95%且严格虚值的Put。IV信号使用评估日该目标合约自身收盘价计算，成交使用下一交易日开盘，不能跨期限共用IV。

## 判定

比较同窗年化、波动、Sharpe、最大回撤、路由周期、指派、Call暂停日与交易次数。真实历史不足5年/10年的窗口明确N/A；理论层只作压力方向验证，不作为可成交历史。单点收益领先不自动晋级，优先要求真实与理论层方向一致且相邻期限不脆弱。
