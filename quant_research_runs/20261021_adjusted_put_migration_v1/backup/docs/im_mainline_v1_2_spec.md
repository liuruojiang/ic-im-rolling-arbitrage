# IM 滚动套利叠加中证1000动量研究候选 v1.2

预注册日期：2026-08-23（Asia/Shanghai）  
状态：独立研究候选；未批准实盘；不修改冻结 IC/IM V2 主线、Poe 或交易配置。

## 1. 版本目的

本版本以 `im_mainline_v1_1.py` 为唯一 IM 父版本，并接入 A 股多头组合 v1.3 中已经固定的中证1000原始动量规则，形成 50% 持续裸滚袖 + 50% 动量门控袖。规则来源和分袖结构以 `2026-08-23_滚IC滚IM叠加动量完整研究记录.md` 为依据。

本版本只生成目标与审计日程，不生成订单。冻结 V2 主线、`notes/mainline_registry.md`、`poe_ic_im_mainlines_v2_bot.py`及首次正式输出保持不变。

## 2. 父版本继承

以下规则完整继承 IM v1.1：

- Put 绝对轴 `2.45 / 2.50 / 2.60`，相对轴 `75% / 85% / 90% / 92.5%`，两轴取较大档；
- `MOM120 < 0` 时 Put 最低3张，只有估值第4档可产生第4张；
- Put 目标执行日+3个日历月、约95%行权价、T收盘评估、T+1共同交易日收盘执行；
- IM Call 为每日D10、IV不低于26%、5%威胁救援、最多5次，救援期限严格使用 `rescue_next_listed`；
- 独立估值网格在分数 `<=1.60` 时 T+1 开盘新增1倍，在 `>=2.00` 时 T+1 开盘退出；网格仓不加 Put 或 Call；
- 每1倍期货按30%保证金/缓冲核算。15%只属于未经经纪商独立验证的操作可行性口径，不进入本版本收益或信号计算。

## 3. 新增动量分袖

中证1000动量参数逐项继承 A 股多头组合 v1.3：

- `MA=35`；
- `Mom=18`；
- 线性权重终点 `W=2.5`；
- Score 条件为 `Score > 0`；
- Abs20 采用 `50% OFF + 50% Abs20>0`；
- 收盘信号目标只允许 `0 / 0.5 / 1.0`；T日收盘确认，T+1共同交易日成为实际动量权重；
- 不加入贴水补偿、目标波动、回撤缩仓、成交量过滤或其他 A 股 v1.3 中未对中证1000启用的覆盖层。

组合名义为：

```text
核心IM名义 = 0.5
动量IM名义 = 0.5 × 动量实际权重
独立网格名义 = 0 或 1.0
总IM名义 = 核心IM名义 + 动量IM名义 + 独立网格名义
```

因此不含网格时总IM名义只允许 `0.5 / 0.75 / 1.0`；含网格时对应为 `1.5 / 1.75 / 2.0`。

## 4. Put 与 Call 覆盖边界

- v1.1 的完整 Put 目标只覆盖持续存在的0.5倍核心IM袖；规范化 Put 数量等于 v1.1 每1倍目标的50%。
- 动量袖不配置 Put；动量权重变化不得改变 Put 目标。
- Call 只覆盖0.5倍核心IM袖；动量袖和独立网格均不卖 Call。
- 动量空仓时只有对应期货名义归零，不影响核心袖、Put、Call或独立网格状态。
- 本版本不使用研究记录中的“动量袖去MOM120下限”诊断，因为 IM 的最终研究判断仍是动量袖不配 Put。

## 6. 强制验证

1. 中证1000 Score、Abs20、收盘目标和T+1实际权重与 A 股 v1.3 语义一致。
2. 动量实际权重只允许 `0 / 0.5 / 1.0`，且必须等于上一共同交易日收盘目标。
3. 核心IM固定0.5倍；动量IM固定为 `0.5 × 动量实际权重`。
4. Put 和 Call 覆盖名义固定为0.5倍核心袖，不随动量或网格放大。
5. 网格信号、T+1开盘状态与 IM v1.1 完全一致。
6. 只有 v1.1 估值第4档可产生规范化2.0张 Put；负动量下限本身最多产生规范化1.5张。
7. 真实本地日程日期唯一、无缺口式错位、分袖公式最大误差不超过 `1e-12`。
8. 冻结 V2 文件、主线登记表和 Poe 文件不得修改。
