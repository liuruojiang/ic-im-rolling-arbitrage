# IC/IM v1.3 定值绩效 v4 对抗性修复规格

预注册日期：2026-09-03（Asia/Shanghai）  
状态：研究审计修复；未批准实盘；v1/v2/v3输出保持只读。

## 固定范围

- 收益数学、样本、成本、30%保证金/缓冲、3%现金收益、期货/期权/网格执行时点与v3完全一致。
- IC/IM逐日收益字节及其SHA-256必须与v3相同；本版只修复验证、依赖清单和明细输出。
- Full窗口保留首行初始化收益。滚动窗口定义为窗口首个可用收盘至终点收盘，因此排除首个样本行收益；图、基准与指标使用同一起点。

## 允许修复

1. IC Put目标日程只保存实际参与收益拼接的唯一model/real层，每个执行日唯一。
2. IC Put交易只保存实际拼接层；模型层必须早于真实期权起点，真实层必须不早于该起点。
3. 运行清单哈希所有实际读取的数据、传递依赖代码和返回相关常量。
4. IC/IM目标仓位、Put/Call与单位字段必须先通过required、numeric、finite及恒等式校验；NaN/Inf失败关闭。

## 验收

- IC/IM收益CSV的规范化`date,ret` SHA-256与v3完全相同。
- IC Put目标日程2756行且执行日唯一；交易事件为185笔model与95笔real。
- 注入NaN/Inf、重复执行日或跨层交易时构建失败。
- 清单覆盖构建时实际读取的全部固定输入和传递代码源。
