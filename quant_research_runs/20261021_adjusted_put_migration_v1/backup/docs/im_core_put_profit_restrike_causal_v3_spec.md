# IM核心Put盈利兑现并重新定价因果扫描 v3

预注册日期：2026-09-16。研究专用，不修改1.3正式规则。

固定当前IM核心Put估值分层、MOM120及防抖、102%目标行权价、约3个月期限、月度维护、成本和数量。比较当前不提前兑现、Put收盘价达到实际买入价2倍、达到3倍三个候选。

倍数在T日收盘确认；若T+1不是原月度维护日且目标数量仍大于0，则在T+1收盘卖出旧Put，并按T+1当前IM价格和原目标数量重新建立约3个月102% Put。新腿实际买价成为下一次触发基准。原月度维护优先，避免同日重复；估值目标降至0时按原规则退出。

真实挂牌与理论延展分别输出。理论早期估值使用认证恢复，但仍为模型/代理。该扫描只检验IM核心Put机制，不冒称完整1.3绩效，不自动晋级生产。
