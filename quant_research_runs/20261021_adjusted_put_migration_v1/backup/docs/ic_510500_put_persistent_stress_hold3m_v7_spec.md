# IC + 510500 Put 压力状态保持与三周期持有 v7 预注册规格

- 版本：`ic_510500_put_persistent_stress_hold3m_v7`
- 预注册日期：2026-08-16，Asia/Shanghai
- 状态：研究回测；未获准实盘；不得解释为交易建议或接入自动/人工下单
- 信号母版：冻结的`ic_510500_put_absolute_valuation_stress_v5`
- 期限母版：冻结的`ic_510500_put_v4_monthly_tenor_rerun_v6`
- 证据边界：v4—v6全部历史均已被观察，本版没有独立OOS，任何通过最多为`watchlist`

## 1. 研究问题

v5已经在2021年高位提前建立50%保护，但价格下跌后PB、ERP和股息率机械改善，日度估值把保护降为0；2022年3—4月和2024年1—2月真正的大额Put赔付日因此没有持仓。v6又证明，强制每月更换2m/3m Put虽然强化2015保护，仍不能弥补v4信号在2021—2024的缺席。

v7只回答两个冻结问题：

1. 固定绝对估值负责“武装”，压力未解除时，即使估值转低也保持保护，能否覆盖v5漏掉的风险兑现阶段；
2. 同一份3m Put跨三个IC月度周期并持有至到期，是否优于每月卖旧买新。

不得在v7内修改PB/ERP/股息边界、SMA120、RV20、25%波动阈值、85%模型执行价或资本口径。

## 2. 冻结信号

### 2.1 `v5_original`

精确复现v5主假设`abs_stress_any`：

- 绝对低估：0%；
- 绝对中/高估且无压力：50%；
- 绝对中/高估且有压力：100%；
- 压力为全收益指数低于SMA120或RV20不低于25%。

T日收盘状态仅在T+1开盘执行；首日初始化规则与v5一致。

### 2.2 `stress_latch`

使用同一v5绝对估值与压力变量，但引入因果状态：

- 估值第一次进入中或高档时，`armed=True`；无压力目标50%，有压力目标100%；
- `armed=True`以后，只要压力仍为真，目标保持100%，即使估值已经转低；
- 估值为低且压力完全解除（趋势与波动压力均为假）时，目标变0并`armed=False`；
- `armed=False`且估值为低时，压力本身不能建立保护；必须再次由中/高估值武装。

状态从具备SMA120/RV20预热后的完整2007日度历史因果推进，不在模型或真实Put样本起点重置。不得使用未来压力持续长度。

同场信号/引擎对照：`always_50`、`always_100`。

## 3. 冻结期限与持有方式

每个信号测试三种执行：

### 3.1 `front_original`

完全使用v5公共前月引擎。`v5_original`和永久对照必须与v5正式逐日结果一致。

### 3.2 `3m_monthly`

完全使用v6的强制月滚定义：新开仓及每个IC `roll_from`日，以执行日+3个自然月为目标，在当日挂牌月份中选择到期日距离最近者；每个IC换月日卖旧买新，即使到期月份相同也重置并计双边成本。

### 3.3 `3m_hold_expiry`

- 新开仓或到期后续保时，以执行日+3个自然月为目标，按v6相同规则选择最近挂牌到期月；
- 模型执行价为执行日中证500现货开盘的85%；真实层选择目标月份中正开盘、正成交量的最低行权价；
- 一次只持有一个到期批次，不在IC月滚日更换；
- 合约存续期内，信号目标提高时允许在下一开盘对同一合约只向上补仓；目标下降或变0时不卖出、不减仓，已有Put继续持有至到期；
- 到期日按收盘内在价值结算，不另收提前平仓成本；下一交易日若最新信号目标仍大于0，再建立新的3m批次；若报价不可执行则顺延并记录；
- 样本结束仍未到期的批次标记为开放，不假定未来结算。

`signal_target_fraction`记录信号请求；`executed_target_fraction`记录实际持有档位。收益和现金扣减只依据实际Put头寸。

运行前日历审计显示：永久持有模型路径除首个2015-04-16不完整批次和样本末开放批次外，目标3m批次均跨3个IC换月日，持有期中位数90个自然日。该事实只用于冻结完整性门槛，不使用任何Put收益。

## 4. 候选规模与归因

每个执行方式包含4条信号/对照：`v5_original`、`stress_latch`、`always_50`、`always_100`；另有每层一个无Put。

模型/真实两层共`2 × (1 + 3 × 4) = 26`条路径。

必须分别报告：

- 状态保持效应：同一期限`stress_latch - v5_original`；
- 期限效应：同一信号`3m_monthly/front_original`；
- 持有到期效应：同一信号`3m_hold_expiry - 3m_monthly`；
- 复合效应：`stress_latch + 3m_hold_expiry`相对v5原始前月及无Put。

## 5. 资本、成本与数据

- IC为100%名义；30%保证金/缓冲，70%现金按年化3%；不放大到3.33倍；
- Put市值从现金袖套扣除；IC与Put每边1bp成本敏感性；到期内在价值结算不计卖出边成本；
- 模型Put使用冻结Black-Scholes与QVIX波动率代理；真实Put使用第三方日线，不代表盘口成交保证；
- 模型2015-04-16至2026-08-14；真实Put 2022-09-19至2026-08-14；Asia/Shanghai交易日；
- 2007估值是指数正式发布前回溯研究历史；2015—2022模型Put不是历史成交。

## 6. 强制窗口与诊断

所有26条路径必须报告含70%现金的CAGR、年化波动、Sharpe和最大回撤：全样本、最近10年、5年、3年、1年。

额外分段沿用v5：

- `development`：2015-04-16至2020-12-31；
- `revision_validation`：2021-01-04至2024-12-31；
- `recent_expansion`：2025-01-02至2026-08-14。

另报：

- 2021-09-13至2024-02-05已知回撤路径的信号目标、实际保护、Put损益和成本；
- 2022-03-15至2022-04-27、2024-01-22至2024-02-05两段赔付窗口；
- 2015事件贡献与2025—2026保险拖累；
- 交易次数、成本、平均Put市值、平均真实入场虚值度；
- 每个持有到期批次的入场、到期、是否完成、覆盖IC换月数、向上补仓次数及报价顺延。

## 7. 完整性门槛

1. 无Put逐日匹配冻结IC；`front_original_v5_original`、front永久50%/100%逐日匹配v5；3m月滚永久对照逐日匹配v6。
2. 26条路径齐全，无重复日期、无未来信号或负执行延迟，收益无缺失且大于-100%。
3. QVIX代理继续通过；永久对照均有真实头寸、成本和非零市值。
4. `stress_latch`在全部“已武装、低估、压力为真”日目标为100%，低估且压力解除日目标为0；状态只依赖当日及之前信息。
5. 模型持有到期永久批次除样本边界外100%在到期前无卖出/减仓，完整批次覆盖3个IC换月日；真实层完成批次至少90%覆盖3个IC换月日，续保最大顺延不超过5个交易日。

完整性失败为`rerun_required/data_sensitive`，不得解释性能。

## 8. 预注册判断

每个`v5_original`或`stress_latch`候选—执行组合相对同层无Put必须同时满足v5单线门槛：

1. `development`最大回撤改善至少3个百分点，CAGR落后不超过1个百分点；
2. `revision_validation`最大回撤改善至少3个百分点，CAGR落后不超过1个百分点；
3. `recent_expansion` CAGR落后不超过1个百分点，最大回撤不得恶化超过1个百分点；
4. 五个强制窗口至少3个最大回撤改善为正；全/10年/5年CAGR落后不超过1个百分点，3年/1年落后不超过3个百分点；
5. 真实Put全样本最大回撤改善至少0.5个百分点，CAGR落后不超过1个百分点；
6. 模型与真实各至少20个实际保护日，2021-09-13至2021-12-31平均实际保护不少于50%。

稳健通过还要求至少一个预先定义的网格邻居也通过单线门槛。邻居为：同一信号的`front_original ↔ 3m_monthly ↔ 3m_hold_expiry`，或同一执行方式的`v5_original ↔ stress_latch`。

若无人稳健通过，决定为`keep_default/reject`。若有稳健通过，最多`watchlist`；优先`stress_latch + 3m_hold_expiry`，否则在通过者中选择平均实际保护最低者。两个及以上相邻通过为`narrow_stable`，四个及以上为`wide_stable`。
