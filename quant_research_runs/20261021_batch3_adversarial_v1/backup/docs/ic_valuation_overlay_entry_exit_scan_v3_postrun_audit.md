# IC固定估值增仓开仓/退出阈值扫描 v3 运行后审计

日期：2026-08-18（Asia/Shanghai）  
状态：研究审计；未批准实盘。

## 结论优先

1. 用户对旧结果的质疑成立。`1.000/2.000` 在底仓最大回撤峰值日2021-09-13仍持有新增1倍IC，并一直覆盖到底仓最大回撤谷值2024-09-23；因此新增仓没有躲开回撤不是显示错误，而是2.000退出阈值没有触发。
2. 降低退出阈值有效。旧规则全样本29.30% CAGR / -56.72% MaxDD；最防御的`0.000/1.250`为20.87% / -24.21%，但正式与2007诊断都只有1个完成周期。
3. 更有周期支持的防御带集中在退出1.250、开仓0.375—0.625：其中0.375、0.500均为正式2个、2007诊断3个完成周期，组合全样本分别23.29%/-31.80%和22.68%/-31.80%。开仓0.125的收益更高，为24.76%/-31.80%，但2007诊断只有2个完成周期。
4. 退出1.250是本版网格下边界，尚无退出轴下侧邻点，因此不能声称已找到完整宽平台。需要新版本向1.250以下扩展退出阈值，不能在v3内补点。
5. 96组中没有候选通过全部预注册门槛。原因不是回撤无改善：69组在底仓回撤峰值时已退出，且最优区回撤改善17—32个百分点；主要失败来自相对旧2倍暴露路径的近期收益容忍。旧规则最近1年CAGR为117.36%，防御带在退出后与底仓相同为53.31%，差64.05个百分点，必然超过预注册6个百分点容忍。

## 交易路径解释

- 旧1.000/2.000：2018-12-20买入，2026-05-12卖出，持有1,787日。
- 0.125/1.250：2022-04-26买入、2023-05-05卖出；2024-02-06再次买入、2025-07-23卖出。
- 0.375/1.250：2022-04-22买入、2023-05-05卖出；2024-01-23再次买入、2025-07-23卖出。
- 0.500/1.250：2022-03-16买入、2023-05-05卖出；2024-01-23再次买入、2025-07-23卖出。

这些防御线在2021-09-13均为空仓，随后只在2022和2024的深度低估期重新进入；因此能避开熊市前半段，但仍会承担“越跌越低估”后的后半段风险。

## 完整性与版本事故

- v2因三个上游SHA-256后半段抄写错误在收益计算前停止；没有正式结果，失败记录单独保留。v2冻结规格未改写。
- v3只纠正哈希和路径，96组研究设计未变；实际组合97条（含底仓）267,332行，2007诊断96条457,056行。
- v1底仓和旧1.000/2.000逐日奇偶误差均为`9.975e-17`；收益/现金恒等式误差0；因果失败0；参数工件complete strict PASS。
- 正式决定为`no_threshold_pair_passed_preregistered_gates/reject`，`selected_candidate=null`。防御带仅为下一轮扩边观察，不是事后晋升或交易建议。
