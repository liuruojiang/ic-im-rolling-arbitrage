# IC 分层研究第四层：独立网格 vs 动量指导网格 v1（预注册）

## 研究目标

固定前三层所有参数，比较三种网格状态：

1. `no_grid`：不加网格；
2. `grid_independent`：冻结估值网格独立运行；
3. `grid_momentum_guided`：冻结估值网格接受已落地动量仓位指导。

三种网格状态分别叠加在以下三种 Put 底座：不加 Put、Put 只保护裸滚 50%、Put 保护裸滚及实际动量袖。Call 继续关闭。

## 固定参数

- 50% 固定裸滚 IC + 50% 动量门控 IC。
- 中证500动量：`MA110 / Mom24 / W2`，50% `Abs20 OFF` + 50% `Abs20 > 0`；实际动量权重只为 `0 / 0.5 / 1.0`。
- Put 规则、理论/真实分层、期权执行与成本完全继承第二层。
- 网格阈值固定为 `<=0.375` 买入、`>=1.000` 卖出；新增 1 倍 IC，新增仓不加 Put。
- 期货每边成本 1bp，网格持仓换月双边 2bp；每 1 倍 IC 使用 30% 保证金/风险缓冲，剩余现金净年化 3%。

## 动量指导语义

- 网格估值信号仍在 T 日收盘生成，并安排 T+1 交易日开盘执行。
- T+1 开盘时，若已落地的动量权重 `momentum_weight > 0`，网格允许执行买入；权重为 `0` 时买入被阻止。
- 网格持仓期间，若已落地动量权重在某交易日变为 `0`，则该交易日开盘退出网格仓；此权重来自前一交易日收盘信号，不使用当日收盘信息。
- 动量权重为 `0.5` 或 `1.0` 时均视为允许，不按动量权重缩放 1 倍网格仓。
- 估值退出 `>=1.000` 始终执行，不受动量影响。
- 网格因动量退出后，若估值仍处于买入区间，则继续按 T 日收盘重新产生下一交易日买入计划；实际执行仍需当日动量允许。

## 比较与收益

- `no_grid` 和 `grid_independent` 必须逐日精确复现第三层对应路径。
- 动量指导网格使用与独立网格相同的 IC 官方开盘、结算、活跃合约、估值分数与换月日历。
- 网格日收益与第三层相同：开平仓日按开盘/结算区间，普通持仓日按前结算/当日结算；扣除交易与换月成本后作为独立新增袖叠加。
- 网格资金占用为 `30% × 网格日终仓位`。现金权重不得为负；不得隐含借款。
- 网格新增仓不改变任何 Put 目标 Delta、Put 张数或期权成本。

## 报告与验证

- 报告全周期、近 10 年、5 年、3 年、1 年和真实 Put 期的年化收益、年化波动、最大回撤、Calmar、持仓天数、交易次数、成本和最大总 IC 名义。
- 单列动量指导相对独立网格及相对无网格的收益/回撤增量。
- 验证动量指导网格不在动量权重 0 时日终持仓，所有估值信号 T+1 执行，强制退出使用已落地权重，状态只为 0/1，日期完整且现金非负。
- 保存逐日路径、独立/指导交易事件、窗口与年度指标、验证、输入哈希及运行清单。

## 研究边界

- 冻结独立网格全周期仅 3 次完整估值循环。动量指导会把这些循环切成更多交易片段，但不能创造更多独立估值周期。
- 本层不扫描网格阈值或动量参数，不改变 Put 配置，不测试 Call。
- 结果仅为研究候选，不修改冻结 IC/IM V2 主线、Poe 或实盘配置。
