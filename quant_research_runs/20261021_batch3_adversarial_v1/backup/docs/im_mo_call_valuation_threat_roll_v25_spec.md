# IM + MO Call PE估值滞回 × 受威胁向上向后移仓 v25 预注册规格

冻结日期：2026-08-19（Asia/Shanghai）  
状态：官方MO短样本机制验证；未批准实盘。

## 1. 研究问题与单层边界

在v23已经冻结的每日检查、IV26正常入场、文章期限—虚值率阶梯和PE20%/60%滞回基础上，只增加一个受威胁救援机制：若已有卖出Call在T日收盘时的剩余虚值率不高于5%，则不受IV26限制，向上提高行权价并向后延长一个实际挂牌到期月，于T+1官方收盘整体移仓。

本版不采用v24的盈利80%提前展期，也不加入40%/60%分批止盈、急跌向内移仓、85%/95%风险度扩缩仓、MOM、网格或发布前PE回溯诊断。任何结果只能归因于受威胁救援规则及其与正式PE状态的交互。

## 2. 基准与候选

- 底仓：冻结的1倍滚IM + `reconstructed_valmom_floor3`三个月95% Put；
- 参照：v20无Call、v20月评D10+IV26、v22每日D10+IV26；
- v23同路径控制A0：`article_ladder_iv26_daily`，无估值、无TP80、无救援；
- v23正式估值B0：`article_pe20_60_hysteresis_iv26_daily`，PE20/60、无TP80、无救援；
- 新候选A2：`article_ladder_iv26_daily_threat5_up5_next1_max5`，A0加救援；
- 新候选B2：`article_pe20_60_hysteresis_iv26_daily_threat5_up5_next1_max5`，B0加救援。

正式增量判断以B2对B0为主；A2对A0用于识别救援本身是否有效。每1张IM固定卖2张MO Call，只覆盖固定底仓，不按可用资金扩张数量。

模型层为2015-04-16—2026-08-14连续期权近似；真实层为2022-07-22—2026-08-14官方IM/MO收盘与结算。正式结论只看官方真实层，模型只作长期方向诊断。

## 3. 完整继承的v23正常路径

- PE使用中证1000官方`official_rolling_pe`，估值历史不早于指数发布日期2014-10-17；
- T日使用截至T日最长十年、早期扩展历史的弱经验分位；
- 分位`<=20%`进入低估修复态，直到`>=60%`才退出；
- 低估修复态正常入场只允许DTE 30—60、最低虚值25%；
- 普通态正常入场依次寻找30—60/15%、61—90/20%、91—120/25%；
- 空仓每日收盘检查，正常新卖Call自身IV须`>=26%`；
- 月度事件日只有当现有Call到期日不晚于该事件`current_expiry`时才正常重选，否则保持远月仓位；
- T日冻结具体合约，T+1官方收盘成交；不可交易时顺延冻结动作，不用未来信息重选；
- 层内排序、成交量/持仓量要求、模型连续行权价、成本、保证金和现金收益均与v23相同。

## 4. 受威胁救援规则

每天收盘在没有待执行动作且已有Call时，先于月度换仓检查：

`threat_otm = 旧Call行权价 / T日中证1000价格指数收盘 - 1`。

当`threat_otm <= 5%`时触发。包括已经平值或实值的Call。

若本轮连续救援次数小于5：

1. 新到期日取T日链上严格晚于旧Call到期日的第一个实际挂牌到期日；模型层取严格晚于旧到期日的第一个模型挂牌到期日；
2. 目标行权价为`旧行权价 × 1.05`；真实层取该新到期日中不低于目标价的最小挂牌行权价，模型层使用精确连续目标价；
3. 真实合约必须在T日有正收盘、成交量和持仓量，且可反解有限正IV；
4. 救援新仓不要求IV`>=26%`，但记录真实IV、Delta、成交量和持仓量；
5. T日冻结旧仓买回与新仓卖出，T+1按同一冻结合约官方收盘整体移仓；若T+1不可交易，则同一冻结动作顺延，不重选；
6. 成交后连续救援次数加1。正常月度换仓、正常空仓新开或止损后下一月度周期重新开始时计数归零。

若找不到上述新合约，则T日冻结买回旧Call并于T+1收盘止损，不在受威胁状态中继续裸露等待。

若已经完成5次连续救援后再次满足`threat_otm <= 5%`，则T日冻结买回旧Call，T+1收盘止损；止损后禁止空仓每日重新卖Call，直至下一个IM月度评估日才解除。该月度评估日按正常v23规则和IV26门槛处理。

同一日优先级为：待执行冻结动作 > 受威胁救援/止损 > 月度正常换仓 > 空仓每日正常入场。受威胁救援不使用当前PE状态重新降低行权价，也不采用v24盈利80%规则。

## 5. 成本、资本与未建模摩擦

- 2张MO Call篮子每边成本1bp；救援买回旧仓并卖出新仓合计2bp；止损买回为1bp；
- Call保证金、Put市值、70%可用现金上限和余额净年化3%收益继承v23；
- 任一日Put市值加Call保证金超过70%记为资本穿透；
- 不模拟盘口买卖价差、冲击成本、涨跌停或盘中成交，官方真实层仍是收盘可成交近似。

## 7. 预注册判定

B2相对B0的正式机制通过条件：

- 真实full和3Y CAGR各自落后B0不超过1个百分点，1Y落后不超过3个百分点；
- 真实full MaxDD不比B0加深超过0.5个百分点；
- 真实最大Call Delta至少下降5个百分点，或最大Call保证金占比至少下降2个百分点；
- 至少发生2次真实救援移仓；
- 资本穿透与最终未执行计划为0，全部审计通过。

A2对A0使用相同门槛独立判定，但不改变B2正式结论。

- B2通过：`valuation_threat_roll_supported_real_short_sample`；
- B2不通过而A2通过：`threat_roll_without_valuation_only`；
- 两条都不通过：`threat_roll_not_supported`；
- 无真实救援或事件不足2次：`insufficient_real_threat_events`。

无论结果如何，最高只能进入官方MO短样本观察池，不获准实盘。不得因结果改变5%、5次、IV26、PE20/60或期限—虚值率规则。
