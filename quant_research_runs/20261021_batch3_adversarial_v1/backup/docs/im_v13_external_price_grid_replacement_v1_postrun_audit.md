# IM 1.3-r6 外部价格网格替换测试：运行后审计

- 运行日期：2026-09-03
- 数据：CFFEX IM/MO真实共同样本，2022-07-22至2026-08-14，共986行
- 固定模块：0.5倍核心、0至0.5倍动量、核心Put、动量Put、当前Call、换月、成本和现金
- 唯一替换：当前估值网格改为中证1000每跌1000点逐档增加、每档等效成本加1000点止盈的外部价格网格
- 执行：T日价格指数收盘确认，下一共同交易日IM官方收盘成交；官方结算价逐日盯市
- 资金：每1倍IM按30%保证金/缓冲；正现金年化3%；网格仓不新增Put或Call
- 权限：研究测试，不修改生产或远端信号

## 结论

不建议用外部价格网格替换当前估值网格。作者样本比例对应的每格0.5倍主候选，CAGR由48.37%降至36.13%，Sharpe由1.517降至1.407，MaxDD由-23.30%扩大到-24.36%。每格1.0倍虽把CAGR拉回47.80%，但MaxDD扩大到-44.07%，并出现1个负现金日，因此不可执行。

## 尺度解释

- 0.25倍：按当前0.5倍持续核心仓缩放作者“2手基础仓、1手网格”的比例。
- 0.50倍：按作者组合30%基础仓作为1倍归一化后，每格1手等于0.5倍，是主候选。
- 1.00倍：把原文“每格1手”直接视为当前1倍IM，用于压力测试。

1.00倍路径的平均网格仓0.883倍、最高2倍，与外部交接文件记录的平均0.883手、最高2手一致，说明价格触发、5000点禁增和独立止盈路径得到复现。

## 为什么当前网格收益高但不能过度解读

当前估值网格相对无网格显著提高历史收益，但只有2个完整周期，其中最大正向周期占正向周期贡献78.65%，第二轮从2024-01-18持续到2026-01-12。它仍然存在明显事件集中性；本次结果只能说明外部价格网格没有改善当前样本，不能把当前网格的48.37%视为已经获得充分稳健性验证。
