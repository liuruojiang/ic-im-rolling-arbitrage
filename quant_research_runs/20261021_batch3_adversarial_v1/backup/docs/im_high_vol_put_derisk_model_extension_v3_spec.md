# IM 高波停Put / 降仓理论代理扩展 v3 预注册

预注册时间：2026-08-25（Asia/Shanghai）  
状态：理论/代理压力研究；不是真实MO回测，不改冻结主线，未批准实盘。

## 1. 目的与证据边界

真实CFFEX MO历史仅从2022-07-22开始。v2真实匹配消融显示35%-40%高IV停Put形成“收益型、非防守型”平台，而额外降仓没有改善回撤。本阶段用2015-04-16以来的冻结理论MO/中证1000代理市场覆盖2015、2018、2020等压力期，检验上述现象是否只属于2022年以来短样本。

本层不能解释为可成交IM/MO结果：期货方向腿使用中证1000全收益指数代理，Put用Black-Scholes理论价格，波动率为50ETF QVIX按中证1000/50ETF 60日实现波动率比缩放的代理，不含真实IM基差、MO波动率曲面、盘口或成交冲击。

## 2. 模型基线

- 方向市场与理论Put定价完整继承 `im_mo_csi1000_put_protection_battery_v6.model_market`、`model_baseline`和`im_mo_close_execution_v8.run_model_normal_close`。
- Put估值/动量日程以 `outputs/im_mo_reconstructed_floor_selection_v14/signal_schedules.csv.gz` 的重建floor3日程为起点。
- 全期 `MOM120<0` 时最低4张Put，以贴近冻结v2负动量下限。
- 当57个月历史已足够时，使用冻结v2的 `75%/85%/90%/92.5%` 四档相对阈值和绝对轴取高值；在57个月历史不足的早期，仅保留已认证的重建0-3档估值目标和负动量4张下限。该早期混合口径必须显式标记，不能称为完整v2复现。
- 只研究1倍核心IM代理与Put；真实主线的网格和Call不进入本模型层。

## 3. 候选

阈值只验证真实层形成平台的 `35% / 37.5% / 40%`。

匹配路径：

1. 理论基线：混合v2近似Put + 1倍核心。
2. 全期无Put + 1倍核心。
3. `gate_only`：代理IV高于阈值时Put目标为0，核心1倍。
4. `derisk_keep_put`：Put不变，高IV时核心降仓。
5. `replace_put_derisk`：高IV时Put目标为0并降核心。

降仓函数继承v2真实消融：`inverse_f50`、`linear5_f25`、`linear10_f25`。

## 4. 时点和成本

- T日代理波动率信号，T+1收盘目标变化；新核心权重从下一交易日收益开始生效。
- 理论Put由正式模型执行函数按3个月目标期限、95%行权价运行。

## 6. 决策规则

任何模型结果最多用于判断真实候选是否“方向一致”，不能推广主线。

- 防守确认：同一模式/函数至少两个相邻阈值在Full、10Y和5Y MaxDD均改善至少1个百分点，Full最差20日改善至少1个百分点，且各窗口CAGR不低于基线超过2个百分点。
- 收益现象确认：同一模式/函数至少两个相邻阈值在Full、10Y、5Y CAGR和Sharpe均高于基线，且MaxDD均不恶化超过1个百分点。
- 若真实层收益平台在模型层不成立，标记`real_sample_data_sensitive`。
- 若降仓仍未改善尾部，明确记录“高波降仓未获支持”；不得把少持Put的收益现象归因于降仓。
