# 中证500固定估值连续映射 v2 预注册规格

冻结日期：2026-08-18  
研究状态：估值本体第二层；研究映射；未获准实盘

## 1. 与上一层的关系

上一层 `ic_fixed_valuation_time_weight_v1` 已在不使用未来收益或策略绩效的前提下，得到指数时间权重7.5—12年连续稳健带，机械中心为10年。本版冻结使用：

- 主口径：10年半衰期；
- 强制敏感性：7.5年和12年半衰期；
- 不再扫描或重选时间权重，不使用等权或近10年2倍阶梯决定本版结论。

本版只建立固定经济数值到连续估值风险分数的映射，检查旧固定门槛在加权历史中处于什么位置，以及连续门槛细网格会产生多大覆盖差异。不得使用指数未来收益、策略收益、最大回撤、Put损益或交易次数挑选估值门槛。

## 2. 输入与样本

- 权威输入：`outputs/ic_fixed_valuation_time_weight_v1/monthly_weight_map.csv`和`daily_weight_map.csv.gz`。
- 正式运行必须校验v1规格、运行后审计、月度权重图、日度权重图及v1完整性文件的SHA-256，并验证v1状态为`passed`。
- 月度校准样本固定为2007-01-31—2026-08-17共236个月；日度映射样本固定为2007-01-15—2026-08-17共4,761日。
- 字段：聚合TTM PE、聚合PB、`ERP=1/PE-10年国债收益率`、过去一年已实现股息贡献；价格指数只作为统一审计背景。
- 2007年股息贡献仍属于官方回溯研究历史；不补造2007年前PB、PE或ERP。

## 3. 加权分布与连续风险

对每条半衰期路径，使用v1已经归一化的月末权重。加权分位数定义为排序后累计权重第一次达到或超过目标分位的实际观察值。输出1%—99%、每1个百分点一档的完整分位表。

任意经济值 `x` 的固定加权风险分定义为：

- `PE风险 = sum(w_i * I(PE_i <= x))`，只作审计；
- `PB风险 = sum(w_i * I(PB_i <= x))`；
- `ERP风险 = sum(w_i * I(ERP_i >= x))`；
- `股息风险 = sum(w_i * I(dividend_i >= x))`。

主连续经济风险保持旧信息集和经济权重，避免同时加入PE与ERP重复计算盈利收益率：

`continuous_risk = 25% × PB风险 + 50% × ERP风险 + 25% × 股息风险`

映射表以2026-08-17最大历史加权分布冻结；它是当前固定研究映射，不是因果历史策略。将该映射直接应用于2007—2026并计算策略收益会使用未来估值分布，属于前视，因此本版禁止任何策略回测。

## 4. 旧固定门槛定位与交叉表

旧固定风险规则完整复算：

- PB：`<2.00 / 2.00—<2.50 / >=2.50`映射0/1/2；
- ERP：`>3.00% / 1.50%—3.00% / <=1.50%`映射0/1/2；
- 股息贡献：`>=2.00% / 1.00%—2.00% / <1.00%`映射0/1/2；
- `old_fixed_risk=25%×PB档+50%×ERP档+25%×股息档`，只能取0、0.25……2.00。

本版必须输出：

1. 每条旧原始经济门槛在7.5/10/12年加权分布中的普通分位和风险分位；
2. 每个旧离散总分的月数、10年中心加权占比，以及对应连续风险的10%/25%/50%/75%/90%分位；
3. `old_fixed_risk>=1.50/1.75/2.00`的全期及强制窗口覆盖率、月度episode数量和期末状态；
4. PE 20/25/30/35/40倍只作分布审计，不进入主连续分数。

## 5. 连续总分门槛细网格

固定扫描 `continuous_risk >= threshold`：

- 门槛0.500—0.950；
- 步长0.025；
- 7.5/10/12年三条时间权重；
- 共19×3=57个候选。

每个候选在日度样本和月末样本上报告：

- `full / last_10y / last_5y / last_3y / last_1y`覆盖率；
- 月度高风险episode数、最长连续高风险月数、期末开关；
- 同一门槛下7.5年与10年、12年与10年的月度Jaccard；
- 三条半衰期覆盖率极差。

只作结构稳定标记：同一门槛两侧Jaccard均不低于80%，且三条半衰期最近10年覆盖率极差不超过5个百分点，则为`mapping_stable`。本版不从稳定门槛中选“最优”，也不把覆盖率较合意解释为能预测下跌。

参数工件为适配统一结构，可重复写入中证500价格指数在五个强制窗口的年化收益、波动、Sharpe和最大回撤；这些数对同一窗口的57个候选完全相同，仅是背景，不参与门槛评价。

## 6. 因果年度截面审计

为了判断固定经济位置是否只由2026终点决定，建立不含未来信息的年度截面：

- 截面为2016—2025每年12月最后一个完整月末，以及2026-08-17；
- 每个截面只用当时及以前的月末样本，以该截面为锚按10年半衰期重新归一化；
- 输出PE、PB、ERP、股息贡献的10%/25%/50%/75%/90%加权分位；
- 输出旧原始经济门槛在各截面中的风险分位；
- 以2026中心分布IQR为尺度报告各分位路径的首末漂移和最大年度变动。

该截面只检查经济锚漂移，不能与截面后的指数收益配对，也不能据此挑选表现最好的年份或门槛。

## 7. 变量冗余审计

- 在10年中心权重下，对PE、PB、盈利收益率、10年国债收益率、ERP和过去一年股息贡献输出加权Pearson相关矩阵。
- 对各变量普通秩再使用10年中心权重计算加权Spearman近似矩阵。
- 明确检查PE—ERP及盈利收益率—ERP相关性，判断PE若加入主分数是否会明显重复计权；本版不根据相关性结果重新优化25%/50%/25%权重。

## 8. 完整性与验证

- 冻结规格SHA-256必须在运行前匹配；正式输出目录不存在且不可覆盖。
- v1月/日日期、行数、字段和权重和与v1正式完整性记录一致；所有输入日期唯一、严格递增、无缺失。
- 7.5/10/12年风险映射均在0—1；PB/PE风险随原始值不下降，ERP/股息风险随原始值不下降时不增加。
- 旧固定总分只能取九个0.25离散档；连续分数必须产生至少100个不同日值。
- 57个细网格候选完整覆盖五个强制窗口；参数工件通过complete strict检查。
- 独立测试必须复算加权分位、风险方向、旧固定交叉表、57候选、Jaccard和年度截面无未来数据。
