# IC v1.3 最终联合邻域稳健性预注册 v1

日期：2026-09-17  
状态：研究预注册；不修改生产、账本、日报或交易规则。

## 目标

检验此前逐层保留的 IC 混合候选在联合后是否只是孤立参数点。候选结构固定为：当前 IC v1.3 完整组合、M+1 95% 510500 卖 Put、等名义数量、最多一次提前展期、卖 Put 与核心 Put 同步切换、核心 Put 盈利兑现后重置。

## 网格

- 绝对 IV：35%、37.5%、40%。
- 卖 Put 权利金衰减：50%、60%、70%。
- 核心 Put 盈利兑现：2倍、3倍。
- 共 18 组；不在本层重选期限、数量、估值防抖、相对 IV 或灾难保护。

## 固定口径

- 期货：当前季度 T-3 收盘展期路径。
- IC Call：始终排除。
- 估值、MOM120、Abs20 防抖、动量 Put、0.5/1.0 网格均沿用当前完整组合。
- 卖 Put 准入沿用 IC 当前估值 0/1 档及原 IC v1.3 执行动量许可，不引入卖方 MOM120。
- 所有 510500 Put 单边成本 5BP，期货单边 1BP；每 1 倍期货 30% 保证金/缓冲，现金年化 3%。
- 真实挂牌层与理论延展层分开报告；理论层不得解释为可成交历史。

## 比较与判定

每组联合候选与“相同核心 Put 盈利兑现倍数、但不卖 Put”比较。单组通过须在真实挂牌层和理论延展层同时满足：

1. CAGR 不低于无卖 Put 对照；
2. Sharpe 相对对照不低于 -0.05；
3. 最大回撤绝对值恶化不超过 1 个百分点。

中心候选为 IV37.5% / 衰减60% / 3倍兑现。中心候选通过，且五个单轴邻点（IV35、IV40、衰减50、衰减70、2倍兑现）至少四个通过，才可判定为“联合邻域平台成立”。否则不晋级。即使通过，也仅为研究候选，不构成生产或实盘授权。

## 已知限制

真实 510500 期权历史较短；理论层依赖模型。未纳入动态保证金、强平、税费、盘口容量、整数账户张数与显式延迟成交。
