# 滚 IC / IM 系统研究主线冻结 v2

冻结日期：2026-08-20（Asia/Shanghai）  
状态：用户确认的新研究主线；未批准实盘。

## 1. 版本目的

本版本只改变两套系统的 Put 保护档位与负动量下限，其余底仓、网格、Call、执行、期限和资金口径全部继承 v1。v1 的冻结规范、SHA-256 与首次正式输出保持原样；v2 使用真实历史期货、期权、指数与估值数据重新执行所选 Put 路径，并保存独立的首次正式输出。

## 2. IC 系统

- 固定底仓、固定估值网格与 v1 相同；网格新增仓不增加 Put。
- IC 明确不含 Call。
- 估值分四档：`1.90 / 1.95 / 2.00 / 2.05`分别对应目标绝对 Delta `25% / 50% / 75% / 100%`。
- 中证500全收益指数 `MOM120 < 0` 时，目标绝对 Delta 最低 `50%`。
- 估值目标与动量目标取较大值，不相加；最终目标只允许 `0% / 25% / 50% / 75% / 100%`。
- 使用510500 ETF Put；执行日加3个日历月为目标，选择实际挂牌到期日中离目标最近者，目标行权价/ETF收盘价约95%。随IC月换重置，不持有到期，不做每日 Delta 再平衡；T收盘评估、T+1共同交易日收盘执行。

## 3. IM 系统

- 固定底仓、固定估值网格与 v1 相同；网格新增仓不增加 Put 或 Call 覆盖。
- Put 绝对轴仍为 `2.45 / 2.50 / 2.60`，分别对应1/2/3张。
- Put 相对估值轴改为四档：仅使用有效月份以前最近57个月末数据，按 `75% / 85% / 90% / 92.5%`滚动分位数分别对应1/2/3/4张。
- 绝对估值档与相对估值档取较大值。
- 中证1000全收益指数 `MOM120 < 0` 时，每1倍核心IM最低 `4张` MO Put；最终只允许0/1/2/3/4张，上限4张。
- 执行日加3个日历月为目标，选择实际挂牌MO到期日中离目标最近者，目标行权价/IM约95%。月度重置，不持有到期，不做每日 Delta 再平衡；T收盘评估、T+1共同交易日官方收盘执行。
- 卖 Call 规则完整继承 v1：只覆盖固定1倍核心IM，D10、IV26%、5%威胁救援与 `rescue_next_listed` 期限语义均不改变。

## 4. 不变项

- IC 网格：估值分数 `<=0.375` 时T+1开盘新增1倍，`>=1.000`时退出；总IC单位为1或2倍。
- IM 网格：估值分数 `<=0.85` 时T+1开盘新增1倍，`>=1.25`时退出；总IM单位为1或2倍。
- 绩效收益继续按每1倍期货30%保证金/风险缓冲及剩余现金净年化3%核算。
- 15%只作为用户提供的实盘期货保证金可行性上限，尚未由经纪商独立验证。
- IC 不卖 Call；任何历史 IC Call 诊断不得并入本主线。
- IM 5%救援期限必须为相对旧到期日严格更晚的最近实际挂牌到期日 `rescue_next_listed`，不是固定增加一个日历月。

## 5. 强制验证

1. 所有收益由真实数据和正式执行函数重新计算，不嵌入或伪造行情。
2. v1 基线重算与冻结 v1 日收益最大绝对误差不超过 `1e-12`。
3. IC 四档、负动量50%下限、T+1执行及无 Call 全部逐日验证。
4. IM 四档滚动阈值只能使用有效月以前数据；负动量4张下限、T+1执行及上限4张全部逐日验证。
5. IC 网格组件不随 Put 变更；IM 网格与 Call 组件不随 Put 变更。
6. IM Put 与 Call 只覆盖固定核心底仓，不能随网格仓翻倍。
7. 30%绩效资金口径和15%操作可行性口径分开报告。
8. 输出全样本、近10年、近5年、近3年和近1年绩效，另保存逐日路径、目标计划、交易事件、阈值和当前状态。
