# 收盘日线未更新的明确等待状态 v1

2026-10-21。第三批的紧急只读复核：原`live_proxy`先执行`_validate_v13_ohlcv`，交易日15:00后缺当日日线会先被最近完整交易日校验拒绝；尚未证明昨日成交量占位可绕过这道门禁。

本修订保留该门禁及盘中占位规则，仅将交易日收盘后当日日线尚未覆盖的既有异常细化为RuntimeError子类`DailyOHLCVNotReady`，明确`waiting_for_completed_daily_ohlcv`，错误文案说明等待含成交量的完整日线更新。其他历史过期情形仍按原异常处理。

不得以快照价格、昨日成交量或盘中成交量代替当日完整日线；等待期间不生成完整收盘信号、不写账、不取消原待执行计划。不得把本次状态细化描述为已证实昨日成交量污染正式账本的修复。

验收使用合成的合法OHLCV（明确非真实行情），在IC/IM和15:00、15:01、15:29、15:30分别复现数据仅至前一交易日，要求停止于日线门禁、不取即时价格、不更改输入和锚点。既有累计回归继续通过。冻结输出、正式账本、策略阈值、数量和月度规则不变。本次未部署或发邮件。
