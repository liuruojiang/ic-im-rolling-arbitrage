# IM 新动态估值三档 MO Put v11 数值容差复核预注册规格

冻结日期：2026-08-19  
研究状态：v10实现勘误；仅研究，未批准实盘

## 1. 研究问题

v10已完成真实数据回测，但把小于`1e-12`个百分点的浮点MaxDD差误判为正改善。本版不改变任何估值、Put、候选、数据、执行或成本，只对v10正式逐日结果进行归一化复核。

## 2. 冻结输入

- 输入为`outputs/im_mo_adaptive_valuation_tier_put_v10/`的逐日、窗口、年度、暴露、信号、交易、成本压力和宽度产物。
- v10逐日文件及核心表使用本规格冻结时记录的SHA-256校验。
- 主候选、四条邻线、两个分解诊断、旧规则参照和no-Put均不改变。
- 模型层、真实层、三个月95%月换、0/1/2/3张MO、T收盘信号/T+1收盘执行、30%保证金/缓冲、70%现金年化3%均不改变。

## 3. 唯一纠正

- MaxDD改善至少`0.01`个百分点才计为“改善”；绝对值小于该值一律视为无变化。
- 邻线方向支持同样要求模型层和真实层全样本MaxDD改善均至少`0.01`个百分点。
- 收益容忍、活动次数、2026年年化调整不超过24次和2倍成本符号检验全部沿用v10预注册规则。

## 4. 决策

- 重新计算模型五窗口和真实三个可用窗口的有效回撤改善数、邻线宽度、成本/换手门槛及总决定。
- 只有所有v10预注册门槛在新容差下通过，才可`carry_to_momentum_layer`；否则为`valuation_only_not_sufficient`或`not_testable`。
- 本版是已验证正式产物的归一化勘误，不重新选择参数，不构成独立样本外验证，也不批准实盘。

## 5. 正式产物

- 测试：`test_im_mo_adaptive_valuation_tier_put_v11.py`
