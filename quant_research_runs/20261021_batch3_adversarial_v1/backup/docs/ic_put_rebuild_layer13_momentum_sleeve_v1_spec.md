# IC Put 污染后重建：第十三层动量腿同步卖 Put V1 预注册

## 研究问题

固定当前候选后，检验现行动量IC腿是否也应在相同准入日同步切换为卖 Put。

## 固定口径

- 卖 Put：M+1、95%虚值、修正后95%信号合约IV>30%、每1倍IC总初始卖方绝对Delta 0.5、即时估值、不加卖方MOM120、持有到期。
- 核心买Put固定3倍盈利兑现；动量买Put不做盈利兑现。
- 固定核心腿为0.5倍IC；动量腿为`0.5 × 当日动量执行权重`；网格不参与卖 Put转换。
- 所有510500 Put单边5bp；IC单边1bp；每1倍期货30%缓冲；现金年化3%；IC不含Call。

## 四组对照

1. `profit3x_no_short`：不卖 Put；
2. `fixed_only_qd05`：只转换固定核心腿；这是当前候选，必须逐日复现第十二层95%路径；
3. `momentum_only_qd05`：只转换动量腿；
4. `both_qd05`：固定核心腿和动量腿都转换。

## 动量腿转换语义

- 仅当动量执行权重大于0且卖 Put准入成立时转换。
- 入场名义=`0.5 × 当日动量执行权重`，再按同轮前收盘期权Delta乘以`0.5 / abs(delta)`；规模在卖 Put、交割ETF、恢复IC和等待回本期间固定。
- 入场时同步退出对应动量IC和动量买Put；恢复结束后下一交易日接回当时动量权重。
- 固定核心腿与动量腿分别核算相同路由，同日同合约的经济数量可相加，不相互覆盖。

## 判定

`both_qd05`相对`fixed_only_qd05`须在真实挂牌层和理论延展层同时满足：CAGR不低于对照；Sharpe不低于对照0.05以上；最大回撤绝对值恶化不超过1个百分点；现金非负；核心与动量买Put在各自路由期间均为零，且退出日期不越界。

真实挂牌层为2022-09-19至2026-08-14；理论延展层为2015-04-16至2026-08-14。研究结果不修改生产、日报、账本、登记表或交易接口；完成后等待用户确认。
