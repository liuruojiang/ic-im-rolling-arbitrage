# IM 高波降仓 / Put替换匹配消融扫描 v2 预注册

预注册时间：2026-08-25（Asia/Shanghai）  
状态：研究候选；不改写冻结 `ic_im_system_mainlines_v2`，未批准实盘。

## 1. 目的

第一阶段发现35%-40% Put隐含波动率阈值在2022年以来真实样本中显著提高收益，但几乎没有改善最大回撤；显性Put交易手续费很小，不再作为主要否决门槛。本阶段用匹配消融回答：

1. 收益变化来自高IV时少持Put，还是来自核心IM降仓？
2. 更强、且波动率越高降仓越多的函数，能否真正改善尾部风险？
3. 结果是否在相邻IV阈值形成平台，而不是单一事件或单点最优？

## 2. 权威路径与数据

- 权威基线：真实 `outputs/ic_im_system_mainlines_v2/` IM完整路径。
- 复用 `freeze_ic_im_system_mainlines_v2._im_source_data`、`build_im_selected_schedule` 与 `im_mo_close_execution_v8.run_real_normal_close`。
- 波动率信号完整继承v1：T日真实CFFEX MO链中拟买的3个月、约95% Put收盘隐含波动率；T+1收盘执行。首个MO上市日不使用同日信号。
- 样本：真实CFFEX IM/MO可用区间2022-07-22至2026-08-14。10Y和5Y正式用户报告为N/A；机器表保留可用样本行。
- 固定网格保持独立；核心Call损益、成本、保证金和覆盖随核心同比缩放；IC不在范围内。

## 3. 匹配消融

同一数据、成本与执行时点比较：

1. `v2_baseline`：冻结动态Put，核心1倍。
2. `no_put_full_core`：全期不持Put，核心1倍。
3. `gate_only`：仅在高IV时把Put目标降为0，核心仍1倍。
4. `derisk_keep_put`：Put保持v2，仅在高IV时降低核心IM。
5. `replace_put_derisk`：高IV时Put目标降为0，同时降低核心IM。

`gate_only`拆出少持Put的贡献；`derisk_keep_put`拆出降仓贡献；`replace_put_derisk - gate_only`衡量在相同Put门控上增加降仓的边际贡献。

## 4. 参数网格

IV阈值：`30% / 32.5% / 35% / 37.5% / 40%`。

降仓函数只在 `IV > threshold` 时生效：

- `inverse_f50`：`scale=max(50%, threshold/IV)`。
- `linear5_f25`：`scale=max(25%, 1-5*(IV-threshold))`；IV每高5个百分点，核心约减25个百分点。
- `linear10_f25`：`scale=max(25%, 1-10*(IV-threshold))`；IV每高5个百分点，核心约减50个百分点。

不加入平滑、确认天数、滞后带、实现波动率或IV-RV价差；这些属于后续独立假设。

## 5. 执行与成本

- T收盘信号，T+1官方收盘改变Put目标和核心目标；执行日仍由旧核心权重承担当日收益，新权重从下一交易日生效。
- Put交易继续由正式真实执行函数产生；已有Put在门控开启时按正式函数退出，门控关闭时可重新进入。
- 期货核心缩放成本：`1bp × |核心权重变化|`；有Call时Call篮子缩放成本相同。
- 绩效资金按每1倍IM 30%保证金/缓冲，剩余现金净年化3%。15%只作为未由经纪商独立验证的操作可行性口径。
- 显性Put手续费、期货/Call缩放费完整报告，但不作为本阶段主要研究否决门槛。
- 不计买卖价差、收盘冲击、涨跌停无法成交、订单簿容量、动态保证金上调、税和整数合约取整。

## 6. 指标与完整性

- Full、3Y、1Y：CAGR、年化波动、repo Sharpe、MaxDD、最差5日/20日滚动收益、日收益5% CVaR。
- 10Y、5Y：机器行保留可用样本，用户报告N/A。
- 暴露：平均/最低核心权重、门控天数、核心换手、Put保护天数、Put成本、最低现金权重。
- 基线Put逐日复算误差不超过`1e-12`；检查T/T+1因果、IV缺失、收益恒等式、Call覆盖缩放和日收益不低于-100%。

## 7. 预先决策规则

真实历史不足5年，因此任何结果最多进入研究观察名单，不能修改冻结主线或生产/Poe。

### 防守型观察名单

同一模式和降仓函数至少两个相邻阈值同时满足：

- Full及3Y MaxDD均至少改善1个百分点；
- Full最差20日收益至少改善1个百分点；
- Full CAGR不低于基线超过2个百分点；
- Full Sharpe不低于基线超过0.05；
- 1Y MaxDD不得恶化超过1个百分点；
- 无资金或完整性违规。

### 收益型观察名单

若不满足防守条件，但至少两个相邻阈值在Full和3Y CAGR均高于基线、Full Sharpe高于基线、Full/3Y/1Y MaxDD均不恶化超过0.5个百分点，则标记`return_only_not_defensive`，只说明存在高波时减Put或降仓的收益现象，不解释为风险控制。

否则保持v2默认。模型/代理历史扩展只在真实消融选出稳定候选族后另行预注册，不能与真实结果混写。
