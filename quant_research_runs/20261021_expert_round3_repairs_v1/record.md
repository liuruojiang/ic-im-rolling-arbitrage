## 原日存证与恢复

新增 `ic_im_signal_evidence_v1.py` 和 `ic_im_evidence_adapter_v1.py`，须随 bot/server 完整分发。存证默认位于 StateStore 的 `root / input_evidence`，也可用 `ICIM_EVIDENCE_DIR` 指定。目录与策略 journal 分开；服务部署时应沿用已有持久化 StateStore 挂载。导入模块不采集或创建存证。

存证采用有大小上限的 JSON 类型编码、内容寻址 blob、SHA-256、不可覆盖 manifest 和原子发布，记录来源、参数、行情日期及真实获取时间；保留关键 HTTP 原始报文。恢复前再次核验日期、身份、价格、挂牌月份、利率来源及时间，不只验证文件哈希。不使用 pickle，不全局替换 `requests` 或共享依赖模块。

现有后台刷新循环在补录之后尝试独立采集，即使旧账本补录已受阻也可保留当天输入。每日有早收盘、17:30 后两个采集时段；未完整包允许后续重试。优先保留不可追溯的 IC 挂牌列表和链、MO 与期货报价，再处理日线等输入。每品种沿用 45 秒网络预算。部分失败保留已有证据并标为 incomplete，**不宣称部分包能够自动恢复**。健康信息披露最近采集结果；`ICIM_DISABLE_EVIDENCE_CAPTURE=1` 可禁用采集，测试运行器只在隔离测试时设置它。

历史 IC 月换只有在原日完整包满足角色、产品、输入 revision 和实际采集时点要求后，才解除原“无完整链归档”阻断。原日链不存在、错日、证券 ID 不匹配、错误利率来源、获取完成到了后日，均拒绝；从不改用当前链。原日 18:00 获取的晚间官方利率按原日真实运行时点使用，不伪装成 15:20 已知数据。

明确日期的历史开盘价可由既有 dated-open API 单独补证；补证标记 `original_close=False`、`dated_open_supplement`，保留后日实际获取时点，并在保存前后验证有限正数及允许来源。补证不把收盘价当开盘价，不给缺失的原日期权链补造身份。

新服务部署之前，此独立采集机制不会在现有运行服务中自行生效；本轮也没有补齐任何未来真实原日证据。缺少过去维护日证据时，仍须清楚报告不能自动恢复，按既有人工锚定流程处理。
