# IM 1.60/2.00 网格同步 V2 Put 对照 v22 预注册规格

冻结日期：2026-08-23（Asia/Shanghai）  
状态：预注册研究；未批准实盘。

## 1. 研究问题

用户已把 `1.60` 进入、`2.00` 退出作为当前网格研究标准。本版固定该网格，不再扫描阈值，只比较新增1倍IM是否同步当前V2动态Put。

本版只新增独立研究规格、脚本和输出，不改写现有V2冻结主线、首次正式输出或实盘接口。

## 2. 候选

每个数据/贴水情景包含三条路径：

1. `no_grid_core_put`：固定1倍IM，V2动态Put 0—4张，保留固定核心Call；
2. `grid_core_put`：1.60/2.00新增1倍IM，但Put和Call仍只覆盖固定底仓；
3. `grid_sync_put`：网格持有时Put目标按总IM单位从1倍扩为2倍，即V2目标0/1/2/3/4张变成总计0/2/4/6/8张；Call仍只覆盖固定底仓。

同步只改变Put数量，不改变V2信号、三个月期限、95%行权价、月度换约或T+1收盘执行。IM网格在T+1开盘成交，对应Put在同日收盘调整，新增Put在成交前不产生当日损益。

## 3. 数据层与贴水

- `model_no_basis`：2015-04-16—2026-08-14，中证1000全收益指数模型IM，不计贴水；Put为理论MO；Call为既有模型组件。
- `model_avg_basis`：同一模型路径，固定底仓与网格仓按审计日度几何平均基差 `0.00038985993765572324` 计入，对应几何年化 `10.321159572014937%`；Put和Call不因贴水改变。
- `real_actual_basis`：2022-07-22—2026-08-14，中金所官方IM/MO真实历史；IM收益本身已经包含实际基差，不再叠加平均贴水。

模型V2 Put目标和理论/真实组件来自 `im_roll50_momentum50_fullcycle_put_v1/v2`；真实V2目标与当前 `ic_im_system_mainlines_v2` 逐日核对。模型与真实的1.60/2.00网格状态分别复用v20和v19。

平均贴水来自上市后991日样本并回填全模型期，含明显前视信息。2015—2022的IM/MO不可执行，模型结果只能作为情景敏感性。

## 4. 收益、成本和资金

- 网格T日收盘信号、T+1模型/官方开盘成交；开平每边1bp，持仓随底仓换月双边2bp。
- Put T日信号、T+1收盘成交，继承既有理论/真实MO成本；真实交易腿必须有正收盘价、正成交量，新开仓必须有正持仓量。
- 固定核心Call损益、成本和保证金继承既有组件；网格仓不增加Call覆盖。
- 每1倍IM按30%保证金/风险缓冲；现金权重为 `1 - 30%×总IM单位 - Put市值 - Call保证金`，负值必须原样报告为资本穿透，不得裁剪仓位后宣称通过。
- 现金收益只对正现金按净年化3%计息；不含盘口价差、冲击、容量、涨跌停无法成交、动态保证金上调和税费。

## 5. 输出与决策

输出full、10Y、5Y、3Y、1Y的CAGR、波动率、Sharpe和MaxDD；真实层历史不足5年，10Y/5Y使用全部可用真实样本并明确标注覆盖不足。

同时输出四个1.60/2.00周期的局部MaxDD、Put损益/成本、最高张数、最高Put市值、日终/开仓早盘/Put收盘执行资金穿透和真实交易腿审计。

同步Put只有同时满足以下条件才视为有支持：

1. 模型和真实层均无执行资金穿透，真实交易腿审计通过；
2. `model_no_basis`、`model_avg_basis`和`real_actual_basis`中，full或3Y headline MaxDD均至少改善1个百分点；
3. 三个情景的最坏网格周期局部MaxDD均至少改善2个百分点；
4. 模型full/5Y/3Y和真实full/3Y的CAGR损失均不超过1.5个百分点。

任何一项不满足，保持网格Put只覆盖底仓。本版不得自动晋升参数或修改主线。

## 6. 强制完整性检查

1. V2基础Put模型/真实逐日组件与冻结来源最大误差不超过`1e-12`。
2. 不同步候选的网格状态、方向收益、成本、Call和资金字段逐日复现v20/v21/v19相应来源，允许差异仅为V2 Put替换与明确贴水项。
3. 同步目标严格等于基础V2目标乘总IM单位，最大8张；网格单位变化日必须存在同日Put执行日程。
4. 收益乘法成本、现金利息、净值、日期唯一性、T到T+1因果与Put交易价格完整性全部通过。
5. 参数研究工件完成`complete --strict`审计。
