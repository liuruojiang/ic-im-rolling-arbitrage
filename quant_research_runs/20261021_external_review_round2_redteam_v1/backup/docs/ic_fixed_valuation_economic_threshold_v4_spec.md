- 预注册日期：2026-08-18
- 性质：估值本体的固定高估门槛研究；不使用未来收益，不构成 PUT 保护回测或实盘授权。
- 前置权威版本：`ic_fixed_valuation_factor_structure_v3_1`。

## 1. 研究问题

v3.1 已按纯结构规则选择三因子等权作为透明估值本体。本版回答：

1. 三因子等权的固定原始风险分数在哪一段形成跨时间权重、跨历史时点且有足够重复事件的高估平台；
2. 每条候选线实际对应怎样的 PB、ERP、过去一年股息贡献组合；
3. 旧固定总分 `1.50/1.75/2.00` 与新等权门槛的覆盖率关系是什么。

本版不得用中证500后续收益、IC贴水、PUT损益、最大回撤改善或任何策略绩效选择门槛。

## 3. 固定分数定义

对每个时间半衰期，沿用v3.1已经冻结的三项风险分量：

- `PB风险`：PB越高越危险；
- `ERP风险`：ERP越低越危险；
- `股息风险`：过去一年已实现股息贡献越低越危险。

固定原始等权风险：

`equal3_raw = (PB风险 + ERP风险 + 股息风险) / 3`

本版门槛直接作用于 `equal3_raw`，不得使用v3.1对合成分再次做CDF后的 `normalized_risk`。因此门槛0.70的含义是三个分量风险百分位平均达到70%，而不是“合成分位于历史70%位置”。映射和门槛一经本版冻结，未来不得滚动重估后仍称为同一固定门槛。

## 4. 门槛网格与窗口

- 原始等权风险门槛：0.50—0.90，步长0.01，共41档；
- 时间半衰期：7.5、10、12年；
- 参数候选：123；
- 窗口：全样本、最近10年、5年、3年、1年；
- 扫描长表：615行。

扫描框架要求的年化收益、波动、Sharpe和最大回撤只允许填入同窗口中证500价格指数背景，并标记 `underlying_price_index_context_only_no_strategy_return`；同一窗口所有候选必须完全相同，不得参与门槛排序。

## 5. 高估候选的结构门槛

高估候选必须先满足 `threshold >= 0.67`。理由是：三个分量均在 `[0,1]` 时，均值至少0.67意味着不可能只有一个分量高于0.50，避免单一极端因子独自触发“高估”。

每条10年中心候选须同时满足：

1. 7.5年/10年和12年/10年月度状态Jaccard均不低于0.85；
2. 最近10年三个半衰期的月度启动率最大差不超过5个百分点；
3. 全样本月度独立启动段不少于5段，最近10年不少于2段；
4. 最近10年月度启动率在5%—30%之间，使其既是尾部状态又有可重复观测；
5. 全样本启动月中至少90%具有“不少于两个分量风险高于或等于0.50”；
6. 历史时点审计中，2016—2026所有时点的因果映射状态与最终冻结映射状态Jaccard最低不低于0.70，2019—2026最低不低于0.80；
7. 10年中心局部门槛带 `[threshold-0.02, threshold+0.02]` 至少有8个月末观测，可提供经济边界描述。

满足全部条件的相邻门槛须形成至少3个连续点，才称为结构平台。若有多个平台，选择点数最多的平台；点数相同选择门槛更高的平台。平台设计中心为上下界的网格中位点；偶数个中心点时取较低者，体现更早识别高估的保守取向。整个平台均保留，中心不是实盘阈值。

若没有平台通过，本版结论必须为“不选择固定高估门槛”。

## 6. 经济边界反解

每个门槛、每个半衰期输出：

- 局部门槛带内 PB、ERP、股息贡献的加权25%/50%/75%分位；
- 启动状态内三项原始值的加权25%/50%/75%分位；
- 月度向上穿越次数，以及穿越月份三项原始值的中位数；
- 启动月中至少两个分量超过0.50、超过0.60，以及三个分量全部超过0.50的比例；
- 全样本与五个标准窗口的日/月覆盖率、启动段数和最长连续月份。

等权阈值是一张三维边界面，不存在唯一的PB/ERP/股息三元组。报告只能给局部分布和穿越分布，不得把三个中位数误称为同时必须满足的硬门槛。

## 7. 旧固定总分交叉映射

复算旧 `25% PB档 + 50% ERP档 + 25%股息档` 的离散总分。对旧 `>=1.50/1.75/2.00`，分别在以下口径寻找启动率最接近的新等权门槛：

- 全样本月度；
- 全样本日度；
- 最近10年月度；
- 最近10年日度。

该结果只称“覆盖率等价”，不得解释为经济等价或收益等价，也不得用旧1.75强迫新平台包含某一点。

## 8. 历史时点因果审计

时点固定为2016—2025每年12月末及2026-08-17，共11个：

- 每个时点只用不晚于当时的月末历史重算10年半衰期风险映射和 `equal3_raw`；
- 对每个门槛比较因果映射状态与v4最终冻结映射在同一历史片段上的Jaccard；
- 记录因果启动率、最终映射启动率及局部经济边界中位数；
- 不连接或引用任何时点之后的收益。
