## 版本边界

- 父版本为v1.2。IC和IM都替换动量袖目标；IC继续明确无Call。
- IC动量与当前A股多头v1.3中证500执行权重一致：基础规则保持`MA110 / Mom24 / W2`、`Score>0`、`50% OFF + 50% Abs20>0`，并新增基础NAV回撤达到6%后目标减半。基础NAV计2%年化闲置现金收益和0.1%单边换手成本；成交量与高分清仓过滤关闭。
- IM动量与当前A股多头v1.3中证1000执行权重一致：`MA35 / Mom18 / W2.5`、`Score>0`、`50% OFF + 50% Abs20>0`，并依次应用前一信号日`Score>=150`清仓、`Volume/MA160>=0.85`和热身期通过条件。
- IM固定0.5倍核心、独立网格、Put/Call及成本口径继承v1.2；Put和Call只覆盖核心袖。救援期限仍为`rescue_next_listed`。
- 信号日在收盘后确认，目标于下一共同交易日执行。报告必须分别显示信号日、执行日、成交量比率、成交量门禁、极热门禁及盘中占位状态。

## 持久服务

长期入口为`poe_ic_im_v1_3_server.py`，状态实现为`poe_ic_im_v1_3_state.py`，容器入口为`Dockerfile.poe-v1.3`，Modal入口为`modal_poe_ic_im_v1_3.py`。当前构建号为`v1.3-20260903-r6`。

v1.3-r6使用独立目录`runtime/ic_im_v1_3_r6`、独立Modal Volume `poe-ic-im-v1-3-r6-ledger`和Secret `poe-ic-im-v1-3`。状态记录同时带`strategy_version=1.3`、`strategy_revision=r6`和`schema_version=3`；r5及更早记录不能直接载入。首次启用前必须运行`migrate_ic_im_v1_3_r5_to_r6_state.py`，完整校验r5哈希链并在同一核验日生成独立r6创世记录。旧账本只读且不被改写。

`poe_ic_im_mainline_v1_3_bot.py`保留单文件测试兼容，但无跨进程持久存储，不作为长期入口。Modal定时函数是唯一写入者；Web实例每次读取前刷新Volume并保持只读。

## 数据与执行门禁

- IC和IM动量必须取得完整OHLCV。收盘历史优先新浪，其次东方财富、腾讯；价格或成交量非法、日期重复/带时区、OHLC关系错误、成交量量级疑似字段错配均拒绝。
- 盘中当天累计成交量不能与全天MA160直接比较；未获核验时沿用上一已确认日作为占位，并明确标记`realtime_volume_placeholder`，不得写入收盘账本。
- IC/IM只有在同一交易日、全部逐腿数据完整、收盘确认后才整体写账。日期跳跃、部分成功、摘要损坏或来源冲突均保持上一快照。
- 中金所数据仅允许HTTPS。期货和期权挂牌、日期、代码、价格、成交量与持仓均须通过现有严格校验；失败时不得撤保护或推导替代目标。
- 每1倍期货按30%保证金/缓冲计绩效；15%只可作为未经经纪商独立验证的资金可行性上限，不进入本版本绩效。
