# IM 四档估值下 MOM120 负动量 Put 下限扫描 v3

预注册日期：2026-08-20（Asia/Shanghai）  
状态：结果生成前冻结。

## 研究问题

在 IM Put 已固定采用四档估值后，`MOM120 < 0` 时最低使用几张 MO Put 更合适？比较0/1/2/3/4张，不预设4张最优。

## 固定不变的系统

- 1倍核心滚动IM、0.85/1.25估值网格、IM Call规则、执行时点、成本与资金口径全部沿用冻结主线。
- Put绝对估值轴：`2.45 / 2.50 / 2.60`对应1/2/3张。
- Put相对估值轴：使用有效月以前最近57个月末估值，`75% / 85% / 90% / 92.5%`滚动分位数对应1/2/3/4张。
- 绝对估值档与相对估值档取较大值。
- 执行日加3个日历月为目标，取离目标最近的实际挂牌MO到期月，目标行权价/IM约95%；月度重置、不持有到期、不每日Delta再平衡；T收盘评估、T+1共同交易日官方收盘执行。
- 网格仓不增加Put；Call只覆盖固定核心底仓，`rescue_next_listed`语义不变。
- 绩效按每1倍期货30%保证金/风险缓冲及剩余现金净年化3%核算；15%仅作用户提供的操作资金可行性上限。

## 扫描参数

- `mom120_floor_qty = 0, 1, 2, 3, 4`。
- 仅在 `MOM120 < 0` 时生效；最终目标为 `max(估值档, mom120_floor_qty)`，上限4张。
- `3张`是此前规则的参考值；`4张`是用户提出的新候选；0/1/2张用于完整刻画边际效果。

## 样本与报告

- 使用真实IM期货、MO期权、中证1000指数、估值数据和正式执行函数。
- 报告全样本、近10年、近5年、近3年和近1年；若样本不足10年，近10年自动等于可用全样本并明确记录。
- 指标：CAGR、年化波动、仓库口径Sharpe、最大回撤、Put成本、最大Put市值占比、最低原始现金权重、15%操作口径最大日终资金占用、负动量触发天数、下限真正绑定天数、4张暴露天数/事件数和交易事件数。

## 强制审计

1. v1三张旧基线路径复算与冻结日收益误差不超过`1e-12`。
2. 四档滚动阈值只能使用生效月以前数据。
3. `mom120_floor_qty`只改变负动量下限，估值、网格与Call组件保持不变。
4. 所有计划均为T+1执行，实际成交不得早于计划执行日。
5. Put逐日持仓必须与真实交易事件一致；最终张数只允许0/1/2/3/4。
6. 15%操作口径最大日终资金占用不超过100%，但不把15%解释为经纪商已验证事实。

## 决策方法

- 不用单一窗口或单一指标机械选优。
- 先比较3张与4张的全样本、近5年、近3年和近1年CAGR、Sharpe与最大回撤，再查看0/1/2张的单调性和边际变化。
- 若4张相对3张在主要窗口改善最大回撤且Sharpe不下降，并且收益与资金占用可接受，则支持4张；否则保留3张或选择更低档。
- 必须报告稳健性邻域，不能只报告胜者。
