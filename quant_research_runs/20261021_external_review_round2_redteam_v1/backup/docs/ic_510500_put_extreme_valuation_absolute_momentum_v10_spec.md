# IC + 510500 Put 极高估或绝对动量保护 v10 预注册规格

- 版本：`ic_510500_put_extreme_valuation_absolute_momentum_v10`
- 预注册日期：2026-08-17，Asia/Shanghai
- 状态：研究回测；未获准实盘；不得解释为交易建议或接入自动/人工下单
- 估值母版：冻结的`ic_510500_put_extreme_valuation_gate_v9`固定1.75分支
- 执行母版：冻结的`ic_510500_put_persistent_stress_hold3m_v7`三个月Put持有到期引擎
- 证据边界：2015—2026历史已被多轮研究使用，本版没有独立OOS；任何通过最多为`watchlist`

## 1. 研究问题

v9的固定1.75与动态75%在2015年显著改善尾部风险，却在2021-09-13至2024-02-05全部为0保护。提高估值阈值只能识别泡沫起点，不能识别估值已下降但价格趋势仍持续恶化的熊市。

v10只增加一条简单、独立、因果的熊市入口：中证500全收益指数的中期绝对动量转为非正。最终信号为：

> 固定极高估1.75成立，或中期绝对动量不高于冻结阈值，则启动100%三个月Put；买入后持有到期。

本版不增加波动率、回撤、宽度、宏观、Put价格、预测概率、确认天数、止损、止盈或多档仓位。

## 2. 固定极高估入口

完全复现v9的`fixed_175`：

- PB：`<2.00 / 2.00—2.50 / >=2.50`映射为0/1/2；
- ERP：`>3.00% / 1.50%—3.00% / <=1.50%`映射为0/1/2；
- 过去一年股息贡献：`>=2.00% / 1.00%—2.00% / <1.00%`映射为0/1/2；
- `fixed_risk = 25%×PB档 + 50%×ERP档 + 25%×股息档`；
- `fixed_risk >= 1.75`时极高估入口开启。

PE通过ERP中的盈利收益率间接进入，不另加PE权重，避免重复计数。

## 3. 绝对动量入口

在每个交易日T，用中证500全收益指数收盘计算：

`absolute_momentum(H) = TRI_close(T) / TRI_close(T-H) - 1`

- H严格指交易日观察数，不是自然日；
- 只使用T日及之前已经存在的官方/回溯全收益指数序列；
- 主规则冻结为`H=120，absolute_momentum<=0%`，约等于六个月绝对动量；
- T日收盘确认，T+1第一个IC交易日开盘执行；不使用T+1价格反算T日信号；
- 正值表示过去H日全收益上涨，非正表示中期绝对趋势转弱。

选择120日而非单纯“跌破均线”，是为了让阈值具有直接经济含义：过去约六个月持有指数的绝对收益是否已经为负。60日用于更快但更易反复的邻点，240日用于更慢的邻点。

## 5. Put执行与资本口径

- 信号只有0%或100%；两条入口取逻辑“或”，不叠加成200%；
- 一次只持有一个目标3m Put批次，不在IC月滚日更换；
- 已买入Put不因估值或动量恢复而提前卖出/减仓，持有至到期；
- 到期日收盘按内在价值结算；下一交易日只有最新组合信号仍开启才续保；
- 模型执行价为执行日中证500现货开盘的85%；真实层使用目标月份中开盘价、成交量均为正的最低行权价510500 Put；
- IC为100%名义，30%保证金/缓冲，70%现金年化3%，不放大到3.33倍；
- Put市值从可计息现金扣除；IC与Put每边1bp，到期结算不另收卖出边摩擦。

模型样本2015-04-16至2026-08-14；真实Put样本2022-09-19至2026-08-14；Asia/Shanghai交易日。2015—2022模型Put不是历史可成交报价，真实Put第三方日线也不是盘口成交保证。

22条路径必须报告含70%现金的CAGR、年化波动、Sharpe和最大回撤：全样本、最近10年、5年、3年、1年；真实层不足10年/5年显示N/A。

额外报告：

- `development`：2015-04-16至2020-12-31；
- `revision_validation`：2021-01-04至2024-12-31；
- `recent_expansion`：2025-01-02至2026-08-14；
- 2015部分年度、2021-09-13至2024-02-05已知熊市、2022和2024赔付窗口、2025—2026；
- 组合相对`fixed175_only`的增量贡献，以及组合相对`mom120_only`的估值入口贡献；
- 信号目标、实际保护、Put损益、成本、交易次数、平均真实入场虚值度和生命周期。

## 7. 完整性门槛

1. 无Put、v7压力保持前月、v7压力保持3m持有、永久100%与v9正式产物逐日匹配，最大误差不超过1e-14；`fixed175_only`也与v9固定1.75逐日匹配。
2. 22条路径齐全，无重复日期、未来信号、负执行延迟、缺失收益或收益不大于-100%。
3. 绝对动量逐日精确等于全收益指数T日收盘除以T-H日收盘减一；修改未来数据不得影响历史信号。
4. 组合信号逐日精确等于`fixed175_only OR momentum_condition`，且只取0/1。
5. QVIX代理继续通过；永久100%有真实头寸、成本和非零市值。
6. 模型永久完整批次除边界外100%覆盖3次IC换月，真实完成批次至少90%覆盖3次；无提前卖出/减仓，续保最大顺延不超过5个交易日。

完整性失败为`rerun_required/data_sensitive`，不得解释绩效。

## 8. 预注册绩效判断

每个五条组合候选必须同时满足：

1. 相对同层无Put，模型全样本最大回撤改善至少3个百分点，CAGR落后不超过1个百分点。
2. 相对模型无Put，`revision_validation`最大回撤改善至少3个百分点，CAGR落后不超过1个百分点。
3. 五个强制窗口至少3个最大回撤改善为正；全/10年/5年CAGR落后不超过1个百分点，3年/1年落后不超过3个百分点。
4. `development`与`recent_expansion`各自CAGR落后不超过1个百分点，最大回撤不得恶化超过1个百分点。
5. 相对`fixed175_only`，`revision_validation`最大回撤改善至少3个百分点，CAGR落后不超过1个百分点；这判断新增动量层是否真正修复2022—2024缺口。
6. 模型至少20个实际保护日、至少2次启动，且2021-09-13至2024-02-05平均信号目标不少于50%。
7. 真实层至少20个实际保护日；真实全样本最大回撤改善至少0.5个百分点，CAGR落后无Put不超过1个百分点。
8. 至少一个预先定义的阈值或周期邻点也通过以上单线门槛。

若无人稳健通过，决定为`keep_default/reject`。若主规则与至少一个邻点通过，最多`watchlist/narrow_stable`；主规则与阈值两侧或周期两侧形成平台时最多`watchlist/wide_stable`。本版没有独立OOS，不得直接`promote_candidate`。
