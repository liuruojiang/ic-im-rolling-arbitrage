# IC Put 污染后重建：第十二层卖 Put 行权价 ATM vs 95% V1 预注册

## 研究问题

当前 `q_delta05` 的含义是卖出95%虚值 Put，再按开仓前一日合约Delta调整张数，使每1倍IC对应的初始卖方绝对Delta约为0.5；它不是直接卖一张0.5 Delta平价 Put。

本层在相同总初始Delta下比较：

- `strike95_qdelta05`：选择行权价最接近ETF前收盘95%的M+1 Put，再按Delta配量；
- `atm_qdelta05`：选择行权价最接近ETF前收盘100%的M+1 Put，再按Delta配量。

## 隔离原则

- 两组使用完全相同的修正后95%信号合约IV>30%准入日期，以隔离执行行权价差异；不使用各自合约IV重新筛选。
- 固定核心买Put 3倍盈利兑现、卖方不加MOM120、即时估值、持有到期、无相对IV和灾难Put。
- IC不含Call；只替代固定核心0.5倍IC及核心Put，动量腿和网格不变。
- 真实层Delta使用开仓前一交易日挂牌链字段；理论层使用前一交易日市场输入计算Black-Scholes Delta。禁止使用执行日信息定数量。

## 成本与对照

- 所有510500 Put单边5bp；IC单边1bp；每1倍期货30%缓冲；现金年化3%。
- 无卖 Put对照固定相同完整组合和核心Put 3倍兑现。
- 95%路径必须逐日复现第十一层IV30%/Delta 0.5中心。

## 判定

ATM只有在真实挂牌层和理论延展层相对95%路径同时满足以下条件时，才可替换95%：

1. CAGR不低于95%；
2. Sharpe相对95%不低于-0.05；
3. 最大回撤绝对值恶化不超过1个百分点；
4. 现金权重不低于0；
5. 有实际入场事件，且账本误差通过。

同时报告两组相对无卖 Put对照、入场单合约Delta、数量倍数、真实张数、到期实值交割次数和恢复路径。真实挂牌层为2022-09-19至2026-08-14；理论延展层为2015-04-16至2026-08-14。研究结果不修改生产、日报、账本、登记表或交易接口；完成后等待用户确认。
