# IC v1.3-r6 完整换仓日扫描 v1 预注册

- 唯一主研究变量为近月 IC 到期前换仓交易日，目的合约仍为下一实际挂牌月；不测试季度持有。
- 主路径：正式到期日结算基线；到期日收盘 T0 对照；T-1/T-2/T-3/T-5/T-10 收盘执行。T-k 指旧合约实际最后交易日前 k 个交易日。
- 完整保留 0.5 核心、0.5 动量（含正式信号/NAV防御）、估值网格、核心和估值-only动量Put目标；IC不含Call。主路径的Put月度重置随候选IC换月日移动，执行可用性/延期继续由正式Put引擎处理。
- 追加五条同一期货T-1/2/3/5/10但Put月度重置仍用正式日历的诊断路径，用于区分期货换仓与Put重置影响，不参与主规则排名。
- IC每日盯市仍用官方结算；收盘换仓日按旧昨结至旧收盘、加新收盘至新结算分段收益记账，不能把旧结算收益当成收盘成交收益。网格在换仓日同样处理桥接，网格开平仍T+1官方开盘。初始核心期货收益为0，沿用正式初始化。
- 初始1bp、每次换仓双边2bp，交易成本压力为1/2/5倍期货成本；Put费用不变。30%保证金/缓冲，剩余现金3%年化。不声称日线收盘必能成交；无盘口、冲击、涨跌停队列或动态保证金模型。
- 数据固定：CFFEX逐合约IC 2015-04-16至2026-08-14，510500真实Put自2022-09-19；此前Put为模型数据。全/10Y/5Y混合历史单列标识，真实Put期、3Y、1Y另行报告，不把模型期称为真实成交。
- 固定基线必须逐日复现正式r6收益/现金/仓位至1e-12；基线grid/IC行情也要parity。候选必须实际挂牌，换仓双方价格/成交量有效，新合约持仓量>0（旧到期合约持仓量为0不代表无成交）。缺失与不可成交不得静默填充。
- 优选要求相对正式基线和T-3：Full、3Y、真实Put期CAGR不低，Full与真实期最大回撤不额外恶化超过1个百分点，并检查年度集中、相邻参数和成本压力。不能只凭Full最大值选择。
- 只新建研究文件，不编辑现有源引擎、冻结规格、首次输出、Poe/邮件/账本或实盘授权。任何执行或目标变更均不发布。
