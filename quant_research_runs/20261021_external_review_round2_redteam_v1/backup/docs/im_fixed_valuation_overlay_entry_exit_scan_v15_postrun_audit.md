# IM 固定经济估值增仓开仓/退出阈值扫描 v15 运行后审计

日期：2026-08-19（Asia/Shanghai）  
状态：研究否决；未批准实盘。

## 结论优先

1. 144组固定经济分数滞回线没有一组同时通过预注册门槛，正式决定为 `no_fixed_threshold_candidate / reject`；硬门槛0组、严格四邻宽度0组。
2. 否决不是因为增仓没有收益。140/144组通过模型收益门槛，全部144组的模型 full Calmar 都高于固定1倍底仓；真正的问题是回撤：模型风险门槛0/144、真实样本交叉门槛0/144。
3. 真实层固定1倍 IM+主线 Put 为16.99% CAGR / -16.35% MaxDD；全部固定增仓候选的真实 MaxDD 落在 -31.10% 至 -39.03%，即至少恶化14.75个百分点。低估增仓显著提高收益，但没有复现 IC 网格“几乎不拖累回撤”的特征。
4. 57个月相对分位诊断仍只有一次周期。`P25/P75`真实层为26.97% / -39.03%，同样表现为收益增加、回撤显著加深，不能解决固定轴问题。
5. 55条固定候选在模型层至少一次遇到“新增 IM 开仓时，已有长期 Put 市值加60%保证金超过静态初始资本”的情形，全部被资本门槛淘汰；真实层没有这类穿透。普通持有日 Put 上涨后的市值超过40%现金只记录，不误判为追加现金。

## 为什么预注册门槛全部失败

| 门槛 | 通过数 / 144 | 解释 |
| --- | ---: | --- |
| 资本可执行 | 89 | 55条在模型新增仓开仓日发生静态资本穿透 |
| 事件与状态 | 72 | 要求模型至少2个完成周期、跨2个开仓年份、持有不超过70%，真实至少1个周期 |
| 模型收益 | 140 | 大多数增仓线显著提高收益 |
| 模型风险 | 0 | 所有候选在full/10Y/5Y至少一个窗口回撤恶化超过3pp；同时底仓full本身为-54.21%，使-40%绝对上限无法通过 |
| 真实交叉 | 0 | 所有候选真实full回撤至少从-16.35%加深到-31.10% |

模型 full 的 -40% 绝对上限对本层没有区分力：2015年最大回撤发生在估值增仓首次启动前，固定底仓自身已经是 -54.21%。即使删除这条上限，仍没有候选同时满足 full/10Y/5Y 相对底仓回撤最多恶化3个百分点；因此否决不依赖这一个规格缺陷。

## 交易路径说明

`1.40/2.10`模型与真实共同可观察的主要周期为：

- 2022-04-26低估触发，2022-04-27开盘买入；2022-06-27恢复至2.10以上，2022-06-28开盘退出。该段发生在真实 IM 上市前，只存在模型层。
- 2024-01-22低估触发，2024-01-23真实活跃 IM 开盘买入；直到2026-01-12估值恢复，2026-01-13开盘退出。

第二段覆盖了2024年低估后继续下跌以及后续修复，说明“估值已经低”不能阻止价格继续走弱；新增1倍 IM 在低估区仍然把方向暴露从1倍放大到2倍，这就是回撤从 -16.35%加深到 -31.10%的主要原因。

`1.90/2.30`虽在真实层完成2次退出，但2022-07-22上市时承接了上市前已经启动的持仓，一直持有至2026-02-26；随后2026年3—4月又完成一次短周期，并在7月31日再次开仓。更宽松的开仓阈值没有解决长期双倍暴露和回撤问题。

## 对下一层的含义

- 不能直接进入“新增仓同步 Put”层：当前问题首先是低估后过早承受2倍方向风险，而不是新增仓缺少一份 Put。同步 Put 会同时引入成本、资本和流动性，不能修复开仓时机的根因。
- 唯一仍有经济逻辑的简单改进，是把已经冻结的 MOM120 用作低估后的趋势确认：低估只负责进入“允许增仓”状态，MOM120 转正后才买入；MOM120 再转负或估值达到退出阈值时退出。该层必须使用新版本、重新预注册，不能在 v15 内追加。
- 若趋势确认仍不能把真实回撤控制在接近底仓的范围，IM估值网格子系统应当终止，不再通过更复杂规则寻找偶然组合，转向 IM 卖 Call 子系统。
