# IC 分层研究第五层：网格坚韧性检验 v1（预注册）

## 研究目标

不再叠加任何新模块。固定 `50%裸滚IC + 50%动量门控IC` 及“Put只保护裸滚50%”作为主要底座，对 IC 估值网格做三项坚韧性检验：

1. 默认 `0.375/1.000` 三个估值周期的逐周期归因；
2. 默认网格逐周期留一剔除（leave-one-cycle-out）；
3. 入场/退出阈值邻域扫描，并分别测试独立网格与动量指导网格。

不测试 Call，不调整动量或 Put，不把本轮结果自动写入冻结主线。

## 基线与候选

- 共同底座：第二层 `put_bare50_only` 无网格路径。
- 控制：`bare_put_no_grid`。
- 入场阈值：`0.250 / 0.375 / 0.500`。
- 退出阈值：`0.875 / 1.000 / 1.125`。
- 网格模式：`independent / guided`。
- 共 `1 + 3×3×2 = 19` 个候选；默认点 `0.375/1.000` 必须在同批次中。

## 固定执行

- 估值信号 T 日收盘生成，T+1 交易日按活跃 IC 官方开盘价执行。
- 网格新增 1 倍 IC；普通持仓日按前结算至当日结算，开/平仓日按开盘切分；持仓随 IC 换月。
- 每边成本 1bp，持仓换月双边 2bp；每 1 倍新增仓使用 30% 保证金/风险缓冲，剩余现金净年化 3%。
- 独立网格不看动量。
- 动量指导网格仅在已落地 `momentum_weight>0` 时允许完整1倍买入；权重归零时以当日开盘退出；0.5与1均允许；新增网格仓不加 Put。
- 未计盘口冲击、开盘不可成交偏差、动态保证金上调和容量约束。

## 数据与基线复现

- IC：中金所官方活跃合约开盘/结算价，2015-04-16—2026-08-14。
- 估值分数：冻结中证500无界固定经济单位二取三中位数。
- Put：2015-04-16—2022-09-16为QVIX/Black-Scholes理论层，2022-09-19起为真实510500ETF Put。
- 默认独立网格与默认动量指导网格必须逐日复现第四层正式结果，误差不超过`1e-12`；无网格控制也必须复现。

## 逐周期与留一检验

- 默认独立网格的周期由一次买入至对应一次卖出界定；预期三次完整周期。
- 保存每周期起止、交易日、网格袖复合收益、最大回撤、对底座累计收益贡献及动量允许比例。
- 留一剔除时，只将指定默认估值周期内的网格袖置零，其余日期、底座、Put、成本及现金口径不变；独立与指导模式分别重算。
- 对每种模式，以默认网格相对无网格的全周期年化增量为100%；剔除任一周期后仍保留至少50%的原增量，视为留一通过。

## 邻域连续性与决定规则

- 每个模式的9个阈值点中，若至少6个同时满足：
  1. 全周期年化收益高于无网格；
  2. 全周期最大回撤较无网格恶化不超过3个百分点；
  则该模式邻域宽度通过。
- 默认点逐周期绝对收益贡献中，最大单周期占比不得超过50%；独立与指导分别检查。
- 只有邻域宽度、逐周期集中度和留一检验全部通过，网格才可进入`watchlist`；仍不直接晋升主线。
- 任一事件集中度或留一条件失败，则决定为`keep_default`（维持无网格核心），稳定性标记为`data_sensitive`；若邻域本身也失败，可标记`peak_only`或`reject`。

## 输出

- 标准参数扫描产物：`scan_summary.csv`、`window_metrics.csv`、`scan_meta.json`、`record.md`、`command_log.txt`。
- 补充：逐日候选、默认周期归因、留一周期结果、阈值表面、交易事件、基线复现和完整性检查。
- 必须运行严格产物审计与仓库测试；结果仅为研究证据，不修改生产或冻结主线。
