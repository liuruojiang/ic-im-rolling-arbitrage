# IC + 510500 Put 双层验证 v1：预注册规格

冻结日期：2026-08-16  
研究状态：真实短样本交叉验证 + 模型长样本压力测试；未获准实盘

## 1. 研究问题

本版检验IM研究中出现的“周评估值 + 约2个月Put”是否能在中证500体系复现，并明确区分两类证据：

1. `real`层：2022-09-19以来，使用真实IC展期收益和上交所510500 ETF Put实际历史价格，回答跨标的复现问题；
2. `model`层：2015-04-16以来，使用真实IC展期收益、中证500真实路径和因果波动率输入生成理论Put，回答长历史压力测试问题。

510500与159922期权均于2022-09-19上市，因此`real`层不能提供2015年以来期权历史。`model`层必须始终标为模型代理，不得冒充真实可交易回测。为避免只展示有利结果，真实层完整运行`3个评估频率 × 3个期限 × 2种档位`18组；模型层再完整加入`80%/85%/90%`三档固定入场虚值度，共54组。

## 2. 基线与候选

- 方向基线：冻结的`outputs/ic_monthly_discount_roll_v1/daily_nav.csv`中`ic_net_ret`，1倍IC名义、不使用保证金放大。
- 评估频率：`monthly`、`weekly`、`daily`。
- Put期限：`front`、`2m`、`3m`。
- 档位：
  - `binary`：3年类比全收益年化中位数小于0时保护100%，否则0%；
  - `three_tier`：预测`>=3%`保护0%，`0%—3%`保护50%，`<0%`保护100%；少于4个有效类比时保护0%。
- 模型虚值度：入场执行价为当时中证500指数开盘值的`80%/85%/90%`，85%为预先指定主口径，80%与90%只作对称敏感性，不得按结果改选主口径。

真实层候选标签为`real_<frequency>_<tenor>_<tier>`；模型层为`model_m80/m85/m90_<frequency>_<tenor>_<tier>`。每层另设同区间`no_put`基线。

## 3. 数据与样本

### 3.1 共同基础

- IC逐月到期展期：中金所官方月合约结算价，沿用冻结IC v1及其日收益、成本和合约日历。
- 中证500价格/全收益：中证指数官方`000905`与`H00905`收盘；盘中开盘使用新浪`sh000905`OHLC，并与官方收盘逐日交叉核验。
- 估值：乐咕乐股000905日度PE/PB、中证官方价格与全收益指数、中债10年国债；冻结月度锚点沿用`ic_im_valuation_risk_premium_forecast_v3`。
- 时区：Asia/Shanghai；只使用IC实际交易日，不填充缺失交易日。

### 3.2 真实510500 Put层

- 正式诊断区间：2022-09-19至2026-08-14，取IC、510500 ETF和期权价格共同可用日。
- 合约主表：上交所历史期权风险指标接口；只使用`510500PYYMM...`标准`M`合约，排除分红调整`A`合约，避免未知合约单位。
- 价格：新浪逐合约历史日线的open、close、volume；标的ETF为新浪`sh510500`未复权日线。
- 上交所历史接口不提供本研究需要的逐日持仓量，因此真实层流动性条件冻结为`open>0且volume>0`，不得伪造open_interest字段。该层为第三方日线诊断，不是官方结算价或盘口回测。

### 3.3 模型Put层

- 正式诊断区间：2015-04-16至2026-08-14。
- 50ETF QVIX：AKShare `index_option_50etf_qvix`，源数据从2015-02-09起；500ETF QVIX只用于2022-09-19后的代理验证。
- 50ETF价格：新浪`sh510050`未复权日线，仅用于计算滚动实现波动率比例。
- 理论Put为欧式Black-Scholes Put；它不代表任何真实历史510500合约、报价或成交。

所有下载文件在正式运行前冻结到`data/ic_510500_put_proxy_validation_v1/`并记录SHA-256；正式脚本只读缓存，不在回测阶段刷新网络数据。

## 4. 日度估值与因果信号

- 估值特征为PE、PB、`ERP=1/PE-截至T可知的最近10年国债收益率`、过去一年已实现股息贡献。
- 历史相似锚点仍只使用冻结月末状态。非月末T只把T的真实日度状态加入截至T历史，用于当前因果百分位与距离。
- 锚点必须满足`锚点+3年<=T`，最多8个、彼此至少间隔12个月；结果终点不得晚于T。
- 月评使用每月最后一个IC交易日，周评使用每个`W-FRI`周的最后一个IC交易日，日评使用每个IC交易日；均为T收盘计算、下一IC交易日开盘执行。
- 频率提高不等于每天交易。只有目标保护比例改变、目标到期月份改变或旧Put到期时才调整。

## 5. 到期月份

- ETF期权到期日按到期月第四个星期三；若不是共同交易日，顺延至下一共同交易日。
- `front`：执行日后最近到期月份。
- `2m`/`3m`：在当时已挂牌月份中，选择实际到期日与估值日T后2/3个自然月距离最近者；并列选较晚月份。
- 真实层的已挂牌月份以当日上交所主表为准。模型层按上交所标准月份结构模拟：当月、下月及随后两个季月。
- 因旧Put到期而在非评估日补仓时，以补仓执行日加相应自然月重新确定2m/3m目标。

## 6. 真实Put选择、数量与估值

- 在目标月份标准`M`认沽中，按执行价从低到高检查，选择执行日`open>0且volume>0`的最低执行价Put；不使用未来成交判断。
- 新仓100%保护张数为`round(IC开盘近似名义 / (510500开盘价×10000))`，至少1张；50%为该张数的一半四舍五入。IC开盘近似名义使用当日活动IC结算点位×200，避免引入缺失的期货开盘拼接字段。
- 同一合约且保护档位不变时不因轻微名义漂移再平衡；档位改变或换月时重算目标张数。
- 入场/退出使用期权官方代码对应的新浪开盘价；普通日使用收盘价。无当日成交记录时沿用最近已观察收盘作诊断估值并标记；不得用未来价格回填。
- 到期日Put价值强制为`max(K-ETF收盘,0)`；标准合约单位固定10000份。到期不假设开盘卖出，也不收退出成本。
- 调整日若旧Put或新Put缺少正开盘价/正成交量，整笔调整延迟，继续按最近收盘估值；最新估值指令覆盖旧指令。

## 7. 模型Put定价

理论Put输入：

- 标的`S`：开盘用新浪中证500开盘，收盘用官方中证500收盘；两源收盘相对差必须审计。
- 执行价`K`：新建/换月时固定为执行日开盘`S×moneyness`，持有期不变。
- 无风险利率`r`：开盘只使用前一交易日已经可知的最近中债10年国债收益率；收盘使用截至当日可知的最近值。
- 股息率`q`：开盘用前一交易日、收盘用当日的过去一年已实现股息贡献，非负截断；这是诊断性预期股息代理。
- 隐含波动率代理：`sigma_proxy = 50ETF_QVIX × RV60_CSI500 / RV60_50ETF`。RV为截至该时点的60个交易日日对数收益年化标准差；开盘使用T-1比例，收盘可使用T收盘比例；不使用未来数据、不做结果后上下限裁剪。
- 若当日QVIX开盘缺失，开盘只可向后查找此前最近QVIX收盘；收盘只可向后查找截至当日最近QVIX收盘，并记录陈旧天数。
- 到期价值为`max(K-S,0)`。保护单位在建仓时固定为`当时IC名义/S_open`的100%或50%，换月或档位改变时重算。

调仓损益与真实层相同：旧Put计前收盘至卖出开盘，新Put计买入开盘至当日收盘；普通日收盘到收盘。

## 8. 波动率代理和真实层校验门槛

在不参与参数选择的2022-09-19后共同区间，先检验`sigma_proxy`与500ETF QVIX收盘：

- Pearson相关系数至少0.60；
- 中位绝对误差不超过5个波动率百分点；
- 中位有符号误差绝对值不超过3个百分点。

若任一门槛失败，2015年以来模型层只能报告为`weak_proxy`敏感性，不能用于支持或否定频率/期限结论。

另比较真实层18组与模型85%层同区间的候选CAGR横截面Spearman相关；相关至少0.50且“周评2个月相对月评3个月”的方向在二档、三档中至少一条一致，才把模型层称为结构交叉验证。否则模型长样本只保留为情景压力测试。

## 9. 成本、现金与收益

- IC收益及每边1bp成本完全沿用冻结IC v1。
- Put交易成本按IC名义比例计：100%保护每买或卖一边1bp，50%为0.5bp；换月为卖旧加买新。到期归零/结算不收假设卖出成本。
- 不额外假设盘口冲击；真实层开盘价不证明容量，模型层更无成交含义。
- 70%现金按年化3%计息，并逐日扣除Put盯市权利金占IC名义的比例；现金权重下限为0。
- 不把30%保证金放大为3.33倍方向敞口，不计追加保证金、税费、行权/结算费和ETF申赎摩擦。

组合日收益为冻结IC净收益加Put损益，再按乘法扣Put交易成本；现金贡献另行加入。所有候选同时报告不加现金和加现金结果。

## 10. 强制输出与判定

- 真实层与模型层分别报告全样本、最近10年、5年、3年、1年CAGR、年化波动、Sharpe和MaxDD；不足窗口显示N/A，模型层不得与真实层窗口混写。
- 展示年度结果、保护暴露、交易次数、累计成本、延迟、缺失估值携带比例、平均入场虚值度和权利金占用。
- IC无Put基线必须在各层共同区间逐日复现冻结IC v1，最大绝对误差不超过`1e-14`。
- 信号、交易、类比结果均不得使用未来信息；逐日收益、费用、现金权重和净值恒等式误差不超过`1e-12`。
- 事件集中度至少展示最佳候选相对月评3个月二档的最大单日、前5个正贡献日和逐年相对因子。

主判断顺序：

1. 真实层是否复现IM中周评2个月相对月评3个月的方向；
2. 模型85%层的全样本、10年、5年是否同向；
3. 80%/90%相邻虚值度是否形成支持，而非85%单点；
4. 最近3年/1年与事件集中度是否否定全样本印象。

由于真实期权样本短、价格来自第三方日线且模型层不是实价，本版任何结果最多为`watchlist`，不得自动晋升或接入实盘。若模型校验失败，决定必须为`rerun_required`或保留纯诊断；不得修改RV窗口、QVIX缩放、虚值度或门槛追救本版。
