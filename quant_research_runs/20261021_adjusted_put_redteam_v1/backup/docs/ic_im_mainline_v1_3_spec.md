## 1. 范围

本版本以 `ic_im_mainline_v1_2` 为父版本。IC腿完整复用 `ic_mainline_v1_2`，逐日目标、收益、Put、网格与IC无Call规则必须零差异。IM腿使用 `im_mainline_v1_3`，只把动量目标升级为当前A股多头v1.3中证1000完整过滤链。

## 2. IM升级

IM保留 `MA35 / Mom18 / W2.5`、`Score>0`和`50% OFF + 50% Abs20>0`，新增：

- 信号日 `Score>=150` 时下一执行行清仓；
- `Volume/MA160>=0.85`才保留信号，160日暖机未就绪时放行；
- 最终权重只允许0/0.5/1，且在下一共同交易日执行。

完整定义以 `docs/im_mainline_v1_3_spec.md` 为准。

## 3. 不变项与权限

不定义IC与IM之间的资本分配，不跨品种净额结算，不生成订单。IM固定核心、网格、Put/Call、成本、现金和保证金口径均继承v1.2。冻结V2仍是登记表默认研究主线；本版本不构成自动或人工下单授权。

## 4. 强制验证

1. IC目标、收益和事件对v1.2逐日误差为0。
2. IM最终动量执行权重对当前A股v1.3 `zz1000`权威路径逐日误差不超过`1e-12`。
3. IM核心、网格、Put/Call逐日不变，Put可解释延迟事件保留且未解释差异为0。
4. 本地、Poe、服务、独立v1.3账本和日报使用同一规则；盘中不可写账本。
5. 参数页、信号页和表现页明确披露Score150、MA160/0.85、T+1与研究权限。
