# IM 动量门控滚动 v1 预注册规格

日期：2026-08-22  
状态：研究预注册；未批准实盘

## 用户澄清后的唯一策略结构

本版不是两条策略的组合，也不扫描滚 IM 与动量策略的资本比例。

动量策略只负责决定 IM 目标仓位：

- 动量目标为 1：持有 1 倍 IM，并在需要时滚动；
- 动量目标为 0.5：持有 0.5 倍 IM，并按 0.5 倍仓位滚动；
- 动量目标为 0：不持有 IM、不发生换月，资金全部处于现金层。

本版不含 Put、Call、估值网格、方向网格或其他保护/增强信号。

## 固定动量信号

- 中证1000价格指数；
- `MA35 / Mom18 / W2.5`；
- 原始方向条件：`Score > 0`；
- 绝对动量采用已经固定的 50% OFF + 50% 静态 `Abs20 > 0`；
- 目标仓位为 `0.5 * I(Score > 0) + 0.5 * I(Score > 0 and Abs20 > 0)`；
- T 日收盘确认信号，T+1 个共同交易日使用该目标仓位；不扫描任何信号参数。

## 数据与样本

- IM：中金所官方逐月历史包，使用官方结算价；
- 信号：中证指数有限公司官方中证1000价格指数 `000852`；
- 信号历史从 2014-10-17 起暖机；正式可执行样本从 IM 上市日 2022-07-22 起；
- 正式截止日取 IM 与官方指数共同确认的最近交易日；
- 时区 Asia/Shanghai；不使用全收益指数生成信号；
- 因 IM 历史不足，10年和5年窗口必须显示 `N/A`。

## 成本、滚动与现金

- 单边期货成本 1bp；
- 动量目标仓位变化按 `1bp * abs(delta_weight)` 计费；
- 换月日只有在目标仓位大于0时才滚动，成本为 `2bp * weight`；
- 目标仓位为0时，期货收益与换月成本均为0；
- 每1倍 IM 以净资产30%作为保证金及缓冲占用；现金权重为 `1 - 30% * IM目标仓位`；
- 现金按净年化3%的固定情景计息。该现金收益是假设，不是历史可交易产品回测。

## 输出与验证

- 只输出一条正式策略：`im_momentum_gated_roll`；
- 展示全样本、最近10年、5年、3年、1年的年化收益和最大回撤；
- 保存逐日目标仓位、期货收益、进出成本、换月成本、现金权重、策略收益和净值；
- 校验目标仓位为0的日期没有 IM 收益和换月成本；
- 校验本路径与上一版误解释报告中的纯动量端点逐日一致，但撤回上一版的“组合权重”结论；
- 本结果只作历史研究，不生成当前下单信号，不批准实盘。
