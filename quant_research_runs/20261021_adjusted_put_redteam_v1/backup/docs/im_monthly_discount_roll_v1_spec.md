# IM 逐月到期展期贴水研究 v1：预注册规格

冻结日期：2026-08-16  
研究状态：预注册研究；未获准实盘

## 1. 研究问题

以中证1000股指期货（IM）为独立研究对象，回答：从 IM 上市至最新可用交易日，持有最近月合约至到期并在到期日以结算价进入下一月合约，历史总收益、相对中证1000价格指数的展期/基差收益，以及加入保证金之外现金管理后的组合收益分别如何；这些收益在全样本、最近10年、5年、3年、1年是否稳定。

总收益拆为：

1. 中证1000指数方向收益；
2. IM 相对中证1000价格指数的展期/基差超额；
3. 与中证1000全收益指数的差异，用于显示股息口径影响；
4. 1倍名义敞口下，70%净资产按年化3%管理的现金收益假设。

本版独立于 `ic_monthly_discount_roll_v1`，不得覆盖 IC 或其他策略的正式产物。

## 2. 预注册假设

- H1：IM 逐月到期展期的毛收益相对中证1000价格指数，在全样本和可用强制窗口中为正。
- H2：扣除每边1bp交易摩擦敏感性后，上述相对价格指数超额仍为正。
- H3：相对中证1000全收益指数后，IM 的经济超额小于相对价格指数的“贴水收益”；差异主要反映价格指数不含现金股息。
- H4：在不放大1倍名义敞口的前提下，将70%净资产配置于年化3%的高流动性现金管理资产，可提高组合年化收益，但不能消除 IM 方向风险和每日盯市造成的回撤。

本版为机制与历史事实检验，不设置自动晋升实盘门槛，也不据结果自动产生交易信号。

## 3. 数据与正式样本

### 3.1 期货

- 数据源：中国金融期货交易所官方历史行情月包：`http://www.cffex.com.cn/sj/historysj/YYYYMM/zip/YYYYMM.zip`。
- 品种：所有 `IMYYMM` 月度合约。
- 字段：交易日、合约、结算价、前结算价、收盘价、成交量、持仓量；回测主价格使用结算价。
- 起点：IM 首个交易日 2022-07-22。
- 终点：运行时可验证的最新完整官方交易日，预期为 2026-08-14；若不同，必须在元数据中记录且不得静默替换。

### 3.2 指数

- 中证1000价格指数：中证指数有限公司官方历史接口，代码 `000852`。
- 中证1000全收益指数：中证指数有限公司官方历史接口，代码 `H00852`。
- 只使用官方接口返回的收盘值，不做复权或前向填充。

### 3.3 日历与时区

- 使用中金所实际交易日与中国内地交易日历，不前向填充缺失交易日。
- 时区：Asia/Shanghai。
- 正式样本取 IM、价格指数、全收益指数共同可用区间。

## 4. 合约选择与执行口径

1. 初始日以当日官方结算价进入首个最近月合约 `IM2208`。
2. 每个合约持有至其最后交易日，以当日最终结算价结束该合约。
3. 同一到期日以当日结算价进入下一个自然月合约；下一交易日起使用新合约的结算价收益。
4. 到期日收益仅计旧合约从前一交易日结算价到最终结算价的变化，不把旧合约与新合约价格差当作即时损益。
5. 最新未到期合约按最新官方结算价盯市，并标记为未完成周期。
6. 名义敞口恒为组合净资产的1倍，不按30%保证金占用把期货敞口放大至3.33倍，也不做波动率目标或择时。
7. 资金安排假设为30%净资产作为保证金及盯市缓冲，70%净资产配置于可随时变现/质押转出的现金管理资产。现金管理资产的净年化收益假设固定为3.00%，不是历史实测理财或打新收益。
8. 每日按组合净资产重置为1倍期货名义、30%/70%资金结构；假设现金管理资产能够满足每日盯市资金划转。该假设不等于实际经纪商风控、出入金和质押效率。

若某月下一自然月合约在滚动日无结算价，正式运行必须失败并报告，不得改用主力连续、后月或填充值。

## 5. 收益定义

### 5.1 IM 连续展期总收益

- 合约内日收益：`settle_t / settle_{t-1} - 1`。
- 展期拼接按第4节执行，不对合约价差作后复权或加减点处理。
- 毛收益：不扣费用。
- 成本敏感性：每个实际开仓或到期/平仓等价交易按名义金额每边1bp；初始进入收1bp，每次月度换月收2bp。该成本是统一研究敏感性，不代表任一具体券商历史费率。

### 5.2 贴水/基差超额

- 日相对价格指数因子：`(1 + r_IM) / (1 + r_000852)`。
- 日相对全收益指数因子：`(1 + r_IM) / (1 + r_H00852)`。
- 月度已实现基差因子：`(F_exit / F_entry) / (S_exit / S_entry)`。
- 同时报告入场贴水 `S_entry / F_entry - 1`，并单列到期最终结算价与指数收盘的收敛残差。

中金所最后结算价并非中证1000日收盘点位；月度基差是可复现的结算价—收盘价近似，不解释为无误差套利收益。

### 5.3 保证金之外现金管理

- 现金管理资产日收益：`(1 + 3%)^(1/252) - 1`。
- 现金收益对总净资产的日贡献：`70% × 现金管理资产日收益`。
- IM净组合日收益：`r_IM净 + 70% × r_现金资产`。
- 净贴水加现金日收益：`r_IM相对价格指数净 + 70% × r_现金资产`。

现金层采用净年化3%的用户情景假设，不伪装为已观测数据。其年度理论贡献约为总净资产的2.1个百分点；日度复合和交易日数会造成极小差异。

## 6. 强制展示窗口与指标

终点统一为共同数据的最新交易日。强制窗口：

- 全样本；
- 最近10年；
- 最近5年；
- 最近3年；
- 最近1年。

完整历史不足相应窗口时显示 `N/A` 并说明原因，不缩短窗口冒充完整窗口。每个可用窗口至少展示：

- IM 毛收益与净成本敏感性的年化收益、最大回撤；
- 中证1000价格指数与全收益指数的年化收益、最大回撤；
- IM 相对价格指数与相对全收益指数曲线的年化收益、最大回撤；
- IM净收益加70%现金管理，以及净贴水加70%现金管理的年化收益、最大回撤。

另按自然年展示2022年至2026年各年的年化收益与最大回撤，明确首尾年份为部分年度。全样本另展示年化波动率、Sharpe（无风险利率按0，仅为描述）、完成月数、月度基差均值/中位数/胜率、入场贴水分布、最差月份与换月次数。

年化使用252个交易日；最大回撤由对应日净值历史峰值计算。

## 7. 未来3年与5年情景

假设指数终点与当前点位持平，仅估计贴水与现金收益：

- 悲观：2023—2025三个完整自然年中最低的净贴水年化收益；
- 中等：全样本净贴水 CAGR；
- 乐观：最近1年净贴水 CAGR。

每种情景同时报告：纯贴水年化、加总净资产2.1个百分点现金贡献后的组合年化，以及按该年化复合的3年/5年累计收益。该部分是基于历史锚点的条件推演，不是预测保证。

## 8. 完整性检查

- 官方月包下载状态、SHA-256、文件月数与日数写入数据清单。
- 合约代码必须匹配 `^IM\d{4}$`，月份连续且每个完成周期都有入场和退出价格。
- 比较 CFFEX `pre_settle` 与同合约上一交易日 `settle`，记录不一致数量和最大差异。
- 检查到期日新旧两张合约是否同时有结算价。
- 指数与期货日期内连接；报告删除日期及原因，不静默填充。
- 检查绝对值超过10%的期货日收益并列出来源，不自动截尾。
- 每个窗口使用同一条冻结曲线切片，不在窗口内重置合约规则或参数。

## 9. 明确排除

- 不用主力连续或价差复权连续合约替代真实月合约链。
- 不把30%保证金解释为3.33倍杠杆；不计超过1倍名义的方向敞口。
- 不把3%现金收益视为历史实测值；不计具体理财/打新申购约束、波动、税费、赎回延迟或额度。
- 不计盘口冲击、保证金追缴、经纪商加收保证金与极端行情流动性折价。
- 不假设能以中金所最终结算价成交；实盘执行版本需另建研究，使用到期日前可交易时点和真实买卖价/滑点。
- 不把最新持仓、当前贴水或未来情景解释为交易建议。
