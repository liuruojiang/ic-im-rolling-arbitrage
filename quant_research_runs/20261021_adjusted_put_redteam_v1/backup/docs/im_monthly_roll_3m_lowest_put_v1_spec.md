# IM 当月合约 + 约3个月最低执行价 Put 保护 v1：预注册规格

冻结日期：2026-08-16  
研究状态：预注册研究；未获准实盘

## 1. 研究问题

在冻结的 `im_monthly_discount_roll_v1` 逐月到期展期策略上增加保护腿：持有当月 IM 合约，同时按合约乘数匹配买入约3个月后到期、当日最低执行价的中证1000股指看跌期权（MO），检验该保护是否降低最大回撤，以及为此牺牲多少收益。

本版只测试这一层，不加入择时、估值、风险溢价、波动率目标或保证金杠杆，不覆盖既有 IM v1 正式产物。

## 2. 预注册假设与判定

- H1：扣除统一成本敏感性后，保护策略的全样本最大回撤浅于同口径未保护 IM 基线。
- H2：在可用的强制窗口中，保护策略在至少3个窗口改善最大回撤；历史不足的10年、5年窗口必须显示 `N/A`，不得缩短冒充。
- H3：保护腿会形成长期期权成本，年化收益允许低于基线；按标准流程，若全样本回撤改善不足8个百分点，则全样本年化收益落后超过1个百分点或3年/1年落后超过3个百分点时，结论只能为观察/诊断。即使回撤改善超过8个百分点，也不自动晋升实盘。
- H4：最低执行价 Put 的保护效果会随实际最低档与标的距离、隐含波动率和剩余期限显著变化；必须报告入场执行价距离、权利金占名义本金比例和流动性。

## 3. 正式数据与样本

### 3.1 IM 与 MO

- 数据源：中国金融期货交易所官方历史行情月包：`http://www.cffex.com.cn/sj/historysj/YYYYMM/zip/YYYYMM.zip`。
- IM：`IMYYMM`，合约乘数200元/点；主价格为每日结算价。
- MO Put：`MOYYMM-P-STRIKE`，合约乘数100元/点；主价格为每日结算价。
- 因乘数不同，每1份 IM 等价名义配2份同一 MO Put；研究曲线允许按净资产做分数份额缩放，不声称整数合约可精确复制。
- 起点：IM/MO 共同首个交易日 2022-07-22。
- 终点：运行时可验证的最新完整官方交易日，预期为 2026-08-14；如不同必须写入元数据。

### 3.2 指数与现金情景

- 中证1000价格指数：中证指数有限公司官方数据，代码 `000852`。
- 中证1000全收益指数：中证指数有限公司官方数据，代码 `H00852`。
- 现金管理仅为用户给定情景：30%净资产作为保证金/盯市缓冲，剩余现金按净年化3%计息；买入 Put 的权利金占用从可计息的70%中扣除。
- 日历与时区沿用 IM v1：中金所实际交易日，Asia/Shanghai，不前向填充。

## 4. IM 基线

同口径基线必须复用 `im_monthly_discount_roll_v1` 的真实逐月合约链：

1. 初始以 `IM2208` 结算价进入；
2. 每张最近月 IM 持有至最后交易日；
3. 到期日以结算价进入下一自然月 IM，日收益不把新旧合约价差记作损益；
4. 1倍名义敞口，收益指数按每日净资产重置；
5. IM 成本敏感性为每边名义本金1bp，初始1bp，每次完整换月2bp。

必须把本次重新生成的基线与冻结 IM v1 的重合日期结果核对；不一致则正式运行失败。

## 5. Put 选择、持有与换仓

### 5.1 目标到期月

- 每次 IM 月度入场日所属月份记为 `m`，目标 MO 到期月固定为 `m+3`，不是按当时已挂牌合约序号选择。
- 中金所通常在到期周五之后的下一交易日才挂牌新的第三个月度期权。目标合约尚未出现时，不假设可以提前成交；继续持有上一保护腿，直到目标月份 Put 在官方日行情中首次实际出现。
- 首次样本日直接按当天已挂牌的 `MO2210` 建仓。
- 春节等休市造成的自然日延迟必须原样保留并报告。

### 5.2 执行价与数量

- 主口径：在目标月份 Put 首次可选日，从当日所有官方挂牌 `MOYYMM-P-STRIKE` 中选择数值最低的执行价，不使用未来合约链。
- 最低执行价按字面定义；季度到期合约可能保留早先挂牌的更低执行价，因此不强制等同于当日约10%虚值。
- 数量：每1份 IM 名义匹配2份所选 Put。
- 流动性敏感性：同一选择日改选执行价最低且当日 `volume > 0`、`open_interest > 0` 的 Put；若不存在则该周期失败，不得填充。

### 5.3 日度损益与换仓

- Put 日度收益贡献按乘数匹配后的点数损益计算：`(P_t - P_{t-1}) / F_{t-1}`；这等价于2份100元/点 Put 对1份200元/点 IM 的损益占前一日 IM 名义本金。
- 保护腿从实际建仓日下一交易日起产生损益；换仓日先按旧 Put 当日结算价计完损益，再以新 Put 当日结算价建仓，新 Put 当日不产生损益。
- 旧 Put 一直持有至新 Put 实际挂牌/建仓日，以避免人为留下无保护空窗。
- 最新未完成保护周期按最新官方结算价盯市，不收假设平仓成本。
- 如果已选 Put 在应持有日缺少官方结算价，正式运行失败，不得前向填充、插值或改选合约。

## 6. 成本与现金收益

- IM 成本：与基线一致，每边1bp。
- MO 成本敏感性：每次买入或卖出整组2份 Put，按被保护 IM 名义本金每边1bp；初始建仓1bp，每次保护腿换仓2bp。该值用于覆盖手续费、价差和无法以结算价成交的统一敏感性，不冒充历史逐笔真实成本。
- 主比较使用：基线 IM 净收益 vs. IM + Put 净收益。
- 现金版基线每日增加 `70% × [(1+3%)^(1/252)-1]`。
- 现金版保护策略的可计息权重为 `max(0, 70% - P_t/F_t)`；`P_t/F_t` 是2份 Put 权利金市值占1份 IM 名义的比例。权利金本身仍作为组合资产按市值计入，不在买入日重复扣减本金。

## 7. 强制输出与对比

统一终点展示：全样本、最近10年、最近5年、最近3年、最近1年。每个可用窗口至少展示：

- 基线净年化收益、最大回撤；
- 主保护策略净年化收益、最大回撤；
- 年化收益差（保护减基线，百分点）；
- 最大回撤改善（保护最大回撤减基线最大回撤，按浅化百分点显示为正）；
- 主保护策略加现金管理、基线加现金管理；
- 流动性敏感性结果。

另按自然年展示2022—2026年相同对比，首尾年份标注部分年度。全样本必须报告：

- Put 损益对累计和年化收益的贡献；
- 49次（或实际次数）Put 选择的入场日期延迟、执行价/指数或 IM 的距离、权利金占 IM 名义比例；
- 入场日成交量、持仓量、零成交次数；
- 基线最差5个交易日及当日 Put 缓冲；
- 最大回撤起点、谷底、修复日；
- 月度/年度保护有效性，不仅展示单一总样本。

年化按252个交易日，最大回撤由日净值历史峰值计算。

## 8. 完整性检查

- 记录每个月包路径、来源、SHA-256、成员日期范围和最新交易日。
- 合约代码分别严格匹配 `^IM\d{4}$` 与 `^MO\d{4}-P-\d+$`。
- 每个 Put 选择只使用当日或更早可见数据；报告目标月首次挂牌相对 IM 换月日的延迟。
- 选中 Put 在整个持有区间必须每日有结算价；验证没有重复日期/合约和缺失值。
- 主口径若使用零成交官方结算价，报告中必须显著标记为估值而非可成交证据。
- 与 IM v1 基线重合区间的每日净收益、成本日期和换月表逐项核对。
- 绝对值超过10%的组合日收益只审计、不截尾。

## 9. 明确排除

- 不使用 Black-Scholes、隐含波动率拟合、ETF 期权或合成期货替代真实 MO 官方结算价。
- 不提前使用尚未挂牌的 `m+3` 合约，不用未来最低执行价回填。
- 不把30%保证金放大成3.33倍 IM 敞口。
- 不模拟盘中止损、动态 Delta、波动率择时、滚动执行价或持有 Put 至到期的三层重叠保护。
- 不声称能以官方结算价成交；不计盘口冲击、涨跌停、保证金追缴和券商加收。
- 本版是保护机制历史检验，不生成实时下单信号，不构成交易建议。
