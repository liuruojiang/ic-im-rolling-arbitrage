# IC v1.3完整组合：高IV卖Put＋核心Put盈利兑现联合复算 V1

预注册日期：2026-09-17。研究专用，不修改生产、日报、账本或交易状态。

## 完整组合基线

- 固定核心0.5倍IC＋现行动量0.5倍IC；动量执行权重使用Score即时与Abs20连续两日严格大于+1%的恢复防抖，并重算原6%基础净值防守。
- IC期货严格季度T-3收盘展期；固定核心、动量和网格共用同一季度链。
- IC估值分数0.5进入、1.0退出的0.5倍网格；网格不配置Put，IC不卖Call。
- 核心Put使用现行估值分层与MOM120负值即时启用、连续两日严格大于+1%解除防抖；动量Put仅按现行估值×动量权重；两腿均约3个月、95%目标行权价并按目标Delta配量。
- 所有510500 Put单边成本5BP；IC期货单边1BP；每1倍期货30%缓冲；现金年化3%。

## 卖Put增强

- 仅替代0.5倍固定核心袖，不替代动量期货、动量Put或0.5倍网格。
- 新卖Put须满足估值0/1档、原IC 1.3执行动量许可、M+1 95% Put合约IV严格大于37.5%。不重新加入已取消的IC卖PutMOM120。
- 权利金衰减60%后最多提前滚动一次到紧接下一挂牌月，新腿重新通过全部准入。
- 路由日T+1开盘同步退出固定核心IC与核心Put；已有动量Put保持原规则。
- 实物交割后ETF转IC及整轮扣费回本退出保持既有规则；恢复时进入当前季度IC链。

## 核心Put盈利兑现增强

- 比较无盈利兑现、2倍兑现与3倍兑现。
- T日收盘达到实际入场权利金倍数后，最早T+1收盘卖出旧核心Put并按当日目标Delta重建约3M/95% Put；新权利金成为下一触发基准。
- 固定核心路由开盘退出优先于收盘盈利兑现；目标归零、月度维护和目标Delta调整优先，冲突日不得重复交易。
- 盈利兑现只作用于核心Put；动量Put不使用该规则。

## 候选

- `baseline`：完整当前组合，无卖Put、无盈利兑现。
- `profit2x_only`、`profit3x_only`：只增加核心Put盈利兑现。
- `short95_only`：只增加固定核心卖Put路由。
- `joint2x`、`joint3x`：卖Put路由与对应核心Put盈利兑现联合。

## 数据与判定

- 真实挂牌层：2022-09-19至2026-08-14。
- 理论延展层：2015-04-16至2026-08-14；理论510500 Put只作方向证据。
- 早期估值必须使用恢复后的显式状态，禁止缺失默认0/1档。
- 先逐日复现冻结季度T-3完整组合旧口径，误差不超过1e-12；再统一切换到上述当前规则和5BP Put成本。
- 联合候选在真实和理论层的全样本CAGR均须不低于对应`baseline`，Sharpe不得低于基线，最大回撤绝对值恶化不得超过0.5个百分点。
- 联合候选还需与对应盈利兑现单项及`short95_only`比较：CAGR不得低于两者较优值，最大回撤不得比两者较差值再恶化超过1个百分点。
- 路由退出与盈利兑现同日重复事件必须为0，现金权重不得为负。真实事件稀少必须明确标注。
