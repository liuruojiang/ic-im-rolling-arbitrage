# IC Put 估值四档细分扫描 v2（预注册）

- 版本：`ic_put_four_valuation_tier_scan_v2`
- 日期：2026-08-20（Asia/Shanghai）
- 性质：研究参数扫描；不修改冻结的`ic_im_system_mainlines_v1`。

## 1. 研究问题

现有IC Put估值规则为`1.90/2.00/2.10 → 25%/50%/75%`目标绝对Delta。本版在现有`1.90—2.10`估值区间内细分为四档，并把第四档设为100%目标绝对Delta。

## 2. 固定组件

- 固定1倍滚IC、`0.375/1.000`估值网格保持不变；网格新增IC不配置Put。
- IC继续明确不含Call。
- Put仍使用510500 ETF Put、三个月目标期限、95%目标行权价、实际挂牌月份、随IC月换重置及T收盘评估/T+1共同交易日收盘执行。
- `MOM120<=0`只保底25%目标Delta，不直接触发第四档。
- 绩效按每1倍期货30%保证金/缓冲及剩余现金年化3%计算。

## 3. 候选阶梯

| 候选 | 估值分阈值 | 目标绝对Delta |
| --- | --- | --- |
| `IC_baseline_075` | `1.90/2.00/2.10` | `25%/50%/75%` |
| `IC_existing_top_100` | 原2.10最高档直接升至100% | 三档参照 |
| `IC_4tier_1900_2000_2050_2100` | `1.90/2.00/2.05/2.10` | `25%/50%/75%/100%` |
| `IC_4tier_1900_2000_2050_2075` | `1.90/2.00/2.05/2.075` | `25%/50%/75%/100%` |
| `IC_4tier_1900_1975_2050_2075` | `1.90/1.975/2.05/2.075` | `25%/50%/75%/100%` |
| `IC_4tier_1900_1950_2000_2050` | `1.90/1.95/2.00/2.05` | `25%/50%/75%/100%` |

所有阈值在运行前冻结；不得根据结果追加或移动候选。

## 4. 数据、区间与验证

- 正式结论只使用真实IC/510500 Put样本：2022-09-19至2026-08-14。
- 估值分为冻结的中证500PB、ERP、过去一年已实现股息贡献三项固定经济压力的二取三中位数。
- 必须报告`full/last_10y/last_5y/last_3y/last_1y`；较长窗口截到真实样本起点。
- 基准必须同批重跑，并与冻结`real_grid_only`逐日收益核对，最大绝对误差不超过`1e-12`。
- 必须审计第四档目标天数、实际目标100%天数、事件数、实际Put张数、有效Delta、Put成本、最大市值占用及最低原始现金权重。

## 5. 判定

候选进入观察需同时满足：

1. 第四档至少触发5个交易日且至少跨2个独立事件；
2. 全样本最大回撤不劣于基准；
3. 全样本年化收益相对基准下降不超过2个百分点；
4. 全样本Sharpe不低于基准；
5. 近3年与近1年不能同时在收益和最大回撤上均劣于基准；
6. 最低原始现金权重不低于0，且所有收益有限。

若只有单一四档阶梯通过而相邻阶梯不支持，标记`peak_only`；不得直接替换冻结主线。

## 6. 成本与限制

- 继承正式IC、网格和510500 Put的既有成本。
- 排除买卖价差、收盘冲击、涨跌停未成交、盘口容量、动态保证金上调和税费。
- 510500 ETF Put实际张数按执行时目标Delta和合约绝对Delta动态取整，不把100%目标Delta误解为固定张数。
