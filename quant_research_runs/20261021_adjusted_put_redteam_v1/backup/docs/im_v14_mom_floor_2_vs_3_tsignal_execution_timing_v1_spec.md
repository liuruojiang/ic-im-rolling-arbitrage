# IM v1.4 Put：T 日选约与成交时点敏感性（研究预注册）

日期：2026-09-19。研究用途，不改正式主线、信号或账本。

## 固定项

- 使用 v1.4-r1 全联合回放：核心仓、动量仓、0.5 倍网格、Call、路由和既有成本均保留。
- 仅比较核心与动量长 Put 的负 MOM120 最低数量：2 张和 3 张。
- 行权价：每个交易事件均以 T 日（`signal_eval_date`）IM 收盘价选择最接近 102% 的上市 Put。
- 核心 Put 的 IMC 许可改为以 T 日路由状态判定，避免在 T+1 执行日读取路由状态。

## 成交情景

1. `tclose_select_t1_open`：T 日选约，T+1 官方开盘价成交；开盘缺失时才退回同日收盘价，并逐笔记录。
2. `tclose_select_tclose_proxy`：T 日选约，以同合约 T 日官方收盘价代理成交；不可执行，只用于时点敏感性。
3. `tclose_select_t1_close`：T 日选约、T+1 官方收盘价，仅作同一因果选约方式的参照。

不纳入买卖价差、冲击成本、盘口容量与限价成交概率；因此不作实盘晋级或参数选择。
