# 中证500 Put 保护研究主线 v1

记录日期：2026-08-18  
状态：用户确认的研究主线；未获准实盘

## 1. 冻结结论

中证500 Put 保护的后续研究主线固定为：

- 估值：中证500无界固定经济分的二取三中位数。
- 估值三级门槛：`1.90 / 2.00 / 2.10`。
- 交易时目标绝对Delta：依次为`25% / 50% / 75%`。
- 趋势下限：当中证500全收益指数`MOM120 <= 0`时，目标Delta不得低于`25%`；趋势与估值取较大值，不相加。
- Put：510500 ETF Put，目标期限3个月、95%虚实值规则，随IC月换退出旧Put并换入新的目标Put，不持有到期。
- 评估与执行：T日收盘评估，T+1下一共同交易日收盘执行；不做每日Delta再平衡。
- 资本口径：1倍IC名义，30%保证金/缓冲，70%现金净年化3%，每边1bp。

其中二取三分数为三项固定经济压力的中位数：

1. `PB压力 = (PB - 1.50) / 0.50`
2. `ERP压力 = (4.50% - ERP) / 1.50%`
3. `股息压力 = (3.00% - 过去一年股息贡献) / 1.00%`

## 2. 选择依据

- v21中，`1.90/2.00/2.10 + MOM120最低25%`模型全样本CAGR/MaxDD为`18.94% / -27.80%`，真实510500 Put样本为`17.89% / -20.51%`。
- v22中，1.80起步相对1.90没有改善全样本MaxDD，却分别损失模型0.40个百分点、真实0.08个百分点CAGR；2.00起步收益更低。因此1.90保留为研究中心。
- MOM120最低50%和75%没有获得跨窗口支持；25%继续作为趋势分支默认。
