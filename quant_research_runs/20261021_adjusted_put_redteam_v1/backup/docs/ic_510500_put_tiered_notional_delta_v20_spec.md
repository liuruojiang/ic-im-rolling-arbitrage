## 1. 研究问题

用户接受为了显著降低回撤而小幅牺牲收益，并提出把二元保护继续按估值严重度分档。本版不再改变估值本体、MOM120、Put期限、执行价或成交时点，只检验以下两个问题：

1. 当风险从轻到重时，把95% Put的标的名义规模从1倍提高到2倍、3倍，能否比当前固定1倍保护显著降低回撤；
2. “一份Put”并不等于固定25% Delta。为避免把名义份数误解为实际保护率，同时检验按建仓/换档时Delta定仓至25%/50%/75%的版本。

本版不是阈值优化：只跑一组事前冻结的`2.00/2.10/2.15`严重度阶梯和必要控制组，不根据结果改阈值、加滞后、加仓位上限或回头挑窗口。

## 3. 严重度分档与冻结候选

### 3.1 每日风险档位

使用v6“二取三中位数”`unbounded_median_knot`：

| 风险档 | 估值条件 | MOM120补充 |
| --- | --- | --- |
| 0 | 中位数低于2.00 | 且MOM120大于0 |
| 1 | 中位数不低于2.00、低于2.10 | MOM120不高于0时至少升至1档 |
| 2 | 中位数不低于2.10、低于2.15 | MOM120不改变2档 |
| 3 | 中位数不低于2.15 | MOM120不改变3档 |

即`风险档=max(估值档, 1[MOM120<=0])`。MOM120只提供最低一档，不把估值2档或3档降回1档。边界按“达到阈值即进入高一档”。

### 3.2 同批候选

模型层和真实期权层各跑5条，共10条：

1. `no_put`：滚IC加现金基准；
2. `binary_notional1x`：风险档大于0时固定1倍标的名义Put，是v19`median200_or_mom120`当前路径；
3. `binary_delta25`：风险档大于0时，在建仓、月换或从0/非0切换时按25%绝对Delta定仓，作为Delta方法控制组；
4. `tier_notional123`：1/2/3档分别持有1/2/3倍标的名义Put；
5. `tier_delta255075`：1/2/3档在建仓、月换或换档时分别按25%/50%/75%绝对Delta定仓。

Delta候选在档位不变时不做每日Delta再平衡；只在新开、每月随IC换Put、或风险档变化时重算数量。不存在事后仓位上限；必须如实报告为了达到目标Delta所需的最大Put标的名义倍数、Put市值和大于100%实际Delta保护的天数。

## 4. Put、Delta、成本与成交

- 日评；T日收盘计算档位，下一共同交易日收盘执行；样本首日保留冻结引擎的初始状态例外。
- Put固定`3m_monthly_exit_m95`：目标到期月约为执行日后三个月，执行价/标的收盘最接近95%；信号持续时随IC逐月卖旧买新，不持有到期。
- 模型层使用冻结Black–Scholes/QVIX代理；Put Delta为`-exp(-qT)N(-d1)`。模型Delta定仓数量使交易时`Put标的名义倍数 × |Delta| = 目标Delta`。
- 真实层使用510500 ETF Put实际收盘价。先由实际收盘价、ETF收盘、执行价、剩余期限和同日冻结利率/股息率反解隐含波动率，再计算Delta；若价格不满足Black–Scholes可解边界，允许退回同日冻结QVIX代理波动率，但须逐笔标识和统计。
- 真实Delta数量为整数张：先计算1倍IC名义对应的ETF期权张数，再按`目标Delta/|Delta|`缩放并四舍五入；逐笔实际目标误差不得超过2个百分点。固定名义候选沿用同一整数张规则。
- Delta换档时只调整当前Put张数，不在月中另换执行价；月换时重新选择目标月份95% Put。
- 1倍IC名义；30%保证金/缓冲，70%现金净年化3%；Put市值从可计息现金扣除。IC和Put每边1bp；Put成本按实际买卖的标的名义倍数计，月换计卖旧买新双边成本。
- 不对超过70%可用现金的Put市值做静默截断：若出现，候选判为不可实施；逐日组合收益仍不得小于等于-100%。

## 6. 预注册判定

### 6.1 方法内的分档增益

`tier_notional123`相对`binary_notional1x`，`tier_delta255075`相对`binary_delta25`分别判定。每种分档方法须同时满足：

1. 模型和真实全样本MaxDD各改善至少2个百分点；
2. 模型五窗口至少三个MaxDD改善，真实三个可用窗口至少两个改善；任何窗口MaxDD不得加深超过1个百分点；
3. 模型全/10年/5年CAGR落后不超过2个百分点，3年/1年落后不超过4个百分点；真实全样本落后不超过2个百分点，3年/1年落后不超过4个百分点；
4. 模型2档、3档各至少20个执行后持有日；真实2档、3档各至少1个执行后持有日。真实高档总样本不足20日时，无论绩效如何都只能作为识别性证据；
5. 最大Put市值不超过组合初始权益的70%，无收益小于等于-100%，真实成交Delta目标误差逐笔不超过2个百分点，真实隐波回退占Delta定仓交易不超过5%。

### 6.2 no-Put底线与跨方法稳定性

每条分档候选相对同层`no_put`还须满足：全样本MaxDD改善；模型全/10年/5年CAGR落后不超过2个百分点、3年/1年不超过4个百分点；真实全样本不超过2个百分点、3年/1年不超过4个百分点。

- 固定名义和Delta两种分档方法均通过6.1及6.2：`cross_method_supported/watchlist`；
- 仅一种通过：`method_specific/watchlist`；
- 两种均未通过：`reject_tiering`，维持当前1倍保护研究基准。

真实上档样本短、样本被多轮研究重复使用，任何结果都不构成独立样本外验证，不得直接晋升实盘。
