# IM + MO Call 5%威胁救援最大历史代理检验 v26r1 预注册规格

冻结日期：2026-08-19（Asia/Shanghai）  
状态：修正PE可用起点后的长期合成诊断；不是真实IM/MO；未批准实盘。

## 1. v26预检修正

v26在收益计算前发现：中证1000价格指数和全收益指数可回算至2005年，但本地官方滚动PE首个非空日为2012-06-29，不是2005年。v26永久保留为`failed_preflight_pe_history_start_mismatch`，不产生性能结果。

v26r1不填补或虚构早期PE，拆成两条研究轴：

1. 2007年起无估值轴：始终使用普通态文章期限—虚值率阶梯，只检验5%救援本体；
2. 2012-06-29起PE轴：使用当时已有历史计算PE20/60滞回；2012-06-29—2014-10-16标记为指数发布前回算。

## 2. 数据与最大可测边界

- 中证1000官方价格指数`000852`和全收益指数`H00852`：2005-01-01—2026-08-14；
- 官方滚动PE首个非空日：2012-06-29；
- 中债10年国债收益率：2007-01-04起；
- 原QIVX波动率模型完整起点：2015-04-16；
- 无估值轴从所有价格、利率、60日RV和一年股息字段完整的首个交易日起运行；PE轴从2012-06-29或其后的首个共同交易日起运行；均结束于2026-08-14。

2007—2014年指数及2012—2014年PE均是发布前回算，不是当时可交易产品；所有扩展结果只能作诊断。

## 3. 2015年前IV敏感性

2015-04-16以后完全使用冻结的`QIVX50 × 中证1000/50ETF 60日实现波动率比`。此前使用严格滞后的中证1000价格指数60日RV乘以下固定倍数：

- P25：`0.9984611590392641`；
- P50：`1.1352106814268557`；
- P75：`1.2692067075266782`。

倍数是2015-04-16—2026-08-14现有模型`implied_sigma/RV60`的经验分位，不按策略收益选择。它使用后见统计回填早期，因此三场景方向一致只是结构敏感性通过，不构成因果可交易IV。

## 4. 候选与固定规则

每个IV场景同时运行四条：

- `normal_no_rescue`：无估值，普通态文章阶梯，无救援；
- `normal_threat5`：同上，增加5%救援；
- `pe20_60_no_rescue`：2012-06-29起PE20/60滞回，无救援；
- `pe20_60_threat5`：同上，增加5%救援。

普通态正常入场依次使用30—60天/最低15%虚值、61—90天/20%、91—120天/25%；低估修复态只允许30—60天/25%。空仓每日检查，正常开仓理论IV须`>=26%`。

5%救援完全继承v25r2：

- `旧Call行权价/指数收盘-1 <= 5%`即触发；
- 取严格下一个模型挂牌到期月，行权价精确等于旧行权价`×1.05`；
- 救援豁免IV26；T收盘冻结，T+1收盘理论价执行；
- 连续最多5次，第6次或没有下一挂牌月时买回并暂停至下一月评；
- 不含TP80、分批止盈、急跌向内移仓、风险度扩仓或救援参数扫描。

## 5. 代理底仓与成本

- 1倍中证1000官方全收益指数日收益代理滚IM方向收益，不含历史IM贴水；
- 月度模型到期日计底仓双边2bp，首日单边1bp；
- 每1倍指数名义卖1倍Call篮子，Call每边1bp，救援换仓2bp；
- 70%资本上限减去Call保证金后的余额按净年化3%计息；
- 不含Put、真实IM保证金波动、买卖价差、冲击成本、盘中跳空、涨跌停或挂牌流动性。

由于本版不含主线Put和IM贴水，组合CAGR/MaxDD不能与v25r2正式组合的17.60%/-16.36%直接横比；只比较同一代理底仓上的有无救援增量。

## 6. 必报结果与长期判定

每条候选必须报告full/10Y/5Y/3Y/1Y CAGR与MaxDD；每个IV场景报告有无救援的CAGR/MaxDD差、逐年收益、Call损益与成本、持仓日、最大及95分位Delta、最大保证金、救援/止损次数和最大连续救援次数。另分别报告2015-04-15以前与2015-04-16以后区间。

无估值轴和PE轴分别判定。某一轴只有在P25/P50/P75三个场景全部满足以下条件才记为方向支持：

- full和10Y CAGR落后同场景无救援不超过1个百分点，5Y/3Y/1Y落后不超过3个百分点；
- 最大Call Delta至少下降10个百分点；
- 每个场景至少发生5次救援；
- 最终待执行动作、资本穿透与全部审计错误为0。

两轴均通过：`extended_proxy_directionally_supported_both_axes`；仅一轴通过：`extended_proxy_axis_dependent`；场景间方向不一致：`iv_assumption_sensitive`；均失败：`extended_proxy_not_supported`。无论结果如何都不得晋升实盘或反选倍数。
