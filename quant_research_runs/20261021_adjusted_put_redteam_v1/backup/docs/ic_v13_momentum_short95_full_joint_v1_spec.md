# IC v1.3 动量腿高IV转卖Put完整组合测试 v1

日期：2026-09-17  
状态：研究预注册；不修改生产、日报、账本或交易状态。

## 研究问题

在当前IC v1.3完整组合及已保留的固定核心腿卖Put研究候选上，检验现行动量期货腿在相同准入条件下同步转为卖Put，能否进一步改善完整组合。

## 固定口径

- 固定核心0.5倍IC、现行动量0至0.5倍IC、0.5倍估值网格。
- IC季度T-3；核心与动量买Put沿用当前约3个月、95%目标行权价及现行估值/MOM120规则，核心Put三倍盈利兑现。
- 卖Put固定为M+1、95% 510500 Put、绝对IV严格高于37.5%、估值0/1档加原IC 1.3执行动量许可；不重新加入卖方MOM120。
- 权利金衰减50%后最多提前展期一次，新腿重新准入；数量为等名义`q1_notional`。
- IC不卖Call。所有510500 Put单边5BP，IC期货单边1BP；每1倍期货30%保证金/缓冲，现金年化3%。

## 动量腿转换语义

- 仅当现行动量执行权重大于0且上述卖Put准入成立时，动量腿才能转换。
- 入场规模=`0.5 × 当日动量执行权重`；该规模在整轮卖Put、实物交割ETF转IC、IC恢复及等待回本期间固定。
- 入场日同步退出对应动量IC及动量买Put；整轮恢复完成后，下一交易日重新接回当时的现行动量权重。
- 固定核心腿与动量腿分别核算数量；同日同合约允许数量相加，不互相覆盖。

## 四组对照

1. `profit3x_no_short`：核心Put三倍兑现，不卖Put。
2. `fixed_only_q1`：只转换固定核心腿，必须逐日复现既有衰减50%、5BP候选。
3. `momentum_only_q1`：只转换动量腿。
4. `both_q1`：固定核心腿与动量腿都转换。

## 判定

`both_q1`相对`fixed_only_q1`须在真实挂牌层与理论延展层同时满足：CAGR不低于对照、Sharpe不低于对照0.05以上、最大回撤绝对值恶化不超过1个百分点；现金权重不得为负，转换日对应买Put必须同步退出。真实事件稀少或理论贡献过度集中时只保留研究证据，不构成生产晋级。

## 已知限制

理论510500 Put为代理；真实期权历史较短。未纳入动态保证金、强平、税费、盘口容量、整数账户张数及显式成交延迟。
