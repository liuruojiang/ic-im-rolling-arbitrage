# IM + MO 每日D10 Call 5%威胁救援确认 v27 预注册规格

冻结日期：2026-08-19（Asia/Shanghai）  
状态：固定主线增量确认；未批准实盘。

## 1. 研究问题

用户确认IM卖Call的正常评估频率是每日，而不是月评。本版只回答：在冻结的`front_d10_iv26_daily`上增加v25r2的5%威胁救援，能否在相同数据、成本、日评和T+1收盘执行下控制Call尾部风险，而不破坏原线。

本版严格排除PE20/60、文章15%/20%/25%期限—虚值率阶梯、TP80、分批止盈、急跌向内移仓、网格和风险度扩仓。不得读取结果后补参数。

## 2. 基线与候选

- 基线：v22冻结`front_d10_iv26_daily`；空仓每日收盘按当前月度周期的前月/下一到期月选择最接近0.10 Delta且虚值、正收盘、正成交量、正持仓量的MO Call，合约自身IV不低于26%才开仓；正常月换仍在IM月度换仓节点处理。
- 候选：`front_d10_iv26_daily_threat5_up5_next1_max5`；正常入场、月换和IV26与基线完全相同，只增加5%救援。
- 每1张IM卖2张MO，覆盖固定1倍IM底仓，不覆盖任何新增网格仓。

## 3. 5%救援

- 已有Call每日收盘计算`旧行权价/中证1000收盘-1`；不高于5%即触发；
- T日收盘冻结，T+1官方收盘买回旧Call并卖出严格更晚的最近挂牌到期日；
- 新行权价至少为旧行权价105%，真实离散合约向上取首个满足者；
- 救援属于已有风险管理，豁免IV26；
- 每条连续救援链最多5次；第6次或下一期限没有有效合约时买回旧Call并暂停，至下一IM月度评估节点重新允许每日开仓；
- 威胁动作优先于同日普通月换。

## 4. 数据、样本与执行

- 模型层：2015-04-16—2026-08-14，沿用v22/v25冻结理论Call与中证1000模型市场；
- 真实层：2022-07-22—2026-08-14，CFFEX官方IM/MO收盘、结算、成交量和持仓量；
- 底仓：冻结`reconstructed_valmom_floor3`三个月95% Put的1倍滚IM路径，不改变Put；
- 信号：T日收盘；执行：T+1官方收盘。若旧/新真实合约当日无正收盘、成交量或持仓量，沿用冻结合约并记录顺延；
- Call每边1bp，救援换仓合计2bp；30% IM保证金/缓冲，Put市值和Call独立义务保证金扣减可计息现金，余额净年化3%；
- 不含买卖价差、收盘冲击、涨跌停和盘口容量，必须单独披露。

## 5. 预注册通过门槛

基线必须与v22正式逐日路径、交易和非新增遥测信号一致。候选只有同时满足以下条件才可进入整套IM组合审计：

1. 模型full/10Y/5Y CAGR相对基线落后不超过1pp，3Y/1Y不超过3pp；
2. 真实full CAGR落后不超过1pp，3Y/1Y不超过3pp；真实10Y/5Y因MO历史不足报告N/A；
3. 模型和真实最大Call Delta均至少降低5pp，最大Call保证金均不恶化；
4. 模型至少5次、真实至少2次成功救援；最终待执行0、资本穿透0；
5. 收益/现金恒等式、IV26、D10选约、5%触发、行权价上移、到期日后移、T/T+1因果和官方收盘价审计全部通过。

通过记为`confirm_daily_d10_threat5_for_im_combination`；未通过记为`keep_daily_d10_without_threat5`，并停止条件式整套IM组合正式审计，不得事后放宽门槛。
