# IM M+1卖95% Put相对IV入场扫描 v1（预注册）

## Research Question

在已修正的IM v1.3混合路由中，将卖Put的绝对IV严格大于35%入场条件替换为因果滚动IV分位，检验相对IV是否能在不同波动率年代提供更稳定的入场尺度。

## Frozen Strategy Rules

- M+1卖95% MO Put；权利金衰减60%后最多提前滚动一次到紧接下一个实际挂牌月份。
- 新腿重新通过当前估值0/1档、MOM120绝对动量及既有防抖；早期估值恢复必须启用。
- 路由时IM、核心Put和Call同步退出；Call在Put、现金和回本期间暂停，IMC恢复后按原规则重新准入。
- 不加入灾难保护Put；上一轮已拒绝该增强项。
- 实物/现金结算后的IM回本退出保持不变；不修改生产或冻结主线。

## Relative-IV Definition

- 每个T日使用当日收盘可得的M+1、约95%行权价Put隐含波动率。
- 与T日以前、同一信号序列最近`W`个有效交易日IV比较；分位定义为`历史IV <= 当日IV`的比例。
- 历史窗口不包含当天，不使用未来数据；不足60个有效历史观测时相对IV信号无效并关闭卖Put入场。
- 仅改变首次入场的高IV判定。已经进入卖Put周期后，仍按既有60%衰减、到期、指派和回本状态机管理，不因IV分位回落提前退出。
- 严格使用`relative_iv_percentile > Q`，边界相等不触发。

## Candidate Grid

- 原对照：绝对`IV > 35%`。
- 相对窗口：`W = 126 / 252 / 504`个交易日。
- 入场分位：`Q = 70% / 80% / 90%`。
- 共1条绝对基线和9条相对IV候选。

## Data and Execution

- 真实层：现有IM/MO挂牌历史，2022-07-22起；真实期权开盘、收盘、成交量和持仓量。
- 理论层：现有2015-04-16起Black-Scholes延展M+1/M+2 MO Put，同一市场、利率、股息率和波动率序列；不得解释为可成交历史。
- T收盘计算绝对/相对IV与准入，T+1开盘执行；单边1bp标的名义成本、每1倍期货30%保证金/缓冲、3%现金收益。

## Diagnostics

- 每个候选保存原始IV、因果相对分位、历史观测数、入场许可、路由周期、指派、提前滚动和Call暂停日。
- 报告full、10Y、5Y、3Y、1Y的年化收益、波动率、仓库口径Sharpe和最大回撤；真实历史不足的5Y/10Y明确N/A。
- 原绝对IV候选必须与上一轮修正后M+1输出逐日收益误差不超过`1e-12`。

## Pre-registered Decision Rule

相对IV只有在以下条件全部满足时才可保留为研究候选：

1. 真实层和理论层全样本Sharpe均不低于绝对IV35基线；
2. 两层全样本最大回撤均不得恶化超过0.50个百分点；
3. 两层全样本CAGR均不得低于绝对基线超过0.50个百分点；
4. 同一窗口至少两个相邻分位方向一致，或同一分位至少两个相邻窗口方向一致；禁止按单一峰值晋级；
5. 真实层至少产生3个完整卖Put周期，理论层至少产生8个，避免以几乎不交易取得表面改善。

通过仍只代表研究候选，不自动替换1.3版本、不生成交易建议。

## Limitations

- 分位窗口会把不同期限结构、波动率偏斜和市场制度压缩成单一历史排名。
- 60日热身期关闭入场，2015年理论样本早期不能视为完整相对IV策略历史。
- 不含真实买卖价差、冲击、容量、动态保证金、强平、税费和整数合约约束。
