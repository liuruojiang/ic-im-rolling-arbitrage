# 中证500固定估值网格研究主线 v1

- 冻结日期：2026-08-18
- 状态：用户确认的后续研究基线；**未批准实盘**
- 适用范围：后续卖Call及其他增量研究的默认对照，不得据此接入自动下单、人工交易信号或生产风险配置。

## 1. 固定底仓

1. 常态持有1倍名义的滚动IC底仓，按既有活跃合约与月度展期规则执行。
2. 底仓Put管理继续引用`docs/ic_510500_put_research_mainline_v1.md`，本文件不改写其估值、MOM120、期限、Delta、换仓和执行规则。

## 2. 固定网格参数

1. 估值分数采用v6无界固定经济单位的二取三中位数：
   - PB压力：`(PB - 1.50) / 0.50`；
   - ERP压力：`(4.50% - ERP) / 1.50%`；
   - 过去一年股息压力：`(3.00% - 股息) / 1.00%`；
   - 三项压力取中位数。分数越低越低估，越高越高估。
2. T日收盘估值分数不高于`0.375`时，于T+1交易日使用当时活跃IC的官方开盘价新增1倍名义IC。
3. 新增仓持有期间继续随活跃IC逐月展期，并获得对应IC价格及展期收益。
4. T日收盘估值分数不低于`1.000`时，于T+1交易日使用当时活跃IC的官方开盘价退出全部新增仓。
5. 网格仓只有0倍或1倍两个状态，不连续加仓，不翻倍，不在区间内反复做点数网格。
6. 新增网格仓不配置Put；底仓Put规则保持不变。

## 3. 资本与成本口径

1. 每1倍IC名义按30%保证金/风险缓冲计；底仓与网格仓同时持有时合计按60%计。
2. 未占用资金按用户假设年化3%计息。
3. IC交易成本按每边1bp；新增仓月度换月计一买一卖共2bp。
4. 结果均为标准化1倍名义研究口径，不等于任意账户可直接交易的整数合约数量。

## 4. 选择证据与边界

1. v4风险优先机械最高点`0.375/1.000`的模型全样本、最近10年、5年、3年、1年CAGR/MaxDD分别为：
   - 25.97% / -27.38%
   - 22.32% / -27.38%
   - 27.99% / -27.38%
   - 47.39% / -17.36%
   - 53.31% / -10.48%
2. 正式样本完成3个估值周期；2007年起的指数诊断样本完成4个周期。事件数仍少，存在制度、估值结构和执行样本外失效风险。
3. `0.500/1.000`和`0.375/0.875`只作为附近确认线，不属于本研究主线。
4. v5显示新增仓同步底仓Put未通过预注册门槛；因此本主线固定为“底仓保留Put、新增网格仓不加Put”。
5. 该参数来自已冻结的v4/v5研究及用户明确选择。它只固定后续研究参照，不将v4的`peak_only`证据升级为实盘许可。
