# IC核心Put与高IV卖95% Put切换研究 v1

预注册日期：2026-09-16。研究专用，不修改生产、账本或下单规则。

## 固定比较

- 基线A：1倍月度滚动IC，30%期货保证金/缓冲，剩余现金年化3%。
- 基线B：基线A加当前IC核心510500 Put；95%目标行权价、约3个月、月度维护，估值四档与MOM120两日严格大于+1%解除防抖取较高保护。
- 候选：正常持有基线B；若前收盘最近月95% 510500 Put的IV严格高于门槛，且卖Put满足估值0/1档与原IC 1.3执行动量许可，则下一开盘同时平IC、平核心Put并卖出该Put。

## 固定参数

- IV门槛：20%、22%、24%、26%、28%、30%、32.5%、35%、37.5%、40%。
- 卖Put权利金衰减60%后，下一开盘最多提前换至紧接下月一次；新腿重新通过估值0/1档与原IC 1.3执行动量许可，不加入IC卖PutMOM120。
- 实物交割后下一开盘卖ETF、买等值IC；按既有月展期滚动，整轮扣费损益达到退出成本后下一开盘退出。
- 高IV但不满足卖Put准入时继续IC与核心Put，不切现金。
