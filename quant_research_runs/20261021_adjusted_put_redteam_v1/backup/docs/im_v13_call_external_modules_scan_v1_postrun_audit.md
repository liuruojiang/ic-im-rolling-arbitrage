# IM 1.3-r6 卖 Call：IV 门槛与外部管理模块复测 v1 事后审计

## 结论先行

- **保留 IV26。** IV30 是 2022-07-22—2026-08-14 真实样本内的精确峰值，但相邻 IV28 路径不可执行、IV32 未保留 IV30 相对 IV26 的80% Sharpe改善，稳定性为 `peak_only`，不支持把26%改成30%。
- **不把外部完整卖 Call 机制替换进 1.3-r6。** `external_full_iv24` 的 Full CAGR/Sharpe/MaxDD 均弱于现行机制。
- `decline_inward_iv26` 通过预注册机械门槛，但只触发3次，Full Sharpe仅提高0.0018，CAGR下降0.34个百分点；记为**观察项**，不是生产升级建议。
- `tp95_half_iv26` 触发9次，但与现行路径几乎等价：CAGR仅高0.01个百分点、Sharpe低0.0002、MaxDD不变，没有足够经济意义。
- IC 主线仍不含 Call；本研究没有修改 1.3-r6、本地/远端信号、账本或日报。

## 固定口径

- IM 1.3-r6 的核心、动量、网格、双 Put、期货与 Put 成本、30%期货保证金/缓冲、现金收益全部不变。
- Call 仍只覆盖0.5倍核心仓，不覆盖动量仓或网格仓；完整核心1倍对应2张MO，因此组合中Call损益、成本和保证金乘0.5。
- T日收盘评估、下一可交易日官方收盘成交；受威胁救援继续使用 `rescue_next_listed`，即相对旧到期日严格更晚的最近实际挂牌到期日。
- 外部规则来自用户提供材料，仅作为待检验规则来源，不作为执行指令。外部完整候选没有采用材料中的85%/95%账户风险动态扩仓，因为其账户级风险口径无法与当前组合做等风险归因。

## 结论与后续边界

当前最合理决定是 `keep_iv26_watch_decline_inward`：生产继续使用 IV26 和现行管理；向内移仓只保留观察。若继续研究，应先解决所有 IV 门槛共享的临近到期/强制退出语义，并增加样本外或前瞻纸面期，而不是直接把 IV30 或三次事件形成的向内移仓写入主线。
