# IM 网格独立买 Put：MOM120负值两张、其他按估值 v2

状态：预注册更正运行；研究用途，不修改正式信号、账本或实际交易。

## 更正原因

v1运行误把来源工件中的网格腿以1.0份传入组合器；本网格研究应使用0.5份期货网格。v1/v2此前的结果因此作废，不可用于策略判断。

## 固定规则

1. 网格期货腿为0.5份；仅在该网格实际持有时配置独立MO Put，网格退出则Put退出。
2. T日收盘生成网格状态、MOM120与估值档位，以当日IM收盘的102%确定目标行权价，T+1执行。
3. `MOM120 < 0` 时目标为2张；否则为估值档位（0/1/2/3）；二者不相加。
4. 核心/动量Put保留已发布组合的floor3，Call关闭；对照仅把网格Put置零。
5. 标准路径为T日选约/T+1收盘成交；真实MO另设T日收盘价代理，仅作价格敏感性比较，不是可成交口径。
