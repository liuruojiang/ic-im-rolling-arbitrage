## 研究问题与配对

固定前三层结论：绝对 IV 严格大于30%、不增加卖方MOM120、M+1、卖95% Put、等名义q1、持有至到期。只检验卖Put期间同步买入同到期、同数量的深度虚值灾难保护Put：

- `none`：不买灾难保护Put，作为“不加第四层”的基线；
- `tail90`：目标行权价为前一交易日510500收盘价的90%；
- `tail85`：目标行权价为85%；
- `tail80`：目标行权价为80%。

真实挂牌层选择同到期且低于卖出腿行权价、最接近目标比例的挂牌Put。两腿必须在T+1开盘均有正价格和正成交量，否则整组不开仓，不允许退化成裸卖Put。

## 固定和排除

- 只转换固定核心0.5倍；动量腿不卖Put；IC无Call。
- 既有估值0/1档和原IC执行动量许可保留；不增加MOM120。
- M+1持有到期，不加提前展期、相对IV或估值防抖。
- 核心买Put三倍盈利兑现、季度IC T-3、动量、网格、指派恢复及整轮含成本回本退出保持相同。
- 每一条510500 Put腿单边5bp；IC单边1bp；期货30%保证金/缓冲；现金年化3%。不含bid/ask、冲击、容量、税和动态保证金。

## 数据与判断

- 真实挂牌层：2022-09-19至2026-08-14；5Y/10Y为N/A。
- 理论延展层：2015-04-16至2026-08-14；理论期权不冒充挂牌成交。
- `none`必须逐日复现第三层M+1路径，最大误差不超过`1e-12`。
- 保护候选只有同时满足以下条件才可保留：真实和模型全样本年化损失均不超过1.50个百分点；两层最大回撤均不得恶化超过0.50个百分点；至少一个可比层最差卖Put周期改善；样本内至少出现一次保护腿正到期赔付；至少两个相邻档方向一致。单点最优不晋级。
