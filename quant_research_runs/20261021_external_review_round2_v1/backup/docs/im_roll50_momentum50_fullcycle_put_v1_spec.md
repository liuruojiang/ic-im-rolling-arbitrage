# 50%滚IM + 50%动量门控：全周期Put叠加 v1

日期：2026-08-22  
状态：预注册研究规格；未批准实盘

## 研究目标

在已固定的“50%单纯滚IM + 50%动量门控滚IM”全周期代理路径上，只加入当前IM V2主线Put规则，比较不加Put、只保护固定0.5倍核心袖、按逐日总IM敞口等比例保护三条路径。Call与网格继续关闭。

## 固定底仓

- 沿用`im_roll50_momentum50_fullcycle_proxy_v1`的逐日底仓、平均贴水代理、换月、期货成本和现金规则；
- 动量参数固定为`MA35 / Mom18 / W2.5`，50% Abs20 OFF + 50%静态`Abs20 > 0`；
- 组合总IM名义为0.5、0.75或1倍；每1倍IM占用30%保证金及缓冲，其余现金按净年化3%计息；
- 不重新扫描底仓、贴水或组合权重。

## Put规则

- 采用IM V2规则：绝对估值轴`2.45 / 2.50 / 2.60`对应1/2/3张；57个月滚动相对估值轴`75% / 85% / 90% / 92.5%`对应1/2/3/4张；两轴取最大；若中证1000全收益指数`MOM120 < 0`，最低4张；最终0至4张；
- 目标期限约3个月，行权价约为IM的95%；T日收盘信号，T+1交易日收盘执行；月度期限重置，不做日内或逐日Delta再平衡；
- 真实IM/MO期直接读取`outputs/ic_im_system_mainlines_v2/daily_candidates.csv.gz`中`IM_4tier_q750_850_900_925_mom4`的冻结Put损益、费用、市值和持仓；不带入其网格、Call或期货底仓；
- 上市前使用既有中证1000理论Put模型，仅抽取Put组件。理论估值数据开始前，相对与绝对估值目标为0，但因模型价格本身从2015-04-16才可用，正式Put可比样本从该日开始；
- 57个月相对估值历史不足时，相对轴为0，绝对轴和MOM120轴仍按可用历史运行；
- 理论层与真实层切换时，在最后一个理论日计一次理论持仓平仓费用，真实层首日使用冻结真实建仓费用。

## 保护规模

1. `no_put`：原50/50底仓，不加Put；
2. `put_fixed_0p5_core`：冻结V2的1倍核心Put组件恒定乘0.5，只保护持续存在的0.5倍滚IM核心袖；这是与当前“Put只保护固定核心”口径一致的主比较；
3. `put_scaled_total_exposure`：Put组件逐日乘组合总IM名义0.5/0.75/1，保护全部当日IM敞口；该路径使用归一化分数张数，仅作研究诊断，不代表整数合约可直接执行。

禁止在组合仅0.5倍IM时仍使用完整1倍Put组件，以免过度保护。

## 收益与现金重组

- 先从原组合收益中扣除原现金利息，得到已经计入期货费用的底仓非现金收益；
- 加入缩放后的Put逐日损益后，再乘缩放后的Put费用：`(1 + 底仓非现金净收益 + Put损益) * (1 - Put费用) - 1`；
- 现金权重为`原组合现金权重 - Put市值占比`，不得低于0；现金收益按年化3%加入；
- Put损益、费用和市值均使用同一个保护缩放系数。

## 正式窗口与输出

- 共同可比样本终点取冻结Put数据终点2026-08-14，而不是无Put底仓较晚的2026-08-21；
- 正式Put可比全样本从理论Put模型起点2015-04-16开始，并展示10年、5年、3年、1年的年化收益和最大回撤；
- 保存逐日底仓、Put原始组件、缩放组件、现金、净收益、净值、回撤、目标/实际Put规模、代理/真实标记；
- 保存年度表现、窗口表现、回撤峰谷、资本占用和真实冻结组件逐日一致性检查。

## 结论边界

- 2015-04-16至2022-07-21的Put为理论定价代理，且底仓贴水使用上市后平均值回填，含明确前视假设；
- 2022-07-22以后Put为真实MO收盘路径，但冻结数据仅截至2026-08-14；
- 未计盘口价差、冲击成本、收盘成交容量、动态保证金上调、价格限制和整数张数误差；
- 本结果只用于研究比较，不构成当前信号、下单建议或生产参数变更。
