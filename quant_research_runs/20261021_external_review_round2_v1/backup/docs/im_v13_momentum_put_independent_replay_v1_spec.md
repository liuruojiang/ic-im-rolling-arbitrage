# IM v1.3 动量仓 Put 独立交易账本重放 v1

状态：预注册真实市场重放；研究用途，不修改冻结V2、v1.3研究信号、Poe、账本或交易配置，不构成实盘授权。

## 1. 问题

在保持 IM v1.3 fixed-performance v5 的期货核心仓、动量信号、独立网格、核心仓Call、成本、30%保证金/缓冲和3%现金收益不变时，用原始真实MO合约逐日独立维护动量仓Put，验证此前“按父Put收益比例缩放”的近似结论。

## 2. 样本与数据

- 只使用真实IM/MO：2022-07-22至2026-08-14。
- IM与MO来源沿用冻结CFFEX本地数据入口；MO Put原始字段必须包括合约、日期、OHLC、结算价、前结算价、成交量、持仓量、行权价、挂牌月及实际到期日。
- 上市前理论Put、模型贴水和任何代理扩展全部排除。
- 5年、10年明确为N/A，不允许理论数据补齐。

## 3. 固定策略组件

- 动量规则为v1.3：`MA35 / Mom18 / W2.5`、Abs20、`Volume/MA160>=0.85`及`Score>=150`过热退出；实际权重0/0.5/1，对应0/0.25/0.5倍IM。
- Put信号为当前`current_4tier_mom3`：估值档与MOM120负值3张下限取较大值，最高4张；约3个月、95%目标行权价。
- 核心仓始终0.5倍且保留独立核心Put；网格仓不加Put；Call仍仅覆盖核心仓。
- 不改变期货和网格的实际收益、换月、成本及Call逐日组件。

## 4. 独立Put执行账本

- 信号日T收盘评估，下一共同交易日T+1官方收盘成交；若目标合约没有有效正收盘价或成交量，则保持待执行状态，不虚构成交。
- 选定月份为执行规则的约3个月实际挂牌MO月份；在当日有正收盘、正成交量和正持仓量的Put中，选择行权价/IM收盘最接近95%的合约。
- 已持仓期间每日按官方结算价盯市；成交日旧仓先以收盘成交至结算、再建立新仓并从收盘计至结算。
- 同月数量变化在原合约增减；目标月份变化则旧合约平仓、新合约开仓；信号归零则平仓；不得持有越过实际到期日。
- 每归一化MO合约单边成本0.00005；不计价差、冲击、容量、涨跌停和动态保证金。

## 5. 整数映射

- 在4倍参考资本上运行整数交易账本。
- 核心仓目标原始整数为`2 * q`；动量仓目标原始整数为`2 * q * momentum_execution_weight`，其中`q`为0至4，因此始终为整数。
- 每日Put损益、成本、市值和张数再除以4回到1倍净资产归一化口径。
- 这证明规则在4倍参考资本单位上可整数化，但不替代用户实际账户资金规模、合约乘数和经纪商保证金映射。

## 6. 比较路径与验证

1. `core_only_independent_replay`：只运行核心Put独立账本。
2. `core_plus_momentum_independent_replay`：核心与动量Put使用两个相互独立的合约账本。
3. `scaled_approximation_reference`：只用于对照此前按比例缩放结果，不作为本次执行证据。

强制验证：

- 核心独立重放必须与v5当前基准逐日Put损益、成本、市值、数量和组合收益达到1e-12内一致，否则本实验失败关闭。
- 所有交易价必须逐腿回查原始MO当日收盘；新开合约必须有正成交量、正持仓量；目标数量必须为整数且非负。
- 独立动量账本不得复用核心仓的损益序列或通过乘法生成。

## 7. 输出与决策边界

- 报告真实全样本、3年、1年；5年、10年N/A并说明样本不足。
- 输出逐日曲线、两套Put账本、逐笔交易、生命周期、窗口指标、年度指标、价格完整性、延迟执行和资金审计。
- 仍沿用前次门槛：相对仅核心仓，最大回撤改善至少1个百分点、CAGR损失不超过0.5个百分点、Sharpe不下降、最差20/60日不恶化、现金非负，才记为研究支持；不自动修改主线。

正式输出：`outputs/im_v13_momentum_put_independent_replay_v1/`，首次生成后不得覆盖。
