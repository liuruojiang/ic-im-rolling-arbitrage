## 1. 文件与部署

单文件入口为`poe_ic_im_mainlines_v2_bot.py`。脚本包含POE头、PEP 723依赖、运行时兼容层、自然语言路由、哈希校验的v2真实逐日收益、指数比较曲线、实时行情抓取和信号状态计算，可直接复制到POE脚本编辑器。

本地复现：

```powershell
uv run --script .\poe_ic_im_mainlines_v2_bot.py "查询最近一年表现"
```

## 2. v2规则

- IC估值四档：`1.90 / 1.95 / 2.00 / 2.05`对应目标绝对Delta`25% / 50% / 75% / 100%`；`MOM120<0`时最低50%。IC不含Call。
- IM绝对估值轴`2.45 / 2.50 / 2.60`对应1/2/3张；57个月滞后相对轴`75% / 85% / 90% / 92.5%`对应1/2/3/4张，两轴取较大值；`MOM120<0`时最低4张，上限4张。
- IC、IM网格和IM Call规则继承v1；IM救援期限仍为`rescue_next_listed`。
- 截至2026-08-14的冻结状态：IC目标50% Delta、26张`510500P2609M07250`；IM目标4张`MO2610-P-6600`。

## 3. 自然语言命令

| 示例 | 行为 |
|---|---|
| `查询` | 返回IC与IM的v2冻结快照 |
| `实时信号` / `实时信号 IM` | 重新抓取盘中指数、期货和期权行情并计算盘中规则状态 |
| `信号` / `信号 IC` | 重新抓取行情并返回最近可确认的收盘规则状态 |
| `查询 IC 参数` / `查询 IM 参数` | 返回相应四档参数 |
| `查询最近一年表现` | 分别输出IC和IM净值、指数比较曲线及下方最大回撤曲线 |
| `查询最近3年` / `最近五年 IM` | 识别最近X年 |
| `从2023年到2025年` | 识别完整自然年区间 |
| `SC 2022年至2024年` | `SC`按IC兼容别名处理 |

日期解析另支持显式起止日期、最近/过去N月、今年、去年、前年、单独年份和年月。历史查询到达正式截止日以后时，仅在月度状态未变化的区间用真实期货、期权和指数日行情续接；遇到需要重新选合约的状态变更点即停止，不用假设持仓填补。

`最近三年半`按42个月解析；含“参数/规则/阈值”的混合命令有意优先进入参数查询，例如`实时信号和参数`只返回参数。这是单路由设计，不是未决的匹配顺序。

## 5. 实时数据与边界

- 中金所：IC、IM期货和MO期权链。
- 上交所：510500ETF及其期权链、实际挂牌到期月份。
- 腾讯：中证500和中证1000价格指数；东方财富作为备用。
- 每次“信号”命令重新联网取数，不复用上次结果。
- 中金所月度日行情按字段名读取并校验`合约代码/今收盘/今结算/前结算`，正式段后首日的期货及IM期权`前结算`必须与冻结锚点一致；收益、指数和数据段标记不允许出现重复交易日。
- 2026年市场阶段与合约到期顺延使用中金所官方休市安排；周末始终视为休市，9:25—9:30标为集合竞价，9:30起标为连续交易。代码明确登记当前正式日历覆盖年份为2026；其他年份仅有工作日回退，不冒充正式节假日日历，后续部署跨年时须补新年度交易所休市表。
- 到期前收盘判断使用“下一交易日等于到期日”，因此2026-06-19端午顺延至6月22日时，6月18日收盘仍能正确形成T-1月换信号。行情中只要出现未覆盖年度的挂牌合约，信号会显示日历提示；代码已登记2027年度休市表发布后扩表的显式TODO。
- IC目标Delta为0时目标数量严格为0且不选Put；IM连续救援计数达到5后再次受5%威胁时买回Call并暂停，不再生成第6次救援。
- IM目标Put为0张时显示“无需Put（目标0张）”，月换时不再选择无意义的新MO Put合约。
- IC期权续接除检查续接交易日外，还要求新浪历史日线包含正式截止日，并验证该日收盘与冻结`put_mark`一致；所有锚点容差统一为`1e-6`，缺少具体合约时包装为带产品、腿和合约号的错误。
- 估值基本面在POE中使用冻结PE/PB/股息/国债参数随最新价格做代理更新；MOM120使用最新价格指数历史做代理。页面会明确标示代理属性。
- 脚本没有账户读取、仓位写入、交易适配器或下单函数。
