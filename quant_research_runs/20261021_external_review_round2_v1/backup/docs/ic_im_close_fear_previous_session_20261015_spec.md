# IC/IM 收盘恐慌数据沿用规范

2026-10-15 用户明确选择：“收盘也沿用上一交易日，并明确标注”。本条覆盖此前盘中沿用规范中禁止收盘沿用的条款，扩展到正式收盘研究信号及网格账本。现有已确认账本不回写；首次适用于尚未完成的2026-10-14信号日及以后。

## 输入选择及资格

1. 合格当日恐慌值优先。网页/CSV同源一致、有限值0–100、日期顺序、真实时间、SHA-256及既有交易日历门禁保持。
2. 当日尚未发布时，仅可用信号日前一实际交易日的合格读数。相对信号日独立查正式日历；不得从昨日账本的沿用字段继续传递更早值。T-1也没有时继续失败关闭。
3. 若最新同日点只有15:00或更早更新，不能作为正式当日收盘恐慌值，即使取数跨到下一天。可以按本授权取同一合格CSV的严格T-1行；保留最新来源数据日T和页面实际更新时刻，不把它们改成T-1。
4. 沿用值必须有上一交易日收盘后来源证据。收盘输入采集在信号日收盘后或之后的真实日期；页面更新不能未来，也不能早于其声称的数据日。源冲突、未来、无时区、非法读数及日历不覆盖仍关闭。

## 身份与证明

收盘输入修订为 `ic_im_close_fear_previous_session_20261015_v1`，状态 `close_previous_session`。保留真实 `fear_data_date`、独立上一session、CSV最新日、页面数据日、原CSV SHA-256、URL、开始/完成及页面更新时间、`fear_fallback_applied=true`。

原因 `same_day_not_published` 时，来源最新日/页面日均须为T-1；原因 `same_day_not_close_confirmed` 时，来源最新日/页面日均须为T，页面更新为T日且不晚于15:00。用于计算的恐慌数据日始终为T-1。state与云端打包器分别独立校验。

网格25/50阈值、0.5倍、首次入场来源冻结及退出不重入不变。Put、Call、动量、季度/月度维护及schema4/r1不变；fix11 BUILD/RULE/DELIVERY保持参数身份，由独立输入修订明确本次授权。旧信号身份与历史记录保持原值。
