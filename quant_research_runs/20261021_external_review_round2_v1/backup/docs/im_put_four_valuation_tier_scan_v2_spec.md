# IM Put 估值四档细分扫描 v2（预注册）

- 版本：`im_put_four_valuation_tier_scan_v2`
- 日期：2026-08-20（Asia/Shanghai）
- 性质：研究参数扫描；不修改冻结的`ic_im_system_mainlines_v1`。

## 1. 研究问题

现有IM Put估值规则为三档，第四档若设在样本外就不会触发。本版把滚动估值分位区间内部细分为四档，检验每1倍固定IM底仓的最高保护由3张扩展到4张。

## 2. 固定组件

- 固定1倍滚IM、`0.85/1.25`估值网格与冻结的每日D10/IV26/5% `rescue_next_listed` Call保持不变。
- Put仍使用三个月目标期限、95%目标行权价、实际挂牌MO合约、月度重置和T收盘评估/T+1官方收盘执行。
- `MOM120<=0`只保底3张，不直接触发4张；4张只能由估值第四档触发。
- 网格新增IM不增加Put或Call覆盖。
- 绩效按每1倍期货30%保证金/缓冲及剩余现金年化3%计算。

## 3. 四档定义

每个交易日使用当月以前最近57个月末的`unbounded_median_knot`，以线性分位数计算四个阈值；不读取当月或未来数据。相对档位为0/1/2/3/4，最终估值档取固定绝对档0/1/2/3与新相对档的较大值。

| 候选 | 57个月滚动分位阈值 | 说明 |
| --- | --- | --- |
| `IM_baseline_3` | 原`75/85/95`三档 | 冻结基准 |
| `IM_existing_val_top_4` | 原估值3档直接映射4张 | 最窄的第四档参照 |
| `IM_4tier_q750_850_900_950` | `75/85/90/95` | 保守四档，保留95%最高边界 |
| `IM_4tier_q750_850_900_925` | `75/85/90/92.5` | 只下移最高边界 |
| `IM_4tier_q725_825_875_925` | `72.5/82.5/87.5/92.5` | 邻近均匀阶梯 |
| `IM_4tier_q700_800_875_925` | `70/80/87.5/92.5` | 更宽的低中档邻域 |

四档候选均按`max(固定绝对档, 新相对档, MOM120保底3张)`形成最终0至4张目标。

## 4. 数据、区间与验证

- 正式结论只使用真实IM/MO样本：2022-07-22至2026-08-14。
- 估值阈值历史来自冻结的日/月估值数据；57个月样本严格早于阈值生效月。
- 必须报告`full/last_10y/last_5y/last_3y/last_1y`；较长窗口截到真实样本起点。
- 基准必须同批重跑，并与冻结`full_put_grid_call`逐日收益核对，最大绝对误差不超过`1e-12`。
- 必须审计第四档目标天数、实际持有4张天数、第四档事件数、估值档分布、Put成本、最大市值占用及最低原始现金权重。

## 5. 判定

本版以风险改善优先。候选进入观察需同时满足：

1. 第四档至少触发5个交易日且至少跨2个独立事件；
2. 全样本最大回撤不劣于基准；
3. 全样本年化收益相对基准下降不超过2个百分点；
4. 全样本Sharpe不低于基准；
5. 近3年与近1年不能同时在收益和最大回撤上均劣于基准；
6. 最低原始现金权重不低于0，且所有收益有限。

若只有单一阶梯通过而相邻阶梯不支持，标记`peak_only`，不得直接替换冻结主线。

## 6. 成本与限制

- 继承正式MO Put、IM期货、网格及Call成本。
- 排除买卖价差、收盘冲击、涨跌停未成交、盘口容量、动态保证金上调和税费。
- 每日官方收盘价不等于收盘集合竞价可成交证明；本版不构成实盘接入或下单授权。
