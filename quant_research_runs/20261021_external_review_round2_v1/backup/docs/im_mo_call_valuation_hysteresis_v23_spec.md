# IM + MO Call 十年PE估值滞回 v23 预注册规格

冻结日期：2026-08-19（Asia/Shanghai）  
状态：官方MO短样本机制验证；未批准实盘。

## 1. 研究问题与边界

在v22已经确认“空仓时应每日收盘检查IV和可卖合约”的基础上，单独检验外部策略的估值滞回是否能修复每日入场在2024年9月急涨中的损失：

- PE十年分位不高于20%时进入低估/修复态；
- 进入后即使PE回升仍保持低估/修复态，直到PE十年分位达到60%才退出；
- 低估/修复态只允许卖出剩余期限30—60天、虚值至少25%的Call；
- 其余状态按30—60天/15%、61—90天/20%、91—120天/25%的顺序寻找Call；
- 任一状态只有所选合约IV不低于26%才卖出。

本版不叠加盈利40%/60%/80%分批止盈、盈利80%提前展期、受威胁向上向后移仓、急跌向内移仓、85%/95%风险度扩缩仓、MOM门控或网格。估值状态变化本身不强平已有Call，只影响下一次空仓入场或必须换月时的选约。

## 2. 基准、候选与归因

- 底仓：冻结的1倍滚IM + `reconstructed_valmom_floor3`三个月95% Put；
- 无Call参照：v20 `base_core_put`；
- 既有月评D10参照：v20 `front_d10_iv26`；
- 既有每日D10参照：v22 `front_d10_iv26_daily`；
- 同路径控制A：`article_ladder_iv26_daily`，每日检查、始终使用文章高位期限—虚值率阶梯，不使用估值状态；
- 正式候选B：`article_pe20_60_hysteresis_iv26_daily`，在A上只增加正式PE20/60滞回；
- 数据敏感性诊断C：`article_pe20_60_hysteresis_iv26_daily_backfill_diag`，规则与B相同，但允许2012-06-29至指数发布日前的官方回溯PE参与十年分位。C不得参与正式通过判定。

每1张IM固定卖2张MO Call，只覆盖固定底仓，不按可用资金扩张数量。模型层为2015-04-16—2026-08-14连续期权近似；真实层为2022-07-22—2026-08-14官方IM/MO收盘与结算。正式结论只看官方真实层，模型只作长期方向诊断。

## 3. PE十年分位与滞回状态

PE取本地中证1000价格指数文件`official_rolling_pe`，不用第三方六种PE字段反选结果。

正式B：

- 可用估值历史不早于中证1000发布日期2014-10-17；
- T日分位样本为`[max(2014-10-17, T-10年), T]`内所有非空PE观测；
- 不要求足十年才产生分位，早期使用当时已有的扩展历史；
- 弱经验分位为`样本中PE <= T日PE的行数 / 样本行数`；
- T日收盘计算，最早T+1收盘成交；当日PE可以参与当日分位，不使用T日之后数据。

诊断C只把估值历史起点改为本地官方回溯序列首日2012-06-29。由于该段早于指数发布日期，必须标记为pre-publication backfill diagnostic。

状态机从各自估值起点开始：初始为普通态；任一日分位`<=20%`转为低估/修复态，并一直保持；任一日分位`>=60%`转回普通态，并一直保持。20%—60%之间不切换。普通态不是“高估断言”，只是尚未处于低估后修复阶段。

## 4. 每日检查、选约与执行

每日状态机继承v22的收盘信号、T+1收盘执行、持仓逐日结算、成本和资本恒等式，但不使用TP80：

- 空仓时每个交易日收盘检查；已有Call不因每日IV或PE变化重复加仓；
- IM月度事件日，若现有Call到期日晚于事件的`current_expiry`，保持远月仓位；否则买回并按当日状态重新选择；
- 若T日选中，冻结具体合约并在T+1收盘成交；计划成交日不可交易时保持同一冻结动作顺延，不用未来数据重选；
- 实盘可交易要求：T日及成交日收盘价、成交量、持仓量均为正，T日可以反解IV；
- 分层按顺序选择首个存在合格合约的层；层内优先虚值超额最小、DTE最接近中点，再按持仓量和成交量由高到低、到期日、行权价、合约代码确定；
- 低估/修复态唯一层：DTE 30—60、最低虚值25%、中点45；
- 普通态三层：30—60/15%/45，61—90/20%/75，91—120/25%/105。

模型层在同样DTE和状态规则下选最接近中点的理论到期日，以`spot*(1+最低虚值率)`为连续行权价，使用当日模型波动率定价和IV26门控。

## 5. 成本、现金与资本

- 2张MO Call篮子每边成本1bp，开仓/平仓各1bp，换仓2bp；
- Call保证金、Put市值、70%可用现金上限和余额净年化3%收益完整沿用v19/v20/v22；
- 任一日Put市值加Call保证金超过70%记为资本穿透；
- 不模拟盘口点差、冲击成本、涨跌停或盘中成交，官方真实层仍是收盘可成交近似。

## 6. 必报结果与审计

1. 模型full/10Y/5Y/3Y/1Y，以及真实full/10Y/5Y/3Y/1Y；真实10Y/5Y不足时必须显示N/A；
2. 所有可用窗口的CAGR、MaxDD、CAGR差和MaxDD改善，真实逐年区间收益；
3. A与B的开仓、换仓、平仓、持仓日、Call损益、成本、保证金及各层选约次数；
4. B/C逐日PE、十年分位、样本数、状态、阈值穿越和状态区间；
5. 2022-07-22—12-31、2024-09-18—10-08、2025、2026YTD压力与机会窗口；
6. A/B信号逐日差异，尤其2024-09-26是否仍卖出以及所选行权价；
7. v20无Call/月评与v22每日D10逐日奇偶、收益/现金恒等式、T/T+1因果性、冻结合约无未来重选、IV门控、DTE/虚值率、官方收盘、资本穿透和正式/回溯PE隔离审计。

## 7. 预注册判定

B相对同路径控制A的机制通过条件：

- 真实全样本和3Y CAGR各自落后A不超过1个百分点；1Y落后不超过3个百分点；
- 真实全样本MaxDD改善，且不得在可用的full/3Y/1Y三个窗口中有任何一个加深超过2个百分点；
- 2024-09-18—10-08组合收益相对A至少改善10个百分点；
- 2022-07-22—12-31组合收益不低于A；
- A/B至少产生2次不同的真实选约、跳过或入场动作；
- 资本穿透与最终未执行计划为0，全部审计通过。

满足则记为`valuation_hysteresis_supported_real_short_sample`；收益容忍通过但压力改善不足记为`valuation_hysteresis_not_material`；压力改善通过但收益容忍失败记为`stress_tradeoff_only`；其他为`not_supported`。无论结果如何，最高只能进入官方MO短样本观察池，不获准实盘。

诊断C只报告数据敏感性。若C与B在真实样本的状态、交易或结论不同，必须标记`prepublication_history_sensitive`，不得用C替代B。
