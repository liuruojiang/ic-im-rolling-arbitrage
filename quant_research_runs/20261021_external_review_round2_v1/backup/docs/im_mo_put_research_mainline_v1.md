# 中证1000 IM/MO Put保护研究主线 v1

记录日期：2026-08-19  
状态：用户确认的研究主线；未获准实盘

## 1. 冻结结论

中证1000 Put保护的后续研究主线固定为：

- 估值基础：PB、ERP、过去一年已实现股息贡献三项固定经济压力的二取三中位数`unbounded_median_knot`。
- 估值绝对轴：固定经济分`2.45 / 2.50 / 2.60`依次进入1/2/3档。
- 估值相对轴：仅使用上月及以前57个月末观测，滚动`75% / 85% / 95%`分位依次进入1/2/3档；当月门槛锁定。
- 估值最终档：绝对轴与相对轴取较大值，目标为0/1/2/3张MO Put。
- 趋势满保护：当中证1000全收益指数`MOM120 <= 0`时，每1份IM固定持有最高档3张MO Put；当`MOM120 > 0`时，重新服从估值最终档0/1/2/3张。估值与趋势取较大值，不相加，上限为3张。
- Put：MO，目标期限3个月、95%目标行权价，按月退出并换入，不持有到期。
- 评估与执行：T日收盘评估，T+1下一共同交易日收盘执行；不做每日Delta再平衡。
- 资本口径：1倍IM方向名义，30%保证金/缓冲，70%现金净年化3%；Put市值从可计息现金中扣除。

## 2. 选择依据

- v7在不读取Put收益的前提下，从36—84个月、四组分位阶梯的二维扫描中选出`57个月 + 75%/85%/95%`宽平台中心；2022—2024低估、2025修复、2026一定高估的年代语义成立。
- v13补回2015年高估信息后，确认2015-04-16模型首日估值已为3档，避免MOM120在快速股灾中明显滞后。
- v14中，趋势满保护3张的模型全样本/近10年/近5年为`2.90%/-54.21%`、`5.04%/-26.45%`、`7.20%/-20.22%`；真实IM/MO全样本/近3年/近1年为`16.99%/-16.35%`、`27.07%/-16.35%`、`33.75%/-9.63%`。
- v14机械规则原按“最低有效保护强度”选择2张；用户在审阅2/3张边际结果后，按风险优先偏好明确选择3张为研究主线。3张在多数模型和真实窗口收益更高、模型长窗回撤更低；限制是相对2张尚未在真实全样本最大回撤上显示增量，且5倍Put成本下真实CAGR低约0.28个百分点。
