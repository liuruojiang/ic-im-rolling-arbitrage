# IM v1.3-r6 完整策略：当月—下月价差触发换仓扫描 v3 预注册

## 研究问题与边界

- 检验监控当前持有 IM 与下一实际挂牌 IM 的价差，是否比固定 T-1/T-2/T-3 换仓取得更好的完整 v1.3-r6 收益风险表现。
- 只改变核心/动量/网格使用的 IM 期货换仓触发；动量、估值、网格状态、独立核心/动量 Put、Call 月度日历、D10/IV26、5% 威胁与 `rescue_next_listed` 均保持正式 r6。
- 研究输出不修改主线、Poe、GitHub/Gmail、持久账本或实盘授权。

## 价差信号

- 每日收盘用 `log(当前合约收盘价 / 下一挂牌合约收盘价) * 365 / 两合约实际到期日间隔天数` 计算年化价差。
- 正值表示当前合约价格高于下月合约；当年化价差不低于阈值时，收盘卖当前、买下一挂牌合约。
- 只在旧合约剩余 15 个实际交易日内监控；若始终未触发，T-3 收盘强制换仓，避免进入最后两个交易日。
- 阈值固定为 0%、5%、10%、15%、20%。所有判断只使用当日及以前数据。

## 对照与完整重放

- 同一运行包含正式 `expiry_settle_front`，固定 `next_t01_close`、`next_t02_close`、`next_t03_close`，以及五个价差阈值候选，共九条路径。
- 使用 CFFEX 官方逐合约 IM 行情及冻结 MO 数据，真实区间 2022-07-22 至 2026-08-14。
- 候选日仍取得旧合约官方结算收益，收盘按官方收盘价判定并换仓，下一交易日持有新合约；首次 1bp，换仓 2bp。
- 完整重算期货结算收益、动量换月成本、网格开平仓/换月、独立核心与动量 Put、Call 的 IM 归一化分母；Put/Call 自身日历和规则不变。
- 每 1 倍期货保留 30% 保证金/缓冲，现金按 3% 年化；期权成本和组合乘法顺序沿用 r6。

## 审计、窗口与判断

- 正式基线逐日完整收益、现金、期货、网格、Put、Call 误差不高于 1e-12；合约必须实际挂牌且成交量、持仓量有效。
- 报告 Full/3Y/1Y；5Y/10Y 因真实历史不足为 N/A，禁止代理补齐。
- 主要门槛：相对固定 next T-3，Full 与3Y CAGR均不降低，Full MaxDD不恶化超过2个百分点；同时披露阈值实际触发次数、T-3兜底次数、触发时点分布、年度归因和流动性。
- 对阈值选择进行期货交易成本 2倍、5倍压力测试。任何领先若集中于少量极端换仓或单一年份，只能作为研究线索。
- 通过门槛也不自动升级正式 r6 或构成下单建议。
