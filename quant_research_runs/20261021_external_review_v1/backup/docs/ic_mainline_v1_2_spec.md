# IC 滚动套利叠加中证500动量研究候选 v1.2

预注册日期：2026-08-23（Asia/Shanghai）  
状态：独立研究候选；未批准实盘；不修改冻结 IC/IM V2 主线、Poe 或交易配置。

## 1. 版本目的与父规则

本版本补齐 IC/IM 动量分袖 v1.2 的 IC 腿。仓库不存在独立的 `ic_mainline_v1_1.py`，因此 IC 父规则使用当前冻结 IC V2；动量规则逐项继承 A 股多头组合 v1.3 的中证500袖；分袖与 Put 消融结论来自 `2026-08-23_滚IC滚IM叠加动量完整研究记录.md`。

本版本只生成研究目标日程和审计，不生成订单，不修改 `notes/mainline_registry.md`、冻结规范、首次正式输出或 `poe_ic_im_mainlines_v2_bot.py`。

## 2. 50:50期货分袖

- 50%资本始终运行裸滚IC核心袖；
- 50%资本运行中证500动量门控IC袖；
- 中证500动量参数固定为 `MA=110 / Mom=24 / W=2.0`；
- Score条件为 `Score>0`；Abs20为 `50% OFF + 50% Abs20>0`；
- 收盘目标只允许 `0 / 0.5 / 1.0`，T日收盘确认，T+1共同交易日形成实际动量权重；
- 动量IC名义等于 `0.5 × 动量实际权重`，因此无网格总IC名义为 `0.5 / 0.75 / 1.0`。

不引入贴水补偿、目标波动、回撤缩仓、成交量过滤或 A 股 v1.3 中未对中证500启用的其他覆盖层。

## 3. Put覆盖

核心袖使用完整冻结 IC V2 Put：

- 估值 `1.90 / 1.95 / 2.00 / 2.05` 对应目标绝对Delta `25% / 50% / 75% / 100%`；
- `MOM120<0` 时目标绝对Delta最低50%；
- 核心袖对组合的目标Delta贡献为 `0.5 × 完整V2目标Delta`。

动量袖只使用估值Put：

- 保留相同估值四档；
- 删除动量袖自身的 `MOM120<0` 最低50%下限；
- 动量袖空仓时Put目标为0；
- 动量袖对组合的目标Delta贡献为 `0.5 × 动量实际权重 × 估值目标Delta`。

组合Put目标为：

```text
组合目标Delta
= 0.5 × 完整IC V2目标Delta
+ 0.5 × 动量实际权重 × 仅估值目标Delta
```

期限、95%目标行权价、随IC月换重置、T收盘评估和T+1共同交易日收盘执行完整继承冻结规则。IC明确不卖Call。

## 4. 独立估值网格

- 估值分数 `<=0.375` 时，T+1活跃IC官方开盘新增1倍；
- 估值分数 `>=1.000` 时，T+1活跃IC官方开盘退出；
- 网格不接受动量门控；动量归零不得强制退出网格；
- 网格新增仓不配置Put，也不卖Call；
- 网格参数只继承冻结V2，不把本轮仅3个独立周期的回测结果解释为参数升级证据。

含网格时总IC名义为 `1.5 / 1.75 / 2.0`。

## 6. 强制验证

1. 中证500动量参数、Score、Abs20、收盘目标与 A 股 v1.3 逐项一致。
2. 动量实际权重只允许0/0.5/1，且等于上一共同交易日收盘目标。
3. 核心/动量期货名义分别为0.5和 `0.5×动量实际权重`。
4. 核心Put、动量估值Put与总目标Delta严格满足分袖公式。
5. 动量空仓时动量Put为0；MOM120下限不得进入动量袖Put。
6. IC Call目标始终为0。
7. 网格状态与冻结网格逐日一致、T+1开盘执行、独立于动量且不增加Put。
8. 所有日期唯一并一对一对齐；公式最大误差不超过 `1e-12`。
9. 冻结V2、主线登记表和Poe文件不得修改。
