# IC v1.3 衰减50%与60%成本及周期最终对决 v1

日期：2026-09-17  
状态：研究预注册；不修改生产、账本、日报或交易规则。

## 固定条件

- 当前完整IC v1.3组合；季度T-3期货路径；IC无Call。
- M+1、95% 510500卖Put、等名义数量、绝对IV严格高于37.5%。
- 即时估值0/1档加原IC v1.3执行动量许可，不引入卖方MOM120。
- 最多提前展期一次，新腿重新准入；固定核心IC与核心Put同步切换。
- 核心Put三倍盈利兑现；无灾难保护、无相对IV。

## 对决

- 权利金衰减：50%与60%。
- 所有510500买卖Put单边成本：5BP、10BP、20BP；每档完整重跑状态机。
- 期货单边1BP；每1倍期货30%保证金/缓冲；现金年化3%。
- 每档与相同成本、相同核心Put三倍兑现但不卖Put的组合比较。
- 5BP下对每个卖Put周期做留一：用同口径无卖Put收益替换该周期区间。

## 预注册判定

50%替代60%成为研究候选须同时满足：

1. 真实挂牌层5/10/20BP下，50%的CAGR与Sharpe均不低于60%，最大回撤绝对值相对60%恶化不超过0.5个百分点；
2. 真实挂牌层50%的最差逐周期留一年化不低于60%；
3. 理论延展层10BP下，50%相对60%的CAGR落后不超过0.1个百分点、Sharpe落后不超过0.01、最大回撤绝对值恶化不超过0.5个百分点；
4. 50%在真实与理论层10BP下均通过相对无卖Put对照门槛：CAGR不低于对照、Sharpe差不低于-0.05、回撤绝对值恶化不超过1个百分点。

单周期绝对贡献超过50%继续标记集中度失败。该项若两档共同失败，属于共同证据限制，不阻止两档之间的相对排序，但阻止生产晋级。

## 限制

真实挂牌历史较短，理论层为模型延展。未纳入动态保证金、强平、税费、盘口容量、整数账户张数和显式成交延迟。
