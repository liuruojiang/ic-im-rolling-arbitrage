# 滚 IC / IM 系统研究主线冻结 v1

冻结日期：2026-08-20（Asia/Shanghai）  
状态：用户确认的研究主线；未批准实盘。

## 1. 目的与证据边界

本版本不重新选择参数、不重跑市场收益，只把用户最终确认的 IC 与 IM 系统组成固化为唯一研究主线，并从既有首次正式输出提取对应路径。旧研究结论和失败审计不得改写；本版通过只表示主线定义、来源哈希、组件隔离与资金口径复核一致，不表示获准自动或人工下单。

## 2. IC 系统主线

### 2.1 固定底仓

- 常态持有1倍名义滚动 IC，按既有活跃合约和月度展期规则执行。
- 每1倍期货在收益核算中保留30%保证金/风险缓冲；其余可计息现金净年化3%。

### 2.2 买 Put

- 估值为中证500三项无界固定经济压力的二取三中位数：PB、ERP、过去一年已实现股息贡献。
- 分数`1.90 / 2.00 / 2.10`对应目标绝对Delta`25% / 50% / 75%`。
- 中证500全收益指数`MOM120 <= 0`时，目标Delta最低25%；估值和趋势取较大值、不相加。
- 使用510500 ETF Put；执行日加3个日历月为目标，选择实际到期日离目标最近的挂牌合约月，目标行权价/ETF收盘价约95%。
- 随IC月换重置，不持有到期，不做每日Delta再平衡；T收盘评估、T+1共同交易日收盘执行。

### 2.3 固定估值网格

- 使用同一无界固定经济分数。
- T收盘分数不高于`0.375`，T+1活跃IC官方开盘新增1倍；分数不低于`1.000`，T+1官方开盘退出新增仓。
- 网格只有0或1倍两个状态，持有期照常逐月滚IC。
- 新增网格仓不配置Put。

### 2.4 明确排除

- IC系统不卖Call；所有IC Call研究均为历史否证/诊断，不进入本主线。
- 权威既有路径为`ic_put_grid_call_combined_v2`中的`model_grid_only`和`real_grid_only`；必须验证其Call损益、成本、保证金、覆盖和`has_call`均为0/False。

## 3. IM 系统主线

### 3.1 固定底仓

- 常态持有1倍名义滚动IM，按既有活跃合约和月度展期规则执行。
- 收益核算继续按每1倍30%保证金/风险缓冲与剩余现金净年化3%。

### 3.2 买 Put

- 估值为PB、ERP、过去一年股息贡献三项固定经济压力的二取三中位数`unbounded_median_knot`。
- 绝对轴`2.45 / 2.50 / 2.60`与仅使用上月及以前57个月末数据的相对轴`75% / 85% / 95%`分别给出1/2/3档，取较大档。
- 中证1000全收益指数`MOM120 <= 0`时，每1倍IM最低3张MO Put；最终0/1/2/3张，上限3张。
- 执行日加3个日历月为目标，选择实际到期日离目标最近的MO月份，目标行权价/IM约95%；月度重置，不持有到期，不每日Delta再平衡；T收盘评估、T+1共同交易日官方收盘执行。

### 3.3 固定估值网格

- 使用`unbounded_median_knot`；分数不高于`0.85`时T+1活跃IM官方开盘新增1倍，分数不低于`1.25`时T+1官方开盘退出。
- 网格最多新增1倍，组合IM总名义为1或2倍；持有期间逐月滚IM。
- 新增网格仓不增加Put，也不增加Call覆盖。

### 3.4 卖 Call

- 只覆盖固定1倍IM底仓，每1张IM卖2张MO Call；不覆盖网格新增仓。
- 空仓时每日T收盘检查：以当前IM参考到期日为锚点，选择严格更晚的最近实际挂牌MO Call到期日，在该期限内取最接近0.10 Delta的虚值Call；合约自身IV不低于26%时，T+1官方收盘开仓。
- 月度节点只刷新参考期限，不把策略改成月评。
- 已有Call每日检查`旧行权价/中证1000价格指数收盘-1`；不高于5%时，T+1官方收盘买回旧Call，并选择相对旧到期日严格更晚的最近实际挂牌到期日，行权价至少提高5%。
- 上述救援期限的规范名称是`rescue_next_listed`，不是固定增加一个日历月；连续救援继续从当前远月向后，最多5次。第6次或没有更晚合格合约时买回并暂停至下一IM月度节点。
- 救援豁免IV26；不包含PE门控、分批止盈、TP80、急跌向内移仓或风险度扩仓。

### 3.5 资金口径

- 绩效收益继续继承冻结研究的30%保证金/风险缓冲假设，不事后增加可计息现金。
- 资金可行性另使用用户提供的实盘事实假设：每1倍IM实际期货保证金不高于15%。因此旧统一审计中以30%×2倍计算的早盘穿透，需按15%×实际IM单位重新解释。
- 15%是用户提供的上限假设，不是本研究从经纪商结算单独立验证的事实；实盘前仍须用实际账户保证金率、交易所临时上调和期权保证金规则复核。

1. 上述正式输出清单和关键文件SHA-256一致。
2. IC主线路径Call字段全部为0/False，IC总单位只为1或2倍。
3. IM完整路径Put和Call不随网格仓翻倍，事件和组件隔离沿用旧审计通过项。
