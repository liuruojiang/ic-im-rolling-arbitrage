# IM + MO Call 固定底仓收益增强 v19 预注册规格

冻结日期：2026-08-19（Asia/Shanghai）  
状态：预注册研究；未批准实盘。

## 1. 研究问题与边界

在冻结的固定1倍滚IM + `reconstructed_valmom_floor3` 三个月95%主线Put上，卖出固定1倍标的名义的 OTM MO Call，测试期限与目标Delta是否能提高收益且不显著恶化回撤。

本版完全排除估值网格。新增估值仓、网格收益、网格保证金和网格Put均不得进入任何路径。Call只覆盖固定1倍IM名义。

## 2. 基准与样本

- 无Call基准：v14 `reconstructed_valmom_floor3`逐日模型/真实路径；
- 模型：2015-04-16—2026-08-14，中证1000全收益指数 + 冻结理论Put + 理论Call；
- 真实：2022-07-22—2026-08-14，实际滚IM、官方MO Put和本版新建的官方MO Call；
- 真实样本不足5年，5Y/10Y显示N/A，最高只能进入观察池。

## 3. 冻结候选

1. `front_d10`：下一到期月、目标Call Delta 0.10；
2. `front_d20`：下一到期月、目标Call Delta 0.20；
3. `2m_d10`：到期日最接近评估日后2个月、目标Delta 0.10；
4. `2m_d20`：同期限、目标Delta 0.20。

Delta只用于选择行权价，不缩放卖出名义。每1张MO对应100倍指数、1张IM对应200倍指数，因此真实层固定卖出2张MO Call；模型层使用1倍连续标的名义。

## 4. 月换与因果执行

- 初始样本日T评估，T+1收盘首次卖出；
- 此后以真实/模型IM月度换约日为当前到期日，在到期日前第2个交易日T评估、前1个交易日T+1收盘买回旧Call并卖出新Call；
- `front`选择实际到期日严格晚于当前到期日的最近挂牌月；`2m`选择满足该条件且到期日最接近T+2个月的挂牌月；
- T日冻结合约，T+1不得根据新Delta重选；若真实预选新Call或旧Call没有正收盘价、成交量、持仓量，则保留旧仓并顺延同一预选动作；
- 不设置Delta触发提前移仓、止损、冷却期或估值/MOM门控；这些必须另建版本。

## 5. Delta与定价

### 模型层

使用与既有IM理论Put市场一致的中证1000现货、政府债利率、过去一年股息贡献和波动率代理，以Black-Scholes欧式Call定价，并反解精确目标Delta行权价。

### 真实层

1. 只在T日实际挂牌、OTM且收盘价/成交量/持仓量均为正的目标到期月Call中选择；
2. 用T日官方Call收盘价反解隐含波动率，再计算Call Delta，选择与0.10/0.20误差最小者；
3. 隐含波动率无法在1%—500%区间求解的合约不参与；不使用未来报价或T+1重算结果选合约；
4. 真实日终损益按官方结算价盯市，交易价为官方收盘价。

收益计算前的市场预检显示：49次评估×4候选共196次选择，无缺失、T+1不可执行0；Delta中位误差0.008—0.020。`2m_d10`最大误差0.108，必须在结果中披露并标记数据敏感，不得按收益删除该日期。

## 6. 收益、成本与资本

- Call为空头，收到权利金与负债同时建立，不把权利金直接记为收益；收益来自空头逐日盯市；
- MO每张每边成本0.5bp；2张合计每边1bp，月换旧2张买回+新2张卖出合计2bp；
- 组合收益为IM毛收益 + Put损益 + Call空头损益后，依次乘IM、Put、Call成本；
- Call按独立义务仓管理。保证金近似为每张 `[Call结算价 + max(12%×指数 - OTM额, 7%×指数)] ×100`，2张合计后除以`IM结算价×200`；模型用同式连续名义；
- 可计息现金为 `max(0, 70% - Put市值比例 - Call保证金比例)`，年化3%；
- 任一交易日Put市值+Call保证金超过70%记为资本穿透，候选不得通过。

## 7. 必报结果

模型full/10Y/5Y/3Y/1Y，真实full/3Y/1Y的CAGR、波动、Sharpe、MaxDD、Calmar；逐年结果；交易次数、Delta误差、IV、期限、成交量、持仓量、ITM天数、Call损益/成本、平均与最高保证金、资本穿透；以及2024-09-18—10-08急涨期。

## 8. 预注册判定

候选进入观察池必须同时满足：

1. 模型full、10Y CAGR均不低于无Call基准；
2. 真实full、3Y CAGR均不低于无Call基准；
3. 模型和真实full MaxDD均不得加深超过2个百分点；
4. 资本穿透0，真实T+1不可执行0，Delta中位误差不超过0.025、最大误差不超过0.12；
5. 所有基准奇偶、收益/现金恒等式、因果和真实收盘价审计通过。

若多条通过，机械选择四个主窗口（模型full/10Y、真实full/3Y）相对无Call CAGR改善最小值最高者；同分依次选择真实full MaxDD较浅、Delta较低、期限较短者。相同期限的0.10/0.20两档均通过才标记`narrow_stable`，否则`peak_only`。无候选通过则保留无Call基准。
