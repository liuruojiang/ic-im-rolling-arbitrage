# IC + 510500 Put 固定/动态极高估门控 v9 预注册规格

- 版本：`ic_510500_put_extreme_valuation_gate_v9`
- 预注册日期：2026-08-17，Asia/Shanghai
- 状态：研究回测；未获准实盘；不得解释为交易建议或接入自动/人工下单
- 估值母版：冻结的`ic_510500_put_absolute_valuation_stress_v5`
- 执行母版：冻结的`ic_510500_put_persistent_stress_hold3m_v7`三个月Put持有到期引擎
- 证据边界：2015—2026历史已被多轮研究使用，本版没有独立OOS；任何通过最多为`watchlist`

## 1. 研究问题

v8证明尾部概率模型有轻微信息，但概率—价格门控没有形成稳健组合改善，且持有到期会把短暂信号放大成长时间暴露。v9不再增加预测特征、状态机、压力保持或Put定价条件，只测试用户提出的更简单假设：

> 只有估值进入固定或动态的“极高估”区，才启动100%三个月Put；买入后持有到期。不到极高估不新开，到期时不再极高估则不续保。

本版同时比较固定绝对阈值与动态滚动阈值，但两者使用相同的PB、ERP和过去一年股息贡献、相同权重、相同执行引擎。PE仅作报告，不进入信号，避免在固定/动态分支间更换信息集。

## 2. 固定极高估分支

完全沿用v5的固定绝对风险构造：

- PB：`<2.00 / 2.00—2.50 / >=2.50`映射为0/1/2；
- ERP：`>3.00% / 1.50%—3.00% / <=1.50%`映射为0/1/2；
- 过去一年股息贡献：`>=2.00% / 1.00%—2.00% / <1.00%`映射为0/1/2；
- `fixed_risk = 25%×PB档 + 50%×ERP档 + 25%×股息档`，范围0—2。

V7在`fixed_risk>=0.75`即可武装。v9把启动阈值冻结为：

| 候选 | 启动条件 | 运行前模型触发日/段数 | 真实段触发日/段数 |
|---|---:|---:|---:|
| `fixed_150` | `fixed_risk>=1.50` | 1044 / 9 | 24 / 3 |
| `fixed_175` | `fixed_risk>=1.75` | 804 / 9 | 24 / 3 |
| `fixed_200` | `fixed_risk>=2.00` | 645 / 7 | 0 / 0 |

固定2.00要求三个分项都在最高风险档；真实段没有触发，仍保留为结构边界，但不得因模型结果好看晋升。

## 3. 动态极高估分支

对每个评价日T，只使用`T-8个日历年`至T的日度历史（含T）计算：

- `PB风险分位 = P(历史PB <= 当日PB)`；
- `ERP风险分位 = P(历史ERP >= 当日ERP)`；
- `股息风险分位 = P(历史股息贡献 >= 当日股息贡献)`；
- `dynamic_risk = 25%×PB风险分位 + 50%×ERP风险分位 + 25%×股息风险分位`。

窗口早于数据起点时只使用当时已存在的历史；正式模型从2015-04-16开始，已有约8年预热。不得使用全样本分位回填过去。冻结阈值：

| 候选 | 启动条件 | 运行前模型触发日/段数 | 真实段触发日/段数 |
|---|---:|---:|---:|
| `dynamic_075` | `dynamic_risk>=0.75` | 159 / 12 | 112 / 8 |
| `dynamic_080` | `dynamic_risk>=0.80` | 51 / 4 | 42 / 3 |
| `dynamic_085` | `dynamic_risk>=0.85` | 25 / 3 | 25 / 3 |

0.90运行前没有任何触发，因此不进入收益网格。窗口固定8年，不扫描5/6/7/9/10年，避免把动态标准重新做成窗口寻优。

## 4. 信号与执行

- 日评：T日收盘确认估值状态，T+1第一个IC交易日开盘执行；正式首日沿用已有初始化规则；
- 信号只有0%或100%，没有50%档；阈值满足为100%，否则0%；
- 一次只持有一个目标3m Put批次；不在IC月滚日更换；
- 买入后不提前卖出、不减仓，即使估值退出极高区也持有至到期；
- 到期日收盘按内在价值结算；到期后的下一交易日，仅当最新估值仍满足阈值时续保；
- 本版无压力状态、SMA/RV门控、估值保持、尾部概率、Put价格门控、止盈或重叠批次。

模型层执行价为中证500现货开盘的85%；真实层沿用目标月份中开盘价为正且成交量为正的最低行权价510500 Put。

## 5. 同场基准与规模

每层10条路径：

1. `no_put`；
2. v7 `stress_latch + front_original`；
3. v7 `stress_latch + 3m_hold_expiry`；
4. `3m_hold_expiry + always_100`；
5. 三条固定极高估；
6. 三条动态极高估。

模型/真实两层共20条。固定阈值邻域为`1.50 ↔ 1.75 ↔ 2.00`；动态邻域为`0.75 ↔ 0.80 ↔ 0.85`。两种定义互为比较分支，不互相充当参数邻点。

## 6. 资本、成本与数据

- IC为100%名义；30%保证金/缓冲，70%现金按年化3%；不放大到3.33倍；
- Put市值从可计息现金扣除；IC与Put每边1bp；到期内在价值结算不收卖出边摩擦；
- 模型Put使用冻结Black-Scholes与QVIX波动率代理；真实Put使用第三方日线，不代表盘口成交保证；
- 模型样本2015-04-16至2026-08-14；真实Put样本2022-09-19至2026-08-14；Asia/Shanghai交易日；
- 2007起估值和指数为官方/第三方回溯研究数据；2015—2022模型Put不是历史可成交报价。

## 7. 强制窗口、归因与完整性

所有20条路径必须报告含70%现金的CAGR、年化波动、Sharpe和最大回撤：全样本、最近10年、5年、3年、1年。真实层不足10年/5年显示N/A。

额外报告development（2015-04-16至2020-12-31）、revision_validation（2021-01-04至2024-12-31）、recent_expansion（2025-01-02至2026-08-14），以及2015、2021-09-13至2024-02-05、2022和2024赔付窗口、2025—2026保险拖累。

完整性门槛：

1. 无Put、两条v7压力保持基准和永久100%逐日匹配v7正式产物，最大误差不超过1e-14；
2. 20条路径齐全，无重复日期、未来信号、负执行延迟、缺失收益或收益不大于-100%；
3. 动态分位每个T只使用T及之前、且不早于T-8年的历史；固定分支逐日精确复现v5风险分数；
4. QVIX代理继续通过；永久100%有真实头寸、成本和非零市值；
5. 模型永久完整批次除边界外100%覆盖3次IC换月，真实完成批次至少90%覆盖3次；无提前卖出/减仓，续保最大顺延不超过5个交易日；
6. 每个候选信号只为0/1，执行头寸在批次存续期内不得因信号下降而退出。

完整性失败为`rerun_required/data_sensitive`，不得解释性能。

## 8. 预注册绩效判断

每个固定/动态候选相对同层无Put必须同时满足：

1. 模型全样本最大回撤改善至少3个百分点，CAGR落后不超过1个百分点；
2. 五个强制窗口至少3个最大回撤改善为正；全/10年/5年CAGR落后不超过1个百分点，3年/1年落后不超过3个百分点；
3. development、revision_validation、recent_expansion三个分段CAGR各自落后不超过1个百分点，最大回撤不得恶化超过1个百分点；
4. 模型至少20个实际保护日、至少2次独立启动；
5. 真实层至少20个实际保护日；真实全样本回撤改善至少0.5个百分点、CAGR落后不超过1个百分点；
6. 至少一个同分支相邻阈值候选也通过以上单线门槛。

没有真实触发的候选即使模型通过也只能列为`not_identified`，不得晋升。若无人稳健通过，决定为`keep_default/reject`；若至少两个相邻阈值通过，最多`watchlist/narrow_stable`；同一分支三条全通过为`watchlist/wide_stable`。通过者中优先实际保护日较少的更高阈值。
