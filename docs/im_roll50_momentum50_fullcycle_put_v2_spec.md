# 50%滚IM + 50%动量门控：原V2动态Put完整叠加 v2

日期：2026-08-22  
状态：预注册研究规格；未批准实盘

## 研究目标

纠正v1把Put按0.5倍核心袖缩放的主口径。在固定的“50%单纯滚IM + 50%动量门控滚IM”底仓上，原样叠加IM V2动态Put目标0至4张，不因底仓当日总IM敞口为0.5、0.75或1倍而缩放Put张数。

## 固定底仓与数据

- 底仓、平均贴水代理、期货换月、期货费用、30%/倍保证金缓冲和年化3%现金规则，完全沿用`im_roll50_momentum50_fullcycle_proxy_v1`；
- 动量参数固定`MA35 / Mom18 / W2.5`，50% Abs20 OFF + 50%静态`Abs20 > 0`；
- Put信号与逐日理论/真实组件沿用`im_roll50_momentum50_fullcycle_put_v1`已经验证的共同日历路径；
- 共同样本为2015-04-16至2026-08-14；2018-06-18因理论Put模型缺失，所有路径共同删除；
- 2015-04-16至2022-07-21为理论Put与代理IM，2022-07-22至2026-08-14为冻结真实IM/MO。

## 原V2动态Put规则

- 绝对估值轴`2.45 / 2.50 / 2.60`对应1/2/3张；
- 57个月滚动相对估值轴`75% / 85% / 90% / 92.5%`对应1/2/3/4张；
- 两轴取较高目标；中证1000全收益指数`MOM120 < 0`时最低4张；上限4张；
- 目标期限约3个月，95%目标行权价，T日收盘信号、T+1交易日收盘执行，月度期限重置；
- 每张MO对应0.5倍IM名义，因此0至4张对应0、0.5、1、1.5或2倍Put名义；这是原V2规则自身的保护强度。

## 比较路径

1. `no_put`：不加Put；
2. `put_half_scaled`：v1诊断，动态目标整体乘0.5；
3. `put_original_v2_dynamic`：本版主路径，动态0至4张原样叠加，整体缩放系数恒为1；
4. `put_scaled_total_exposure`：v1诊断，动态Put按当日总IM敞口0.5/0.75/1缩放。

`put_original_v2_dynamic`与`put_half_scaled`都随估值和MOM120变化；两者差异仅是前者不打折、后者整体乘0.5。

## 收益与资本

- 原底仓非现金净收益加Put逐日损益后，乘Put费用；
- Put市值从原底仓现金权重扣除；不得出现负现金；
- 原V2完整Put在底仓低于1倍IM时可能形成比底仓更大的方向保护，这是用户要求的原规则直接叠加结果，必须报告最大Put市值、最低现金和相对底仓保护倍数；
- Call与网格关闭；不改变期货底仓、Put信号、期限、成本或估值阈值。

## 输出

- 全样本、10年、5年、3年、1年的年化收益、最大回撤、波动率、Sharpe和期末净值；
- 理论Put代理期与真实IM/MO期拆分；
- 年度表现、最大回撤峰谷、Put张数分布、资本占用和逐日重组恒等式；
- 主结果必须与不加Put、半规模Put在相同日期上直接比较。

## 结论边界

- 上市前贴水使用上市后平均值回填，Put为理论定价，含明显代理与前视假设；
- 真实MO使用冻结收盘路径，但不含盘口价差、冲击、收盘容量、动态保证金、价格限制和整数合约组合规模误差；
- 本版是研究纠偏，不是生产主线变更、当前信号或交易授权。
