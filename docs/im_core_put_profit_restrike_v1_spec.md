# IM核心Put盈利兑现并重新定价扫描 v1

预注册日期：2026-09-16。研究专用，不修改1.3正式规则。

固定当前IM核心Put估值分层、MOM120及防抖、102%目标行权价、约3个月期限、月度维护、成本和T收盘执行。比较：

- `baseline`：当前规则，不因Put盈利提前处理。
- `profit2x`：持有Put的当日收盘价达到本腿实际买入价2倍时，当日收盘全额卖出旧Put，并按当前IM价格、原目标数量重新买入约3个月102% Put。
- `profit3x`：同上，触发倍数为3倍。

重新买入后的实际价格成为下一次盈利触发基准；允许极端行情中再次触发。若当日同时为原月度维护日，优先按原月度维护处理，不重复交易。估值目标为0时仍按原规则退出。

真实挂牌与理论延展分别输出。理论层早期估值使用已认证恢复，仍是模型/代理结果。该扫描只检验核心Put机制，其他IM组件固定不参与归因；结果不自动晋级完整1.3或生产。
