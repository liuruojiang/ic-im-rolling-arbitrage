# IM买Put与卖Put统一估值防抖 v2（纠正版预注册）

## Correction

v1只对卖Put准入使用估值防抖，没有改变核心买Put的估值目标，不能回答整体交易次数和冲击成本问题。v2废止v1的晋级解释，重新把同一防抖估值档同时用于核心买Put目标和卖Put准入。

## Unified Rule

- 基线：原始估值档0—4即时生效。
- `confirm2`/`confirm3`：估值风险升档立即生效；估值风险降档必须在较低的同一档连续2/3个交易日后生效。
- 核心买Put目标使用防抖后估值档，并继续与现有MOM120保护下限取较高者。
- 卖Put只有防抖后估值档不高于1且现有MOM120许可通过时才允许。
- 其他规则固定：M+1卖95% Put、绝对IV>35%、60%衰减滚动、102%核心Put、Call同步暂停和指派后IM回本退出。

## Candidate Grid

- `instant`、`confirm2`、`confirm3`。

## Required Diagnostics

- 原始与防抖估值档、目标Put数量切换、实际核心Put交易事件和成本率。
- 卖Put周期、提前滚动、指派、Call交易事件和暂停日。
- 真实层与理论层完整绩效窗口；即时基线与上一轮逐日误差不超过`1e-12`。

## Decision Rule

统一防抖候选只有同时满足以下条件才可考虑晋级研究版本：

1. 两层估值档切换数均减少至少20%；
2. 真实层核心Put实际交易事件或核心Put累计成本必须减少；如果只减少信号而不减少订单，不得声称节省交易成本；
3. 两层Full CAGR下降不超过0.50个百分点、Sharpe下降不超过0.02、MaxDD恶化不超过0.50个百分点；
4. `confirm2`与`confirm3`方向一致；优先选择达到20%降噪且规则较短者，除非3日规则有明确额外订单收益；
5. 真实和理论证据分别陈述，不把理论成本节约冒充真实成交证据。

结果仍为研究证据，不自动修改1.3或生产信号。
