# IM + MO Call 高IV入场门控 v20 预注册规格

冻结日期：2026-08-19（Asia/Shanghai）  
状态：机制验证；未批准实盘。

## 1. 研究问题与证据级别

在冻结的1倍滚IM + `reconstructed_valmom_floor3`三个月95%主线Put上，检验“只有拟卖Call自身收盘隐含波动率足够高才建立新空头”能否修复v19持续卖Call的上涨截断损失。

外部策略独立给出26%门槛，但正式运行前已用同一真实样本做过按入场IV分组的只读诊断，因此本版属于机制重放，不是未见样本确认；无论结果多好，最高只能进入观察池。

本版完全排除估值网格、估值门控、MOM门控、日内/每日新开仓、分批止盈、下跌重开、Delta提前移仓、风险度缩放和Call名义优化。

## 2. 基准、样本与候选

- 无Call基准：v19的`base_core_put`；
- 持续卖Call参照：v19 `front_d10`与`2m_d10`；
- 模型：2015-04-16—2026-08-14；
- 真实：2022-07-22—2026-08-14，官方IM/MO逐日数据；
- 固定每1张IM卖2张MO Call，Call只覆盖固定底仓，不覆盖网格。

正式候选：

1. `front_d10_iv24`、`front_d10_iv26`、`front_d10_iv28`；
2. `2m_d10_iv24`、`2m_d10_iv26`、`2m_d10_iv28`。

26%为外部给定主参数；24%和28%只检验局部稳健性，不按收益反选门槛。期限可以在两条26%主线之间机械比较。

## 3. IV定义与因果执行

- 完整沿用v19月度评估日、目标期限、D10选约、隐波反解、初始与正常换约时点；
- IV指T日被D10规则实际选中的那一张Call，用T日官方收盘价反解的合约自身隐含波动率；模型层使用冻结理论市场的T日`sigma_close`；
- T日完成选约和IV判断，T+1官方收盘执行，不能用T+1 IV重选或改变信号；
- 每次月度执行时，旧Call只要存在就必须买回；只有T日IV不低于门槛时，才同时卖出新Call；
- IV低于门槛时平旧后保持空仓，直到下一次冻结月度评估，不允许月中因IV升高重新入场；
- 若应开新仓，旧/新Call均须有正收盘价、成交量和持仓量；若只需平旧，旧Call满足相同条件即可。不可执行时保留旧仓并顺延同一动作，不用未来IV改信号。

本版采用合约自身IV而不是常数期限ATM IV，不能解释为对外部文章完整IV定义的复现。每日机会扫描必须另建版本。

## 4. 收益、成本和资本

- Call开仓不把收到的权利金直接记为利润；旧仓按前结算至买回收盘、新仓按卖出收盘至当日结算确认损益；普通日按结算价逐日盯市；
- 2张MO每个篮子每边成本1bp；平旧并开新为2bp，只平旧或只开新为1bp；
- Call保证金、Put市值、70%可用现金上限和年化3%现金收益完全沿用v19；
- 任一日Put市值+Call保证金超过70%记为资本穿透；不测试85%或95%账户风险度。

## 5. 必报结果

1. 模型full/10Y/5Y/3Y/1Y与真实full/3Y/1Y的CAGR、波动、Sharpe、MaxDD、Calmar；
2. 逐年结果，尤其是2024、2025和2026截至8月14日；
3. 每候选评估数、IV达标数、开仓/换仓/平仓数、持仓日、Call损益、成本、保证金和资本穿透；
4. 2024-09-18—10-08急涨期及2024-09-18低IV跳过审计；
5. 与v19持续D10的逐日奇偶、基准奇偶、收益/现金恒等式、因果和官方收盘价审计。

## 6. 预注册判定

每条26%主线进入观察池必须同时满足：

1. 模型full、10Y CAGR不低于无Call基准；
2. 真实full、3Y CAGR不低于无Call基准；
3. 模型与真实full MaxDD均不得比无Call加深超过2个百分点；
4. 真实full、3Y CAGR均高于对应v19持续D10参照；
5. 模型和真实IV达标入场均不少于5次；
6. 资本穿透0、真实计划T+1不可执行0，基准/参照奇偶、恒等式、因果和官方收盘价审计全部通过。

稳健性标签：

- 同期限24%和28%两条均在真实full/3Y改善对应持续D10，且两条真实full MaxDD均不比无Call加深2个百分点，记为`narrow_stable`；
- 仅26%通过而任一邻点方向失败，记为`peak_only`；
- 26%不通过，记为`not_supported`。

若两条26%均通过，机械选择四个主窗口（模型full/10Y、真实full/3Y）相对无CallCAGR改善最小值较高者；同分选择真实full MaxDD较浅、期限较短者。无主线通过则保留无Call基准。
