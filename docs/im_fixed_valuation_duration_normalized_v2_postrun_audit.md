# 中证1000固定经济估值时长归一确认 v2 运行后审计

状态：第二层完成；形成窄共同平台；二次确认候选；未批准实盘。

## 1. Scope

- 目标：保持IM v1的绝对经济单位和1.50—3.00完整网格不变，只把IC的固定事件次数按IM可用历史月数归一，并增加样本前后段事件确认。
- 市场：中证1000价格指数及同源估值；不含IM贴水、MO、Put、网格或Call。
- 结果性质：冻结真实数据的正式运行结果；但规则由v1失败触发，因此是二次确认，不是独立样本。

## 2. 结论

1. **按历史长度归一后，IC的三项绝对经济压力可以在IM上形成一个窄的共同高估平台。**三项均值独立平台为2.45—2.65，二取三独立平台为2.40—2.60，重叠共同平台为2.45—2.60，共4个连续0.05点，机械中心2.50，判定`duration_normalized_transfer_supported_secondary / narrow_stable`。
2. 这不是移动PB、ERP或股息锚点得到的结果。全样本门槛机械地由IC的236个月至少5段换算为IM的131个月至少3段；最近10年仍为121个月至少2段。其余覆盖、局部样本、多因子和两定义一致性门槛与v1逐项一致，未改门槛不匹配数为0。
3. 中心2.50的最近10年月末启动率为均值26.45%、二取三24.79%；全样本启动段为4/5，前后段启动数为均值3/1、二取三4/1；全样本/近10年Jaccard为90.70%/87.88%。结构确认通过，但后半段启动都集中在2021年，2023-08以来没有再进入2.50高估区，因此独立时代覆盖仍有限。
4. 2026-08-17无界均值2.089、二取三2.082，均低于2.50中心。当前PB 2.53、ERP 1.3115%、过去一年股息贡献0.9181%，没有满足中心二取三的任何一项原始高估条件。因此当前只能称为“未进入本版高估区”，不能由本版进一步称为低估，也不能自动触发Put。

## 4. Event Gate

机械换算：

- 全样本：`ceil(131 × 5 / 236) = 3`段；
- 最近10年：`ceil(121 × 2 / 121) = 2`段；
- 前段：2015-10-30—2021-03-31，共66个月；
- 后段：2021-04-30—2026-08-17，共65个月；
- 启动必须先在完整月序列计算，再按启动月落入前段或后段；跨界持续的一段不能重复计数。

## 10. Risks and Next Layer

- v2的规则是在看到v1因固定5段失败后建立的，因此只能算有经济依据的二次确认，不能算独立OOS验证。
- 共同平台只有4点，是窄平台；中心2.50并不是精确预测最优值，而是2.45—2.60结构带的机械代表。
- 中心事件高度集中在2015—2021；后半段虽通过，但启动都发生在2021。最近3年没有高估事件不是规则失效的证据，却意味着尚无新估值周期的前瞻确认。
- 下一层应先把2.45—2.60作为固定候选带，研究如何构成不陡峭的IM估值分档，并明确三项均值与二取三的执行关系；仍不得用Put、网格或Call结果反向选择估值门槛。完成估值分档冻结后，才进入MO Put层。
- 本版支持保留固定绝对经济估值方向，不批准实盘，也不直接替换现有旧固定1.75纸面规则。
