# IM M+1 卖95% Put保留灾难保护扫描 v1（预注册）

## Research Question

在已修正的 IM v1.3 混合路由中，固定 M+1、绝对 IV 严格大于35%、卖95% Put、权利金衰减60%后最多提前滚动一次，以及卖 Put/核心 Put/Call 同步切换，检验卖 Put 期间同步保留深度虚值多头 Put 能否改善尾部风险。

## Frozen Baseline

- 对照一：当前 IMC + 102% 核心 Put + 原 Call（D10/IV26）。
- 对照二：M+1 卖95% Put 路由，不带灾难保护。
- 卖 Put 准入仍为估值0/1档、MOM120绝对动量及既有防抖；早期估值恢复必须启用。
- 卖 Put 路由时，IM、核心 Put 与 Call 同步退出；Call 在 Put、现金和回本阶段暂停，IMC 恢复后按原规则重新准入。
- 不修改生产或冻结主线。

## Candidate Grid

- `none`：不买灾难保护 Put。
- `90%`、`85%`、`80%`：按前一交易日中证1000收盘价的目标比例，选择同到期、最接近目标行权价且低于卖出腿行权价的挂牌 MO Put；数量与卖出腿相同。

## Execution and State Rules

- T日收盘形成信号，T+1开盘同步卖95% Put并买灾难保护 Put。
- 保护腿与卖出腿同到期、等数量；真实层必须有正开盘价、正成交量及正持仓量，否则该保护候选当次不得开仓，禁止退化成裸卖 Put。
- 60%权利金衰减滚动时，旧卖出腿和旧保护腿在同一T+1开盘同步平仓，新卖出腿和新保护腿同步换到紧接下一个实际挂牌月份；新卖出腿仍须重新通过既有准入。
- 到期按结算价计入两腿；若卖出腿实物/现金结算后进入 IM 回本阶段，保护腿已在同到期日结算，不改变既有 IM 回本退出。
- 所有新增保护腿交易按单边1bp的标的名义成本计费；保持30%保证金/缓冲和3%现金收益口径。

## Data Layers

- 真实层：现有 IM/MO 挂牌历史及真实期权开盘、收盘、成交量、持仓量。
- 理论层：沿用既有 Black-Scholes 延展市场、利率、股息率和波动率序列，补齐 M+1/M+2 的95%卖出腿及80%/85%/90%保护腿；不得解释为可成交历史。

## Outputs and Diagnostics

- 全样本、10年、5年、3年、1年：年化收益、波动率、仓库口径 Sharpe、最大回撤。
- 路由周期数、保护腿可执行拒绝数、提前滚动数、指派数、最差卖 Put 周期损益。
- 保存逐日收益、信号审计、周期、保护腿选择和同步事件审计。

## Pre-registered Decision Rule

灾难保护候选只能作为研究候选保留，且必须同时满足：

1. 真实层和理论层均不得较裸卖 Put 使全样本最大回撤恶化超过0.50个百分点；
2. 真实层和理论层全样本年化收益损失均不超过1.50个百分点；
3. 最差卖 Put 周期损益在有可比周期的层中改善；若样本期内没有触发保护价值，必须标记为“尾部效果未识别”，不得以未发生损失证明有效；
4. 至少两个相邻保护档呈现方向一致，单一最优点不得晋级。

即使通过，也只保留为研究候选，不自动替换1.3版本、不生成交易建议。

## Known Limitations

- 真实历史较短，极端行情与卖 Put 持有期可能不重合。
- 理论层依赖模型价格与校准序列，无真实买卖价差、冲击、容量、动态保证金、强平、税费和整数合约约束。
- 保护腿使用最接近目标的真实挂牌行权价，实际比例可能偏离80%/85%/90%。
