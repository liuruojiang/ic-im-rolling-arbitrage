# IM v1.3高IV卖Put张数与初始Delta口径补测 v1

预注册日期：2026-09-16。研究专用，不修改生产规则、日报、账本或交易状态。

## 研究问题

上一轮固定核心高IV路由按等名义本金配置：每1张IM卖2张MO Put；在完整组合的0.5倍固定核心中等价于卖1张MO Put。该配置的真实入场Delta约为0.32至0.34，并非Delta补足到1。本轮只改变卖Put数量，检查提高初始Delta覆盖后的收益、回撤与资金代价。

## 固定基线

- 完整IM v1.3组合、季度T-1期货链、核心与动量102%买Put、1.6/2.0的0.5倍网格、固定核心Call、Abs20及MOM120防抖均保持上一轮不变。
- 高IV路由仍为估值0/1档、MOM120非负、M+1、95% Put、IV严格大于35%、权利金衰减60%后最多提前滚动一次并重新准入。
- 路由只替代固定核心0.5倍；同步退出固定核心IM、核心Put和Call。动量IM、动量Put和网格不变。
- 核心Put三倍兑现路径保持上一轮规则，路由日开盘优先，禁止同日重复交易。

## 张数扫描

- `q2_notional`：每1张IM卖2张MO；固定核心0.5倍对应1张MO，沿用上一轮等名义本金口径。
- `q3_delta05`：每1张IM卖3张MO；固定核心0.5倍对应1.5张MO，作为初始约0.5 Delta覆盖的中间档。
- `q6_delta10_stress`：每1张IM卖6张MO；固定核心0.5倍对应3张MO，作为初始接近1 Delta覆盖的压力档。
- 使用连续仓位避免整数账户规模干扰。每次开仓仍按当时组合权益缩放；指派恢复IM和回本退出数量继承对应卖Put数量。

## 对照组

- `baseline`、`profit3x_only`。
- 每个张数档分别输出`short95_only`和`joint`，合计8组/每层。
- 真实挂牌层与理论延展层严格分开；基线和q2必须逐日复现上一轮相同候选。

## 成本与资金

- 所有MO Put单边5BP，期货与Call沿用上一轮成本；现金年化3%。
- 期货每1倍保留30%缓冲。
- 正常持有0.5倍固定核心IM时仍为原15%缓冲；只有卖Put、待指派及放大后的恢复IM阶段，15%缓冲才按张数倍数线性放大：q2/q3/q6分别为15%/22.5%/45%。
- 如现金权重低于0，该候选标记资金不可行；可保留无强平的诊断收益，但不得晋级。
- 不加入动态保证金、强平、税费、盘口容量和整数账户约束。

## 判定

- 比较全样本及最近10/5/3/1年年化、波动、Sharpe、最大回撤，并单列年度收益、最小现金权重和短Put周期。
- 提高张数若仅提高年化但恶化最大回撤、出现负现金或优势只集中在极少事件，不视为稳健增强。
- q6为压力档，不因单一收益指标较高而自动晋级。

研究结果不构成生产晋级、交易建议或下单授权。
