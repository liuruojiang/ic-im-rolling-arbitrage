# IM 估值预测择时 + 约3个月最低执行价 Put v1：预注册规格

冻结日期：2026-08-16  
研究状态：预注册研究；未获准实盘

## 1. 研究问题

在冻结的 `im_monthly_discount_roll_v1` 与 `im_monthly_roll_3m_lowest_put_v1` 基础上，只增加一个保护开关：若当时可知的中证1000估值—风险溢价历史类比显示未来3年指数全收益中位数为负，则持有约3个月后到期、最低执行价的 MO Put；否则不持有 Put。

本版回答两个问题：

1. 选择性保护能否比永久保护减少权利金拖累，同时仍改善 IM 最大回撤；
2. 2026-08-14 当前信号是否开启，以及如何把保护成本放入既有3年/5年条件收益情景。

本版不扫描阈值，不用回测结果挑选 PE 分位，不加入价格趋势、波动率、技术指标或盘中风控。

## 2. 预注册假设

- H1：估值预测择时保护的全样本净年化收益高于永久保护。
- H2：估值预测择时保护的全样本最大回撤浅于无保护 IM 基线。
- H3：相对无保护基线，择时保护必须按同切片报告收益损失与回撤改善；若全样本回撤改善不足8个百分点，则全样本年化收益落后超过1个百分点、或3年/1年落后超过3个百分点，只能归类为观察/诊断。
- H4：当前点位若信号开启，加入 Put 不应被解释为提高指数方向期望；它主要改变左尾路径，并支付可观测的历史保险成本。

## 4. 严格走步的估值预测开关

每个冻结 Put 计划入场日 `e` 执行以下步骤：

1. 只取估值日期严格早于 `e` 的最新一条 IM 状态，记为 `s`；不使用 `e` 当日收盘估值在同日结算价交易。
2. 只保留日期不晚于 `s` 的估值历史，分别对四个原始特征在该历史截面重新计算百分位；不得使用 v3 为当前类比生成的全样本历史分位列。
3. 只允许锚点 `a` 满足 `a + 3年 <= s`。前瞻终点取中证1000全收益指数在 `a+3年` 当日或之后第一个交易日，且该终点不得晚于 `s`。
4. 以四维百分位均方根距离衡量锚点与 `s` 的相似度；按距离由近到远选择，锚点之间至少间隔12个月，最多8个。
5. 至少需要4个完整锚点；不足时保护信号固定为关闭，不得降低门槛追救。
6. 取锚点后续3年全收益年化的中位数。若严格小于0，信号为 `ON`；大于等于0为 `OFF`。零阈值固定，不扫描、不优化。

当前信号使用2026-08-14已冻结估值状态，为下一次可交易 Put 换仓提供研究审计状态；它不构成下单指令。

## 5. Put 执行与损益

- 每1份 IM 名义匹配2份 MO Put；合约乘数分别为200元/点和100元/点。
- 目标到期月、实际首次挂牌日、最低执行价及流动性敏感性完全继承永久 Put v1，不重新挑合约。
- 决策/换仓时点为冻结 `put_roll_schedule.csv` 的 `put_entry_date`。
- `OFF -> ON`：当日以官方结算价买入新 Put 组，收1bp成本；当日无新 Put 损益。
- `ON -> ON`：旧 Put 计至当日结算损益后卖出，并买入新 Put，合计收2bp。
- `ON -> OFF`：旧 Put 计至当日结算损益后卖出，收1bp；之后无 Put。
- `OFF -> OFF`：无 Put、无期权成本。
- 最新日若处于 `ON`，只按官方结算价盯市，不收假设平仓成本。
- IM 成本仍为每边1bp；Put 整组每次买或卖按被保护 IM 名义每边1bp。

Put 日损益仍为乘数匹配后的 `(P_t-P_{t-1})/F_{t-1}`。官方结算价用于机制估值，不保证真实可成交。

## 6. 现金管理

- 无保护：70%净资产按用户情景净年化3%计息。
- 有保护日：可计息权重为 `max(0, 70% - P_t/F_t)`；无保护日恢复70%。
- Put 权利金是组合资产，买入时不重复扣减净值；只减少可计息现金。
- 不把30%保证金放大为3.33倍方向敞口。

## 7. 比较线与强制窗口

同一日期、成本、IM 换月和 MO 结算价下比较：

1. 无保护 IM；
2. 永久持有 Put；
3. 估值预测择时 Put（主候选）。

强制展示全样本、10年、5年、3年、1年的 CAGR 与最大回撤；历史不足显示 `N/A`。每个可用窗口展示候选相对无保护及永久保护的收益差、回撤差。另按自然年展示2022—2026年结果。

必须报告：保护开启周期数、日数占比、状态切换次数、Put 买卖次数、累计成本、每个信号日的可知锚点与预测中位数、最差5个 IM 交易日的保护状态与缓冲、最大回撤峰谷和修复日。

## 8. 当前3年/5年条件情景

- 原始无保护情景完全复用估值 v3 的 IM 悲观/中等/乐观3年、5年组合年化与累计收益，不重新挑选类比。
- 先计算历史择时保护相对无保护的全样本年化相对因子：`overlay = (NAV_gated / NAV_unprotected)^(252/N)-1`。
- “历史保险成本重复”情景按 `(1 + v3组合年化) × (1 + overlay) - 1` 调整年化，再按3年/5年复合累计。
- 该调整只表示历史平均保险拖累的条件锚点，不包含未知未来崩盘带来的 Put 收益；不得把它称为完整的保护后预测。
- 由于 v3 只有终点年化分布、没有未来逐日路径，而本策略又在 Put 到期前滚动，无法诚实推导保护后的未来 MaxDD 或最低收益；统一显示 `N/A`。
- 当前信号、当前已持 Put 估值以及下一次计划目标月单列展示；未挂牌的新合约不得假设价格。

## 9. 完整性检查

- 上游文件哈希、行数、日期范围与上游清单核对。
- 所有估值信号严格使用 `state_date < put_entry_date`；每个前瞻类比终点 `<= state_date`。
- 重新计算当前预测必须与 v3 的 IM 3年中位数在浮点容差内一致。
- 新脚本无保护、永久保护曲线必须与冻结 Put v1 完全一致。
- 候选日收益必须逐日由活动 Put 合约重新构造，不得简单用当月开关遮罩永久保护收益，以免在开关切换日错误计入旧 Put 损益。
- 缺失结算价、重复日期、少于4个类比、绝对日收益超过10%均显式记录，不前向填充或截尾。

## 10. 排除与状态

- 不扫描负收益阈值、锚点数量、相似度权重或估值特征。
- 不把当前 PE 73%分位事后设成一个刚好触发的阈值。
- 不加入波动率、趋势、回撤、宏观、隐含波动率或期权贵贱过滤；这些必须另建版本。
- 不模拟持有 Put 到期形成三层重叠保护，不推导不存在逐日路径的未来 MaxDD。
- 本版不生成实时订单、不接入人工或自动下单，结论不构成交易建议。
