# IC + 510500 ETF Put 双层验证 v1：运行后审计

审计日期：2026-08-16  
研究状态：`rerun_required / data_sensitive`；纯诊断，未获准实盘

## 1. 审计结论

本版完整运行了真实层18组与模型层54组预注册候选，但没有形成可用的跨标的复现证据：

- 真实510500 ETF期权层从2022-09-19开始，期间所有月/周/日估值决策的3年类比收益预测均高于3%，最低为3.7976%，所以二档与三档均始终为0%保护；18组真实候选没有发生任何Put交易，全部等同同期IC无Put基线。
- 2015年以来的波动率代理通过了预注册误差门槛，但真实层候选横截面为常数，真实—模型CAGR秩相关无法定义，结构交叉验证失败。
- 模型85%层的保护只出现在2015-04-16至2015-12-23。2016-08-15以后所有候选在10年、5年、3年和1年窗口均与无Put完全相同，长样本差异实际由2015年单一事件段贡献。
- 因此模型层只能作为Black-Scholes理论Put压力测试，不能称为真实510500 ETF期权回测，也不能用来确认IM研究中的“周评+2个月Put”结论。

## 3. 核心结果

### 3.1 真实层

2022-09-19以来无Put及18组候选均为14.54% CAGR、-28.54% MaxDD；加入70%现金年化3%并扣除Put权利金占用后均为16.93% CAGR、-27.33% MaxDD。Put交易数、Put成本和Put损益均为0。

这不是“保护无效”，而是该估值规则在真实期权存在期内没有触发，因而不能比较频率和期限。

### 3.2 模型85%层

| 候选 | 全样本 CAGR / MaxDD | 加70%现金 CAGR / MaxDD |
|---|---:|---:|
| 无Put | 12.94% / -48.31% | 15.30% / -48.06% |
| 月评3个月二档 | 13.99% / -41.41% | 16.37% / -41.16% |
| 周评2个月二档 | 14.25% / -42.97% | 16.63% / -42.89% |
| 月评3个月三档 | 14.74% / -37.05% | 17.13% / -36.80% |
| 周评2个月三档 | 13.60% / -44.29% | 15.98% / -44.03% |
| 日评前月三档 | 14.94% / -37.18% | 17.34% / -36.88% |

二档下周评2个月比月评3个月高0.26个百分点CAGR，但MaxDD深1.56个百分点；三档下周评2个月反而低1.14个百分点CAGR、MaxDD深7.24个百分点。频率与期限结论不具备档位稳定性。

### 3.3 80%/85%/90%虚值度敏感性

周评2个月相对月评3个月的全样本CAGR差：

| 入场虚值度 | 二档 | 三档 |
|---:|---:|---:|
| 80% | +0.07pp | -1.01pp |
| 85% | +0.26pp | -1.14pp |
| 90% | +0.55pp | -1.16pp |

相邻虚值度确认了“二档略占优、三档明显落后”的分裂，而不是确认周评2个月的稳健优势。日评候选在各虚值度上的全样本排名也不能用于事后选参，因为所有差异只来自2015年。

## 4. 事件集中度

- 模型85%周评2个月二档相对月评3个月二档的全样本相对因子为+2.49%，全部发生在2015年；2016—2026逐年相对因子均为0。
- 二档最大单日相对贡献为2015-07-10的+4.22%；前5个正贡献日的对数贡献合计为最终净优势的739%，说明其余日期存在大量反向抵消。
- 模型85%周评2个月三档相对月评3个月三档的全样本相对因子为-10.33%，也全部发生在2015年；2016—2026逐年相对因子均为0。
- 三档前5个正贡献日仍无法抵消其他日期损失。保护目标最后一次为正的日期是2015-12-23。

## 5. 独立实现审计

- 正式逐日表169,554行，74个候选；模型候选各2,756行，真实候选各946行。
- `gross_ret = ic_gross_ret + put_pnl_ret`最大绝对误差`1.995e-16`。
- `ret = (1+gross_ret)×(1-IC成本)×(1-Put成本)-1`最大绝对误差`2.220e-16`。
- `cash_weight = max(70%-Put权利金占用,0)`最大绝对误差`1.665e-16`。
- `cash_ret = ret + cash_weight×((1.03)^(1/252)-1)`最大绝对误差`9.714e-17`。
- 模型和真实无Put基线相对冻结IC v1的逐日最大绝对误差均为0。
- 交易审计没有发现估值日当日或此前执行、计划执行日前执行、未来类比终点、无效收益或小于-100%的日收益。
- 50ETF波动率代理与500ETF QVIX共同938日的Pearson相关为0.8648，中位绝对误差2.4762个波动率点，中位有符号误差+1.7179点，单项门槛PASS。
- 新浪与中证官方000905收盘最大相对差`1.108e-05`，中位数`5.210e-07`。
- 参数扫描产物严格检查PASS；最终决定`rerun_required`，稳定性`data_sensitive`。

## 6. 证据边界与下一步

本版失败的不是波动率代理精度，而是缺乏“估值规则已触发且真实510500期权存在”的重叠历史。不能通过事后放宽3%/0%切换点、修改RV窗口或挑选虚值度追救本版。

如果继续验证，应预注册新版本，并选择不依赖当前估值触发重叠的校验设计，例如先用真实510500 Put做固定保护/固定持有规则的价格引擎校验，再单独保留2015+估值择时为理论压力测试。任何后续结果仍不得覆盖本目录或解释为交易建议。
