# IC 滚动套利叠加中证500动量研究候选 v1.3

预注册日期：2026-09-03（Asia/Shanghai）  
状态：独立研究候选；未批准实盘；不修改IC v1.2、冻结IC/IM V2或旧输出。

## 版本变化

本版本以`ic_mainline_v1_2`为父版本，只把中证500动量权重同步至A股多头v1.3当前完整规则。基础动量保持`MA110 / Mom24 / W2`、`Score>0`和`50% OFF + 50% Abs20>0`；新增基础净值回撤防守：使用未叠加成交量等过滤的基础动量执行权重，按2%年化闲置现金收益、单边10bp动量换仓成本计算基础NAV；若T日基础NAV相对历史峰值回撤不小于6%，则T日确认的动量目标乘0.5，并于T+1共同交易日执行。成交量过滤、Score过热、目标波动和其他覆盖层保持关闭。

基础目标只为0/0.5/1；应用NAV防守后的动量执行权重可为0/0.25/0.5/1。动量IC名义仍为`0.5 × 动量执行权重`。

## 保持不变

固定0.5倍核心袖、IC无Call、0.375/1.000独立网格、核心Put完整V2规则、动量袖只使用估值Put且不使用MOM120下限、30%保证金/缓冲及3%组合现金收益口径均继承v1.2。动量Put目标Delta按新动量执行权重同比缩放；网格不配置Put。

## 数据、时点与验收

动量使用新浪中证500价格指数OHLCV，正式规则从2007-01-15开始并允许更早历史作指标热身；IC/IM共同研究日程为2015-04-16至2026-08-14。T日基础NAV回撤只使用截至T日已经实现的基础路径，防守作用于T+1，不得回写T日收益。

强制验收：与A股多头v1.3中证500`final_weight`逐日最大误差不超过`1e-12`；除动量权重及其派生期货名义、Put目标、现金和收益外，核心、网格、IC无Call和执行时点对v1.2保持零差异；正式绩效必须用新权重重跑期货成本、Put数量/成交与现金，不得直接缩放旧综合指标。
