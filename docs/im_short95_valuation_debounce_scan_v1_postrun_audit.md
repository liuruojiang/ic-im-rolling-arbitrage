# IM M+1卖95% Put估值准入防抖 v1：运行后审计

> **范围纠正（2026-09-16）**：本版只防抖卖Put准入，没有防抖核心买Put估值档，不能用于整体交易次数、交易成本或1.3晋级判断。统一买/卖Put纠正版见`im_short95_unified_valuation_debounce_v2_postrun_audit.md`。

## 结论

`confirm3_le1`（估值2档以上立即关闭，回到0/1档连续3个交易日才重新允许）通过预注册门槛，可保留为研究候选；但真实样本的3个实际卖Put周期完全未改变，因此只能确认许可状态更平滑，不能宣称真实收益增强，也不自动写入1.3版本。

## 核心结果

| 规则 | 真实 CAGR / Sharpe / MaxDD | 理论 CAGR / Sharpe / MaxDD | 周期数（真实/理论） |
|---|---|---|---:|
| 当前即时0/1档 | 20.44% / 1.226 / -16.20% | 16.83% / 1.123 / -16.71% | 3 / 10 |
| 连续2日恢复 | 20.44% / 1.226 / -16.20% | 17.07% / 1.137 / -16.71% | 3 / 9 |

| 0档开、1档保持、2档关 | 19.13% / 1.153 / -16.20% | 16.11% / 1.084 / -16.71% | 3 / 9 |

## 防抖效果

- 真实估值许可切换：即时规则12次，连续2日11次，连续3日9次，档位滞回4次。
- 理论估值许可切换：即时规则51次，连续2日41次，连续3日31次，档位滞回27次。
- 连续3日相对当前分别减少25.0%和39.2%，超过预注册15%门槛。
- 完整许可还受MOM120影响：连续3日使真实完整许可切换从54次降至50次，理论从98次降至82次。

## 路径归因

- 真实层连续2日、3日规则均未改变任何实际入场、退出或滚动，逐日收益与当前即时规则相同。
- 理论层两条确认规则都过滤了2020-09-29的一次入场。其信号日2020-09-28的估值只短暂从2档降至1档一天，IV为35.385%，次日估值即回到2档；当前即时规则因此开仓，而2日/3日确认均拒绝。
- 被过滤周期从2020-09-29持有至2020-10-16，归一化组合周期盈利为0.014796。尽管该周期本身盈利，过滤后整体理论CAGR仍提高0.24个百分点，原因是组合同时避免了该段卖Put路由对IM、核心Put和Call状态的替换效应；不能把提升简单解释成少亏一笔Put。
- 连续2日和3日产生完全相同的实际交易路径，但连续3日更明显地减少估值许可切换，并且只有连续3日在真实层达到15%降噪门槛。

最终判定：`retain_confirm3_as_research_candidate_operational_debounce_real_performance_unidentified`。

## 完整性与限制

- 当前即时规则与上一轮绝对IV35基线逐日收益最大误差：真实和理论均为`9.974659986866641e-17`。
- 防抖仅作用于卖Put估值准入；核心Put、MOM120、网格和期货方向未改写。
- 真实MO历史较短；理论层是Black-Scholes代理，不能替代可成交历史。
