## 研究问题与候选

固定前五层结论：绝对IV严格大于30%、不增加卖方MOM120、M+1、卖95% Put、等名义q1、持有至到期、无灾难保护、无相对IV。只检验估值许可防抖：

1. `instant`：现行卖方估值许可即时生效，作为“不加第六层”的基线；
2. `sell_confirm2`：仅卖Put恢复许可要求连续2个交易日处于0/1档；风险升档立即禁止；
3. `sell_confirm3`：仅卖Put恢复许可要求连续3个交易日；
4. `unified_instant`：核心买Put与卖Put共用核心买Put的T收盘→T+1执行估值档，但不防抖，用于隔离状态来源差异；
5. `unified_confirm2`：共用估值状态，风险升档立即生效，风险降档连续2日确认；
6. `unified_confirm3`：同上，连续3日确认。

所有状态只使用当日及此前数据，最早T+1开盘执行，不使用未来状态回填。

## 固定和排除

- 只转换固定核心0.5倍；动量腿不卖Put；IC无Call。
- 原IC执行动量许可保留；不增加MOM120卖方门槛。
- M+1持有到期；不加提前展期、灾难保护Put或相对IV。
- 核心买Put三倍盈利兑现、季度IC T-3、动量、网格、指派恢复及整轮含成本回本退出保持相同。
- 每条510500 Put单边5bp；IC单边1bp；期货30%保证金/缓冲；现金年化3%。核心买Put和卖Put路径及成本均重新执行。
