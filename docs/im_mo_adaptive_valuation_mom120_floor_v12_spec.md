# IM 新动态估值 + MOM120最低保护 v12 预注册规格

冻结日期：2026-08-19  
研究状态：Put第二层；仅研究，未批准实盘

## 1. 研究问题

v11证明`57个月 + 75%/85%/95%`估值三档只在2026年提供保护，无法覆盖2022—2024年的低估熊市。本版只增加中证1000全收益指数120交易日绝对动量：当MOM120不高于0时，分别要求至少持有1/2/3张MO Put，检验绝对动量能否补足低估熊市，同时保留估值对高估风险的识别。

本版不改变估值窗口、分位、绝对门槛、Put期限、行权价、换仓方式、成交时点、成本、保证金或现金收益；不加入网格、Call、滞后、缓冲带或其他趋势指标。

## 2. 冻结信号与执行

- 估值档位：v7正式中心`dual_w57_q750_850_950`，以及已冻结的54/60月同阶梯、57月宽/严阶梯四条确认线；数量为0/1/2/3张MO。
- MOM120：中证1000官方全收益指数T日收盘 / 120个交易日前收盘 - 1；`<=0`为熊市，`>0`为非熊市，不设容差带。
- 纯MOM候选：熊市持有固定`floor=1/2/3`张，非熊市0张。
- 组合候选：`target_qty = max(v7_valuation_tier, mom120_floor_qty)`；MOM为正时最低数量为0。
- v7估值状态2015-10-19以前不可用，组合候选将估值档视为0，但仍允许已可计算的MOM120生效；不回填未知估值。
- T日收盘确认，下一共同交易日收盘买入、卖出或调档。
- Put固定为三个月目标到期、95%目标行权价、月滚退出；不是持有到期。

## 3. 冻结候选集合

### 3.1 同批基线与参照

- `no_put`；
- 5条估值单独线：中心及四条v7确认线；
- `legacy_fixed175_or_mom120`：旧纸面首选历史参照，不参与新参数选择。

### 3.2 MOM120扫描

- 纯MOM：`mom120_floor1/2/3`，共3条；
- 估值+MOM中心：`valmom_center_floor1/2/3`，共3条；
- 四条估值确认线各叠加floor1/2/3，共12条。

正式保护候选共24条，加no-Put后每层25条。floor只扫描1/2/3，不补中间值，不读取结果后扩网格。

## 4. 数据与成本

### 4.1 模型层

- 2015-04-16至2026-08-14；中证1000全收益基线+理论Put。
- 不是上市前IM/MO，不含上市前真实贴水，只用于长周期机制和参数宽度诊断。

### 4.2 真实层

- 2022-07-22至2026-08-14；冻结中金所IM/MO日行情、活动IM与官方结算盯市。
- 真实10年/5年因IM/MO上市历史不足显示N/A。

### 4.3 资金和摩擦

- 1倍IM方向名义、30%保证金/缓冲、70%现金净年化3%；Put市值从可计息现金扣除。
- IM基线成本沿用v9；每张MO每边成本为IM完整名义0.5bp。
- 正式成本1倍；另报Put成本2倍和5倍敏感性，不据压力成本优化参数。
- 真实合约新开必须close、volume和open interest均为正；退出close和volume必须为正。close不是bid/ask、close VWAP或容量证明，盘口冲击未计。

## 5. 同层比较与经济容差

MaxDD改善至少`0.01`个百分点才记为改善。

每条中心组合候选必须同时相对：

1. 同层`no_put`，判断保护系统整体是否有效；
2. v11估值单独中心，判断新增MOM120是否真正补足回撤；
3. 同floor纯MOM候选，判断保留估值是否有增量。

常规收益容忍：全样本/10年/5年年化最多落后1个百分点，3年/1年最多落后3个百分点。若候选相对no-Put在模型和真实全样本均改善MaxDD至少8个百分点，可放宽为2/2/2/4/4个百分点；放宽必须事前机械应用，不能逐候选解释。

## 6. 核心通过门槛

一个中心floor候选的核心线通过必须满足：

1. 相对no-Put，模型全样本MaxDD改善至少0.01个百分点，且五窗口至少三个改善；
2. 相对no-Put，真实全样本MaxDD改善至少0.01个百分点，且全/3年/1年三个可用窗口至少两个改善；
3. 相对no-Put通过第5节收益容忍；
4. 相对估值单独中心，模型和真实全样本MaxDD均至少改善0.01个百分点，且收益损失不超过常规容忍；
5. 真实层至少两段独立保护；2倍Put成本不得把相对no-Put的全样本年化从非负逆转为负；
6. 真实样本最近一年信号驱动调整年化不超过24次；正常月换单列，不计入该上限。

风险优先选择门槛另要求：相对no-Put真实全样本MaxDD至少改善8个百分点、模型全样本至少改善3个百分点。

## 7. 宽度、估值增量与选择

### 7.1 floor宽度

一个floor只有在相邻floor也通过第6节1—5项核心经济门槛时才有宽度支持；floor1只看floor2，floor3只看floor2，floor2可由任一侧支持。换手上限不用于否定邻点的经济宽度，但会限制正式晋升。

### 7.2 估值参数宽度

若组合候选进入选择，其同floor四条估值确认线中，至少一条窗口邻线和一条分位邻线必须在模型和真实全样本均相对no-Put改善MaxDD至少0.01个百分点。

### 7.3 估值相对纯MOM的增量

同floor组合相对纯MOM必须：

- 模型和真实全样本MaxDD均不得恶化超过0.50个百分点；
- 模型和真实全样本年化均不得落后超过1个百分点；
- 并至少满足一项：任一层全样本或1年MaxDD改善0.50个百分点，或任一层全样本或1年年化提高0.50个百分点且对应MaxDD不恶化超过0.50个百分点。

否则认为估值在该floor没有足够增量，优先纯MOM。

### 7.4 机械选择

1. 在满足核心线、风险优先、floor宽度和换手上限的floor中选择最低floor；
2. 同floor若组合估值增量及估值参数宽度均通过，选择组合；否则选择纯MOM；
3. 若无人满足全部选择门槛，但存在核心经济线通过，决定`watchlist_mom120_floor`；
4. 若核心经济线无人通过，决定`no_mom120_floor_candidate`。

即使选出候选，也只允许进入后续研究评审，不批准实盘。
