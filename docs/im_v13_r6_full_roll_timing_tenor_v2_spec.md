# IM v1.3-r6 完整策略：期货滚动期限与 T-1/T-2/T-3 扫描 v2 预注册

## v1 失败诊断与 v2 修正

- v1 把 Call 月度刷新节点绑定到候选期货换仓节点。远月期货减少换仓次数后，Call 会在下一节点前先到期，因此该设计同时改变了期货与 Call 两套规则，不能回答“只改变期货滚动”的问题。
- v2 保持正式 r6 的 Put/Call 信号日历、到期和救援规则不变。候选期货链只改变期货收益/成本、网格执行价格与换月成本，以及期权按 IM 资金归一化时使用的候选结算分母和 active IM 收盘锚。
- v1 规格及失败记录不改写；v2 为独立预注册研究。

## 研究边界

- 冻结参照为 IM v1.3-r6 完整真实路径：0.5 核心期货、0.5 动量期货、独立核心/动量 Put、1.60/2.00 估值网格和 D10 + 5% 威胁滚动 Call。
- 唯一决策变量为 IM 期货的目的期限和换仓日。动量、估值、网格状态、Put 目标/到期、Call 月度日历/D10/IV26/威胁救援均不变。
- 只产生研究候选证据，不修改主线、Poe、GitHub 日报、账本或实盘授权。

## 数据、候选与记账

- CFFEX 官方 IM 逐合约行情；真实 IM+MO 样本 2022-07-22 至 2026-08-14。
- 候选为 `next_listed`、`target_plus_2m_nearest_listed`、`target_plus_3m_nearest_listed` × T-1/T-2/T-3，另含正式 `expiry_settle_front` parity 基线。
- T-k 是旧合约最后交易日前剩余 k 个实际交易日；周五最后交易时，T-1=周四、T-2=周三、T-3=周二。
- 当日仍取得旧合约结算收益，收盘卖旧买新，下一交易日持有新合约；首次 1bp，换仓双边 2bp。
- 网格按候选合约的开盘、昨结算和结算价重算；动量期货换月成本随候选换仓日重算。
- 核心/动量 Put 与 Call 使用正式引擎重放。Put 选档 active IM 锚和所有期权收益/保证金的 IM 分母采用候选链，但其信号与到期日历不变。
- 每 1 倍期货使用 30% 保证金/缓冲，剩余现金按 3% 年化；沿用 r6 乘法费用顺序。

## 审计和判断

- 正式基线经新入口完整重放，逐日收益、现金权重、期货、网格、核心 Put、Call 合约/收益最大误差不高于 1e-12。
- 候选合约必须每日实际挂牌且行情有效；Put/Call 因果性与 `rescue_next_listed` 不得改变。
- 输出 Full/3Y/1Y；5Y/10Y 因真实历史不足明确 N/A，不使用代理补齐。
- 观察名单要求 Full/3Y CAGR 不低于 next-listed T-3，Full MaxDD 不深于其 2 个百分点以上，改善不集中于单一年份，并披露实际流动性。
- 通过门槛仍不构成主线升级或下单建议。
