# IC / IM v1.4升级候选草案

日期：2026-09-17  
状态：**历史候选草案，已由用户接受对抗性测试披露后批准升级。** 当前正式规则以`docs/ic_im_mainline_v1_4_r1_spec.md`为准；本草案不得替代冻结规格。

## 共同边界

- 从当日有效规则版本向前生效，不追写v1.3历史账本或已发送日报。
- 固定核心腿、动量腿、网格腿继续独立；网格不增加买Put或卖期权覆盖。
- 卖Put只替代固定核心0.5倍期货腿；动量腿卖Put在IC和IM均已否决。
- 买Put与卖Put切换必须在同一执行事件中完成；不得同时保留被替代核心期货、对应核心买Put和卖Put。
- 新卖Put与提前展期的新腿都必须重新通过当时准入；不因已有周期中途失去准入而提前退出。
- 研究收益继续按每1倍期货30%保证金/缓冲；该口径不替代经纪商动态保证金、强平和整数张数验收。

## IC v1.4候选

保留v1.3的季度T-3、固定核心0.5倍、现行动量0至0.5倍、0.5倍估值网格、核心/动量买Put、MOM120与Abs20防抖以及IC无Call。新增：

1. 核心买Put达到实际入场权利金3倍时，T收盘确认、下一共同交易日收盘兑现并按当日现行规则重新建仓；月度维护优先。
2. 固定核心0.5倍在估值0/1档且原IC 1.3执行动量许可成立、目标M+1的95% 510500 Put自身IV严格高于37.5%时，退出固定核心IC和对应核心买Put并卖出等名义`q1_notional` Put。
3. 权利金衰减50%后最多提前展期一次；新腿重新准入。实物交割ETF后按既有ETF→IC转换、IC展期和整轮扣费回本退出规则执行。
4. 卖方准入不加入MOM120；动量腿不转卖Put；不增加灾难保护Put；不改相对IV、估值防抖或Call。

最终升级闸门真实挂牌期：当前v1.3年化26.89%、Sharpe 1.511、最大回撤-11.07%；联合候选30.77%、1.936、-8.12%。理论延展期：18.62%、1.119、-19.58%提升至21.07%、1.269、-12.12%。全样本、近三年和预设近一年风险闸门全部通过；真实16轮卖Put、核心Put三倍兑现2次。理论只有3轮卖Put且单轮贡献集中度仍超过50%，这是未解决的升级残余风险。

证据：`quant_param_scan_runs/20260917_ic_im_ic_v1_3_to_v1_4_final_joint_upgrade_gate_v2/`。

## IM v1.4候选

保留v1.3的季度T-1、固定核心0.5倍、现行动量0至0.5倍、1.6/2.0半仓估值网格、102%核心与动量买Put、MOM120与Abs20防抖、原Call和`rescue_next_listed`。新增：

1. 核心买Put三倍盈利兑现并按当日102%现行规则重新建仓；月度维护优先。
2. 固定核心0.5倍在估值0/1档、MOM120非负、目标M+1的95% MO Put自身IV严格高于35%时，退出固定核心IM和对应核心买Put，每1倍IM口径卖3张MO Put，固定核心0.5倍对应连续研究数量1.5张。
3. 权利金衰减60%后最多提前展期一次；新腿重新准入。现金结算/恢复IM、展期和整轮回本退出沿用已验证规则。
4. 固定核心卖Put、恢复或现金等待周期内暂停固定核心卖Call；固定核心路由完全恢复正常IM后才恢复Call。
5. 动量腿不转卖Put；不增加灾难保护Put；保留绝对IV35%，不切换相对IV；统一估值防抖暂不晋级。

当前完整组合中，固定核心q3联合候选真实年化39.97%、Sharpe 1.827、最大回撤-16.85%；理论25.73%、1.584、-16.15%。相对同口径不卖Put但保留核心Put三倍兑现，真实年化提高2.16个百分点，理论提高1.40个百分点。真实仅3轮且全部盈利，理论10轮；q3约为初始0.5 Delta候选，整数账户张数、动态保证金和尾部强平仍需在实施验收中单列。

证据：`quant_param_scan_runs/20260916_ic_im_im_v1_3_current_full_portfolio_fixed_core_high_iv_short95_router_mo_put_quantity_per_1_im_2_3_6/`、`quant_param_scan_runs/20260917_ic_im_im_v1_3_momentum_short95_full_joint_q3_v2/`。

## 明确不进入v1.4

- IC、IM动量腿转卖Put。
- IC或IM灾难保护Put。
- 用相对IV替代当前绝对IV门槛。
- IM统一估值防抖；IC卖方或买卖Put统一估值防抖。
- IC卖Call或重新引入卖方MOM120。
- Delta补足至1、IM每1倍6张MO压力档、IC初始0.5/1.0 Delta放大档。
- 任何卖Put覆盖网格腿的做法。
