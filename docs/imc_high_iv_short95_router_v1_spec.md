# IMC 高 IV 路由至卖 95% Put：未准入分支比较 v1

预注册日期：2026-09-16（Asia/Shanghai）  
状态：研究扫描；不修改冻结主线、研究信号、Poe 或任何订单。

## 目的

检验当实际待卖的下一月约 95% OTM MO Put 的收盘隐含波动率处于高位时，是否应以既有卖 Put 周期替代纯滚动 IMC；并明确比较高 IV 但卖 Put 未获准入时的两种处理：持现金，或继续 IMC。

## 数据与基线

- 真实层：本地 CFFEX IM/MO 资料，2022-07-22 至 2026-08-14；5Y、10Y 必须 N/A。
- 基线：`outputs/im_monthly_roll_3m_lowest_put_v1/daily_nav.csv` 的纯滚动 IM 加既有 30% 缓冲/3%现金收益路径。
- 卖 Put：下一日历月、前一日中证1000价格指数收盘约 95% 的 MO Put；实值现金结算后转 IM，按月滚动至整轮扣费交易损益回本后下一开盘退出。
- 新卖 Put 许可：前一交易日 `valuation_tier <= 1` 且 `MOM120 >= 0`；缺失值不许可。已有卖 Put 或回本 IM 不因许可或 IV 变化提前退出。

## IV、时点与候选

- IV 为前一收盘时、上述实际待卖合约的收盘价用 Black-Scholes 反解所得；到期日为该合约实际最后可交易/结算日，利率与股息沿用本地既有 CSI1000 模型市场输入。
- T 收盘信号，T+1 开盘切换。若执行日没有有效开盘报价/成交量/持仓，切换失败并保留既有 IMC，单列审计，绝不使用未来信息替换合约。
- 高 IV 阈值预设为 35%、37.5%、40%，无事后单点择优。首轮不另加迟滞带、IV-RV、网格、Call、买 Put 或动量期货。
- 每个阈值比较两个候选：`cash_when_ineligible` 在高 IV 未许可时平 IMC 后持现金；`continue_imc_when_ineligible` 则维持 IMC。高 IV 且许可时，两者均切换到卖 Put。

## 成本、风险与判定

- 延用单边名义 1bp、期货/期权 200 点值、30%风险缓冲及年化3%现金；切换 IMC 与卖 Put 的开仓/平仓都计成本。
- 不含买卖价差、冲击、涨跌停无法成交、订单簿容量、动态保证金、追保/强平、税费及整数手数。
- 报告 Full/3Y/1Y 与 N/A 的 10Y/5Y，及 CAGR、波动、Sharpe、MaxDD、最差20日、5% CVaR、状态天数、切换次数、现金天数、实值转 IM 与未完成周期。
- 只有同一分支在至少两个相邻阈值、Full 和 3Y 都不较纯 IMC 恶化 MaxDD 超过 1 个百分点，并且收益/Sharpe 取舍透明时才可列观察名单；真实样本不足五年，任何结果均不得晋级正式策略。
