## 2. 冻结子系统

### 2.1 固定底仓与Put

- 固定持有1倍滚IM；
- Put为`reconstructed_valmom_floor3`：PB、ERP、过去一年已实现股息贡献三项固定经济压力的二取三中位数；绝对轴2.45/2.50/2.60与57个月75%/85%/95%相对轴取较大档；
- 中证1000全收益指数MOM120不高于0时，每1倍IM最低3张MO Put；最终0/1/2/3张，上限3张；
- 3个月、95%目标行权价，月度换约，不每日Delta再平衡；T收盘评估、T+1共同交易日官方收盘执行。

### 2.2 固定估值网格

- 使用无界固定经济分数`unbounded_median_knot`；
- 分数不高于0.85时，T+1活跃IM官方开盘新增1倍IM；分数不低于1.25时，T+1活跃IM官方开盘退出；
- 网格最多新增1倍，组合IM总名义为1或2倍；持有期间照常逐月滚IM；
- 新增网格仓不增加Put，也不增加Call覆盖。

### 2.3 每日D10救援Call

- 只覆盖固定1倍IM底仓，每1张IM卖2张MO Call；
- 空仓时每日收盘按当前IM月度周期的前月选择最接近0.10 Delta的虚值Call，合约自身IV不低于26%才在T+1官方收盘开仓；月度节点只刷新当前期限；
- 已有Call每日检查`旧行权价/中证1000收盘-1`，不高于5%即在T+1官方收盘向上至少5%、向后最近一个挂牌到期日救援；救援豁免IV26，连续最多5次；
- 第6次或无更晚有效合约时买回并暂停，至下一IM月度评估节点重新允许每日开仓；
- 不含PE估值门控、文章期限—虚值率阶梯、TP80、分批止盈、急跌向内移仓或风险度扩仓。

## 3. 统一账户与候选层

同一层内直接合并逐日毛损益、成本和资金占用，不允许相加既有NAV。模型与真实层各构造5条：

1. `roll_im_no_put`：1倍滚IM，无Put、网格、Call；
2. `core_put_floor3`：1倍滚IM + 主线Put；
3. `core_put_grid_085_125`：上层 + 0.85/1.25网格，新增仓无Put；
4. `core_put_call_d10_threat5`：主线Put底仓 + 每日D10/IV26/5%救援Call；
5. `full_put_grid_call`：主线Put底仓 + 0.85/1.25网格 + 每日D10/IV26/5%救援Call；Put和Call仍只对应固定底仓。

统一日收益为：

`(1 + IM底仓毛收益 + 网格IM毛收益 + Put损益 + Call损益) × (1-期货成本) × (1-Put成本) × (1-Call成本) - 1`。

可计息现金权重为：

`max(1 - 30% × IM总单位 - Put市值比例 - Call独立义务保证金比例, 0)`，现金净年化3%。
