# IC Put 污染后重建：第八层核心买 Put 盈利兑现与重建 V1 预注册

## 研究问题

固定前七层已经逐层确认的卖 Put 路径，单独比较核心买 Put 的盈利兑现规则：

- `none`：不因盈利提前换仓，作为本层“未加规则”基线；
- `2x`：收盘价达到本次建仓权利金的 2 倍后，最早下一交易日收盘兑现并按当时规则重建；
- `3x`：同上，阈值为 3 倍。

3 倍路径必须与第七层的持有到期卖 Put 基线路径逐日完全一致，用来证明本层只改变核心买 Put 的盈利兑现阈值。

## 固定口径

- 卖 Put：修正后的 510500 Put ETF 单位 IV，绝对 IV > 30%，不加卖 Put MOM120，M+1、95%、q1、即时估值许可、无相对 IV、无灾难 Put、持有到期。
- 核心买 Put：IC 当前约 3 个月、95% 目标、按 Delta 配量；准入、退出、月度维护与目标 Delta 不变。
- 动量买 Put、季度期货路径、网格及其他组合组件全部不变；IC 不含 Call。
- 510500 Put 单边摩擦 5bp；IC 单边 1bp；期货保证金/缓冲 30%；闲置现金年化 3%。

## 因果执行与优先级

1. T 日收盘使用当日可得收盘价判断是否达到 2x/3x。
2. 最早 T+1 收盘卖出旧核心 Put，并在同一收盘依照当时目标 Delta 买入新的约 3M/95% Put；新权利金成为下一次触发基准。
3. 卖 Put 路由切换优先；若需在开盘退出核心 Put，则取消同日盈利重建，不重复交易。
4. 目标归零、月度维护或目标 Delta 调整优先于盈利重建。
5. 真实挂牌层缺少有效成交价时延后执行，不用未来数据补成交。

## 数据分层

- 真实挂牌层：2022-09-19 至 2026-08-14，真实 510500 Put/ETF 与 IC；样本不足 5 年，5Y/10Y 明确为 N/A。
- 理论延展层：2015-04-16 至 2026-08-14，理论 510500 Put 与历史 IC；仅用于机制与方向检验，不解释为可成交历史。

## 预注册判定

每个候选相对 `none` 分别检查真实挂牌层和理论延展层：

- 全样本 CAGR 不低于基线；
- Sharpe 不低于基线；
- 最大回撤绝对值恶化不超过 0.5 个百分点；
- 真实挂牌层至少发生 2 次可成交盈利重建。

只有 2x 与 3x 均通过，才视为相邻阈值方向稳定并保留本层；否则保留 `none`，不把单点最优晋级。第八层完成后停下等待用户确认，不修改生产、日报、账本、登记表或交易接口。
