## 研究问题与配对

固定前四层结论：绝对IV严格大于30%、不增加卖方MOM120、M+1、卖95% Put、等名义q1、持有至到期、无灾难保护。检验因果滚动相对IV的两种用法：

- `abs30`：只用绝对IV>30%，作为“不加第五层”的基线；
- `replace`：用相对IV分位替代绝对IV>30%；
- `overlay`：保留绝对IV>30%，并要求相对IV分位同时通过。

相对窗口为126/252/504个有效交易日，严格分位门槛为70%/80%/90%，共1条基线与18条候选。

## 相对 IV 定义

- T日使用修正后的M+1、约95%行权价510500 Put收盘反解IV。
- 只与T日之前最近W个有效IV比较；分位=`历史IV <= 当日IV`的比例，历史不包含当天。
- 至少需要60个历史有效观测，否则相对IV无效并关闭新开卖Put。
- 只控制首次入场。进入周期后不因分位或IV回落退出，继续持有到期并沿用指派恢复及整轮含成本回本状态机。
- 门槛严格使用`percentile > Q`，相等不触发。

## 固定和排除

- 只转换固定核心0.5倍；动量腿不卖Put；IC无Call。
- 既有估值0/1档和原IC执行动量许可保留；不增加MOM120。
- M+1持有到期；不加提前展期、灾难保护Put或估值防抖。
- 核心买Put三倍盈利兑现、季度IC T-3、动量、网格、指派恢复及整轮含成本回本退出保持相同。
- 510500 Put单边5bp；IC单边1bp；期货30%保证金/缓冲；现金年化3%。不含bid/ask、冲击、容量、税和动态保证金。
