# IM Put 持有方式 × 三档估值保护 v3：预注册规格

冻结日期：2026-08-16  
研究状态：候选结构对照；未获准实盘

## 1. 研究问题

本版回答两个独立问题：

1. 买入约3个月到期的MO Put后，不再每月提前卖出换新，而是让一组Put连续覆盖约三次IM月度合约并持有到期，结果如何？
2. 把原来0/100%的估值开关改为0/50%/100%三档，结果是否更平滑？

本版同时展示两者的交互，但不扫描或优化阈值。冻结的v2首次正式输出不得覆盖。

## 2. 候选矩阵

同一IM基线、MO官方行情、现金和费用下比较：

| candidate | Put持有方式 | 估值保护档位 |
|---|---|---|
| `no_put` | 无 | 0% |
| `monthly_binary_v2` | 每个估值月重新选择并在T+1开盘换Put | 0%/100%，必须逐日复现v2 |
| `expiry_binary` | 每张Put持有至实际到期 | 0%/100% |
| `monthly_three_tier` | 每个估值月在T+1开盘调整并换Put | 0%/50%/100% |
| `expiry_three_tier` | 每张Put持有至实际到期；只立即补足、不提前卖出 | 0%/50%/100% |

这是一组结构性候选，不以历史最优值作为晋升依据。

## 4. 当前v2估值的准确含义

v2不是直接用一个PE阈值定义“高估/低估”，而是一个严格走步的估值状态类比预测：

1. 特征为聚合滚动PE、聚合PB、`ERP=1/PE-10年国债收益率`、过去一年已实现股息贡献。
2. 每个状态日只用当时可知的数据计算四个因果历史百分位。
3. 在四维百分位空间内寻找最多8个、彼此至少间隔12个月且后续3年结果已经完整可知的相似锚点。
4. 以相似锚点后3年中证1000全收益年化中位数作为条件预测。
5. v2中该中位数小于0为100%保护，否则0%；少于4个有效类比时不保护。

因此v2严格说是“估值条件下的前瞻收益档位”，不是单一静态估值倍数。高PE/PB倾向于贵，高ERP和高股息倾向于便宜，但最终由四维联合历史类比决定。

## 5. 三档保护定义

为只柔化v2而不另造一套估值模型，三档仍使用同一个严格走步的3年全收益中位数：

- **低估/回报有利档：预测中位数 `>= 3%`**，0%保护，即0张MO。
- **中性档：`0% <= 预测中位数 < 3%`**，50%保护，即1张MO。
- **高估/回报不利档：预测中位数 `< 0%`**，100%保护，即2张MO。
- 少于4个完成类比：沿用v2的保守研究口径，0%保护。

3%上界来自用户已指定的闲置现金年化收益假设，不从回测结果选择。0%下界沿用v2原阈值。每1份IM的合约乘数为200元/点，每张MO为100元/点，所以1张MO对应50%名义保护，2张对应100%。

2026-08-14当前预测中位数为-1.57%，按冻结三档规则属于100%保护档。

## 6. 每月换Put候选

- 每个正式估值状态日`T`收盘确认档位，下一共同交易日开盘调整到目标张数。
- 旧Put在开盘卖出，新Put在同一开盘买入；即使目标张数不变，也更新到新的约3个月Put。
- 目标日期为`T+3个自然月`；选择已挂牌月份中实际到期日与目标日期最近者，并列选较晚月份。
- 2022-07-22初始例外以结算价建立，当天无Put盘中损益。
- `monthly_binary_v2`必须逐日复现冻结v2；否则正式运行失败。

## 7. 持有到期候选

- 每个已买入的MO Put合同均持有到实际到期结算，不因月度估值下降而提前卖出。
- 当月度目标张数高于当前未到期张数时，`T+1`开盘立即买入差额；目标下降时不卖，等待已有Put自然到期。
- Put到期后，若最新已知估值目标高于剩余张数，则在下一个共同交易日开盘补足；新Put目标日期为该补仓执行日加3个自然月。
- 总未到期张数上限为2。若50%升至100%，可以形成两个不同买入日或到期月的1张Put批次；每张均独立持有到期。
- 到期日为合约月份第三个星期五；若该日不是共同交易日，顺延至其后的第一个共同交易日。历史审计中`MO2606`因此按2026-06-22而不是6月19结算。
- 到期日使用官方结算价；到期后不收假设卖出交易成本，不计交易所行权/结算附加费。

## 8. 到期月、执行价与流动性

- 在目标月份选择当日**最低且同时满足开盘价>0、成交量>0、持仓量>0**的Put。
- 不使用收盘后才能知道的价格选择；成交量和持仓量仅作为当日该合约存在真实交易的最低可执行过滤。
- 预运行只读审计显示，持有到期路径只有一次不能使用字面最低档：2023-02-20的`MO2305-P-6100`无开盘成交、成交量和持仓量，按规则选择`MO2305-P-6200`。该调整在查看候选收益前冻结。
- 其余持有到期入场均使用字面最低档；全部选中合约在持有区间的官方结算价完整。

## 9. 日度损益与成本

- 每张MO的日损益率为`0.5 × Put点数变化 / 前一日活动IM结算价`。
- 普通持有日使用结算价到结算价；买入日使用开盘价到当日结算价；到期日使用前结算价到官方到期结算价。
- 多批次Put逐张相加；IM收益和IM费用完全沿用冻结基线。
- MO每张每次买或卖收0.5bp的IM名义成本；2张整组每边1bp。到期结算不收假设卖出成本。
- 无Put时70%现金按年化3%计息。有Put时，从70%中扣除`Σ(张数×Put结算价)/(2×IM结算价)`；Put市值已通过盯市损益计入组合。
- 不把30%保证金放大成3.33倍方向头寸。

## 10. 强制输出与核验

- 全样本、10年、5年、3年、1年CAGR、年化波动、Sharpe和MaxDD；历史不足的用户报告显示N/A。
- 2022—2026逐年CAGR和MaxDD。
- 各候选保护张数均值、保护日占比、0/1/2张日数、入场/卖出/到期数量、交易边和累计成本。
- 全部批次的买入日、到期日、目标日期、到期月、执行价、开盘价、成交量、持仓量和到期结算。
- 单列2024-01-02、2024-01-22、2024-02-01、2024-02-05，验证持有到期候选在2月5日仍持有3月Put。
- 核验日期唯一递增、核心列无缺失、全部类比结果终点不晚于状态日、费用和现金权重恒等式。

## 11. 判定边界

- 重点回答持有到期是否降低换仓成本、是否因放弃中途兑现Put浮盈而改变收益和回撤。
- 三档重点回答风险是否比0/100%开关平滑；不因某个候选全样本最好就追认阈值。
- 样本只有约4年，且最低执行价Put在历史到期时可能长期归零；任何候选最多列为观察，不直接晋升实盘。
- 官方开盘价不保证没有盘口冲击；不计经纪商附加保证金、行权/结算费、税费和盘中保证金追缴。
