# IM v1.3 核心 Put 盈利兑现完整组合回放 v1

预注册日期：2026-09-16。研究专用，不修改生产规则、账本或信号。

## 研究问题

把已经通过因果校验的核心 Put 盈利兑现机制放回同一条 IM v1.3 完整组合，比较：

- `baseline`：核心 Put 不提前兑现；
- `profit2x`：核心 Put 收盘价达到实际入场权利金 2 倍，T+1 收盘平旧腿并按当日 102%、约 3 个月重新建仓；
- `profit3x`：同上，阈值为 3 倍。

月度维护优先，估值目标归零仍按原规则退出；新腿实际买价成为下一次触发基准。盈利信号只使用 T 日收盘，T+1 收盘执行，禁止同收盘前视。

## 固定组合口径

- 0.5 倍固定 IM 核心仓；
- 0.5 倍动量袖，历史反事实使用现行 Abs20 恢复防抖：转负立即降风险，连续两个交易日严格大于 +1% 才恢复满仓；Score、成交量和过热过滤保持原规则；
- 1.6 买入、2.0 卖出的 0.5 倍网格，不给网格加 Put；
- 核心 Put：现行估值分层、MOM120 防抖、102% 行权价、约 3 个月、月度维护，并恢复认证的 2015 年早期估值；
- 动量 Put：MOM120<0 时按原数量规则，102% 行权价；随当前动量袖权重更新，不套用核心 Put 的 2x/3x 盈利兑现；
- IM Call：沿用 D10、IV26 的已验证固定路径。本研究没有卖 Put 路由，因此不触发卖 Put 期间暂停 Call 的规则；
- 期货按同一已验证季度链、每倍 30% 保证金/缓冲、现金年化 3%；期货、Put、Call 原成本模型保持不变。

## 数据与分层

- 理论延展层与真实 IM/MO 层分别输出，不把理论期冒充可交易历史；
- 使用本地已验证行情、期权链和完整组合组件，截止共同可用日；
- 真实零成交期权仍沿用现有官方结算估值处理；不加入不存在的盘口、冲击、整数手数、追保或强平重放。

## 验证与决策

- 三条路径除核心 Put 盈利兑现阈值外完全相同；
- 检查信号日严格早于执行日、月度维护与盈利兑现不重复、网格确为 0.5 倍、现金非负、收益有限；
- 报告 full、10Y、5Y、3Y、1Y；真实层历史不足的窗口明确为 N/A；
- 2x/3x 仅作为研究候选，不因单一收益指标提高而自动晋级生产。
