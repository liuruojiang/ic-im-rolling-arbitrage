- `0.67—0.71`：跨7.5/10/12年状态稳定、经济边界样本充足，但最近10年都只有1个启动段，低于至少2段要求；历史时点稳定性也失败。
- `0.72—0.75`：全样本仅4个启动段、最近10年1段，同时历史时点稳定性失败。
- `0.76`：唯一通过历史时点条件以外全部七项的单点；全样本/最近10年启动段为5/2，最近10年覆盖10.74%，7.5/10和12/10年Jaccard为91.11%/91.46%。但单点不构成平台，而且历史时点Jaccard最低仅37.84%，2019年后最低54.88%。

- `0.83`以上在10年中心最近10年已没有月末启动，不能作为有重复观测支持的门槛。

## 为什么历史时点全部失败

本版虽然把最终门槛固定在`equal3_raw`，但三个分量仍是“原始经济值在当时历史加权CDF中的风险位置”。CDF会随样本扩展和估值中枢迁移而变，所以该分数仍然是相对历史的动态定义。

以0.76为例，因果映射与2026最终冻结映射在相同历史片段上的状态Jaccard为：

| 历史时点 | Jaccard |
| --- | ---: |
| 2016-12 | 37.84% |
| 2019-12 | 54.88% |
| 2022-12 | 67.07% |
| 2023-12 | 74.39% |
| 2024-12 | 78.05% |
| 2025-12 | 93.90% |
| 2026-08 | 100.00% |

这种收敛是样本逐渐接近最终样本的机械结果，不能当作门槛历来稳定。用户此前对动态估值标准的质疑在本层得到支持：仅仅冻结最终CDF，并不能让其历史定义变成固定经济标准。

## 下一层建议

继续提高或降低CDF门槛没有意义。下一版应彻底删除历史分位作为基础分量，回到固定经济单位，并把旧离散阶梯连续化：

- PB固定压力：以PB 2.00对应1分、2.50对应2分，按0.50 PB连续线性变化；
- ERP固定压力：以ERP 3.00%对应1分、1.50%对应2分，按1.50个百分点连续变化；
- 股息固定压力：以股息2.00%对应1分、1.00%对应2分，按1个百分点连续变化；
- 三项等权后再对总分1.40—2.00做细网格结构审计。

这一路径才是真正不随起始年份重算的固定估值标准。上述公式只是下一版建议，尚未预注册或用于策略收益。
