# IM + MO Call 每日入场与盈利80%提前展期 v22 预注册规格

冻结日期：2026-08-19（Asia/Shanghai）  
状态：官方MO短样本机制验证；未批准实盘。

## 1. 研究问题与边界

回答两个相互递进、可单独归因的问题：

1. v20只在月度换仓评估日检查IV26；改为每个交易日收盘在空仓状态下检查，能否捕捉月中高IV机会并提高收益？
2. 在每日检查基础上，当已卖Call的收盘价相对本次实际卖出成交价下跌80%后，不等到原月度换仓，而是提前向后一个到期月展期，能否进一步提高权利金效率？

本版固定使用v20真实样本表现较好的当月D10结构和IV26，不扫描Delta、IV、期限或盈利阈值。v21固定15%/20%/25%虚值阶梯已未胜过D10，因此不再混入。完全排除估值门控、MOM、分批止盈、受威胁上涨移仓、急跌向内移仓、85%/95%风险度缩放和网格。

盈利80%提前展期只对应外部规则中“近月Call每手盈利80%以上且存在符合条件的远月时全部挪到远月”。40%/60%/80%分批减仓是另一个机制，本版不测试。

## 2. 基准、样本与候选

- 底仓：冻结的1倍滚IM + `reconstructed_valmom_floor3`三个月95% Put；
- 无Call基准：v20 `base_core_put`；
- 月评参照：v20 `front_d10_iv26`；
- 候选A：`front_d10_iv26_daily`，空仓时每日检查；
- 候选B：`front_d10_iv26_daily_tp80`，候选A加盈利80%提前展期；
- 每1张IM固定卖2张MO Call，只覆盖固定底仓；
- 模型层：2015-04-16—2026-08-14，理论连续执行诊断；
- 真实层：2022-07-22—2026-08-14，官方IM/MO收盘与结算。

正式晋升只看官方真实层；模型没有真实波动率微笑、离散行权价和流动性，只作长期方向诊断和参数工件完整性支持。

## 3. 月度周期与每日D10选约

月度周期完整沿用v19/v20：每次IM月度换仓事件的T日为周期切换评估日，T+1收盘执行；该周期的目标Call到期月固定为v20当月D10在T日选中的目标月份。

- 月度事件日：若现有Call到期日不晚于该事件对应的`current_expiry`，必须买回；同时用T日D10规则选择新周期Call，只有合约自身IV不低于26%才卖出，否则转为空仓。
- 空仓的普通交易日：在当前周期固定目标到期月内，用当日官方收盘、当日中证1000价格指数、利率与股息率重新计算各可交易虚值Call的IV和Delta；选Delta绝对误差最小者。若其IV不低于26%，T+1收盘卖出；否则继续空仓，下一交易日再检查。
- 已有Call且未触发月度换仓或盈利展期时，不因每日IV变化主动平仓，也不重复加仓。
- 可交易要求：T日和实际成交日合约收盘价、成交量、持仓量均为正且T日可反解IV；不可执行时保持原仓并顺延同一冻结动作，不用未来信息重选。

模型层在固定周期到期日上，用T日`sigma_close`和连续行权价构造精确0.10 Delta Call。

## 4. 盈利80%提前展期

只对候选B生效。每日T收盘计算：

`剩余价格比例 = 当前Call官方收盘价 / 本轮实际卖出成交收盘价`。

当剩余价格比例不高于20%时，视为本轮Call盈利至少80%。随后在T日官方链中：

1. 只寻找实际到期日晚于当前Call到期日的月份；
2. 选择最早的可用更远到期月；
3. 在该月按同一D10规则选合约；
4. 只有新合约自身T日IV不低于26%时，冻结“买回旧Call并卖出远月Call”的动作，于T+1收盘执行；否则继续持有旧Call，下一交易日重新检查。

实际展期成交后，盈利基准重置为新Call的实际卖出收盘价。若已提前展到更远月份，期间遇到较早的月度事件时保持该远月仓位；只有事件的`current_expiry`达到或超过现有Call到期日时才进入正常月换。

本版不把“收到的权利金”直接计为收益；旧仓按前结算至买回收盘、新仓按卖出收盘至当日结算确认损益，普通日按结算价逐日盯市。

## 5. 成本、现金与资本

- 2张MO篮子每边成本1bp；开仓/平仓各1bp，换仓2bp；
- Call保证金、Put市值、70%可用现金上限和3%现金收益完全沿用v19/v20；
- 任一日Put市值加Call保证金超过70%记为资本穿透；
- 不使用外部策略85%或95%的动态风险度，也不按剩余资金增加Call数量。

## 6. 必报结果与审计

1. 模型full/10Y/5Y/3Y/1Y与真实full/3Y/1Y的CAGR、波动、Sharpe、MaxDD、Calmar；
2. 真实逐年区间累计收益，尤其2022、2024和2026；
3. 月评参照、每日A、每日+TP80 B的开仓/换仓/平仓、持仓日、Call损益、成本和保证金；
4. 每日检查新增了哪些入场段，2022年是否捕捉到月评遗漏的高IV；
5. TP80信号数、可用远月数、实际展期数、触发时剩余价格比例、展期前后IV/Delta/到期日；
6. 2024-09-18—10-08急涨期；
7. v20无Call/月评参照逐日奇偶、收益/现金恒等式、T信号/T+1执行、无未来重选、盈利比例、远月顺序、官方收盘和资本审计。

## 7. 预注册判定

每日检查A的机制通过条件：真实full和3Y CAGR均不低于月评参照；真实full MaxDD不比无Call加深超过2个百分点；每日新增开仓至少2次；资本穿透和计划T+1不可执行为0；全部审计通过。

TP80 B的增量通过条件：真实full和3Y CAGR均不低于A；真实full MaxDD不比A加深超过2个百分点；实际提前展期至少2次；资本穿透和计划T+1不可执行为0；全部审计通过。

- A、B均通过：`daily_and_tp80_incremental_supported_real_only`；
- 只有A通过：`daily_supported_tp80_not_supported`；
- A不通过但B相对月评通过：`combined_effect_only_not_separable`；
- 都不通过：`daily_and_tp80_not_supported`。

任一结果最高只能进入官方MO短样本观察池，不代表获准实盘。不得因结果改写26%、0.10 Delta或80%门槛。
