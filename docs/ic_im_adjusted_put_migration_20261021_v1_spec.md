## 身份及时间

1. 官方事件给出M→A、同一八位ASCII证券ID、调整前后strike/unit、首次挂牌日、调整日、到期日。原M与重新挂牌同名M必须按不同ID区分。
2. 历史身份按生效区间解析。主数据的TIMESAVE只证明该快照日；不得从当前M主数据倒推出未知历史。调整事件只在可证的单次M→A区间使用，后续再次调整或中途摘牌未经证明时不得推断。
3. 涉及实际执行或回放价格，还需该日独立可用性证据；身份条款的有效区间不能代替该日挂牌/成交证明。缺失、冲突、重复或日期越界全部拒绝。

## 单位与现金成本

1. 数量为张数，调整本身不改变张数。原每张现金成本=`旧每单位权利金×旧合约单位`；新每单位经济成本=`原每张现金成本/新合约单位`。保留原始成本、单位、日期及证据，不把前结算价替代入场成本。
2. 不对新经济成本按行情最小报价单位取整；三倍兑现、卖方衰减以每张现金价值比较，避免单位改变造成假阈值。数值采用Decimal；禁止NaN、Infinity、布尔数值和非整数单位/数量。
3. 缺历史成本或缺成本计量日时只完成身份迁移预览，禁止开启三倍兑现或卖方衰减。调整后入场成本不再按原M单位重复转换。
4. 每个核心、动量、卖Put分别核验；同一证券ID可以分属不同袖，但成本不得互相借用。
5. 待执行计划保持原信号日/执行日。跨调整日的旧腿须逐腿重绑，原冻结意图及价格证据原样保留。不能将证券ID不变误作旧代码/旧strike仍可直接使用；未覆盖计划应阻断，而不是取消或顺延。
