# 中证1000 MO Put 收盘执行复测 v8 预注册规格

- 版本：`im_mo_close_execution_v8`
- 预注册日期：2026-08-17，Asia/Shanghai
- 状态：研究回测；未获准实盘；不得解释为交易建议或接入下单
- 冻结经济信号：`fixed175_or_mom120`，即固定风险分不低于1.75，或中证1000全收益指数120交易日绝对动量不高于0
- 研究动机：v6使用T+1开盘成交，2024-10-08的`MO2411-P-4300`开盘350点明显偏离相邻行权价、当日成交均价及结算价；本版按用户要求改为T+1收盘成交

## 1. 研究问题

在不改变信号、保护比例、Put目标比例、期限选择、期货基线、现金收益及成本的前提下，把Put买卖从T+1开盘改为T+1收盘，重测：

- `front_exit`、`2m_monthly_exit`、`3m_monthly_exit`、`3cycle_hold_expiry`；
- 目标行权价比例85%、90%、95%；
- 同层`no_put`基线；
- 冻结v6开盘执行路径只作为历史对照，不改写、不重算。

参数网格在运行前冻结为4个结构×3个目标比例，共12条保护路径；不得根据结果增删期限或行权价。

## 2. 两层证据

1. `real`：2022-07-22—2026-08-14，真实中金所IM逐月展期和MO日度行情。
2. `model`：2015-04-16—2026-08-14，中证1000全收益指数1倍暴露和理论Put。2022年前不是历史IM/MO，不含不存在的IM贴水，只用于期限结构的长窗口诊断。

真实层为实盘可交易品种证据；模型层不得冒充历史期货或期权成交。

## 3. 收盘执行定义

### 3.1 信号与执行时点

- T日收盘后，用不晚于T日的数据确认目标数量；
- 在下一共同交易日T+1的收盘时点执行；
- 不允许把T日信号用于T日收盘成交；
- 初始样本日使用当日收盘成交，明确标记为上市起点初始化例外。

### 3.2 真实MO

- 1份IM名义对应2张MO为100%保护；
- 目标月份选择沿用v6；
- 入场合约在目标月份中要求`close>0`、`volume>0`、`open_interest>0`，按`abs(strike/active_IM_close-target_moneyness)`最小选择；并列选较低行权价、较小合约代码；
- 退出要求旧合约当日`close>0`且`volume>0`；若不可执行，顺延且记录，最多5个交易日；
- 卖旧按旧Put当日`close`，买新按新Put当日`close`；
- 日终仍按官方`settle`盯市。因此交易日旧仓收益为`close-prior_settle`，新仓收益为`settle-close`；无交易日为`settle-prior_settle`；
- Put到期按冻结的官方到期/结算路径处理。

### 3.3 理论Put

- T+1收盘用当日中证1000官方收盘、截至收盘可知的利率、股息及波动率代理定价；
- 入场行权价严格为当日收盘现货的85%/90%/95%；
- 新仓收盘建立后当日理论Put收益为0；旧仓按当日理论收盘价退出；
- 月份挂牌和到期规则沿用v6冻结模型。

### 3.4 严格三周期

- 选择恰好覆盖未来3次IM月度换月、并在第4次换月前到期的最早已挂牌Put；
- 收盘建仓；信号关闭不提前退出，持有到期；
- 到期后仅在最新信号仍开时续保；
- 完整生命周期模型和真实层都必须100%覆盖恰好3次换月，否则本版失败。

## 4. 基线、资金与成本

- `real_no_put`冻结复现v6的真实滚IM净收益；
- `model_no_put`冻结复现v6中证1000全收益指数理论基线；
- 100%方向名义，30%保证金/缓冲，70%现金按年化3%计息；不按保证金放大方向敞口；
- Put权利金市值从70%可计息现金扣除；
- Put每一边按完整名义1bp，50%保护按0.5bp，卖旧买新两边分别计费；
- 不计买卖价差、盘口冲击、收盘集合/最后成交可获得性、经纪商附加保证金、税费及行权结算附加费；这些必须作为实盘差距单列。

## 5. 强制窗口与输出

两层每条路径强制输出：全样本、最近10年、5年、3年、1年的年化收益、年化波动、Sharpe和最大回撤。真实层10年/5年因MO历史不足显示N/A，并说明原因，不得省略。

另强制输出：

- 2022—2026逐年收益和最大回撤；
- 2024年专表；
- 开盘执行v6与收盘执行v8的同路径差异；
- 交易次数、保护日占比、成本和入场虚值度；
- 收盘价横截面异常审计、成交量/持仓量审计；
- 2024-10-08两个月95%路径不得使用350点开盘价，必须使用收盘字段；
- 每条路径相对同层no-Put的收益差与回撤改善。

## 6. 完整性门槛

1. v6脚本、v6逐日结果、v7审计及原始IM/MO行情SHA-256必须冻结记录；
2. 两层no-Put逐日与v6最大绝对误差不超过`1e-14`；
3. 所有常规执行日严格晚于信号评估日；
4. 所有真实买卖价必须逐笔等于原始行情同合约同日期`close`，最大误差不超过`1e-14`；
5. 真实入场合约必须100%匹配当日收盘点位下的最近目标可执行合约；
6. 每条保护路径必须有非零持仓、成本及交易；
7. 日期唯一、收益无缺失且大于-100%；
8. 2024-10-08 `MO2411-P-4300`若被退出，成交价必须为原始`close=12.2`，不得为`open=350`；
9. 模型/真实层完整严格三周期生命周期100%恰好覆盖3次换月；
10. 任一价格、合约、因果、基线或核心完整性门槛失败时，结论为`rerun_required`。

## 7. 预注册判定

单线相对同层no-Put：

- 模型全样本、10年、5年最大回撤均改善，且各窗口CAGR落后不超过2个百分点；
- 真实全样本及3年最大回撤至少改善0.5个百分点，CAGR落后不超过2个百分点；
- 真实1年CAGR落后不超过3个百分点，最大回撤不得恶化超过1个百分点；
- 模型和真实各至少20个保护日。

稳定性：

- 行权价邻点：同期限至少一个85↔90↔95邻点也单线通过；
- 期限邻点顺序：`front_exit ↔ 2m_monthly_exit ↔ 3m_monthly_exit ↔ 3cycle_hold_expiry`，至少一个邻点也单线通过；
- 只有单点通过为`peak_only`；有一侧连续支持为`narrow_stable`；两侧或多期限连续支持为`wide_stable`。

本版最多晋级`research_watchlist`，不得自动改为获准实盘。
