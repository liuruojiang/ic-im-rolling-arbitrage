# IM M+1卖95% Put估值准入防抖扫描 v1（预注册）

## Research Question

在已修正的IM v1.3混合路由中，固定绝对`IV>35%`，只对卖Put新腿的估值0/1档准入增加防抖，检验能否减少估值1/2档边界附近的反复许可，同时不把该仓位改造成新的动量策略。

## Frozen Rules

- M+1卖95% MO Put；权利金衰减60%后最多提前滚动一次到紧接下一个实际挂牌月份。
- MOM120许可、现有MOM120相关防抖、早期估值恢复、102%核心Put、Call暂停、指派后IM回本退出均保持当前口径。
- 路由时IM、核心Put与Call同步退出；Call在Put、现金和回本阶段暂停。
- 不加入灾难保护；不采用上一项未晋级的相对IV。
- 防抖只改变卖Put新腿的估值许可，不改变核心Put数量、网格、期货方向或持仓内退出，因此不新增动量仓。

## Candidate Grid

1. `instant_le1`：当前对照；估值档0/1立即允许，2档以上立即禁止。
2. `confirm2_le1`：2档以上立即禁止；回到0/1档后须连续2个交易日才允许。
3. `confirm3_le1`：2档以上立即禁止；回到0/1档后须连续3个交易日才允许。
4. `tier_hysteresis_0_on_2_off`：0档开启许可，1档维持上一状态，2档以上关闭。

所有状态只使用当日及此前估值。当天T收盘得到许可，最早T+1开盘执行；不得回填未来状态。

## Data and Cost

- 真实层：2022-07-22起IM/MO挂牌历史及真实开盘、收盘、成交量、持仓量。
- 理论层：2015-04-16起既有Black-Scholes延展M+1/M+2 MO Put；代理结果不得解释为可成交历史。
- 单边1bp标的名义成本、每1倍期货30%保证金/缓冲、3%现金收益；其余执行和成本与当前修正基线一致。

## Diagnostics

- 估值原始允许状态、防抖后状态、连续日数、状态切换数、与原始状态不同日数。
- 完整卖Put许可、实际路由周期、提前滚动、指派、核心Put同步退出和Call暂停日。
- full、10Y、5Y、3Y、1Y的CAGR、波动、仓库口径Sharpe和最大回撤；真实5Y/10Y明确N/A。
- 当前`instant_le1`必须与上一轮绝对IV35基线逐日收益误差不超过`1e-12`。

## Pre-registered Decision Rule

防抖候选只有同时满足以下条件才可保留为研究候选：

1. 估值许可状态切换数较当前减少至少15%；
2. 真实层和理论层Full CAGR均不得下降超过0.50个百分点；
3. 两层Full Sharpe均不得下降超过0.02；
4. 两层Full MaxDD均不得恶化超过0.50个百分点；
5. `confirm2`与`confirm3`方向应一致；若只有单个候选改善，则标记为单点、不晋级；
6. 若防抖未改变任何实际卖Put周期，只能判定“操作状态简化、收益未识别”，不能声称策略增强。

即使通过，也只保留研究候选，不自动修改1.3版本或生成交易建议。

## Limitations

- 估值档由日度信号复算而来，真实MO历史较短，边界反复和可执行入场的重合次数可能很少。
- 理论层使用代理期权和校准carry；不含真实买卖价差、冲击、容量、动态保证金、强平、税费与整数合约。
