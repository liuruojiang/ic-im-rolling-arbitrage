# 中证1000双轴时代自适应估值 v5 预注册规格

冻结日期：2026-08-19  
研究状态：估值本体研究；未批准实盘

## 1. 研究问题

v3固定绝对分档`2.45/2.50/2.60`在真实IM样本2022-07-22以后始终为0档；从2022年初计算也只有极少数非0日。该规则仍可表示跨时代的绝对极端高估，但已经不能单独承担当前环境中的估值相对位置识别。

本版不直接把固定阈值从2.45事后降低到某个新数值，也不读取IM、MO、Put、贴水或策略收益。它建立两个彼此可解释的轴：

1. **绝对经济轴**：完整保留v3二取三固定分档，表示跨时代绝对压力；
2. **近期环境轴**：用当时已经公开的历史月末二取三分数，以指数时间衰减权重计算年度固定分位阈值，表示当前相对自身近期环境的位置。

最终双轴档位取两轴的较高值。近期轴增加新环境分辨率，但不能抹去绝对极端高估。

## 2. 冻结数据与基础分数

- 输入只使用v3冻结的`daily_tier_states.csv.gz`和`monthly_tier_states.csv`，样本2015-10-19至2026-08-17。
- 基础分数固定为`unbounded_median_knot`，即PB、ERP、过去一年已实现股息贡献三项固定经济压力的二取三中位数；不切换到均值。
- 绝对轴严格复用v3：`<2.45 / 2.45—2.50 / 2.50—2.60 / >=2.60 -> 0/1/2/3档`。
- 收益字段只报告同窗中证1000价格指数背景，不参与任何选择；不运行IM、MO、Put、网格或Call。

## 3. 近期轴年度因果校准

### 3.1 年度锁定

- 每个自然年使用上一自然年最后一个月末为`as_of`；校准历史只能包含`date <= as_of`的月末分数。
- 至少需要36个月末观测；因此预计最早从2019年开始启用近期轴。未满足暖机时近期轴为0档，双轴仍保留绝对轴。
- 一旦某年的三个阈值计算完成，整个自然年固定不变；不做日度、周度或月度滚动阈值，不加入确认天数或滞后。
- 每个月末观测的权重为`0.5 ** (age_years / half_life_years)`；同月只有一个观测，避免交易日数量造成时代权重偏差。
- 加权分位采用按分数从低到高排序后的累计权重首次达到目标分位的观测值；边界使用`>=`进入更高档。

### 3.2 冻结候选

半衰期固定为`5 / 7.5 / 10年`，分位阶梯固定为：

- 主阶梯`75% / 85% / 95%`：近期轴累计进入1/2/3档的校准目标约为25%/15%/5%；
- 宽松诊断`70% / 80% / 90%`：累计目标约30%/20%/10%，只用于压力测试，不得晋升。

对每个半衰期和阶梯分别输出：

- `relative_*`：只使用近期轴，作为定义诊断；
- `dual_*`：`max(absolute_tier, relative_tier)`，作为可执行估值候选。

事前唯一主候选为`dual_h75_q758595`；`dual_h5_q758595`和`dual_h10_q758595`是必须同时支持的半衰期左右邻点。70/80/90系列无论分布看起来多好，都不能替代主候选。

## 4. 强制指标

所有候选及`absolute_v3`基线同时报告全样本、最近10年、5年、3年、1年：

- 日度/月末0/1/2/3档占比、平均档位、非零覆盖；
- 累计达到1/2/3档覆盖；
- 非零事件数、最长持续期、升级/降级、跨两档跳变和年化切换；
- 与绝对轴的精确一致率、平均绝对档差；
- 中证1000价格指数年化、波动、Sharpe和MaxDD背景，语义固定为`underlying_price_index_context_only_no_strategy_return`。

另输出：

- 2015—2018、2019—2021、2022年至今三个时代切片的状态分布；
- 每年三个冻结阈值、样本月数、有效样本量、最近3/5/10年及2022年前权重占比；
- 主候选三种半衰期的逐日精确一致率、线性加权Kappa和Jaccard；
- 2022年至今各累计档位的覆盖、事件数、活跃年份；
- 当前分数、绝对档、近期档、双轴档及当前年度阈值。

## 5. 预注册选择门槛

### 5.1 主候选自身

`dual_h75_q758595`必须同时满足：

1. 2022年至今非零日度覆盖在10%—40%；累计2档覆盖在4%—30%；3档覆盖在1%—20%；
2. 2022年至今精确1/2/3档各自占比均至少1%，排除再次坍缩成单一档；
3. 2022年至今累计1档至少2个独立月末事件、累计2档至少2个、累计3档至少1个；至少3个自然年出现非零状态；
4. 2019—2021至少存在1个非零月末事件，避免只对2022以后单一时代拟合；
5. 2019年至今的日度年化切换不超过24次；
6. 三个年度阈值的相邻年份绝对变化中位数均不超过0.35，最大值均不超过0.75；
7. 2026年度校准中最近5年月末合计权重不低于50%，确保近期权重实质高于早期。

### 5.2 半衰期邻点支持

在2022年至今，主候选与5年、10年半衰期邻点分别要求：

- 精确档位一致率不低于70%；
- 线性加权Kappa不低于0.60；
- 非零状态Jaccard不低于75%；
- 两个邻点也分别满足主候选门槛1—5。

### 5.3 决策

- 主候选自身及两个邻点全部通过：`freeze_dual_h75_q758595_for_next_put_layer / wide_stable`；
- 主候选自身通过但任一邻点失败：`watchlist_regime_aware_dual_axis / peak_only`；
- 主候选自身失败：`no_regime_aware_valuation_candidate / reject`。

70/80/90系列只解释更宽松覆盖的代价，不参与上述决策；不得看到状态分布后修改分位、半衰期、暖机月数或门槛。

## 6. 因果与完整性

- 每个年度阈值的最大输入日期必须不晚于上一年末；逐年截断重算必须与正式阈值完全一致，未来行使用数为0。
- v3绝对轴逐日奇偶误差必须为0；双轴必须逐日等于`max(absolute, relative)`。
- 相同半衰期/阶梯的日度和月末必须使用同一年度阈值；阈值必须严格递增，否则该年度不可用并计为失败。
- 所有候选和五窗口必须完整；价格指数背景在同一窗口所有候选必须完全相同。
- 本版不含交易执行、手续费、滑点、保证金、现金收益或期权流动性。即使冻结候选，也只允许进入下一层MO Put研究，不批准实盘，不生成交易指令。
