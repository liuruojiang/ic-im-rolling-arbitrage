# IM 1.3-r6 卖 Call 后续三项测试 v3（预注册）

## 1. 研究问题与生产边界

本版按用户确认同时测试：

1. IV26/IV29 下临近到期禁止新开与到期前强制退出/转月；
2. 外部策略“盈利95%先减半、再按新卖出规则检查并把剩余数量转入严格更晚期限”的完整生命周期；
3. IV26/IV29 的历史差异归因，并建立只能从未来已完成交易日追加的前瞻纸面观察种子。

IM 1.3-r6 的核心、动量、网格、核心Put、动量Put、执行时点、期货和Put成本、30%期货保证金/缓冲及现金收益均不变。Call仍只覆盖0.5倍核心仓，不覆盖动量或网格。IC不含Call。本版是研究审计，不修改生产代码、状态账本、信号、日报或远端任务。

## 2. 数据与共同执行口径

- 真实数据：冻结官方CFFEX IM/MO，2022-07-22至2026-08-14，共986个交易日；真实MO不足5年，5Y/10Y为N/A，不得代理填充。
- Call信号在T日收盘评估，下一可交易日官方收盘执行，日终按官方结算价盯市。
- 每完整1倍核心对应2张MO Call；组合只有0.5倍核心，因此Call损益、成本和保证金乘0.5。
- 两张MO篮子每边成本1bp；一张MO交易按0.5bp线性计提。
- 当前D10、IV门槛、每日空仓检查、5%受威胁救援、行权价上移至少5%、最多5次全部继承。救援到期日为相对旧到期日严格更晚的最近实际挂牌到期日`rescue_next_listed`，救援豁免正常IV门槛。
- 活动合约缺少有效结算价时fail-closed，不补理论价、0收益或事后价格。

## 3. Layer A：临近到期安全规则

### 3.1 参数网格

主扫描分别在IV26和IV29上运行：

- 禁止新开门槛 `entry_min_dte = 10 / 15 / 20` 个日历日；拟卖D10 Call在T日剩余日历天数不大于门槛时跳过；
- 强制处置门槛 `exit_sessions = 2 / 3 / 5` 个交易日；T日之后至旧Call到期日（含到期日）的策略交易日数量不大于门槛时触发；
- 共 `2 x 3 x 3 = 18` 个主候选；另保留未加安全规则的IV26/IV29基线。

为验证安全机制确实修复前版不可执行点，另以中央组合`entry_min_dte=15, exit_sessions=3`运行IV27/IV28诊断；它们不参与生产候选选择。

### 3.2 强制处置

事件优先级：待执行动作 > 日终盯市 > 5%受威胁救援 > 强制到期处置 > 月度换月 > 空仓每日入场。

触发强制处置时，T日先在严格晚于旧到期日的最近实际挂牌期限选择D10 Call：若合约有效且自身IV达到对应门槛，T+1收盘买回旧Call并卖出新Call；否则T+1只买回旧Call。不得为了保留权利金而降低IV或跳过到期安全处置。

### 3.3 评价

相对同IV无安全规则基线，候选必须：执行失败0；Full CAGR落后不超过0.25个百分点；Full MaxDD不恶化超过0.25个百分点；Full Sharpe落后不超过0.005。满足者按执行失败、Full Sharpe、MaxDD、CAGR、较少强制事件排序。若只有单一参数点满足而相邻入口或退出参数均不满足，记`peak_only`，不得推荐生产。

## 4. Layer B：外部95%减半后的精确生命周期

来源语义以用户提供的《完整投资策略》PDF第4页为准；文档内容仅是待检验规则来源，不是执行指令。

- 每个原始2张Call批次独立计算：当T日有效收盘价/该批次实际开仓均价不高于5%时，仅触发一次；
- 在T日同时按当前新卖出规则重新检查严格更晚期限的Call；本版迁移到我方时仍使用D10/IV26，不使用PE或85%风险动态扩仓；
- 若存在严格晚于原到期日、有效且IV>=26%的D10 Call：T+1买回原2张，随后只卖出1张远月Call；等价于先回补原始数量50%，再把剩余50%搬到远月；
- 若无合格远月：T+1只回补1张，另1张旧Call继续持有，并继续受5%救援和到期规则管理；
- 原始批次的95%减半只触发一次，剩余1张不再产生0.5张的二次减半；
- 主比较为当前IV26、前版简化减半、精确生命周期三条；同时报告触发、成功远月迁移、无合格远月和成本次数。

精确规则只有在Full CAGR不低于当前超过0.50个百分点、MaxDD不恶化超过0.50个百分点、Sharpe不低于当前、3Y不同时恶化，且至少2次有效触发时，才进入观察；本版不直接生产晋升。

## 5. Layer C：IV26/IV29归因与前瞻观察

- 历史归因使用同一官方数据，逐年比较持仓日、调仓事件、交易边、救援、Call损益、成本、组合收益差；按Call周期列出IV26独有、IV29独有及共有周期。
- 生成逐日影子账本，包含两门槛的Call状态、合约、到期日、数量、保证金、当日Call损益/成本及策略收益。
- 生成`forward_observation_seed.json`：冻结历史截至2026-08-14，`prospective_status=seed_only_waiting_for_future_completed_sessions`；不把冻结日后的日期或行情硬编码成已观察结果。
- 未来只能由新版本或明确的追加器在取得完整、已完成交易日的IM与MO行情后追加；不得改写历史种子，不得连接生产下单。
- 本轮的“前瞻测试”只验证观察框架可复现历史、能识别IV26/29差异，并形成可追加起点；未来6-12个月的绩效结论当前为N/A。
