# IM + MO 前月95%固定/动态估值与绝对动量验证 v5 预注册规格

- 版本：`im_mo_front95_fixed_dynamic_momentum_validation_v5`
- 预注册日期：2026-08-17，Asia/Shanghai
- 状态：真实合约研究回测；未获准实盘；不得解释为交易建议或接入下单
- 研究边界：中金所没有中证500股指期权；本版用2022-07-22同时上市、同以中证1000指数为标的的IM与MO检验IC+510500ETF Put结论能否跨标的成立
- 证据边界：全历史仅约4年、已经多轮复用；任何正面结果最多为研究观察

## 1. 研究问题

在真实IM逐月多头上，用真实中证1000股指Put（MO）复现前月95%工具，比较：

1. 不加Put；
2. 仅`MOM120<=0%`；
3. 仅固定绝对风险`fixed_risk>=1.75`；
4. 仅最近8年动态风险`dynamic_risk>=0.75`；
5. `fixed_risk>=1.75 OR MOM120<=0%`；
6. `dynamic_risk>=0.75 OR MOM120<=0%`。

本版只回答同指数股指期货+股指期权上，前月95%工具及固定/动态结论是否同方向。不得在看收益后调整阈值、动量周期、Put月份、虚值度、保护比例或退出规则。

## 2. 产品事实与可比边界

中金所当前股指期权为IO（沪深300）、MO（中证1000）、HO（上证50），没有中证500股指期权。因此不能把IC+510500ETF Put直接替换为“IC期权”。本版使用严格同标的指数的IM+MO，但这是中证1000跨标的复核，不是中证500原策略的同品种复现。

IM合约乘数200元/点，MO合约乘数100元/点；每1份IM名义配2张MO为100%名义保护。

## 4. 信号

### 4.1 绝对动量

`MOM120(T)=中证1000全收益指数收盘(T)/收盘(T-120个交易日)-1`。`MOM120<=0%`为风险开启。

### 4.2 固定1.75

- PB：`<2.00 / 2.00—2.50 / >=2.50`映射0/1/2；
- ERP：`>3.00% / 1.50%—3.00% / <=1.50%`映射0/1/2；
- 过去一年股息贡献：`>=2.00% / 1.00%—2.00% / <1.00%`映射0/1/2；
- `fixed_risk=25%×PB档+50%×ERP档+25%×股息档`，达到1.75开启。

该阈值原为中证500规则，移植到中证1000只作外部压力测试，不宣称已针对中证1000校准。

### 4.3 动态75%

每个评价日T只用`T-8个自然年`至T的已有日度状态：

- `PB风险分位=P(窗口历史PB<=当日PB)`；
- `ERP风险分位=P(窗口历史ERP>=当日ERP)`；
- `股息风险分位=P(窗口历史股息贡献>=当日值)`；
- `dynamic_risk=25%×PB风险分位+50%×ERP风险分位+25%×股息风险分位`。

达到0.75开启。2015-10-19以前没有合格中证1000日度估值，早期8年窗口只使用当时已有历史，不得用未来或全样本分位补齐。

### 4.4 因果执行

每日T收盘计算信号，T+1第一个共同IM/MO交易日开盘执行。2022-07-22上市首日使用2022-07-21已知状态，并按官方结算价初始化；2026-08-14状态只作当前审计，不进入收益。

目标只有0或2张MO，即0%或100%保护；OR规则任一入口成立即2张。

## 5. 前月95% MO

- 前月：执行日已挂牌且实际到期日晚于执行日的最近到期MO月份；
- 95%：在目标月份、当日`open>0`、`volume>0`、`open_interest>0`的Put中，选择`abs(执行价/当日活动IM合约开盘价-0.95)`最小者；并列先选较低执行价，再选较小合约代码；
- 这是约5%虚值的行权价目标，不是95%保护比例或Delta；
- 信号开时买入；信号关时下一交易日开盘卖出；
- 信号持续且前月变化时，开盘卖旧买新；正常路径不持有旧前月至收盘结算；
- IM自身月滚不单独触发MO交易；但IM和MO同为第三个星期五到期，前月切换通常与IM换月同日；
- 调整日旧Put或新Put不可执行时延迟整笔调整，继续按官方结算价盯市旧Put并逐日重试；最大允许5个交易日，超出则正式失败。

## 6. 损益、成本与现金

- IM日收益与IM费用逐日复用冻结基线；1倍IM名义，不按30%保证金放大至3.33倍；
- 每张MO损益率=`0.5×Put点数损益/前一日活动IM结算价`；2张对应1份IM名义；
- 普通持有日结算到结算；买卖/换仓日用开盘价执行并计开盘至结算损益；
- MO每张每买或卖收0.5bp IM名义成本，2张整组每边1bp；换月卖旧买新共2bp；
- 30%保证金/缓冲，70%现金年化3%；Put市值从可计息70%中扣除；
- 不计盘口冲击、经纪商附加保证金、行权结算附加费、税费和盘中追保；官方开盘/结算价不是大额成交保证。

## 7. 强制输出与判定

六条路径展示含现金的CAGR与MaxDD：全样本、最近10年、5年、3年、1年；10年/5年因上市历史不足必须为N/A。另输出逐年、保护日、开关次数、交易边、累计成本、实际入场虚值度、流动性延迟和当前研究状态。

相对同场无Put：

- 单线工具支持：全样本MaxDD改善至少0.5个百分点，CAGR落后不超过1个百分点；最近3年/1年CAGR落后不超过3个百分点且MaxDD不恶化超过1个百分点；
- 动态相对固定方向复现：动态OR全样本CAGR不低于固定OR，且MaxDD不得比固定OR恶化超过1个百分点；最近3年同样检查；
- 若只有回撤改善但收益超限，为`costly_protection`；若真实同指数上动态不再优于固定，为`cross_underlying_not_confirmed`；
- 任一候选都不能因约4年复用样本获准实盘。

最终只给`confirmed_on_im_mo`、`partly_confirmed`或`not_confirmed`研究结论，不做实盘晋升。

## 8. 完整性

1. noPut逐日收益和现金收益必须与冻结IM基线最大误差<=1e-14；
2. 日度估值在冻结IM月末的五项特征最大误差<=1e-14；
3. 所有普通执行日严格晚于信号日；动量、固定、动态和OR目标逐日复算误差<=1e-14；
4. 真实MO选约与当日前月、95%目标及流动性规则100%匹配；
5. 六条路径齐全、日期唯一、无缺失、无<=-100%收益；
6. 交易不早于计划日、最大顺延<=5个交易日；全部实际入场目标张数为2；
7. 收益、Put损益、费用、Put市值和现金权重恒等式误差<=1e-12。
