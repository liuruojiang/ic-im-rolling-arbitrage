## 1. 版本目的与父版本

本版本以 `im_mainline_v1_2.py` 为父版本，只替换中证1000动量袖的目标权重。固定0.5倍核心、0.5倍动量资本、独立网格、Put、Call、成本、30%保证金/缓冲与3%现金收益全部保持父版本口径。

## 2. 动量规则

- `MA35 / Mom18 / W2.5`；`Score > 0`。
- `50% OFF + 50% Abs20 > 0`，基础目标只允许 `0 / 0.5 / 1.0`。
- 信号日使用中证1000价格指数的当日收盘和累计成交量。
- `Volume / MA160 >= 0.85`才保留基础目标；MA160未形成时放行。
- 信号日 `Score >= 150` 且过滤后目标非零时，将下一共同交易日动量权重清为0。
- 最终收盘目标和下一交易日执行权重只允许 `0 / 0.5 / 1.0`；动量IM名义为 `0.5 × 执行权重`。
- 所有过滤均在T日收盘确认并只作用于下一共同交易日；不得用T日信息抹掉T日收益。

权威来源为 `D:/动量策略/A 股股指多头策略/poe_cn_four_index_raw_momentum_combo_v1_3_bot.py` 的 `zz1000` 袖。实现时记录其源码SHA-256和策略规格哈希，并逐日对账最终执行权重，最大误差不超过 `1e-12`。

## 3. OHLCV与失败关闭

输入至少包含唯一、递增、日频的 `date/open/high/low/close/volume`。价格必须有限且为正，最高/最低价关系必须成立，成交量必须有限、为正且通过指数累计成交量数量级检查。重复日期、日期错位、缺列、无效价格、不可验证成交量或过期实时数据均失败关闭，不得把价格、期货成交量或成交额冒充指数成交量。

## 4. 不变组件

- 固定核心IM始终0.5倍；独立网格完整继承 v1.2 的 `<=1.60` 新增1倍、`>=2.00` 退出及T+1开盘执行。
- Put和Call只覆盖固定核心，动量与网格均不配置期权。
