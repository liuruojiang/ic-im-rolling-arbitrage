# IC固定估值增仓三条观察线Put同步对照 v5 运行后审计

日期：2026-08-18（Asia/Shanghai）  
状态：研究对照；未批准实盘。

## 结论

三条线的`sync_put_total_ic`均未通过预注册门槛，正式决定为`retain_core_put_only_for_overlay/preregistered_gate_not_met`：新增估值仓暂不随底仓同步扩Put。

同步Put不是完全无效，但风险收益交换不足：

- 主观察`0.375/1.000`模型全样本只改善0.42pp MaxDD，却损失0.67pp CAGR；真实Put改善1.34pp MaxDD、损失1.85pp CAGR。
- `0.500/1.000`模型层改善最明显：MaxDD从-31.19%降至-24.58%，改善6.62pp，只损失0.62pp全样本CAGR；但模型5年损失1.42pp，真实全样本损失2.16pp，且真实3年MaxDD反而加深0.11pp，因此没有模型/真实交叉确认。
- 更早退出`0.375/0.875`模型全样本只改善0.42pp、真实改善1.34pp，收益分别损失0.49pp和1.62pp，也没有过关。

## 为什么同步保护性价比不高

- 新增仓只在深度低估后短期持有，主要捕捉修复行情；同步Put恰好在反弹期间损耗。
- 三条线模型层额外Put累计损益分别约-6.21%、-6.44%、-4.66%，额外交易成本只有0.12%、0.16%、0.10%；真实层额外Put累计损益约-5.83%、-6.65%、-5.28%，成本约0.12%、0.13%、0.21%。主要损失来自Put本身，而不是手续费。
- 同步只在主线目标非零时保护。新增仓退出快、部分退出日主线目标已归零，因此同步Put的作用区间有限。

## 执行与风险审计

- 新增IC开仓日，若核心目标25%，同步目标在同日收盘准确变为50%；退出日同日收盘恢复核心目标。目标公式误差0、应当发生的同日Put调仓遗漏0。
- 正式14条组合路径、25,914行；v4核心模式逐日误差`9.975e-17`，v21底仓误差`3.209e-16`；收益/现金恒等式误差0，因果失败0。
- 模型/真实最大目标Delta误差为`1.11e-16`/0.896pp；资本门槛通过，真实Put交易后最高市值8.43%，低于40%Put前现金。
- `0.375/0.875`真实同步路径最大所需Put名义达到8.85倍，原因是低绝对Delta合约需要更多张数才能达到50%目标；虽未触发现金门槛，但放大了执行和流动性风险。
- 本版不批准同步Put用于新增仓；底仓Put主线不受影响。若未来继续，优先研究`0.500/1.000`的部分同步（例如只增加一半目标），而不是在三条线上继续全量同步。
