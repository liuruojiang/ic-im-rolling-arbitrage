# 50%滚IM + 50%动量门控：中证1000全周期代理 v1

日期：2026-08-22  
状态：用户指定的上市前贴水代理研究；未批准实盘

## 研究目标

将固定的“50%单纯滚IM + 50%动量门控滚IM”从IM真实上市期向前延伸至中证1000价格指数可测起点，观察更长市场周期。

## 正式分层

- `2014-10-17—2022-07-21`：代理期。IM尚未上市，不存在可执行IM价格；
- `2022-07-22—2026-08-21`：真实期。使用中金所官方逐月IM结算价；
- 全样本、10年和5年结果均含不同长度的代理期，必须显式标记；
- 最近3年和1年完全位于真实IM期。

## 上市前IM代理收益

1. 使用中证指数官方`000852`价格指数日收益作为方向收益；
2. 在IM真实期计算逐日毛基差因子：`(1 + IM毛收益) / (1 + 中证1000价格指数收益) - 1`；
3. 将2022-07-22—2026-08-21全部991日毛基差因子的几何年化平均折算为固定日度基差；
4. 上市前代理IM毛收益为：`(1 + 指数日收益) * (1 + 固定日度基差) - 1`；
5. 该平均值使用未来真实IM样本反推，属于用户指定的回填情景，存在明确前视信息，不得称为可执行回测或样本外验证。

## 换月与成本

- 上市前按股指期货通常的每月第三个星期五滚动；若规则日不是指数交易日，使用此前最近交易日；
- 单纯滚IM袖初始建仓1bp，每次换月两边2bp；
- 动量门控袖按`1bp * abs(delta_weight)`计进出成本，只在目标仓位大于0的代理换月日按`2bp * weight`计换月成本；
- 真实IM期保留正式上游的实际换月日与成本；为保持真实期端点一致，2022-07-22上游初始1bp成本仍保留。

## 组合与现金

- 50%资本配置单纯滚IM；50%配置固定中证1000动量门控滚IM；
- 动量参数为`MA35 / Mom18 / W2.5`，50% Abs20 OFF + 50%静态`Abs20 > 0`；
- T日信号、T+1共同交易日目标；组合总IM名义为0.5、0.75或1倍；
- 每1倍IM使用净资产30%作为保证金及缓冲，其余现金按净年化3%的固定情景计息；
- Put、Call与网格全部关闭。

## 输出与验证

- 同表展示单纯滚IM代理、动量门控滚IM代理及50/50组合；
- 强制展示全样本、10年、5年、3年、1年的年化收益与最大回撤；
- 每个窗口报告代理日数、真实日数和代理占比；
- 真实IM期逐日结果必须与现有正式两袖和50/50组合端点一致；
- 保存逐日代理/真实标记、固定基差、换月事件、成本、仓位、现金和收益；
- 不扫描贴水值或组合比例。本版只运行用户指定的上市后平均贴水情景。

## 结论边界

上市前不存在IM，本版代理不能证明当时真实可获得同样贴水，也不能用于实盘晋升。它只能回答：如果早期市场环境拥有与上市后平均相同的滚IM基差，固定50/50结构在中证1000完整价格周期中的历史表现如何。
