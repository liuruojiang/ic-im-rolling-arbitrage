# 人民币账户 ICIM v1.3-r6 整数Put、处置顺序与成交延迟压力测试 v5

状态：预注册研究；不修改 v1.3-r6 信号、仓位、Poe、Gmail、远端发布或交易配置。

## 1. 研究问题

在 v4 极端路径压力测试基础上，补齐三个最关键的执行缺口：450万元 IC/IM 腿级账户的 Put 整数张数、风险瀑布处置顺序，以及连续单边市中风险动作延迟0/1/2个交易日成交。目标是判断“六个跌停仍能生存”是否依赖分数Put与即时成交假设。

账户总额1500万元，其中A策略600万元盘中不可调用；ICIM子账户900万元，IC/IM各450万元。所有结果只用于研究审计。

## 2. 冻结输入与整数映射

- 完整复用 `run_rmb_icim_v13_extreme_path_stress_v4.py` 的真实946个持仓截面、期货与Call整数手数、期权合约、行权价、期限、压力定价和中金所Call保证金公式。
- IC Put目标保护名义取冻结真实账本 `actual_notional_fraction × 450万元`；510500ETF期权乘数10000，张数按 Python `round` 的正式引擎语义取最近整数，非零目标至少1张。
- IM核心与动量Put分别取 `0.5 × put_qty_normalized × 450万元` 的目标保护名义；MO乘数100，分别按最近整数取整，非零目标至少1张。
- 取整后的当前市值用冻结账本隐含的单位期权价格重建。必须报告整数化前后保护名义、Put市值和张数误差。
- 不得给网格新增Put；IC仍无Call。

## 3. 压力路径

所有路径逐步盯市，单步价格变化不超过10%；仓位只在风险动作实际成交后改变。

1. `down6_priced_put`：累计 -10%/-19%/-27.10%/-34.39%/-40.95%/-46.86%；保证金15%/18%/20%/22%/25%/25%；Put IV 60%升至120%，Put卖出折价25%。
2. `down8_priced_put`：在down6后继续两个跌停，累计 -52.17%/-56.95%；保证金25%，Put IV130%/140%，折价30%。
3. `down6_put_zero`：与down6相同，但Put压力收益、可用价值和变现回收均为0，表示极端报价或保护失效下界。
4. `down6_then_rebound`：先走完整down6，再以每日不超过10%的反弹逐步回到起点；保证金与IV缓慢回落，用于检验过早减期货造成的反弹踏空，以及过早卖Put对继续下跌的影响。

## 4. 四种处置顺序

- `external_put_first`：平Call → 卖Put → 减网格 → 减动量 → 减核心。
- `call_grid_first`：平Call → 减网格 → 减动量 → 卖Put → 减核心。
- `grid_call_keep_put`：减网格 → 平Call → 减动量 → 卖Put → 减核心。
- `pro_rata_futures_first`：平Call → 核心/动量/网格期货同比例减仓 → 卖Put。

每一步只执行到风险度不高于95%且可用现金非负；后续步骤不得继续无必要处置。减少期货不产生即时成交损益，但之后路径只按剩余名义计盈亏。

## 5. 成交延迟

- `delay0`：触发当步成交，是v4乐观基准。
- `delay1`：下一压力步结束后才成交，表示1个交易日无法平仓或卖出期权。
- `delay2`：第二个后续压力步结束后才成交。
- 等待期间所有仓位和保证金继续盯市；若权益先变成非正，直接记录资不抵债。
- 路径结束时尚未成交的风险指令记为`unresolved_end_breach`，不得算作生存通过。

## 6. 成本、流动性和判据

- Put按情景折价卖出；Call按压力模型价平仓，不另加价差。
- 期货平仓不加冲击成本且假定延迟结束后可成交，因此即使delay2仍偏乐观。
- 85%只记录预警；95%或可用现金为负时发出风险指令。
- 每个候选至少报告：最大权益损失、最低现金、触发截面数、平Call/卖Put/减网格/减动量/减核心截面数、资不抵债数、期末未解决风险数，以及V形反弹后的期末权益。
- 首要排序：资不抵债和期末未解决风险最少；其次核心减仓最少；再比较最大权益损失和反弹期末权益。不得按收益优化历史主线。

## 7. 决策边界

- 若整数Put使`external_put_first/delay0/down6_priced_put`较v4分数Put新增核心减仓或资不抵债，v4生存结论降级为不可复用。
- 若任一替代顺序在down6/down8中严格减少核心减仓或资不抵债，同时V形反弹期末权益不明显更差，可列为风控候选；不得自动写入生产。
- 若delay1或delay2产生资不抵债或未解决风险，实盘前必须建立更早的网格准入/现金缓冲，而不能依赖95%事后处置。
- 5Y/10Y由于真实共同期权历史不足明确N/A；历史收益不因压力测试改变。
