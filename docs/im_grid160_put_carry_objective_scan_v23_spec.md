# IM 1.60/2.00 网格下 Put 与贴水收益目标复评 v23 预注册

状态：`preregistered_research_only`。本研究不修改冻结 V2，不构成实盘授权。

## 研究问题

在固定 `1.60进入 / 2.00退出` IM 网格、网格仓不增加 Put、现有 Call 规则不变的前提下，重新评估 MO Put 保护是否过度严格、是否侵蚀“长期滚动 IM 获取贴水”的核心目标。不能只按最终 CAGR 选择 Put；必须分别检验估值第四档和 `MOM120<0` 最低4张的边际保护、成本、反弹拖累与资金占用。

## 候选

所有 Put 只覆盖固定1倍 IM 核心，网格新增1倍不增加 Put 或 Call：

1. `no_put`：0张控制组；
2. `legacy_3tier_mom3`：旧三档估值，57个月相对分位75%/85%/95%与绝对轴取较大值，MOM120<0最低3张，上限3张；
3. `legacy_3tier_mom4`：旧三档估值，MOM120<0最低4张，上限4张，用于隔离动量4张底线；
4. `current_4tier_mom0`；
5. `current_4tier_mom1`；
6. `current_4tier_mom2`；
7. `current_4tier_mom3`；
8. `current_4tier_mom4`：当前V2，57个月相对分位75%/85%/90%/92.5%与绝对轴取较大值，MOM120<0最低4张。

估值和动量目标始终取较大值，不相加；目标仅允许整数0—4张。

## 固定组合组件

- 固定1倍滚IM；网格在估值分数不高于1.60时T+1开盘新增1倍，不低于2.00时T+1开盘退出。
- Call完整保持当前D10/IV26/5%救援规则，只覆盖固定核心。
- Put期限、95%目标行权价、月度换约、T收盘信号与T+1官方收盘执行不变。
- 不测试网格同步Put；v22已经否决最高8张同步保护。

## 数据情景

1. `real_actual_basis`：2022-07-22—2026-08-14，中金所官方IM/MO真实历史。IM收益已含实际基差；用同日中证1000价格指数收益拆出固定核心的实现基差，仅作归因，不重复加入收益。
2. `model_avg_basis`：2015-04-16—2026-08-14，中证1000模型IM与理论MO，加入上市后991日测得的固定日度几何平均基差0.00038985993765572324（年化10.321159572%）。该情景存在明显未来信息回填，只作敏感性。
3. `model_no_basis`：同一2015模型路径但不加基差，用于隔离Put自身表现。

## 成本与资金

- IM与网格成本继承冻结路径；网格单边1bp、持有换月双边2bp。
- Put继承理论/真实MO官方路径成本；未计买卖价差、收盘冲击、容量、涨跌停无法成交、动态保证金上调和税费。
- 绩效按每1倍IM 30%保证金/缓冲，Put市值与Call保证金扣减可计息现金，剩余正现金年化3%。
- 另报告用户提供的15%期货保证金操作口径，但注明未由经纪商独立验证。

## 必须报告

- full、10Y、5Y、3Y、1Y：CAGR、波动率、Sharpe、MaxDD；真实不足5年的覆盖明确标记。
- 相对no Put与当前四档4张的CAGR、MaxDD差。
- 平均/最高Put张数、0—4张天数、Put成本、Put净损益、最高Put市值、30%与15%资本穿透。
- 实现/情景基差贡献；Put净贡献占基差贡献比例。
- 指数下跌日Put贡献、单日反弹超过1%时Put拖累；最坏网格周期局部回撤。
- 当前四档4张在模型与真实路径的逐日Put组件复现误差。

## 预注册选择原则

“贴水目标兼容”的候选必须同时满足：

1. 相对no Put，`real_actual_basis` full或3Y最大回撤至少改善3个百分点；
2. 相对no Put，`model_avg_basis` full或5Y最大回撤至少改善3个百分点；
3. real full与model_avg_basis full CAGR损失均不超过2个百分点；
4. 真实15%操作口径无日终资本穿透，Put执行日无资本穿透；
5. 至少一个相邻MOM下限或三档/四档拆分候选表现方向一致，不接受孤立峰值。

通过门槛的候选按真实full Sharpe、真实3Y Sharpe、较低平均Put张数与较低Put成本综合选择；若较轻候选与当前四档4张的真实CAGR差不超过1个百分点、MaxDD不恶化超过1个百分点且平均Put张数至少降低15%，优先较轻候选。否则保持当前四档4张。任何结论只进入`watchlist`，须用户另行批准才能建立新冻结版本。

若当前四档4张真实/模型逐日复现误差超过1e-12、收益恒等式失败或官方交易腿价格/成交量审计失败，则结论为`rerun_required`。
