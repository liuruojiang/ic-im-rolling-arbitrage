v4 证明：即使总门槛固定，只要 PB、ERP、股息三个基础分量仍由历史加权 CDF 产生，历史定义就会随样本起点和终点漂移。本版彻底删除历史分位，回答：

1. 把旧固定经济切换点连续化后，是否存在不依赖历史样本起点的高估阈值平台；
2. 平台在全样本与更重要的最近10年中是否具有足够覆盖、独立事件和多因子共同证据；
3. 结论是否依赖“切换点是连续分的整数锚点”这一种插值习惯。

不得使用中证500后续收益、IC贴水、PUT损益、最大回撤改善或任何策略绩效来选择门槛。

## 3. 主定义：整数锚点连续分

三个固定经济压力分均截断在 `[0, 2]`：

- `PB压力 = clip((PB - 1.50) / 0.50, 0, 2)`，因此 PB 2.00 对应1分，2.50对应2分；
- `ERP压力 = clip((4.50% - ERP) / 1.50%, 0, 2)`，因此 ERP 3.00% 对应1分，1.50%对应2分；
- `股息压力 = clip((3.00% - 过去一年股息贡献) / 1.00%, 0, 2)`，因此股息2.00%对应1分，1.00%对应2分。

固定经济总分：

`fixed_equal3_knot = (PB压力 + ERP压力 + 股息压力) / 3`

公式只依赖当日三项经济变量，不依赖样本长度、权重、分位或重新拟合。PB 越高、ERP 越低、股息越低，总分不得下降。

## 4. 插值口径敏感性

旧离散阶梯也可解释为“旧切换点是相邻档位的边界中点”。本版预注册第二套仅用于敏感性诊断的固定公式：

- `PB压力_mid = clip(0.50 + (PB - 2.00) / 0.50, 0, 2)`；
- `ERP压力_mid = clip(0.50 + (3.00% - ERP) / 1.50%, 0, 2)`；
- `股息压力_mid = clip(0.50 + (2.00% - 股息) / 1.00%, 0, 2)`；
- `fixed_equal3_mid = 三项均值`。

在未触及截断区时，第二套总分等于主定义总分减0.50。因此主阈值 `T` 固定与敏感性阈值 `T-0.50` 配对；不得事后寻找能使状态最相似的敏感性阈值。

## 5. 主门槛网格与窗口

- 主定义总分门槛：1.40—2.00，步长0.05，共13档；
- 配对敏感性门槛：0.90—1.50，步长0.05，共13档；
- 正式候选仅为13条主门槛；
- 窗口：全样本、最近10年、5年、3年、1年；
- 扫描长表：65行。

扫描框架中的年化收益、波动、Sharpe和最大回撤只允许填入同窗口中证500价格指数背景，并标记 `underlying_price_index_context_only_no_strategy_return`。同一窗口所有候选必须完全相同且不得参与门槛排序。

## 6. 结构门槛与平台选择

每条主候选须同时满足：

1. 全样本月度独立启动段不少于5段，最近10年不少于2段；
2. 最近10年月度启动率在5%—30%之间；
3. 全样本启动月中至少90%具有“不少于两个主定义分量大于或等于1.00”，避免一个极端变量独自触发高估；
4. 主门槛局部带 `[T-0.05, T+0.05]` 至少有8个月末观测；
5. 主定义 `T` 与边界中点定义 `T-0.50` 的全样本月度状态 Jaccard 不低于0.85；
6. 两种定义在最近10年的月度状态 Jaccard 不低于0.85，且最近10年月度启动率绝对差不超过5个百分点；
7. 两种定义在2026-08-17的当前启动状态相同。

满足全部条件的相邻门槛须形成至少3个连续点，才称为结构平台。若有多个平台，选择点数最多的平台；点数相同选择门槛更高的平台。平台设计中心为上下界的网格中位点；偶数个中心点时取较低者，体现更早识别高估的保守取向。整个平台均保留，中心不是实盘阈值。

若没有平台通过，本版结论必须为“不选择固定高估门槛”。不得放宽条件或缩小步长后把新结果并入本版。

## 7. 历史时点不变性与经济边界

时点固定为2016—2025每年12月末及2026-08-17，共11个。对每个时点：

- 仅截取不晚于该时点的历史行；
- 用固定公式重算主定义与敏感性定义；
- 与最终文件在相同历史片段逐行比较，最大绝对误差必须不超过`1e-12`，每条门槛的状态必须完全一致；
- 不连接或引用时点之后的收益。

每条主门槛输出：

- 局部带与启动状态内 PB、ERP、股息的25%/50%/75%分位；
- 月度向上穿越次数和穿越月经济变量中位数；
- 全样本和各标准窗口的日/月覆盖率、启动段数及最长连续月份；
- 三个分量截断在0或2的比例，识别连续分是否实际上退化为离散平台。

总分门槛是一张三维边界面，局部中位数不得表述为三个同时必须满足的硬门槛。

## 8. 旧离散分诊断

复算旧 `25% PB档 + 50% ERP档 + 25%股息档` 的离散总分，并对旧 `>=1.50/1.75/2.00` 输出全样本、最近10年的日/月覆盖率。该表只用于解释旧固定1.75与本版连续等权分的差异，不参与平台选择，也不得称为经济等价或收益等价。
