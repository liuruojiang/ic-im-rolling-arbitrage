# IM 102% Put 下 MOM120 保护数量扫描 v1

## 问题

在已发布的 IM v1.3-r7 `MOM120 + 双Put102%` 全组合上，检验原先负动量下限3张是否仍合适。102%目标行权价、选约、期货、网格、Call、估值档、成本、资金和执行时点固定，仅把 MOM120<0 时的父Put下限扫描为1、2、3张。

## 数量口径

- 核心Put：`max(估值档, floor)`；动量Put：`floor × 已执行动量多头权重`。
- 两条Put均用102%目标、约3个月实际挂牌MO、月度重选；原组合的连续归一化数量与双腿缩放保持，绝不伪装为整数账户成交。
- 候选`floor3`是已发布102%组合基线，必须逐日与已验收工件复现；`floor1`、`floor2`只替换负动量下限。

## 数据与决定

- 模型层和真实MO层均运行；用户结论以真实MO层为主，真实样本2022-07-22起，5年/10年N/A。
- 报告全样本、10年、5年、3年、1年收益、波动、Sharpe、最大回撤，以及Put资金占用、净成本和交易数。
- 仅当候选相对floor3在真实层没有恶化全样本/近3年/近1年最大回撤超过0.50个百分点，且相邻数量档表现不矛盾，才可保留研究候选；不自动修改已发布信号。
