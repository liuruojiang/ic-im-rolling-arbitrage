## 结论

1. v3的退出1.250不是最佳中心。向下扩展后，风险优先机械最高点为`开仓0.375/退出1.000`：正式全样本25.97% CAGR / -27.38% MaxDD，Calmar 0.949；相对旧`1.000/2.000`少3.33个百分点CAGR，但最大回撤改善29.34个百分点。
2. 共有7组通过预注册风险门槛，形成`开仓0.375—0.500、退出1.000—1.250`为主、并延伸到`0.375/0.875`的连续区域。`0.500/1.000`为附近确认线，25.95%/-31.19%，正式/2007周期4/5。
3. 机械最高点没有通过严格四向宽度：四个邻点的Calmar保留率均超过80%，其中三个同时通过风险门槛；唯一失败的是`0.250/1.000`，其Calmar反而更高为1.032，但2007诊断只有2个完成周期，低于预注册3个周期，而不是绩效坍塌。
4. 因而正式标签为`watchlist_risk_first_candidate_edge_or_peak/peak_only`，但经济解释应为“绩效平台较宽、低开仓阈值的独立周期证据不足”，不能误读为中心点两侧收益或回撤突然恶化。
5. 完成周期仍集中：`0.375/1.000`的正式三段均在2022—2024；2007诊断额外增加2008年一段，共4段。事件数有限，不能直接晋升实盘。

## 交易解释

`0.375/1.000`的正式三段为：

- 2022-04-22买入，2022-07-05退出；
- 2024-01-23买入，2024-04-29退出；
- 2024-08-29买入，2024-10-08退出。

较低退出阈值让新增仓只参与低估后的第一段修复，不再像旧2.000规则那样长期维持2倍IC；这既保留部分低估反弹和滚IC收益，也显著缩短双倍暴露时间。
