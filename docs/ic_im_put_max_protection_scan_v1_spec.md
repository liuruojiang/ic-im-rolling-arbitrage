# IC / IM Put 最高保护档扩展扫描 v1（预注册）

- 版本：`ic_im_put_max_protection_scan_v1`
- 日期：2026-08-20（Asia/Shanghai）
- 性质：研究参数扫描；不修改`ic_im_system_mainlines_v1`冻结主线。

## 1. 研究问题

用户要求测试：

1. IC每1倍固定底仓的最高目标绝对Delta由`0.75`扩展到`1.00`；
2. IM每1倍固定底仓的MO Put最高数量由`3张`扩展到`4张`。

由于“扩展最高档”可能表示直接提高现有最高档，也可能表示新增第四档，本扫描在结果产生前同时预注册两类解释。不得根据结果事后改变候选定义。

## 2. 固定不变的主线组件

- IC：固定1倍滚IC、`0.375/1.000`网格、网格仓不加Put、明确不含Call。
- IM：固定1倍滚IM、`0.85/1.25`网格、每日D10/IV26/5% `rescue_next_listed` Call；网格仓不增加Put或Call覆盖。
- Put期限、95%目标行权价、实际挂牌月选择、月度重置和T+1收盘执行保持不变。
- 绩效每1倍期货使用30%保证金/缓冲，剩余现金年化3%。
- 复用既有真实合约选择、成交可用性和成本逻辑；不引入理论成交价。

## 3. IC候选

共同基础为当前`l190_mom25`：估值分`1.90/2.00/2.10`对应`0.25/0.50/0.75`目标Delta，`MOM120<=0`最低`0.25`。

| 候选 | 定义 |
| --- | --- |
| `IC_baseline_075` | 当前冻结基准，不变 |
| `IC_top_trigger_100` | 原本目标`0.75`的日期直接改为`1.00`，即2.10最高档直接升档 |
| `IC_add_100_at_215` | 保留0.75档；估值分达到2.15时新增1.00档 |
| `IC_add_100_at_220` | 保留0.75档；估值分达到2.20时新增1.00档 |
| `IC_add_100_at_230` | 保留0.75档；估值分达到2.30时新增1.00档 |

IC实际Put张数继续按执行时510500 Put绝对Delta动态计算，不设固定张数上限；只改变目标Delta上限。

## 4. IM候选

共同基础为当前`valmom_center_floor3`：估值绝对轴和57个月相对轴给出0/1/2/3张，`MOM120<=0`最低3张。

| 候选 | 定义 |

| `IM_baseline_3` | 当前冻结基准，不变 |
| `IM_top_trigger_4` | 当前目标3张的日期直接改为4张 |

| `IM_add_4_abs265_rel99` | 保留原规则；分数达到2.65或滚动百分位达到99%时新增4张档 |
| `IM_add_4_abs270_rel99` | 保留原规则；分数达到2.70或滚动百分位达到99%时新增4张档 |

## 5. 数据与区间

- IC真实样本：2022-09-19至2026-08-14。
- IM真实样本：2022-07-22至2026-08-14。
- 不用2015年至期权上市前的理论期权路径作本次结论。
- 指标窗口：`full/last_10y/last_5y/last_3y/last_1y`；窗口早于真实样本起点时截到真实样本起点并记录实际日期。
- 基准必须在同一次运行中重算，并与冻结主线逐日收益核对，最大绝对误差不得超过`1e-12`。

## 6. 指标与判定

必须报告：年化收益、年化波动、Sharpe、最大回撤、Put成本、最大Put市值占用、最小现金权重、最高实际Put张数/有效Delta、最高档触发天数。

候选进入晋级观察的最低条件：

1. 全样本最大回撤改善至少1个百分点；
2. 全样本年化收益相对基准下降不超过2个百分点；
3. 全样本Sharpe不低于基准；
4. 近3年和近1年不能同时在年化收益与最大回撤上劣于基准；
5. 不出现现金权重低于0或单日收益不有限。

不满足则保留原上限；只在单一阈值表现突出而邻近阈值退化时标记`peak_only`，不得直接晋级。

## 7. 执行与摩擦边界

- IC/510500 Put：沿用正式真实路径的合约历史、收盘执行和单边成本。
- IM/MO Put：沿用中金所官方开收盘/结算/成交量/持仓量及既有单边成本。
- 继承冻结网格、期货和IM Call成本。
- 排除：买卖价差、收盘冲击、涨跌停未成交、盘口容量、动态保证金上调和税费；结果必须保留这些限制。
