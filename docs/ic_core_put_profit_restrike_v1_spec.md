# IC 核心 Put 盈利兑现与重新建仓 V1 预注册

## 研究问题

在 IC v1.3 当前核心保护 Put 规则不变的前提下，比较：

- baseline：不因盈利提前换仓；
- profit2x：期权收盘价达到本次建仓权利金的 2 倍后，最早下一交易日收盘全部兑现并按当时规则重建；
- profit3x：同上，阈值为 3 倍。

分别测试纯滚动 IC + 当前核心 Put，以及加入当前 M+1 卖 95% Put 路由后的完整混合组合。

## 固定口径

- 核心保护腿沿用 IC 当前规则：约 3 个月、目标行权价/ETF 约 95%，按目标 Delta 配量；不使用 IM 的 102%。
- 买 Put 准入沿用现行估值分层、120 日绝对动量与既有防抖；不修改目标 Delta。
- 卖 Put 固定为 M+1 510500 95% Put、绝对 IV > 37.5%、权利金衰减 60% 最多提前滚一次、每次新腿重新检查估值 0/1 档与原 IC 1.3 执行动量许可。
- IC 不含 Call，不恢复已取消的卖 Put MOM120。
- 实物交割后的 ETF 转 IC 与 IC 回本退出保持原规则。
- 510500 Put 单边摩擦 5BP，往返 10BP；ETF 与 IC 单边 1BP；30% 风险缓冲，闲置现金年化 3%。

## 因果执行与优先级

1. T 日收盘用实际收盘价（理论层用当日模型收盘价）判断是否达到 2x/3x。
2. 最早 T+1 收盘卖出旧 Put，并在同一收盘按当时目标 Delta 买入新的约 3M/95% Put；新权利金成为下一次触发基准。
3. 卖 Put 路由切换优先：若 T+1 开盘需同时平 IC、平核心 Put、卖出短 Put，则执行开盘退出，不再执行收盘盈利换仓。
4. 月度维护、目标归零退出、目标 Delta 调整优先于盈利换仓；冲突日不重复交易。目标调整后若旧盈利条件仍成立，可在后续交易日执行。
5. 真实层没有可成交收盘价时延后，不用未来价格补成交。

## 数据分层

- 真实挂牌层：2022-09-19 至 2026-08-14，真实 510500 Put/ETF 与 IC 样本。
- 理论延展层：2015-04-16 至 2026-08-14，理论 510500 Put 与历史 IC。
- 理论早期估值必须使用已恢复的显式历史状态；禁止把缺失估值默认为 0/1 档。

## 预注册判定

候选只有在以下条件全部满足时才保留为后续研究候选：

- 纯滚动保护组合与卖 Put 混合组合中，真实层和理论层的全样本 CAGR、Sharpe 均不低于各自 baseline；
- 最大回撤绝对值相对 baseline 恶化不超过 0.5 个百分点；
- 2x 与 3x 至少方向一致，不依赖单一阈值翻转；
- 真实层至少出现 2 次可成交盈利重建，否则标记为样本稀疏，不能晋级。

本研究只产生研究结论，不修改生产、登记表或交易建议。
