# IC/IM fix8：卖 Put 固定额度下的核心/动量配比复测

2026-09-26。研究反事实，不更改正式策略、日报或历史账本。现行 v1.4-r1 fix8、核心/动量 50/50 是各品种基准；卖 Put **始终开启**最新持续展期规则，不设“不卖 Put”候选。IC 与 IM 单独回测、单独评价，不拼接历史。

## 结论

固定卖 Put 的每单位目标额度后，IC 增加核心仍提高历史全期净年化，但每档都加深最大回撤；100/0 对比 50/50 年化增加 **2.23 个百分点**，最大回撤加深 **7.63 个百分点**。IM 则从 60/40 开始全期净年化和最大回撤都劣于 50/50；100/0 年化下降 **3.61 个百分点**，最大回撤加深 **7.23 个百分点**。因此本次不建议改动 IC 或 IM 的正式 50/50。若用户愿意明确接受 IC 更深回撤，60/40 等可作为风险偏好候选，但不能把较高年化解释成更安全。

## 相比前一轮，口径究竟改了什么

前一轮提高核心时，`SELLER_SCALE=core_weight/0.5`、卖方资金缓冲也随核心扩大。那测试的是“整个核心包一起扩大”，不能单独解释用固定核心替换动量的效果。本轮卖 Put **仍按正式规则持续展期**，但所有配比保持 `SELLER_SCALE=1.0` 与卖方缓冲率 15%；核心期货及对应核心买 Put 随核心调整，动量期货及动量买 Put 随动量调整，网格保持不变。卖 Put 的每次新开/展期目标张数按信号日已知账户权益归一后，与 50/50 一致；因各路径权益不同，绝对张数并非机械相同。

原卖方随核心放大的 100/0 年化为 IC 36.46%、IM 28.01%；本轮固定卖方后分别为 34.52%、25.73%。因此旧扫描中较高的 100/0 收益有一部分来自**扩大卖 Put**，不能归因于削减动量。两轮成本、历史窗口与执行时钟相同，但只有本轮适合回答“卖 Put 保持既有规模、改变核心/动量配比”的问题。

## 数据、执行与对抗核查

- 历史样本使用现有真实挂牌期货/期权日期链；50/50 与既有 fix8 历史纸面账本逐日净值及逐事件一致，最大数值误差约 7.45e-9 元。非现行配比只作为研究反事实，未晋级生产。
- 买 Put 普通调整及 3 倍兑现为 T 收盘信号、T+1 开盘纸面执行；月度维护与指定季度换月仍按正式收盘时钟。期货单边 1bp、期权单边 5bp、闲置现金年化 3%。每 1 倍期货预留 30% 是研究绩效口径的风险缓冲，**不是经纪商实际保证金率**。不以成交量作为阻断条件；没有另加真实订单簿冲击压力情景。
- 两品种 12 条路径均通过独立审计：从日净值重算年化和最大回撤，检查现金/期权/ETF 权益恒等式、费用、T+1 下一交易日、45 个 IC 与 48 个 IM 维护日、卖方交易日期/合约及全部新开/展期的信号日归一化目标额度。IC 检查 98 个原始买方期权报价键，未使用开盘代理；IM 检查 160 个，动量开启的每条路径有 4 个明确标记的缺失开盘报价代理边，100/0 有 2 个。错误净值、错误执行日与禁用动量袖假成交注入均被识别。
- 5 年/10 年真实样本不足，结果表明确记 N/A。研究账户使用连续标准化张数，不等于用户账户的整数成交净值。IC、IM 样本起止不同，不能直接以两者年化大小排名。
- **未测试未来动量参数失效**：本轮只用已实现的正式动量信号改变配比。它说明降低动量权重的历史收益/回撤代价，不证明未来参数失效时哪档最优。
