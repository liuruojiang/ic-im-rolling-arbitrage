# IM买Put与卖Put统一估值防抖 v2：运行后审计

## 纠正结论

用户指出v1遗漏买Put是正确的。统一防抖后，核心买Put真实交易确实明显减少，但在当前单边1bp成本假设下，节约不足以覆盖延迟减仓造成的持仓路径损失，因此暂不按当前成本口径晋级。若实际核心Put综合单边摩擦接近30bp标的名义，3日防抖才出现跨真实/理论层反超，必须用真实成交单独验证。

## 当前1bp结果

| 规则 | 真实 CAGR / Sharpe / MaxDD | 理论 CAGR / Sharpe / MaxDD |
|---|---|---|
| 即时估值档 | 20.44% / 1.226 / -16.20% | 16.83% / 1.123 / -16.71% |
| 2日确认降档 | 18.97% / 1.147 / -16.20% | 17.28% / 1.153 / -16.71% |
| 3日确认降档 | 19.65% / 1.172 / -16.20% | 16.42% / 1.105 / -16.71% |

风险升档均立即生效；只有估值风险下降、买Put需要减少以及卖Put许可需要恢复时等待确认。

## 真实订单与成本

3日规则相对即时规则：

- 估值档切换减少56.4%；

- 实际核心Put交易事件减少24.7%；

这证明防抖确实节省了买Put交易，但真实CAGR同时下降0.79个百分点、Sharpe下降0.054，未通过预注册绩效门槛。变化主要来自更长时间持有较高Put档位，而不是交易费本身。

## 核心Put成本压力测试

其他成本保持1bp，只把核心Put单边成本从1bp提高：

| 核心Put单边成本 | 真实即时 CAGR | 真实3日 CAGR | 理论即时 CAGR | 理论3日 CAGR |
|---:|---:|---:|---:|---:|
| 1bp | 20.44% | 19.65% | 16.83% | 16.42% |
| 10bp | 17.01% | 16.53% | 13.36% | 13.12% |
| 20bp | 13.31% | 13.16% | 9.62% | 9.55% |
| 25bp | 11.49% | 11.51% | 7.80% | 7.80% |
| 30bp | 9.71% | 9.88% | 6.00% | 6.08% |

约25bp时CAGR接近盈亏平衡；约30bp时3日规则的CAGR和Sharpe才在真实、理论两层同时超过即时规则。该阈值是标的名义单边综合摩擦，不是期权费率或权利金百分比，不能在没有真实成交、买卖价差和冲击数据时假定成立。

## 决策

- 当前1bp研究口径：`do_not_promote_unified_debounce_performance_gate_failed`。
- 成本敏感性：`confirm3_watchlist_if_verified_effective_core_put_cost_ge_30bp`。
- v1卖Put准入局部测试不再作为晋级依据。
- 不修改1.3、生产信号或账本。

## 完整性

- 即时基线与上一轮逐日收益最大误差：真实、理论均`9.974659986866641e-17`。
- 所有核心Put、卖Put和Call路径重新执行，未用旧结果直接相加。
- 理论层仍是Black-Scholes代理；高成本压力只改变成本扣减，不改变交易路径。
