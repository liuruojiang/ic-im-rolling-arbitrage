# IM v1.3 动量腿高IV转卖Put完整组合测试 v1

日期：2026-09-17  
状态：研究预注册；不修改生产、日报、账本或交易状态。

## 研究问题

在已经保留的IM固定核心腿卖Put研究候选基础上，检验现行动量期货腿在相同高IV条件下同步转为卖Put，能否进一步改善完整IM v1.3组合。

## 固定组合

- 固定核心0.5倍IM、现行动量0至0.5倍IM、1.6/2.0的0.5倍估值网格。
- 期货季度T-1收盘展期；核心Put与动量Put沿用102%和当前MOM120/估值规则。
- 核心Put三倍盈利兑现；IC/IM生产规则不变。
- 卖Put口径固定为M+1、95% MO Put、IV严格高于35%、估值0/1档且MOM120非负、权利金衰减60%后最多提前展期一次并重新准入。
- 数量沿用已保留的`q3_delta05`：每1倍IM卖3张MO Put；连续数量研究口径。
- 所有MO Put单边5BP；期货及Call沿用当前成本；现金年化3%。

## 动量腿转换语义

- 仅当动量执行权重大于0且卖Put准入同时成立时，才允许动量腿进入卖Put。
- 入场规模=`0.5 × 当日动量执行权重`；该规模在整轮卖Put、指派恢复IM及等待恢复期间固定，不随之后动量信号每日调整。
- 入场日同步退出对应动量IM；对应动量Put目标置零。卖Put轮结束并恢复IM后，下一交易日重新接回当时的现行动量权重。
- 任一卖Put腿处于卖Put、现金等待或指派恢复状态时，固定核心Call暂停；两条卖Put腿都恢复正常IM后Call才恢复。
- 固定核心腿与动量腿分别维护状态机和数量；同日同合约允许数量相加，不互相覆盖。

## 四组对照

1. `profit3x_no_short`：核心Put三倍兑现，不卖Put。
2. `fixed_only_q3`：只转换固定核心腿，必须逐日复现既有q3候选。
3. `momentum_only_q3`：只转换动量腿。
4. `both_q3`：固定核心腿和动量腿分别按上述规则转换。

## 判定

`both_q3`相对`fixed_only_q3`须在真实挂牌层和理论延展层同时满足：CAGR不低于对照、Sharpe不低于对照0.05以上、最大回撤绝对值恶化不超过1个百分点；现金权重不得为负，路由日不得重复买卖对应Put。真实事件稀少时仅保留研究候选，不构成生产晋级。

## 已知限制

理论MO为代理；真实历史较短。未纳入动态保证金、强平、税费、盘口容量、整数账户张数及显式成交延迟。
