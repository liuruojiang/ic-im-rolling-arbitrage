## 2. 固定月末历史

每个评估日T：

1. 从完整月度状态中只取`date <= T`的记录，按日期排序；
2. 分别取最近`84 / 90 / 96`个已完成月末；不得包含T以后月末，不得把当月日值追加为月末；
3. 可用历史必须不少于目标数量，使用行数必须严格等于84、90或96；
4. 当前T日日度PB、ERP、股息贡献和审计PE只作为待映射值，不进入历史分布样本；
5. 历史长度以观测数量固定，因此月内每个交易日不会因自然月边界少一条，也不依赖回测起始参数。最早数据仍来自2007-01-31，不补写2007年前估值。

主经济风险仍为：

`economic_risk = 25% × PB风险 + 50% × ERP风险 + 25% × 股息贡献风险`

PE只进入等权四因子结构对照，避免与ERP重复计权。

## 3. v4冻结网格

主经济分数：

- 历史月末数：`84 / 90 / 96`；
- 连续映射：`L/H = 0.40/0.80、0.50/0.90、0.60/0.90`；
- 9个候选：`econ_m84_l40_h80`等。

结构对照：`equal4_m90_l50_h90`。

基准：`no_put`、`always_50`、`always_100`。模型/实际两层共26个候选。

同一映射的窗口邻居固定为84—90、90—96；跨84—96只作跨度诊断。映射邻居仍为0.40/0.80—0.50/0.90和0.50/0.90—0.60/0.90。

连续映射、十进制四舍五入、执行、成本及资金公式完全继承v3，不得修改。

## 4. 判断标准的字段修订

v3第7节全部保留，其中“8/10/12年”在v4一律解释为“84/90/96个最近已完成月末”。通过候选必须有相邻6个月历史长度的候选共同通过，且相邻候选保护日Jaccard至少60%、保护并集上的目标平均绝对差不超过20个百分点。

若多个候选通过，仍选择平均保护比例最低者；相差不超过1个百分点时，优先90个月和中间映射0.50/0.90。通过也最多为`watchlist`；网格有效但无人通过为`keep_default/reject`；完整性失败为`rerun_required`。
