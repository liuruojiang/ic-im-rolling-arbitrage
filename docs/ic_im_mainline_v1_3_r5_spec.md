1. OHLCV必须日期唯一递增；截至2026-08-14的权威历史日期索引用SHA-256绑定，此后逐交易日连续。IC必须含正式起点和暖机历史；成交量过小或成交额冒充均拒绝。盘中供应商若已返回当天未完成K线，成交量状态冻结到前一确认日并标为占位。
2. IC与A股权威从2007-01-15起逐日核对执行权重、基础NAV和回撤；任一非有限值或误差超过1e-12失败关闭。

4. 账本写入跨进程排他；校验产品、收盘阶段、状态锚点、T+1日期、离散仓位、期权数量、IC无Call、序号/文件名/逐交易日哈希链。陈旧完整信号不得虚报推进；健康检查必须识别滞后或超前。
