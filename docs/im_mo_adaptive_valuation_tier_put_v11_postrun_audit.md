## 结论

- v7冻结的`57个月 + 75%/85%/95%`估值档位直接映射0/1/2/3张三个月95%月换MO Put，只改善了最近1年，不能改变真实全样本和最近3年的最大回撤。
- 模型全样本MaxDD从-70.07%加深到-70.42%，恶化0.35个百分点；真实全样本和最近3年的MaxDD与no-Put相同，只有最近1年从-20.91%改善到-15.58%。
- 结论为`valuation_only_not_sufficient/recent_only`。估值本体仍可用于识别高估状态，但不能单独承担IM熊市保护；下一层若继续，应只增加MOM120绝对动量，不重扫估值参数。

## v10勘误与v11边界

v10真实层全样本和最近3年的MaxDD差分别只有约`8.77e-13`和`2.22e-13`个百分点，属于浮点噪声。v10用严格`>0`误判为改善，已记录为实现审计失败，正式目录不覆盖。

v11不改变逐日路径、交易、成本和候选，只规定MaxDD至少改善`0.01`个百分点才有经济意义，并从v10已验证产物归一化重算决定。v11是本层权威判定。
