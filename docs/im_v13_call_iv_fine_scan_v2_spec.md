# IM 1.3-r6 卖 Call IV24%-30% 逐1%细扫 v2（预注册）

## 1. 研究问题

在 v1 粗扫发现 IV30 为样本内峰值、但2个百分点邻点未形成稳健平台后，仅对正常 Call 入场门槛 `24% / 25% / 26% / 27% / 28% / 29% / 30%` 做逐1个百分点细扫，判断 IV26 是否仍应保留，以及 IV29-30 是否形成更窄但连续的平台。

## 2. 冻结边界

- 当前策略固定为 IM 1.3-r6；IC 不含 Call，本版不研究或添加 IC Call。
- IM 核心、动量、网格、核心Put、动量Put、期货和Put成本、现金收益、30%期货保证金/缓冲均不变。
- Call 只覆盖0.5倍核心仓；完整1倍核心对应2张MO Call，组合中的Call损益、成本和保证金乘0.5。
- Call 合约继续使用 D10；空仓每日T收盘检查，拟卖合约自身IV达到门槛后下一交易日官方收盘执行。
- 已有Call的5%受威胁救援、行权价上移至少5%、最多5次及救援IV豁免全部不变。救援期限是相对旧到期日严格更晚的最近实际挂牌到期日 `rescue_next_listed`，不是固定加一个日历月。
- 不加入PE20/60、止盈、快速下跌向内移仓、动态账户风险或其他外部模块。
- 本版为研究审计，不修改1.3-r6生产代码、账本、信号、日报或远端任务。

## 3. 数据与执行

- 冻结真实数据：官方CFFEX IM/MO，2022-07-22至2026-08-14，共986个交易日。
- T日收盘信号，下一可交易日官方收盘成交；日终按官方结算价盯市。
- 活动Call缺少有效结算价时保持现行 fail-closed，不得补理论价格、0收益或事后增加强平规则；该门槛记为不可执行/N/A。
- 真实MO历史不足5年，因此5Y和10Y必须记为N/A，不得用模型或代理数据补齐。

## 4. 参数网格与选择规则

网格固定为：`24%, 25%, 26%, 27%, 28%, 29%, 30%`。IV26为现行基线。

选择规则：

1. 排除执行失败的门槛；
2. 排除 Full CAGR 低于IV26超过0.50个百分点，或 Full MaxDD深于IV26超过0.50个百分点的门槛；
3. 剩余门槛按 Full Sharpe、Full MaxDD、Full CAGR依次排序；
4. 若样本内峰值不是IV26，至少一个相邻1个百分点门槛必须保留峰值相对IV26的80% Full Sharpe改善，并且峰值及该邻点的3Y Sharpe均不低于IV26，才标记为连续平台；
5. 连续平台成立时，选择平台中更接近IV26的较低门槛作为研究候选，以减少参数跳变；否则结论为保留IV26；
6. 近1年仅作压力诊断，不独立决定门槛。

不得在看到结果后改变网格、容忍线、排序或平台定义。

## 5. 必须输出与审计

- 每个门槛的Full/10Y/5Y/3Y/1Y CAGR、波动、Sharpe、MaxDD、最差20/60/120日收益、最低现金、Call持仓日、交易次数、救援次数、Call损益/成本/保证金。
- 现行IV26 Call组件与1.3-r6正式组件逐日最大误差不超过1e-12。
- 现行IV26完整组合与1.3-r6正式日收益、现金权重逐日最大误差不超过1e-12。
- T/T+1因果错误为0；正式成交价与官方收盘误差不超过1e-12；负现金日为0。
- 输出目录：`outputs/im_v13_call_iv_fine_scan_v2/`。
- 参数扫描目录：`quant_param_scan_runs/20260903_im_v13_call_iv_fine_scan_v2/`，完成后必须通过 strict 检查。

本规格冻结后不得改写。
