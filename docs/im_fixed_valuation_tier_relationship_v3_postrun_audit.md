# 中证1000固定经济估值分档与双定义关系 v3 运行后审计

日期：2026-08-18（Asia/Shanghai）  
状态：估值本体第三层完成；冻结二取三分档为下一层候选；未批准实盘。

## 1. Scope

- 目标：把v2共同平台2.45—2.60转成0/1/2/3严重度档位，并在不看收益的前提下明确均值与二取三的执行关系。
- 市场：中证1000价格指数及同源估值；不含IM贴水、MO、Put、网格或Call。
- 结果性质：冻结真实数据正式运行结果；估值平台仍继承v2的二次确认和窄平台限制。

## 2. 结论

1. **二取三主状态通过全部预注册门槛，冻结为下一层MO Put回测的估值输入候选。**固定阶梯为`2.45 / 2.50 / 2.60 -> 1 / 2 / 3档`，0档为低于2.45；决定为`freeze_median_tier_ladder_candidate_for_next_put_layer / narrow_stable`。
2. 均值不需要成为额外硬门槛。均值与二取三日度精确档位一致率为全样本91.69%、最近10年90.98%，月末为93.89%/93.39%；月末相差至少2档比例为3.05%/3.31%，全部通过85%/80%/5%的预注册标准。
3. 严格共同确认`consensus_min`没有提供结构优势：最近10年累计1档覆盖只从二取三25.62%降到24.79%，但日度年化切换反而从9.14次升至9.97次。增加一个绑定条件只减少约0.83个百分点覆盖，却提高状态切换复杂度，因此不采用。
4. 当前2026-08-17均值2.089、二取三2.082，四种关系全部为0档。该结果表示“未进入固定高估平台”，不是低估判断，更不是Put交易指令。

三个累计档位都满足全样本至少3段、最近10年至少2段及前后半段各至少一次启动。>=1与>=2的覆盖只差0.83个百分点，也解释了精确1档历史上只有很少时间。

最近5年二取三日度非零覆盖为7.27%，最近3年和1年均为0。估值分档在2023-08以后没有启动；因此它本身不能承担“熊市发生后持续保护”的职责。下一层MO Put若要覆盖低估起点后的趋势熊市，必须把估值分支与独立趋势分支分开测试，不能事后把趋势效果归因给估值。

## 11. Risks and Next Layer

- 估值平台仍是v1失败触发的v2二次确认，且只有2.45—2.60四点；本版不能把`narrow_stable`升级成独立OOS证据。
- 中间档历史占比很小；保护强度是否真能平滑损益必须由MO真实/模型双层回测检验，不能从状态表推断。
- 最近3年估值档位恒为0，单独使用估值保护很可能无法覆盖2022—2024式慢熊；趋势分支应作为独立候选，不得与估值混成一个无法归因的规则。
- 下一层建议以`median_primary: 2.45/2.50/2.60 -> 25%/50%/75%`作为冻结估值输入，先在同一IM/MO收盘执行、3个月95%月换、30%保证金/70%现金3%框架下比较：no-Put、估值分档单独、MOM120单独、两者取较大值。原有旧固定1.75只作历史参照，不能作为新估值基线。
