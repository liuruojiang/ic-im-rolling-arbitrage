# IC买Put与卖Put估值防抖扫描 v1（预注册）

## Research Question

在M+1卖95% Put、绝对`IV>37.5%`、权利金衰减60%的IC混合路由中，分别检验：

1. 只对卖Put的估值0/1档恢复许可增加连续日确认；
2. 将同一估值防抖状态同时用于核心买Put目标与卖Put准入。

目标是减少估值边界反复和实际Put交易，同时确认在修正后的单边5BP成本下，节约是否足以覆盖防抖造成的持仓延迟。

## Frozen Rules

- 卖Put期限M+1、目标95%、绝对IV严格大于37.5%、衰减60%后最多提前滚动一次。
- 卖Put仍须通过原IC 1.3执行动量许可；不重新引入已取消的IC MOM120。
- 核心买Put继续使用现行估值目标与已发布的MOM120负值即时保护、连续两日严格大于1%解除规则；本层只改变估值档的降档时点。
- 卖Put、IC与核心Put同步切换；实物交割ETF→IC、IC月度展期及整轮扣费回本退出不变。
- 不加入灾难保护，不采用未晋级的相对IV；IC不含Call。
- 不修改生产、日报、账本或冻结主线。

## Pre-run Timing Correction

首次基线校验在生成结果前发现：当前卖Put准入直接读取其既有执行日估值状态，而核心买Put使用前一收盘评估、下一交易日执行的档位；真实层有3个日期不一致。为避免把日期对齐本身误算成防抖效果，新增`unified_instant`隔离对照。当前`instant`仍严格复现现有路径；统一防抖同时与当前基线及`unified_instant`比较。

## Candidate Grid

1. `instant`：估值档即时生效；当前对照。
2. `sell_confirm2`：仅卖Put准入防抖；估值2档以上立即禁止，恢复至0/1档连续2个交易日后允许。
3. `sell_confirm3`：仅卖Put准入防抖；恢复至0/1档连续3个交易日后允许。
4. `unified_instant`：买卖Put共用核心买Put的T收盘→T+1执行估值档，但不增加防抖，用于隔离统一日期状态本身的影响。
5. `unified_confirm2`：在`unified_instant`状态上，风险升档立即生效，风险降档须在较低的同一档连续2个交易日后生效。
6. `unified_confirm3`：同上，连续3个交易日确认。

所有状态只使用当日及此前数据。T日收盘得到状态，最早T+1开盘执行；不使用未来状态回填。

## Data and Cost

- 真实层：2022-09-19至2026-08-14真实510500 Put、ETF与IC。
- 理论层：2015-04-16至2026-08-14理论510500 Put延展与历史IC，不解释为可成交期权历史。
- 每一笔510500 Put买卖按标的名义单边5BP；ETF与IC单边1BP；每1倍期货30%保证金/缓冲，现金年化3%。
- 核心买Put和卖Put交易路径、交易事件与成本必须重新执行，禁止从旧结果直接相加。

## Required Diagnostics

- 原始与防抖估值档、估值许可切换、核心Put目标Delta切换。
- 核心Put实际交易事件及累计成本率；卖Put周期、提前滚动、实物交割与建仓/换月期权交易边数。
- full、10Y、5Y、3Y、1Y绩效；真实历史不足窗口明确N/A。
- `instant`必须与上一层绝对IV37.5%输出逐日误差不超过`1e-12`。
- 理论早期估值不得缺失或默认成0档。

## Pre-registered Decision Rule

### 仅卖Put准入防抖

候选只有同时满足以下条件才可保留：

1. 两层估值许可切换均减少至少15%；
2. 两层Full CAGR下降不超过0.50个百分点、Sharpe下降不超过0.02、MaxDD恶化不超过0.50个百分点；
3. `sell_confirm2`与`sell_confirm3`方向一致；
4. 若没有改变实际卖Put周期，只能判定为许可状态简化，不能声称收益或成本增强。

### 买卖Put统一防抖

候选只有同时满足以下条件才可考虑晋级研究版本：

1. 两层估值档切换均减少至少20%；
2. 真实层核心Put实际交易事件或买卖Put合计建仓/换月交易边数减少至少20%，且累计核心Put成本下降；
3. 两层Full CAGR下降不超过0.50个百分点、Sharpe下降不超过0.02、MaxDD恶化不超过0.50个百分点；
4. `unified_confirm2`与`unified_confirm3`方向一致；优先选择满足门槛且规则较短者，除非3日规则有明确额外交易或风险收益优势；
5. 真实与理论证据分别陈述，不把理论成本节约冒充真实成交证据。

通过也只代表研究候选，不自动修改1.3版本或生成交易建议。

## Limitations

- 真实挂牌历史短，估值边界反复未必与可执行卖Put窗口重合。
- 5BP是标的名义单边综合摩擦假设，不是权利金百分比；仍不含逐笔真实买卖价差、容量、动态保证金、强平、税费或整数张数约束。
- 理论层依赖Black-Scholes输入，不是可成交历史。
