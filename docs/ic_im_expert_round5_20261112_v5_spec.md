1. 保留公开挂牌函数返回list的接口；新日ic.months存储有版本、信号日、明确状态及来源失败分类的结果封套。仅预期的纯传输不可用或列表未经核验可作为成功记录的不可用结果；原有其它role、原始HTTP、身份/日期/到期冲突、存证丢失/损坏、日历缺口仍按原硬门槛失败。
2. 新封套在采集、回放与加载就绪路径同样校验。纯传输不可用在采集/回放还原同一专用异常，候选继续实际月链的全部身份、价格、时间与到期核验，并在候选数据状态及数据审计中披露。缺原始封套不能冒充传输不可用。旧日list格式原包读取不改写。
3. 非传输列表不合格只使本次entry/roll候选不可交易，保持已验证核心、动量、网格输出；不得从未知列表推定未挂牌。真正依赖列表的核心重置选约仍不得在无列表时猜月份。403、结构错误和实际冲突不能借纯传输回退放行。
4. 同一公共查询内缓存挂牌的已验证结果或已分类的不可用结果；候选与重置消费同一份，返回副本防止调用方污染。查询结束、异常与下一次重试恢复上下文；不引入跨查询缓存，不把存证缺失、硬冲突缓存成可用结果。采集现有同role/key合并机制继续生效。
