# IC高IV卖95% Put期限分层补测 v1

预注册日期：2026-09-16。研究专用，不修改生产规则、日报、账本或交易状态。IC不卖Call。

## 固定规则

- 新卖Put须同时满足：前一收盘估值0/1档，以及原IC 1.3 `momentum_execution_weight>0`；不使用已取消的IC MOM120。
- 卖510500 95%目标行权价Put；T收盘信号、T+1开盘执行。
- 合约IV严格大于37.5%；权利金衰减60%后最多提前滚动一次到紧接当前持仓的下一挂牌月，新腿重新通过相同准入。
- 路由日开盘同步退出固定核心IC和当前核心Put；已有卖Put不因准入失效提前退出。
- 实物交割后下一共同交易日开盘卖ETF、买等名义IC；IC按原规则展期，整轮扣费交易损益回本后下一开盘退出。

## 唯一变量：初始卖Put期限

- `front10`：执行月最近挂牌月；若至实际到期不足10个共同交易日，则回退至M+1。
- `m1`：执行月之后第1个月。
- `m2`：执行月之后第2个月。
- `m3`：执行月之后第3个月，作为更远期限否证档。

提前衰减滚动始终只从当前合约滚至紧接下一挂牌月，不重新跳回上述初始期限。

## 比较与判定

- 基线为滚IC＋当前核心Put；另保留纯滚IC技术对照。
- 真实挂牌层为2022-09-19至2026-08-14；理论延展层为2015-04-16至2026-08-14，理论510500 Put只作方向压力证据。
- 比较Full、10Y、5Y、3Y、1Y年化、波动、Sharpe和最大回撤；单列周期、实物交割、提前滚动、缺链/回退次数。
- 期限候选须在真实与理论两层不依赖单点窗口，且不以更高尾部风险换取少量收益。真实周期过少时只保留研究候选。
