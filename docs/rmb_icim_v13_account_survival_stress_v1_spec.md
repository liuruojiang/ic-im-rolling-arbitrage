# 人民币账户 ICIM v1.3-r6 账户生存压力测试 v1

状态：预注册研究；不修改信号、仓位、Poe、Gmail、远端发布或交易配置。

## 1. 研究问题

在人民币账户 1500 万元、V8.0-A 600 万元、ICIM 900 万元的计划下，检验当前 ICIM v1.3-r6 历史仓位遇到保证金上调、Call 保证金扩大、账户权益骤降和期权变现折价时，外部策略的 85% 停止新增风险、95% 强制降险及“先平 Call、再卖 Put、最后减期货”瀑布能否维持账户生存。

ICIM 内部固定 IC/IM 各半，各分配 450 万元。A 资产不计入当日可用期货保证金；仅另报下一交易日出售 A 后可提供的潜在支援，不把它伪装成即时流动性。

## 2. 冻结输入

- IC：`outputs/ic_im_mainline_v1_3_r6_fixed_performance/ic_daily.csv.gz`，只使用 `data_layer=real`。
- IM：`outputs/ic_im_mainline_v1_3_r6_fixed_performance/im_daily_real.csv.gz`。
- IM 当前 Call：`outputs/im_v13_call_followup_battery_v3/call_daily_components.csv.gz` 中 `iv26_current`。
- 样本：三者共同交易日 2022-09-19 至 2026-08-14；内连接，不前向填充。
- IC Put 市值占用由 `1 - cash_weight - 30% × total_units` 反推；IM 直接使用 `put_mark_fraction`。
- IM Call 组件文件为完整核心袖口径，组合中按 0.5 缩放；必须与 IM `cash_weight` 分解在 1e-12 内一致。

## 3. 压力轴

- 每 1 倍期货保证金率：15%、20%、25%、30%、35%。15%仅为用户提供的操作假设，不视为经纪商确认值。
- Call 保证金放大倍数：1.0、1.5、2.0。
- ICIM 账户权益即时损失：0%、10%、20%。这是通用资金压力，不声称为特定市场路径或期权定价结果。
- Call 平仓成交相对当前标记价：1 倍、2 倍；超过当前标记价部分计为额外权益损失。
- Put 应急变现回收率：100%、75%、50%；不足部分计为额外权益损失。

基准情景为 15% / 1.0 / 0% / 1.0 / 100%。严重情景为 30% / 2.0 / 20% / 2.0 / 50%。35%用于超压边界，不解释为常规保证金预测。

## 4. 风险度与瀑布顺序

- 风险度 = （期货保证金 + Call 保证金）/ 压力后 ICIM 权益。
- 当日可用现金 = 压力后权益 - 期货保证金 - Call 保证金 - 长 Put 市值占用。
- 风险度高于 85% 时，下一笔新增期货或新增 Call 应被阻止；已有仓位可继续持有。
- 风险度高于 95%或可用现金为负时，依次：
  1. 平掉全部 Call，释放 Call 保证金；高于当前标记价的平仓部分扣减权益。
  2. 若现金仍为负，卖出全部 Put；按情景回收率变现，折价部分扣减权益。
  3. 若风险度仍高于95%或现金仍为负，按 IC/IM 期货保证金占比同比例减仓，直至风险度不高于95%。
- 本测试只判断资金生存与所需减仓，不把压力动作回写成一条新的历史收益曲线。

## 5. A 资产支援边界

- 即时严格口径：A 的 600 万元完全不可用于当日追保。
- T+1 参考口径：假设 A 资产先发生 10% 压力损失，再按剩余市值出售；报告弥补“平 Call + 卖 Put 后、减期货前”资金缺口所需出售的 A 比例。
- 不建模涨跌停、卖出失败、银期转账截止时间，因此 T+1 支援只是乐观参考，不能替代 ICIM 自身缓冲。

## 6. 输出与决策

每个情景和 Full/3Y/1Y窗口至少报告：最高风险度、最低现金、85%阻断日数、95%强制日数、首次触发日、平Call日数、卖Put日数、减期货日数、最大减仓比例、最大资金缺口和所需 A 支援比例。5Y/10Y为N/A。

- 若基准情景需要任何强制减期货，判定当前 900 万 ICIM 规模不具备基础资金可行性。
- 若 20%保证金、1.5倍Call保证金、10%权益损失下无需减期货，记为通过中度压力。
- 严重情景允许减仓，但必须量化首次触发、最大减仓和 A 支援需求；不得把通过定义为收益优化。
- 所有结果仅为研究审计。真实部署前仍需经纪商保证金表、期权保证金公式、银期转账规则和实际整数合约复核。
