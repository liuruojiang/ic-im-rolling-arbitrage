- 版本：`ic_fixed_valuation_unbounded_score_v6`
- 预注册日期：2026-08-18
- 性质：估值本体定义与固定高估区域研究；不构成PUT保护回测或实盘授权。
- 前置权威版本：`ic_fixed_valuation_raw_economic_score_v5`。

## 1. 研究问题

v5已经消除历史起点漂移，但0/2截断使大量PB、ERP、股息压力堆在2分，破坏两种连续化口径本应恒定0.50的平移关系。本版回答：

1. 取消截断、保留固定经济单位后，是否存在覆盖、事件和局部样本均充分的高估阈值平台；
2. 三项压力的算术均值是否与“至少两项达到同一压力线”的二取三定义指向相同经济区域；
3. 若两套定义不能相互确认，分歧究竟来自单因子极端值、事件不足还是尾部覆盖不足。

不得使用中证500后续收益、IC贴水、PUT损益、最大回撤改善或其他策略结果选择估值门槛。

## 3. 固定经济压力：取消截断

整数锚点主定义不设上下限：

- `PB压力 = (PB - 1.50) / 0.50`；
- `ERP压力 = (4.50% - ERP) / 1.50%`；
- `股息压力 = (3.00% - 过去一年股息贡献) / 1.00%`。

因此旧切换点仍保持原经济含义：PB 2.00/2.50、ERP 3.00%/1.50%、股息2.00%/1.00%对应1/2分；超过二档后压力继续增加，低于零档后允许为负数。

边界中点对照同样不截断：

- `PB压力_mid = 0.50 + (PB - 2.00) / 0.50`；
- `ERP压力_mid = 0.50 + (3.00% - ERP) / 1.50%`；
- `股息压力_mid = 0.50 + (2.00% - 股息) / 1.00%`。

三项边界中点压力必须逐点严格等于相应整数锚点压力减0.50；后续均值和中位数也必须严格相差0.50。该对照只审计公式，不参与阈值选择。

## 4. 两个并列估值本体

1. `unbounded_mean`：三项整数锚点压力的算术平均；
2. `unbounded_median`：三项整数锚点压力的中位数，即第二高压力。

`unbounded_median >= T`严格等价于下列三个固定经济条件至少两项成立：

- `PB >= 1.50 + 0.50*T`；
- `ERP <= 4.50% - 1.50%*T`；
- `股息贡献 <= 3.00% - 1.00%*T`。

均值允许三项互相补偿，中位数禁止单一极端因子独自触发。两者使用相同经济压力刻度和相同阈值，不进行事后覆盖率匹配。

## 5. 网格、窗口与基线

- 家族：`unbounded_mean`、`unbounded_median`；
- 阈值：1.50—3.00，步长0.05，共31档；
- 正式候选：62条；
- 窗口：全样本、最近10年、5年、3年、1年；
- 扫描长表：310行。

本研究没有获准实盘或生产默认阈值。v5截断定义是同源研究基线，只做重叠阈值1.50—2.00的逐点公式和覆盖率诊断，不参与v6平台选择。

扫描协议要求的年化收益、波动、Sharpe和最大回撤只填同窗口中证500价格指数背景，标记`underlying_price_index_context_only_no_strategy_return`；同一窗口全部62个候选必须完全相同。

## 6. 单家族核心条件

对每个阈值分别计算均值家族和中位家族。每个家族的核心条件为：

1. 全样本月度独立启动段不少于5段，最近10年不少于2段；
2. 最近10年月度启动率在5%—30%之间；
3. 局部门槛带`[T-0.10, T+0.10]`至少有8个月末观测。

均值家族另须满足：全样本启动月中至少90%具有`unbounded_median >= 1.00`，即至少两个经济分量已越过旧第一档，防止单一无界极端值独自触发。

连续三个及以上相邻0.05点通过本家族全部核心条件，才记录为该家族的独立结构平台。独立平台只用于诊断，不能单独成为最终门槛。

## 7. 双定义共同确认与最终平台

同一阈值T须同时满足两个家族的全部核心条件，并满足：

1. 均值与中位数全样本月度状态Jaccard不低于0.70；
2. 最近10年月度状态Jaccard不低于0.70；
3. 最近10年两种定义的月度启动率绝对差不超过10个百分点。

上述条件共同形成8项逐点门槛：均值事件、均值尾部覆盖、均值局部样本、中位数事件、中位数尾部覆盖、中位数局部样本、均值多因子证据、双定义状态确认。

通过全部条件的相邻阈值须形成至少3个连续点，才称为最终共同平台。若有多个平台，选择点数最多的平台；点数相同选择阈值更高的平台。设计中心为网格中位点；偶数个中心点时取较低者。整个平台均保留，中心不是实盘阈值。

若没有共同平台，本版结论必须为“不选择固定高估门槛”；不得事后降低Jaccard、扩大覆盖差或改用覆盖率匹配。

## 8. 经济边界、历史时点与影响诊断

对两家族每条阈值输出：

- 全样本和五个标准窗口的日/月覆盖率、独立启动段及最长连续月份；
- 局部带和启动状态内PB、ERP、股息的25%/50%/75%分位；
- 向上穿越次数和穿越月经济变量中位数；
- 均值启动月的中位压力、最大压力减中位压力、至少两项越过1分的比例；
- 中位数规则对应的三项固定原始经济阈值。

历史时点固定为2016—2025每年12月末及2026-08-17，共11个。每个时点只截取当时已有行重算，均值、中位数及全部阈值状态须与最终文件的相同历史片段完全一致，最大误差不超过`1e-12`，不得连接未来收益。

另输出：

- 无界均值与无界中位数的差值分布和极端月份；
- v5截断三分量必须等于v6无界三分量逐项裁剪至`[0,2]`，最大误差不超过`1e-12`；
- 当前两套分数、是否进入最终平台各点和对应原始经济阈值。
