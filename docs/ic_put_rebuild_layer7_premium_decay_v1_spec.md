## 研究问题与候选

固定前六层结论：绝对IV严格大于30%、不增加卖方MOM120、M+1、卖95% Put、等名义q1、即时估值许可、无灾难保护、无相对IV。只改变卖Put持有期管理：

- `hold`：持有至到期，作为“不加第七层”的基线；
- `decay50/60/70/80`：期权收盘权利金相对开仓权利金分别衰减50%/60%/70%/80%后，T日收盘触发，T+1开盘最多提前展期一次。

提前展期时同步买回旧M+1卖Put并卖出紧接下一个实际挂牌月份的95% Put；新腿须重新通过即时估值、原IC执行动量许可和绝对IV>30%。不满足时等待，不允许绕过准入。

## 固定和排除

- 只转换固定核心0.5倍；动量腿不卖Put；IC无Call。
- 核心买Put三倍盈利兑现、季度IC T-3、动量、网格、指派恢复及整轮含成本回本退出保持相同。
- 不加卖方MOM120、灾难保护Put、相对IV或估值防抖。
- 510500 Put每次买卖单边5bp；IC单边1bp；期货30%保证金/缓冲；现金年化3%。不含bid/ask、冲击、容量、税和动态保证金。

## 数据与判断

- 真实挂牌层：2022-09-19至2026-08-14；5Y/10Y为N/A。
- 理论延展层：2015-04-16至2026-08-14；理论期权不冒充挂牌成交。
- `hold`必须逐日复现第六层即时许可路径，最大误差不超过`1e-12`。
- 提前展期候选须在真实和模型两层同时满足：年化低于持有到期不超过0.50个百分点；Sharpe下降不超过0.02；最大回撤恶化不超过0.50个百分点；两层均至少实际发生一次提前展期。
