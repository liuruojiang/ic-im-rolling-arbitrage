# IM 作者式 Put 数量消融：真实 IM/MO 数据预注册规格 v1

## 1. 研究目的

本研究只回答一个问题：外部策略按“从当前点位跌至最虚值 Put 行权价时，由 Put 覆盖全部 IM 基础仓与网格仓损失”反推的 Put 数量，在计入真实期权价格、交易滑点、手续费和现金占用后，是否对组合长期收益作出正贡献；以及该数量是否已经超过有效保险剂量。

本版是独立研究分支，不修改任何冻结 IC/IM 主线，不构成实盘批准。

## 2. 样本与数据

- 正式样本：2022-07-22 至 2026-08-14。
- 期货：中金所官方 IM 日度开盘、收盘、结算、成交量、持仓量。
- 期权：中金所官方 MO Put 全链日度开盘、收盘、结算、成交量、持仓量及 Delta。
- 指数：中证指数有限公司官方中证1000价格指数收盘。
- 只使用正式样本内真实 IM/MO，不使用上市前理论期权或代理 IM。
- 初始资本：人民币 10,000,000 元。
- 全部候选使用同一日期、同一 IM 基础仓和网格仓路径；Put 盈亏不得反向改变期货仓位，以保证归因可比。

## 3. 共用 IM 基础仓与网格路径

### 3.1 IM 基础仓

- IM 基础名义目标为组合净资产的 30%。
- 首日以及每个自然年首个共同交易日，使用前一共同交易日的 P0（无 Put）净资产和当日执行价格向下取整为完整 IM 手数。
- 中证1000收盘低于5000点时，禁止增加基础仓；允许维持或减少。
- IM合约乘数为200元/点。
- 期货每边成本按成交名义的1bp计入。

### 3.2 IM 换月

- 使用逐月合约。
- 在到期日前3个自然日对应的首个可执行共同交易日收盘，平旧月、开下月。
- 持有期间按官方结算价逐日盯市；交易按官方收盘价。
- 换月时，每手网格仓等效成本按“原等效成本 + 新合约收盘价 - 旧合约收盘价”调整。

### 3.3 IM 网格

- 无未平网格仓时，网格顶部随中证1000收盘创新高而上移。
- 首次自顶部回撤1000点触发1手网格仓；此后每再下跌1000点新增1手。
- 首次触发后顶部冻结，直至本轮全部网格仓止盈。
- 每手独立记账；成交价为T日收盘触发后下一共同交易日的活动IM收盘价。
- 每手止盈线为该手等效成本加1000点；T日收盘确认，下一共同交易日收盘平仓。
- 当某档触发时中证1000已低于5000点，该档不新增；指数重新不低于5000点后才恢复检查，禁止在更低位置追补已跳过档位。
- 全部网格仓平仓后，以当日指数点位重新开始跟踪下一轮顶部。
- 同日先执行既有待办退出，再执行新增；换月优先于网格成交。

### 3.4 现金

- 每日预留当日期货名义的30%作为保证金/风险缓冲。
- 除期权市值和上述缓冲外的正现金，按净年化3%计息。
- 本版不模拟卖Call、黄金、IC、红利低波或海外资产；它们均不参与Put边际归因。

## 4. 作者式 Put 规则的可复现定义

### 4.1 合约选择

在T日收盘后：

1. 只看剩余30至59个自然日的MO Put；存在多个月份时选最近到期月份。
2. 该月份内，在官方结算价为正且成交量或持仓量至少一项为正的Put中，选择最低行权价。
3. 若30至59日没有合格月份，选择到30日或59日边界距离最小的月份；距离相同选更近月份。
4. 同月份近平值Put定义为行权价与当日中证1000收盘绝对距离最小的合格Put；并列时选较低行权价。
5. T日形成指令，T+1共同交易日按官方收盘价执行。若目标合约在T+1没有正收盘价或成交量为0，则该指令不执行，下一日重新按最新信息计算，不向后寻找成交日。

### 4.2 理论保护数量

- 从当前指数点位跌至所选最低行权价的IM损失：

  `max(指数收盘 - 行权价, 0) × 200元 × 被保护IM手数`

- 单张MO理论保护增值：

  `max(同月近平值Put结算价 - 最低行权价Put结算价, 0) × 100元`

- 完整作者式理论张数：

  `ceil(IM损失 / 单张MO理论保护增值)`

这是对文档中“最虚值Put上涨为同期限平值Put价格”的透明、可审计重建。原文没有披露额外隐含波动率路径公式，因此本版不人为添加未说明的波动率冲击；该限制必须写入最终结论。

### 4.3 市值上限与数量管理

- 正常阶段Put市值上限：160,000元 × 当日总IM手数。
- 初始或换合约时，按理论张数与市值上限共同确定建仓数量。
- 同一Put合约持有期间：
  - 理论需求上升时补仓；
  - 理论需求下降时不减仓；
  - 只有按当日官方结算价计算的Put市值超过上限时，才卖出超限部分。
- 期限月份或最低行权价改变时，全部卖出旧合约，并按新合约重新建仓。

### 4.4 交易摩擦

- 买入价：官方收盘价 + `max(官方收盘价×5%, 0.2点)`。
- 卖出价：`max(官方收盘价 - max(官方收盘价×5%, 0.2点), 0)`。
- 手续费：每张每边18元。
- 日终持仓按官方结算价估值。

## 5. 候选组

- `P0`：不买Put。
- `P-core`：只按IM基础仓手数计算理论保护，保留“只增不减”和按基础仓计算的市值上限。
- `P25`：完整作者理论张数的25%，先乘比例后向上取整；保护基础仓与网格仓，保留“只增不减”。
- `P50`：同上，比例50%。
- `P75`：同上，比例75%。
- `P100`：完整作者规则，保护基础仓与网格仓，保留“只增不减”。
- `P100-R`：与P100完全相同，但同一合约的理论需求下降时允许减仓至最新目标；用于单独识别“只增不减”的代价。

除P-core外，所有候选市值上限均按当日基础仓加网格仓总手数计算。比例候选先缩放理论张数，再应用完整市值上限。

## 6. 评价指标

正式输出至少包括：

- 全样本、近3年、近1年：CAGR、最大回撤、年化波动率、Sharpe、Calmar。
- 相对P0的CAGR差、终值差和最大回撤改善。
- Put腿累计已实现与未实现净损益、总买入权利金、总卖出回款、手续费、滑点损失和现金利息机会成本。
- 平均/中位/最高Put张数，平均/最高Put市值占净资产，市值上限触发天数。
- 买入、卖出、换仓次数；无效T+1指令次数。
- 最差5日、20日、60日组合收益。
- 逐年收益和逐年Put贡献。
- 每改善1个百分点最大回撤所牺牲或增加的年化收益。
- 现金或保证金缓冲低于0的天数，只报告、不在第一阶段强制平仓。

## 7. 预注册判定

- “Put对收益有正贡献”：候选相对P0的全样本CAGR严格大于0，且近3年CAGR差不为负。
- “仅为保险”：最大回撤改善，但全样本CAGR差不大于0。
- “数量过多”的事前证据满足任一项：
  1. P25/P50/P75中至少一条相对P100的CAGR高至少1.00个百分点，且最大回撤不比P100深超过0.50个百分点；
  2. P100-R相对P100的CAGR高至少0.50个百分点，且最大回撤不比P100深超过0.50个百分点；
  3. P100增加平均Put张数后，最大回撤不再改善而CAGR继续下降。
- 不根据结果补扫比例、期限、行权价、网格参数或成交时点。

## 8. 边界

- 真实MO历史只有约4年，无法给出真实5年或10年结论。
- 本版不是完整家庭资产组合回测，只隔离IM基础仓、IM网格和Put。
- 不模拟应急卖Put维持IC/IM保证金的第二阶段流动性价值。
- “近平值Put价格差”是对未完全披露公式的唯一主重建；不得把结果表述为对作者私有代码逐行复现。
- 所有结果均为研究用途，未获准实盘。
