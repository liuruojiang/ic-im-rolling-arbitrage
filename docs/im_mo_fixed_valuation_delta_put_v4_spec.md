# IM + MO 新固定估值分档 Delta Put v4 预注册规格

冻结日期：2026-08-18  
研究状态：仅研究，未批准实盘

## 研究问题

`im_fixed_valuation_tier_relationship_v3`已经在不读取策略收益的前提下，把中证1000固定估值冻结为二取三中位数规则，并把2.45、2.50、2.60映射为0/1/2/3档。本版第一次把该估值档位接入IM底仓的MO Put，回答三个彼此分开的题目：

1. 新固定估值分档单独用于Put保护，长期是否改善IM底仓回撤；
2. 绝对动量MOM120单独提供25% Delta保护，是否在模型层和真实IM/MO层都有效；
3. 两者取较大保护强度时，新估值相对纯MOM120是否提供可重复的增量。

本版不扫描新的估值阈值、期限、虚值度或动量保护强度；25%/50%/75%仅来自v3已冻结档位的经济标签。旧固定1.75组合只作历史连续性参照，不参与新规则选择。

## 冻结候选

| 候选 | T日收盘目标有效Delta | 用途 |
|---|---:|---|
| `no_put` | 0 | 同层基线 |
| `valuation_delta255075` | 新估值档0/1/2/3对应0/25%/50%/75% | 检验估值本体 |
| `mom120_delta25` | 中证1000全收益指数MOM120<=0时25%，否则0 | 检验趋势本体 |
| `valuation_or_mom120_delta25` | 上述两者取较大值 | 本版唯一主候选 |
| `fixed175_or_mom120_notional1x_ref` | 旧固定1.75或MOM120触发时2张MO/1份IM | 历史参照，不参与晋升 |

新估值只读取v3冻结的`median_tier`，不得用均值、共同较低档或任一较高档替换。估值历史开始前按0档处理。MOM120继续使用既有中证1000全收益指数定义：当日收盘除以120个交易日前收盘减1；没有足够历史时不触发。

## Put工具与执行

- 工具固定为MO Put：目标到期日在估值/动量评估日后约3个月，行权价选择执行日活动IM收盘价约95%的、收盘价/成交量/持仓量均为正的最近合约。
- 95%是`行权价/活动IM收盘价`，不是保护比例或Delta。
- T日收盘计算信号，T+1第一个可执行共同交易日收盘买入、卖出、调仓或换月；执行日不把新仓的盘中收益计入组合。
- 信号关闭时提前退出；信号持续时随目标3个月合约月份变化卖旧买新，不持有到期固定覆盖三个IM周期。
- 同一合约内只有目标Delta档位改变时才调整张数；不因日常Delta漂移每日再平衡。
- 真实MO若当日旧腿或新腿不满足收盘成交条件，整笔调整顺延，不能只成交一条腿。

## Delta定仓

- 模型层使用v9同源的理论波动率、利率和股息，以Black-Scholes Put Delta计算连续名义；交易时目标有效Delta满足`Put名义倍数 × |Put Delta| = 目标Delta`。
- 真实层用MO执行日收盘价反推隐含波动率并计算Put Delta；价格越界无法反推时才允许使用v9同源波动率代理，必须单独报告回退比例。
- 一份IM对应两张MO的方向名义。目标大于0时，选择使`|张数/2 × |Put Delta| - 目标Delta|`最小的正整数张数；并列时选择较小张数。真实层不允许用小数张。
- 入场、月换和目标档位改变时重新按当时Delta定仓；持有期间报告实际有效Delta，但不每日追到目标。
- 真实整数取整误差的完整性标准不是任意固定2个百分点，而是必须满足“已选张数为所有可行相邻整数中的最近值”；模型层交易时误差不超过1e-12。

## 底仓、资金与成本

- IM底仓、换月和贴水路径保持v9不变；模型层仍是中证1000全收益指数加理论Put，不伪装成上市前真实IM贴水。
- 方向名义1倍；30%作为保证金/缓冲，70%现金按净年化3%计息。
- Put权利金市值从可计息现金中扣减，现金权重下限为0；报告最低剩余现金权重、最大Put权利金占用和最大MO张数。
- IM原有换月成本不变；MO每张每边成本0.00005（两张单边合计相当于完整IM名义1bp）；不计买卖价差、冲击和容量。

## 样本与强制输出

- 模型层：2015-04-16至2026-08-14；估值档位实际可用起点由v3冻结数据决定。
- 真实层：2022-07-22至2026-08-14的官方IM/MO日行情。
- 模型层强制报告全样本、最近10年、5年、3年、1年；真实层因上市历史不足，10年和5年明确为N/A，并报告全样本、3年、1年。
- 同时输出逐年收益/回撤、信号天数、目标档位变化、保护天数、交易事件、入场Delta、取整误差、实际有效Delta、MO张数、Put资金占用、顺延和价格完整性。
- `no_put`和旧参照必须与v9冻结逐日结果校验；最大绝对误差不超过1e-14。

## 预注册判定

### A. 相对no-Put的主门槛

对`valuation_or_mom120_delta25`：

- 模型层全样本/10年/5年年化收益分别不得落后no-Put超过1个百分点，3年/1年不得落后超过3个百分点；全样本MaxDD至少改善2个百分点，五窗口至少三项改善，任一窗口不得恶化超过1个百分点。
- 真实层全样本年化收益不得落后no-Put超过1个百分点，3年/1年不得落后超过3个百分点；全样本MaxDD至少改善2个百分点，三个可测窗口至少两项改善，任一窗口不得恶化超过1个百分点。
- 模型层和真实层MOM120触发日均至少20日；执行与Delta完整性全部通过。

### B. 新估值相对纯MOM120的增量门槛

- 模型层组合相对`mom120_delta25`，全样本/10年/5年年化收益均不得落后超过1个百分点；且全样本MaxDD至少改善1个百分点，或五窗口至少三项MaxDD改善。
- 真实样本若新估值全程为0档，组合必须与纯MOM120的信号、交易和逐日收益严格相同，此时真实层只证明执行无副作用，不证明估值增量；若存在估值增量触发，则按模型层同方向逻辑检查可测窗口。

### C. 决策树

- A、B均通过：`carry_valuation_or_mom120_delta25_to_strength_layer`。
- A通过但B失败，且`mom120_delta25`独立通过A：`carry_mom120_delta25_only`。
- 估值单独路径只作归因诊断；真实层零触发标记`not_testable`，不得计为通过或失败。
- 旧1.75参照无论表现如何，都不能恢复为新估值主线。
- 其余情况：`no_put_candidate_confirmed`。

任何通过结论仍只进入下一层保护强度/工具稳健性研究，不批准实盘，不生成订单或交易建议。
