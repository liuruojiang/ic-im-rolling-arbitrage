# IM 重建估值 + MOM120最低保护主线再裁决 v14 规格

冻结日期：2026-08-19  
研究状态：Put主线选择；未批准实盘

## 1. 研究问题与非盲边界

v12比较了MOM120不高于0时最低1/2/3张MO Put，但模型全样本把2015-10-19以前估值强制按0，导致2015高估股灾没有提前保护。v13用PB与官方PE口径ERP两项保守重建，确认2014-10-17至2015-10-16全部为3档，并使最低2/3张全样本MaxDD额外改善10.18/12.87个百分点。

本版将重建模型层、v12真实IM/MO层、1/2/5倍成本、换手和旧`固定1.75 OR MOM120`参照放到同一选择表，正式回答：最低2张能否成为后续IM Put研究主线，最低3张是否有足够真实增量取代2张。

v12/v13的floor2/3结果在冻结前已经可见，本版是风险预算与策略治理再裁决，不是盲样本参数发现。不得据本版声称独立样本外验证。

## 2. 冻结候选

- `no_put`；
- `legacy_fixed175_or_mom120`：旧固定1.75或MOM120、0/2张参照；
- `reconstructed_valmom_floor1/2/3`：2015-10-19以前使用v13保守认证估值，之后使用v12冻结的`57个月 + 75%/85%/95%`估值；MOM120不高于0时分别要求最低1/2/3张，最终目标取两者较大值。

floor只比较1/2/3，不补中间值，不改变估值、动量、Put期限、行权价、换仓或成交时点。

## 3. 数据与执行

### 模型层

- 2015-04-16至2026-08-14；中证1000全收益基线加理论Put。
- floor1按v13同一早期认证规则首次正式重建；floor2/3必须与v13逐日奇偶。
- 不是上市前IM/MO，不含上市前真实贴水，只用于长周期机制判断。

### 真实层

- 2022-07-22至2026-08-14；直接使用v12官方IM/MO收盘/结算路径。
- 早期估值重建在真实上市期以前，因此真实floor1/2/3必须与v12逐日完全相同。

### 共同执行

- 1倍IM方向名义、30%保证金/缓冲、70%现金净年化3%；Put市值扣减可计息现金。
- 三个月目标到期、95%目标行权价、按月退出；T收盘信号、下一共同交易日收盘成交。
- MO每张每边成本沿用v12；正式1倍，另报2倍/5倍。bid/ask、收盘冲击和容量未计。

## 4. 强制窗口与基线

- 模型层：全样本、最近10年、5年、3年、1年。
- 真实层：全样本、最近3年、1年；10年/5年明确N/A。
- 每条候选报告CAGR、年化波动、Sharpe、MaxDD、峰谷日期、逐年收益和回撤。
- 同时相对no-Put、旧固定1.75参照以及相邻floor比较。

## 5. 主线资格门槛

一个floor须同时满足：

1. 相对no-Put，重建模型全样本MaxDD改善至少10个百分点；
2. 相对no-Put，模型最近10年MaxDD改善至少15个百分点；
3. 相对no-Put，真实全样本MaxDD改善至少15个百分点，且候选真实全样本MaxDD绝对值不超过20%；
4. 相对no-Put，真实最近3年MaxDD改善至少10个百分点；
5. 模型全样本、模型最近10年和真实全样本CAGR均为正；
6. 2倍Put成本下真实全样本CAGR不得低于同成本no-Put；5倍成本下最多落后no-Put 0.50个百分点；
7. 真实最近一年非月换信号调整年化不超过24次；
8. 相对旧固定1.75参照，模型和真实全样本MaxDD均不得恶化超过0.50个百分点，模型和真实全样本CAGR均不得落后超过1个百分点。

按满足全部资格的最低floor作为基础主线候选，体现用较低保护强度达到风险预算。

## 6. 更高floor升级门槛

最低合格floor的相邻更高floor只有在模型和真实层都证明额外防御价值时才可升级：

- 相对低floor，至少一个模型窗口MaxDD再改善2个百分点；
- 且至少一个真实可用窗口MaxDD再改善2个百分点；
- 2倍成本下真实全样本CAGR不得低于低floor；
- 5倍成本下真实全样本CAGR最多落后低floor0.25个百分点。

若高floor不满足跨层增量，保留为防御压力线，不取代最低合格floor。

## 7. 决定与稳定性

- 有合格floor：`select_reconstructed_valmom_floorN_for_im_put_research_mainline`；相邻高floor也合格则`wide_stable`，否则`narrow_stable`。
- 无合格floor但有四项核心回撤门槛通过：`watchlist_reconstructed_floor`。
- 否则：`no_reconstructed_floor_candidate/reject`。

选择只冻结后续IM Put增量研究的默认参照，不等于获准实盘，不接入自动或人工下单。
