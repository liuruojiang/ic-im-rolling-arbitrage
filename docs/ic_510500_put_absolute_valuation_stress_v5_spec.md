# IC + 510500 Put 固定绝对估值与压力升级保护 v5 预注册规格

- 前版证据：`ic_510500_put_rolling_continuous_valuation_v4`

## 1. 研究问题与证据边界

v4证明84/90/96个月滚动分位信号在定义上较稳定，但在2021-09-13至2024-02-05的样本外最大回撤路径中完全没有保护，反而在2025—2026上涨后显著提高保护。v5不再扫描滚动历史分位、历史起点或连续映射边界，改为固定经济单位的绝对估值状态，并让市场压力只决定是否从已建立的50%基础保护升级到100%。

v5是在观察v4全历史结果后提出，因此2021—2026不能再称为独立未见样本。开发段、修订验证段和近期扩张段只用于分段诊断；即使全部通过，v5最多进入`watchlist`，不得直接晋升或解释为真实样本外证明。

在冻结本规格前只审计估值和市场状态分布，不读取v5候选收益。2015-04-15至2026-08-14共2,757个评估日中，固定绝对状态为低564日（20.46%）、中1,148日（41.64%）、高1,045日（37.90%）；压力状态占57.49%。这些比例只用于排除空信号，不参与阈值拟合。

## 2. 固定绝对估值状态

每个T日收盘使用当日已知的PB、简化ERP和过去一年股息贡献；PE仅记录审计，不与ERP重复计权。

PB风险级别：

- `0`：PB < 2.00；
- `1`：2.00 <= PB < 2.50；
- `2`：PB >= 2.50。

ERP风险级别，ERP = 1/滚动PE - 向后as-of的10年国债收益率：

- `0`：ERP > 3.00%；
- `1`：1.50% < ERP <= 3.00%；
- `2`：ERP <= 1.50%。

过去一年股息贡献风险级别：

- `0`：股息贡献 >= 2.00%；
- `1`：1.00% <= 股息贡献 < 2.00%；
- `2`：股息贡献 < 1.00%。

绝对风险分数固定为：

`absolute_risk = 25% × PB级别 + 50% × ERP级别 + 25% × 股息级别`

状态映射：

- 低：`absolute_risk < 0.75`；
- 中：`0.75 <= absolute_risk < 1.50`；
- 高：`absolute_risk >= 1.50`。

阈值均为经济单位的圆整固定值，不在v5内扫描或根据收益修改。

## 3. 市场压力状态

只使用中证500官方全收益指数T日及以前数据：

- 趋势压力：T日全收益指数收盘严格低于包含T日在内的120个交易日简单移动平均；
- 波动压力：最近20个交易日全收益指数日收益率总体标准差乘`sqrt(244)`，不低于25%；
- 综合压力：趋势压力或波动压力任一成立。

完整日度历史从2007-01-15开始，正式模型执行从2015-04-16开始，120日与20日指标均已完成预热。T日收盘状态只允许在T+1开盘调整Put，不允许同日成交；首日使用2015-04-15已完成状态作为初始化例外。

压力状态不允许在低估值状态建立保护；它只对已经因估值进入50%基础保护的状态做升级。

## 4. 冻结候选

四个条件候选均日评、10%以外不再插值：

| 候选 | 低估值 | 中估值 | 高估值 | 压力升级 |
|---|---:|---:|---:|---|
| `abs_base50` | 0% | 50% | 50% | 无 |
| `abs_stress_high` | 0% | 50% | 50% | 高估值且有压力时100% |
| `abs_stress_any` | 0% | 50% | 50% | 中或高估值且有压力时100% |
| `abs_3tier` | 0% | 50% | 100% | 无 |

其中`abs_stress_any`为主假设：估值进入中档后立即在下一开盘建立50%保护，不等待暴跌；趋势或波动恶化只负责把50%提高到100%。其他三条用于分离基础保护、高估值专属升级和纯估值三档的作用。

同场基准：`no_put`、`always_50`、`always_100`。模型/真实两层共14个候选。不得在运行后添加阈值邻居、改变均线/波动窗口或删除表现不佳的结构对照。

## 5. Put、资本和执行口径

完全继承v4已验证的公共框架：

- IC逐月到期持有基线为100%名义，不放大至3.33倍；
- 30%作为保证金/缓冲，70%现金按用户假设净年化3%；Put市值从现金袖套扣除；
- 模型Put：前月、固定85%虚值、日评T+1开盘执行；
- 真实510500 ETF Put：前月、T+1实际可用的最低流动行权价，要求正开盘价和正成交量；
- IC与Put继续使用冻结的每边1bp成本敏感性；不新增盘口冲击、税费或融资杠杆；
- 模型样本2015-04-16至2026-08-14；真实Put样本2022-09-19至2026-08-14；Asia/Shanghai交易日。

模型Put在2015—2022为理论价格，真实Put为第三方日线而非可成交盘口；二者必须分层报告。

## 6. 分段和强制展示

所有候选必须展示含70%现金口径的CAGR和最大回撤：全样本、最近10年、5年、3年、1年。

额外分段：

- `development`：2015-04-16至2020-12-31；
- `revision_validation`：2021-01-04至2024-12-31，已被v4结果用于提出v5，不是独立OOS；
- `recent_expansion`：2025-01-02至2026-08-14，用于检查上涨阶段保险拖累，也不是独立OOS。

已知v4回撤路径诊断：

- 完整路径：2021-09-13至2024-02-05，报告平均目标和保护日比例；
- 早期覆盖：2021-09-13至2021-12-31，候选平均目标必须不少于50%，以验证“高位先保护”而不是暴跌后追买。

## 7. 预注册判断

单个条件候选必须同时满足：

1. `development`相对无Put：最大回撤改善至少3个百分点，CAGR落后不超过1个百分点；
2. `revision_validation`相对无Put：最大回撤改善至少3个百分点，CAGR落后不超过1个百分点；
3. `recent_expansion`：CAGR落后不超过1个百分点，最大回撤不得恶化超过1个百分点；
4. 五个强制窗口中至少3个最大回撤改善为正；全/10年/5年CAGR落后不超过1个百分点，3年/1年落后不超过3个百分点；
5. 真实Put全样本相对真实无Put：最大回撤改善至少0.5个百分点，CAGR落后不超过1个百分点；
6. 模型和真实层各至少20个保护日；2021-09-13至2021-12-31平均目标至少50%；
7. 无Put与冻结IC逐日完全一致；永久50%/100%必须产生实际Put头寸、交易和非零市值；QVIX代理继续通过；无未来估值、均线、波动或执行日泄漏。

结构支持：通过候选还必须至少有一个预先定义的结构邻居同时通过，且两者保护日Jaccard不低于60%、保护并集上的目标MAE不超过25个百分点。邻接关系冻结为：

- `abs_base50` ↔ `abs_stress_high`、`abs_3tier`；
- `abs_stress_high` ↔ `abs_base50`、`abs_stress_any`、`abs_3tier`；
- `abs_stress_any` ↔ `abs_stress_high`；
- `abs_3tier` ↔ `abs_base50`、`abs_stress_high`。

若`abs_stress_any`满足全部条件且有结构支持，优先选它；否则在全部通过者中选择全样本平均保护最低者。任何通过最多为`watchlist`：至少两个相邻候选通过为`narrow_stable`，三个及以上为`wide_stable`。无候选通过为`keep_default/reject`；完整性或输入哈希失败为`rerun_required/data_sensitive`。
