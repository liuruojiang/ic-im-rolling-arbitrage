# IC/IM 动量分袖 v1.3 r6：双品种动量 Put 与远端同步

预注册日期：2026-09-03（Asia/Shanghai）

## 1. 唯一策略变更

- IC继续使用r5已有动量Put：核心袖使用完整估值/MOM120目标，动量袖按执行权重仅使用估值目标，不继承MOM120下限；网格无Put，IC无Call。
- IM新增独立动量Put：

```text
核心Put目标 = 0.5 × parent_put_target_qty
动量Put目标 = 0.5 × momentum_execution_weight × parent_put_target_qty
组合Put目标 = 核心Put目标 + 动量Put目标
```

- IM动量Put使用与核心相同的`current_4tier_mom3`风险档：估值轴与`MOM120<0`三张下限取较大值，估值第四档最高四张。
- IM核心Put与动量Put是两条独立合约账本。动量袖由零重新进入时，按该信号日IM收盘重新选择约3个月、最接近95%行权价的可执行MO Put，不复制核心旧合约。
- 信号日T收盘评估，T+1共同交易日官方收盘执行；缺少旧腿报价、目标腿有效正收盘、成交量或持仓量时失败关闭。
- 核心、动量期货、网格、Call、成本、现金与30%保证金/缓冲规则保持r5不变；IM Call仍只覆盖核心袖，救援期限仍为`rescue_next_listed`；网格仓无Put/Call。

## 2. 真实历史验收

- IC逐日目标和定值收益必须与r5零差异。
- IM使用真实IM/MO 2022-07-22至2026-08-14独立重放；核心与动量Put各自成交、盯市和计费。
- 基准r5真实区间：CAGR约47.01%、Sharpe约1.462、MaxDD约-25.89%。
- r6真实区间验收锚点：CAGR约48.37%、Sharpe约1.517、MaxDD约-23.30%。指标必须从逐日收益重算，不能硬编码。
- IM 5Y/10Y为N/A，不用理论Put补齐；期权每归一化合约单边成本0.005%。未计买卖价差、冲击、容量、涨跌停、动态保证金及实际账户整数映射。
