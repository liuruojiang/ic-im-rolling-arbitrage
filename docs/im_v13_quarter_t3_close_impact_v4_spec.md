# IM v1.3-r6 季度T-3统一执行与冲击敏感性 v4 预注册

2026-09-04。研究补测，不修改既有v2/v3扫描、正式源、Poe、账本和授权。

## 目的

用户希望把IM与IC都统一为季度T-3，并考虑更少换仓的冲击成本优势。本轮比较IM严格季度T-1/T-2/T-3；T-2只作邻近检验。逐月T-1/T-3和正式到期日结算作对照。

- 严格季度：旧合约之后最近实际挂牌的3/6/9/12月合约。持有所选远月到自己的T-k，非每月移仓。初始化与正式基线相同。
- 同时复现之前IM target3m T-1/T-3：执行月份+3个月目标、取最近更晚挂牌月、同距取较早。两种定义若路径不同必须披露，不能直接冒用旧指标。
- 旧target3m不补桥接的两条路径仅用于复现旧结果，标为legacy_settlement_accounting，不参与优选。

## 完整策略与成交记账

- 保留完整r6核心、动量/NAV防御、估值网格、独立核心/动量Put、Call、原费用及现金/保证金。期货期限不改变期权目标或原日历。Call使用v2冻结的正式月度节点；Put原独立日程不变。
- 旧IM候选im_gross_ret=settle/pre_settle-1，缺少收盘换仓桥接。本轮新路径补旧昨结→旧收盘+新收盘→新结算，网格同理；网格开平仍按开盘，已经开盘卖出的网格不参加收盘展期。
- 该桥接与本次IC扫描一致，保留日度归一化期货单位及期权分母，不是固定手数实盘账户。
- 原始逐合约行情，正价格/成交量及新OI检查，按实际交易日倒推T-k。尾部未到期合约不误滚，不使用未来价格决定月份或日期。

## 数据与一致性

- CFFEX IM逐合约/真实MO数据2022-07-22至2026-08-14，共986行，Full按原指标扣初始行985个收益日。
- Full/3Y/1Y可用；5Y/10Y必须N/A，不用上市前代理填充。
- 正式基线完整重放与r6逐日parity<=1e-12；target3m两条legacy与v2输出parity<=1e-12；新旧桥接同一合约链，期权腿与现金不变，变化只出现在期货换仓日。
- 新桥接必须与组合公式重算逐日一致，不能仅在汇总收益上加差额。
- 所有输入和源哈希、真实换仓事件、逐年及多窗口指标保留。仅新增脚本及输出，不修改旧结果。

## 冲击成本情景

- 已有每边1bp期货成本不重复计算；额外对每次期货展期双边各施加0/1/3/5/10bp冲击情景。按当日真实核心+动量+网格持仓单位扣费，不把全策略交易当作只有4次。
- Put/Call费用和保证金不改；每倍期货30%保证金/缓冲，剩余现金3%年化。
- 情景不是实际冲击估计：缺少订单手数、盘口和成交回报，不能用日成交量推断真实盘口冲击。
- 比较同一冲击假设下季度T-1与T-3；另求T-1额外每边冲击达到多少才与T-3年化相等（若根不在0至100bp则明示无范围内解），用于量化简化操作的收益代价，不代表T-3实际更易成交。
- 汇报T-3相对T-1的收益/回撤差、相邻T-2、年度集中、不同冲击情景；不自动选赢家或改正式配置。
