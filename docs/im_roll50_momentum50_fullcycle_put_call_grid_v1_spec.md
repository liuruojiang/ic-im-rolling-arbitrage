# IM 50/50 + Put + Call：网格独立/动量门控对比 v1（预注册）

## 研究问题

在上一轮已选研究结构上加入冻结 IM V2 网格，并比较：

1. `grid_independent`：网格独立运行，仅接受冻结估值分数指导；
2. `grid_momentum_guided`：估值网格还必须接受中证1000动量目标的开关指导。

保留 `no_grid` 作为同口径基线。本轮不扫描网格阈值、规模或交易成本。

## 固定组合基线

- 裸滚袖：固定 0.5 倍 IM。
- 动量袖：`0.5 × momentum_weight` 倍 IM；沿用已执行的 T+1 动量目标。
- Put：只保护裸滚 0.5 倍袖，沿用冻结动态 Put 的 0.5 倍路径；动量袖和网格新增仓均不加 Put。
- Call：只覆盖裸滚 0.5 倍袖，沿用每日 D10、IV>=26%、5%威胁救援及严格更晚挂牌期限、最多5次；动量袖和网格新增仓均不卖 Call。
- 网格关闭时的逐日路径必须复现 `im_roll50_momentum50_fullcycle_put_call_v1` 的 `call_bare_only`。

## 冻结网格定义

- 信号：IM 冻结固定估值分数 `unbounded_median_knot`。
- 低阈值：分数 `<=0.85`，下一交易日开盘新增 1.0 倍 IM。
- 高阈值：分数 `>=1.25`，下一交易日开盘退出新增 1.0 倍 IM。
- 期货换月时，若网格仓仍持有，按冻结规则支付双边换月成本。
- 单边网格交易成本 1 bp；实际开平仓使用真实 IM 开盘价、结算价和成交量，模型层使用冻结模型市场。
- 网格新增仓固定为 1.0 倍，不随 50/50 基线缩放。

## 两种运行方式

### 独立网格

- 完全复制冻结 V2 网格状态机；不读取 MOM120，也不读取本轮 `momentum_weight`。
- 低估触发后即使动量袖为空，也照常于次日开盘买入；仅高阈值触发退出。

### 动量门控网格

- 估值条件仍为必要条件，不以动量替代估值信号。
- 使用 T 日开盘前已知的上一交易日动量目标；实现上与 T 日 `momentum_weight > 0` 对齐。
- 估值低阈值产生的待买指令，仅在执行日动量目标非空时成交；否则取消，若估值仍低可继续产生下一日待买指令。
- 网格持有期间，只要执行日动量目标转为空，则当日开盘强制退出；估值高阈值退出规则仍有效。
- 该定义不使用当日收盘后信息，避免日内前视。

## 收益、资金与样本

- 日内持有、开盘买入、开盘卖出和换月收益完全按冻结网格执行公式重建。
- 总收益先合并 50/50 期货/动量基线、0.5 倍 Put、0.5 倍 Call 和网格期货损益，再乘 Put、Call 和网格成本因子。
- 每 1 倍 IM 占用 30% 绩效保证金/风险缓冲；网格持有时额外扣除 30% 现金权重。
- 剩余现金按年化3%计息；卖 Call 权利金不重复记入现金。
- 共同样本为 2015-04-16 至冻结数据截止日；报告全周期、10年、5年、3年、1年。
- 2022-07-22 起使用真实 IM；更早为冻结理论/代理段。真实网格成交必须有正开盘价和正成交量。

## 强制校验

1. 独立网格的逐日持仓、买卖、损益与成本必须复现冻结 `fixed_L0.85_H1.25` / `core_put_grid_085_125` 网格组件，误差不超过 `1e-12`。
2. `no_grid` 必须逐日复现上一轮 `call_bare_only`，误差不超过 `1e-12`。
3. 动量门控使用的当日目标必须等于上一交易日产生的 `desired_weight`，不得使用当日收盘信号。
4. 不得出现负现金、无效收益、重复日期或未成交的期末待执行指令。
5. 保存两类网格逐笔交易，明确区分估值开平仓与动量强制退出/拦截。

- 所有路径均为研究候选，未批准实盘或下单。
