# IM + MO Call受威胁向上向后移仓 v25r2 运行后审计

日期：2026-08-19（Asia/Shanghai）  
状态：官方MO短样本机制通过；事件集中、长历史模型混合；未批准实盘。

## 结论

在不使用TP80的前提下，给v23正式PE20/60卖Call线增加“旧Call剩余虚值不高于5%时，向上至少5%、向后一个挂牌到期月救援，救援豁免IV26，连续最多5次”的规则，通过了预注册的真实短样本机制门槛：

- 真实full/3Y/1Y CAGR由17.19%/27.38%/33.05%提高到17.60%/27.99%/35.07%，分别增加0.41/0.61/2.02个百分点；
- 组合full/3Y/1Y MaxDD保持-16.36%/-16.36%/-9.46%，没有改善也没有加深；
- 最大Call Delta由74.07%降至32.16%，下降41.91个百分点；
- 最大Call保证金占比由15.95%降至9.74%，下降6.22个百分点；
- 真实正式线只有2次救援移仓和1次因无合格新约止损，增益集中在2026年，不能外推为稳定年化增强。

机械决定为`valuation_threat_roll_supported_real_short_sample`。更准确的标签是`official_real_short_sample_supported_event_concentrated_model_mixed`：它值得保留为尾部风险观察线，但不替换v22每日D10，不获准实盘。

## 固定规则

- 正常空仓入场：继承v23每日收盘检查、IV不低于26%、PE20/60滞回与期限—虚值率阶梯；
- 威胁触发：`旧行权价 / 中证1000价格指数收盘 - 1 <= 5%`，包括平值和实值；
- 救援选约：严格下一个挂牌到期日，取不低于旧行权价`×1.05`的最小挂牌行权价；
- 救援豁免IV26；T日收盘冻结，T+1官方收盘执行；
- 连续最多5次，第6次仍受威胁则买回止损；没有合格新约也买回止损；止损后暂停到下一IM月度评估；
- 每1张IM固定卖2张MO Call；不含TP80、分批止盈、急跌向内移仓、风险度扩仓或网格。
