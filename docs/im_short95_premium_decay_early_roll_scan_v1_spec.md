# IM 卖 95% Put 权利金衰减提前换月扫描 v1

状态：研究预注册；不修改主线、生产脚本或实盘。

## 问题与候选

在既有「估值 tier <= 1 且 MOM120 >= 0 才开卖下一月 95% MO Put；到期实值后转 IM 并回本退出」状态机内，比较：

- `hold_to_expiry`：既有持有到期路径；
- `decay_50`、`decay_60`、`decay_70`、`decay_80`：当前 Put 的收盘结算价首次不高于该腿开仓权利金的 50%/40%/30%/20% 时，信号成立。

每次提前换月均在信号日的下一交易日开盘：买回旧 Put，同时卖出到期日严格晚于旧合约的最早可用 MO Put，并按上一交易日 CSI1000 收盘价选约 95% 行权价。新腿的权利金基准重新设为其本次卖出开盘价。它是已有空头头寸的维护换月，**不**重新施加估值/动量准入；如旧腿到期实值，则仍按原路径现金结算、次日买 IM、回本后退出。

## 不变规则

- 真实层：CFFEX MO/IM 缓存，2022-07-22 至 2026-08-14；模型层单列，仅作方向性延展。
- T 收盘信号、T+1 开盘执行；单边 1bp 名义成本；风险状态 30% 缓冲、现金年化 3%。
- 不模拟盘口、容量、保证金动态、整数张数、强平或滑点。真实层不是可执行实盘收益证据。

## 判断规则

只有当真实与模型层、全样本与近期窗口没有明显冲突，并且相邻阈值形成稳定平台时，才可能提出后续研究候选；否则保持 `hold_to_expiry` 基线。任何结论均不构成下单或生产变更。
