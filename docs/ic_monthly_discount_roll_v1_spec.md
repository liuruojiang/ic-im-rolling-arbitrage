# IC 逐月到期展期贴水研究 v1：预注册规格

冻结日期：2026-08-16  
研究状态：预注册研究；未获准实盘

## 1. 研究问题

以中证500股指期货（IC）为第一条可验证基线，回答：从 IC 上市至最新可用交易日，持有最近月合约至到期并在到期日以结算价进入下一月合约，能否持续获得相对中证500价格指数的正展期/基差收益；该收益在全样本、最近10年、5年、3年、1年是否稳定。

本版不把 IC 策略总收益直接称为“贴水收益”。总收益拆为：

1. 中证500指数方向收益；
2. IC 相对中证500价格指数的展期/基差超额；
3. 与中证500全收益指数的差异，用于显示股息口径影响。

IM、创业板ETF期权和科创50ETF期权只做数据可得性审计，不在本版正式收益结论内。它们若继续研究，必须另建版本并预注册。

## 2. 预注册假设

- H1：IC 逐月到期展期的毛收益相对中证500价格指数，在全样本和多数强制窗口中为正。
- H2：扣除每边1bp的交易摩擦敏感性后，上述相对价格指数的超额仍为正。
- H3：相对中证500全收益指数后，IC 的经济超额将显著小于相对价格指数的“贴水收益”；二者差异主要反映价格指数不含现金股息，不能把全部贴水都解释为免费套利收益。

本版为机制与历史事实检验，不设置根据结果晋升实盘的门槛，也不据结果自动产生交易信号。

## 3. 数据与正式样本

### 3.1 期货

- 数据源：中国金融期货交易所官方历史行情月包：`http://www.cffex.com.cn/sj/historysj/YYYYMM/zip/YYYYMM.zip`。
- 品种：所有 `ICYYMM` 月度合约。
- 字段：交易日、合约、结算价、前结算价、收盘价、成交量、持仓量；回测主价格使用结算价。
- 起点：IC 首个交易日 2015-04-16。
- 终点：运行时可验证的最新完整官方交易日，预期为 2026-08-14；若不同，必须在元数据中记录且不得静默替换。

### 3.2 指数

- 中证500价格指数：中证指数有限公司官方历史接口，代码 `000905`。
- 中证500全收益指数：中证指数有限公司官方历史接口，代码 `H00905`。
- 通过 AKShare `stock_zh_index_hist_csindex` 获取并保留原始窄表；只使用收盘值。
- 指数无需复权；`000905`为价格指数，`H00905`为官方全收益指数。

### 3.3 日历与时区

- 使用中金所实际交易日与中国内地交易日历，不前向填充缺失交易日。
- 时区：Asia/Shanghai。
- 正式样本取 IC、价格指数、全收益指数共同可用区间。

## 4. 合约选择与执行口径

1. 初始日以当日官方结算价进入首个最近月合约 `IC1505`。
2. 每个合约持有至其最后交易日，以当日最终结算价结束该合约。
3. 同一到期日以当日结算价进入下一个自然月合约；下一交易日起使用新合约的结算价收益。
4. 到期日收益仅计旧合约从前一交易日结算价到最终结算价的变化，不把旧合约与新合约价格差当作即时损益。
5. 最新未到期合约按最新官方结算价盯市，明确标记为未完成周期。
6. 主结果为1倍名义敞口、完全抵押口径；不按保证金占用放大收益，不做波动率目标或择时。
7. 主曲线不计抵押现金利息；因此与全收益指数的比较不是“含现金管理”的期货组合比较。

若某月下一自然月合约在滚动日无结算价，正式运行必须失败并报告，不得改用主力连续、后月或填充值。

## 5. 收益定义

### 5.1 IC 连续展期总收益

- 合约内日收益：`settle_t / settle_{t-1} - 1`。
- 展期拼接按第4节执行，不对合约价差作后复权或加减点处理。
- 毛收益：不扣费用。
- 成本敏感性：每个实际开仓或到期/平仓等价交易按名义金额每边1bp；初始进入收1bp，每次月度换月收2bp。该成本是统一研究敏感性，不代表任一具体券商历史费率。

### 5.2 贴水/基差超额

- 日相对价格指数因子：`(1 + r_IC) / (1 + r_000905)`。
- 日相对全收益指数因子：`(1 + r_IC) / (1 + r_H00905)`。
- 月度已实现基差因子：`(F_exit / F_entry) / (S_exit / S_entry)`，其中期货使用该月合约结算价，现货使用同日中证500价格指数收盘。
- 同时报告入场贴水：`S_entry / F_entry - 1`，并单列到期日最终结算价与指数收盘不完全一致造成的收敛残差。

中金所最后结算价并非中证500日收盘点位；月度已实现基差因此是可复现的结算价—收盘价近似，不解释为无误差套利收益。

## 6. 强制展示窗口与指标

终点统一为共同数据的最新交易日。窗口起点取终点向前推对应自然年后的首个共同交易日：

- 全样本；
- 最近10年；
- 最近5年；
- 最近3年；
- 最近1年。

每个窗口至少展示：

- IC 毛收益与净成本敏感性的年化收益、最大回撤；
- 中证500价格指数年化收益、最大回撤；
- 中证500全收益指数年化收益、最大回撤；
- IC 相对价格指数曲线的年化收益、最大回撤；
- IC 相对全收益指数曲线的年化收益、最大回撤。

全样本另展示：年化波动率、Sharpe（无风险利率按0，仅为横向描述）、完成月数、月度基差超额均值/中位数/胜率、入场升贴水分布、最差月份、换月次数。

年化使用252个交易日；最大回撤由各自日净值历史峰值计算。窗口不足时显示 `N/A` 并说明原因，不缩短窗口冒充完整窗口。

## 7. 完整性检查

- 官方月包下载状态、SHA-256、文件月数与日数写入数据清单。
- 合约代码必须匹配 `^IC\d{4}$`，月份连续且每个完成周期都有入场和退出价格。
- 比较 CFFEX `pre_settle` 与同合约上一交易日 `settle`，记录不一致数量和最大差异。
- 检查到期日新旧两张合约是否同时有结算价。
- 指数与期货日期使用内连接；报告被删除日期及原因，不静默填充。
- 检查收益中绝对值超过10%的日期并列出来源，不自动截尾。
- 每个窗口使用同一条已冻结曲线切片，不在窗口内重置合约规则或选择参数。

## 8. 明确排除

- 不用新浪主力连续或任何价差复权连续合约替代真实月合约链。
- 不计保证金杠杆、抵押现金收益、税费、资金容量、盘口冲击与保证金追缴。
- 不假设能以中金所最终结算价成交；本版是到期结算机制研究，实盘可执行版本需另建研究，使用到期日前可交易时点和真实买卖价/滑点。
- 不把报告中的最新持仓或未完成周期解释为交易建议。
