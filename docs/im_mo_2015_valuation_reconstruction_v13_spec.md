# IM 2015高估信号重建与MO Put回撤归因 v13 规格

冻结日期：2026-08-19  
研究状态：历史诊断；未批准实盘

## 1. 研究问题与已知信息

用户在查看重建结果前提出：2015年中证1000快速下跌使MOM120来不及过滤，但股灾前估值极高，若当时估值信号可用，应已启动仓位保护。

本版先核对2015年6月前是否能按既有固定经济估值规则保守认证为高估，再把该信号接入v12同一条三个月95%月换理论Put路径，判断v12全样本MaxDD只改善少量是否主要来自估值历史被人为截在2015-10-19之后。

重要边界：在冻结本规格以前，研究者已只读观察到2015-06-12的历史PE/PB以及2015-04-01至06-12的保守档位方向。因此估值确认不是盲样本发现；但扩展信号的Put净值和MaxDD尚未计算。本版只允许按下述冻结规则运行，不再根据回测结果改变阈值、期限、数量或成交时点。

## 2. 冻结数据

- 乐咕中证1000历史估值：`data/ic_im_valuation_risk_premium_forecast_v4/legulegu_000852_valuation.csv`，2014-10-17起；使用聚合PB并保留聚合TTM PE作交叉检查。
- 中证指数官方000852历史：`data/ic_im_valuation_risk_premium_forecast_v4/csindex_000852.csv`；使用收盘价和官方滚动PE。
- 中债10年国债：`data/ic_im_valuation_risk_premium_forecast_v4/chinabond_government_10y.csv`；只允许同日或向后as-of，不得使用未来收益率。
- v12正式日线和信号作为未扩展基线；理论Put市场、成本、现金和指标函数全部沿用v12冻结依赖。

早期PB是2026年取得的历史序列，不是2015年逐日保存的原始快照；官方PE可独立交叉确认盈利收益率方向。该限制必须在结论中保留。

## 3. 保守认证档位

沿用中证1000固定经济分档阈值`2.45/2.50/2.60`。二取三无界中位数在阈值`T`的经济等价条件为至少两项成立：

- `PB >= 1.50 + 0.50*T`；
- `ERP <= 4.50% - 1.50%*T`；
- `过去一年股息贡献 <= 3.00% - 1.00%*T`。

2015-10-19以前的正式重建不使用发布前回溯的股息贡献，只用PB和ERP两项同时成立来认证档位：

- 两项同时通过`T=2.60`，认证3档；
- 否则两项同时通过`T=2.50`，认证2档；
- 否则两项同时通过`T=2.45`，认证1档；
- 否则为0档，不使用第三项补档。

其中`ERP = 1 / 中证官方滚动PE - 当日可见10年国债收益率`。该规则是原二取三档位的保守下界：通过时第三项无论为何值都不改变档位；不通过时可能低估、不允许高估。

2015-10-19及以后完全恢复v12冻结的v7最终档位，不改写任何既有状态。

## 4. Put回测

- 模型期：2015-04-16至2026-08-14；中证1000全收益基线加v12同一理论Put。
- 候选：`no_put`、v12原组合最低2/3张、2015扩展组合最低2/3张。
- 扩展组合目标：2015-10-19以前为`max(保守认证档位, MOM120最低2或3张)`；以后与v12原目标逐日完全相同。
- 信号T日收盘、下一交易日收盘执行；Put固定三个月目标到期、95%目标行权价、按月退出，不持有到期。
- 1倍IM方向名义、30%保证金/缓冲、70%现金净年化3%；MO每张每边成本沿用v12。不开新参数网格，不加入真实IM/MO层、网格或Call。

## 5. 强制诊断

1. 输出2014-10-17至2015-10-16逐日官方PE、聚合PB、国债、ERP、两项压力和认证档位；未来国债行数必须为0。
2. 报告2015-04-01至06-12、06-12单日、04-16模型起点的档位覆盖及相对阈值安全边际。
3. v12两条原组合的逐日`cash_ret/cash_nav/put_fraction`必须与正式产物误差不超过`1e-14`。
4. 扩展组合在2015-10-19及以后目标数量必须与v12逐日完全相同。
5. 输出全样本、2015-09-02后、2015-10-20后、最近10年/5年/3年/1年CAGR与MaxDD，以及峰值日、谷底日。
6. 单列2015-06-12高点至2015-09-02首次MOM保护日、2016-01-28、2018-10-18、2019-01-31的同高水位回撤。

## 6. 事前解释规则

- 若2015-06-12为认证3档，且2015-04-01至06-12至少90%交易日为认证3档，结论中的“用户高估记忆”判为确认。
- 若任一扩展组合相对对应v12组合把模型全样本MaxDD改善至少10个百分点，结论为`memory_confirmed_and_v12_full_sample_boundary_explained`。
- 若记忆确认但回撤改善不足10个百分点，结论为`memory_confirmed_but_not_main_dd_explanation`。
- 否则为`memory_not_confirmed`。

任何结论都只说明历史归因，不改变v12冻结决定，不构成实盘晋升。
