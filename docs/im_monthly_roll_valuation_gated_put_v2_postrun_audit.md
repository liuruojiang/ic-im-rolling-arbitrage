## 1. 审计结论

`outputs/im_monthly_roll_valuation_gated_put_v2/`是冻结规格
`docs/im_monthly_roll_valuation_gated_put_v2_spec.md`的首次正式输出，不覆盖。
历史回测的信号时点、期权开盘执行、逐日损益、费用、现金权重和上游基线均通过复核。

- 正式样本为2022-07-22至2026-08-14，共986个交易日；50次月度历史决策中35次为ON，保护701日。
- 除MO上市初始例外外，全部执行日严格晚于估值状态日；全部类比结果终点不晚于当时状态日。
- 无Put曲线与冻结上游基线逐日最大差为0；旧永久Put参考与冻结上游逐日最大差为`3.39e-21`。
- 即时择时和同执行永久Put均严格满足正式脚本的乘法费用公式，最大重算误差为`3.21e-16`；Put费用边数分别为70和99。

## 3. 2024年关键执行核对

- 2023-12-29收盘估值预测转负，v2在2024-01-02官方开盘买入`MO2403-P-5000`。
- 2024-01-22无Put IM净收益为-6.90%；该Put贡献+5.58%，v2当日为-1.33%。这证明v2已修正“等待到暴跌后才保护”的执行错误。
- 2024-01-31收盘估值状态转为OFF，v2在2024-02-01开盘卖出；所以2024-02-05 IM下跌-4.53%时已无保护。这是估值变便宜后立即撤保规则的真实结果，不做事后修正。

## 4. 当前状态

2026-07-31最后一个正式月末历史状态为OFF；2026-08-14中期审计状态变为ON，3年类比全收益年化中位数为-1.57%，有效类比7个。因此正确表述是“由OFF转为ON，下一交易日开盘待买”，而不是“同为OFF”。冻结数据没有下一交易日官方开盘价，不虚构合约成交或持仓。

这只是研究信号，不是交易指令。

## 5. 前瞻字段勘误

正式输出`record.md`及`current_forecast_with_protection_cost.csv`把全样本相对CAGR `+0.8546%`称为“历史保险成本”，名称不准确。该数值实际为：

`(1 + 即时择时Put+剩余现金CAGR) / (1 + 无Put+70%现金CAGR) - 1`

它包含历史Put赔付、权利金变化、交易成本和现金占用的全部已实现效果，不是纯保费成本。将它乘入未来情景只能视为“历史净覆盖效果保持不变”的敏感性校准，不能同时声称“未来Put赔付被排除”，也不能视为确定性收益预测。

| 期限 | 情景 | 原估值v3组合年化 | 乘入历史v2净覆盖因子后的敏感性年化 |
|---:|---|---:|---:|
| 3年 | 悲观 | -2.19% | -1.35% |
| 3年 | 中等 | 9.14% | 10.07% |
| 3年 | 乐观 | 19.83% | 20.85% |
| 5年 | 悲观 | 3.44% | 4.32% |
| 5年 | 中等 | 11.02% | 11.97% |
| 5年 | 乐观 | 15.02% | 16.00% |

由于未来下跌路径、隐含波动率、Put赔付和换仓价格未知，保护后的未来MaxDD仍为N/A。若要估计纯保险成本或未来路径分布，应新建版本并预注册期权定价/路径模型；不得改写本版正式输出。
