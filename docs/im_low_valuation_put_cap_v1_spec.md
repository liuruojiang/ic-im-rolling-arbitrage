# IM 低估值条件下核心买 Put 减仓/取消扫描 v1

## 研究问题

以冻结的 IM 四档估值 + `MOM120<0` 最低 3 张 MO Put 路径为基线，检验估值处于低档（估值目标为 0 或 1 张）时，是否应减少或取消**估值驱动的**核心买 Put。

## 固定输入与执行

- 复用 `im_put_four_tier_mom120_floor_scan_v3.py` 的真实 IM/MO、估值、网格、Call、成本、30%保证金/缓冲、3%现金和 T 收盘信号/T+1官方收盘执行路径。
- 基线为 `IM_4tier_mom_floor_3`，即 `target=max(valuation_tier, 3 if MOM120<0 else 0)`。
- 低估值定义为当月已知估值档 `valuation_tier in {0,1}`；不得使用未来估值或把缺失估值当作低估。
- 不修改冻结主线或 v1.4 研究信号；本研究仅分析历史长 Put 保护路径，不能替代 v1.4 卖 Put 路由审计。

## 候选

1. `baseline_floor3`：未修改的基线。
2. `low_value_cap1_preserve_mom`：低估值时，估值部分最多 1 张；负动量最低 3 张仍保留。
3. `low_value_no_put_preserve_mom`：低估值且 MOM120 非负时，取消估值驱动 Put；负动量最低 3 张仍保留。
4. `low_value_no_put_override_mom`：低估值时一律取消 Put，包括负动量保护；这是风险更高的边界对照，不是默认候选。

## 报告与决定

- 输出全样本、10年、5年、3年、1年 CAGR、波动率、仓库 Sharpe、MaxDD、Put成本、实际持仓和交易事件；样本不足窗口须明确标识。
- 以基线为唯一比较线。若低估值取消 Put 仅因极少数日子而无可辨识差异，明确报告为“样本不识别”，不视作有效简化。
- 仅当候选在全样本及近3年/1年至少两窗不使 MaxDD 恶化超过 0.5 个百分点、且没有更差的尾部事件，才可保留为后续研究候选；不自动晋级。
