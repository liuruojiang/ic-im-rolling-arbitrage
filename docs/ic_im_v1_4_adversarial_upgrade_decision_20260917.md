# IC / IM v1.4 对抗性测试与升级决定

日期：2026-09-17  
决定：**此否决结论已被用户在审阅风险收益取舍后明确覆盖。** 用户接受IC回撤增加与IM q3样本集中度，当前正式规则改由`docs/ic_im_mainline_v1_4_r1_spec.md`承接。本文件保留为对抗审计历史证据，不得再解释为当前版本状态。

## 为什么不能升级

多智能体对会计成本、执行时点、状态机和发布迁移分别进行对抗审查后，发现三项会实质改变结论的问题：

1. IC 真实期把样本最后报价日误当作合约到期日，导致 2026-08-14 对尚未到期的 2026-09 Put 做了虚假到期结算。
2. IM 从固定核心 IM 切换到卖 Put 时，旧逻辑在开盘退出 IM/核心 Put，却到收盘才关闭对应卖 Call，形成日内裸 Call；现已统一修正为同一 T+1 开盘同步退出。
3. IM 卖 Put 入场名义上报告单边 5BP，旧动态代码实际只扣 1BP；现已按所有 MO Put 单边 5BP 重算，并增加 10/20BP 压力档。

同时修正了卖 Put 提前展期受阻后的等待状态：触发日与等待原因必须持久化，不能每天清空后重新触发。

## 修正后的 IC 结果

完整 v1.3 基线真实挂牌层为年化 26.89%、Sharpe 1.511、最大回撤 -11.07%；“固定核心卖 Put＋核心 Put 三倍盈利重置”的联合方案为 30.38%、1.833、-11.94%。收益和 Sharpe 提高，但最大回撤恶化 0.87 个百分点，超过预注册允许的 0.50 个百分点，因此真实全样本门槛失败。

理论延展层基线为 18.62%、1.119、-19.58%；联合方案为 21.32%、1.279、-12.12%，表现改善，但不能覆盖真实挂牌层的失败。结论为：IC 固定核心卖 Put 联合方案不晋级。

核心 Put 三倍盈利重置单项仍是正向研究候选：真实年化 28.21%、最大回撤 -11.07%；理论年化 19.79%、最大回撤 -12.12%。但现有 v1.3 持久账本没有可靠保存当前核心 Put 的实际入场权利金，无法安全判断既有持仓的三倍阈值；在完成可验证迁移前不单独发布。

证据：`quant_param_scan_runs/20260917_ic_im_ic_v1_3_to_v1_4_final_joint_upgrade_gate_redteam_v3/`。

## 修正后的 IM 结果

### 固定核心 q3

所有 MO Put 单边 5BP 时，不卖 Put、只保留核心 Put 三倍盈利重置的真实/理论年化分别为 37.81%/24.33%；固定核心 q3 联合方案为 38.80%/25.33%。最大回撤真实由 -16.26%变为 -16.85%，理论由 -16.21%改善为 -16.15%。

成本压力本身通过：在 10BP 时 q3 相对不卖 Put 的真实/理论年化优势为 1.12/1.09 个百分点；20BP 时为 1.37/1.27 个百分点，最大回撤恶化均未超过 1 个百分点。

但逐周期剔除失败：真实挂牌层只有 3 个卖 Put 周期，其中 2025-04-10 周期贡献占全部正向年化贡献的 67.7%，超过预注册 50% 上限；理论层 10 个周期的最大占比为 28.4%。因此 q3 只保留为稀疏样本研究候选，不晋级。

### 动量仓卖 Put

真实层固定核心 q3 年化 38.80%、Sharpe 1.811；固定核心和动量仓都转卖 Put 后为 38.72%、1.788，均下降。理论层年化略升至 25.44%，但 Sharpe 从 1.590 降至 1.546。跨层门槛失败，明确不加入动量仓卖 Put。

证据：

- `quant_param_scan_runs/20260917_ic_im_im_v1_3_short95_quantity_redteam_v2/`
- `quant_param_scan_runs/20260917_ic_im_im_v1_3_momentum_short95_full_joint_q3_redteam_v3/`
- `quant_param_scan_runs/20260917_ic_im_im_v1_3_to_v1_4_redteam_fixed_core_q3_short95_core_put_3x_all_put_cost_5_10_20bp_and_cycle_leave_one_out/`

## 发布与状态迁移审查

即使收益门槛通过，当前也缺少可安全发布的 v1.4 状态契约：卖 Put/恢复 IM、核心 Put 实际入场权利金、盈利退出待执行日、提前展期等待原因和触发日都需持久化；旧账本无法重建的核心 Put，不得在迁移日直接套用三倍盈利退出，只能等下一次正常重置后启用。回滚必须通过向前版本修订，不能把新 schema 账本直接回退给 v1.3 读取。

## 最终结论

- 不创建、不冻结、不切换 v1.4 正式版本；版本号不占用。
- v1.3 继续作为当前有效研究信号版本。
- IC/IM 核心 Put 三倍盈利重置、IC 固定核心卖 Put、IM 固定核心 q3 均仅保留为研究候选。
- IC/IM 动量仓卖 Put继续否决；IC 不引入 Call，也不重新引入卖方 MOM120。
- 本轮未修改生产入口、账本、定时任务、GitHub/Gmail、Poe/Modal，也未生成任何交易或下单动作。

## 重新启动 v1.4 的最低条件

1. 补充更多真实挂牌卖 Put 周期，或使用事先冻结的时间外样本，使 IC 回撤和 IM 周期集中度门槛同时通过。
2. 完成核心 Put 入场权利金与 pending 状态的可审计 schema、迁移和幂等测试。
3. 用同一账本做 v1.3 与候选版本的逐日影子对照，并再次执行完整对抗审查。
