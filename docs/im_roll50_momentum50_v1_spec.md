## 组合定义

- 50%资本配置单纯滚IM：始终保持该袖1倍IM名义，每月滚动；
- 50%资本配置动量门控滚IM：使用固定中证1000动量目标0/0.5/1，有仓才滚动，空仓时该袖全部现金；
- 两袖资本权重固定为50%/50%，不扫描其他比例；
- 组合总IM名义为 `0.5 + 0.5 * momentum_weight`，只可能为0.5、0.75、1倍；
- 组合逐日净收益为两袖各自逐日净收益的等权和，再进行复利。

- 中证1000价格指数；
- `MA35 / Mom18 / W2.5`；
- 50% Abs20 OFF + 50% 静态 `Abs20 > 0`；
- T日收盘确认，T+1共同交易日使用目标仓位。
