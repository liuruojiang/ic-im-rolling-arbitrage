# 50%裸滚IM + 50%动量IM：动量袖Put去MOM120下限 v4

日期：2026-08-23  
状态：预注册规则消融研究；未批准实盘

## 研究问题

固定v3的50%裸滚IM与50%动量IM结构，检验动量袖Put中的`MOM120 < 0`四张下限是否与动量门控重复。裸滚袖继续执行完整IM V2 Put；只有动量袖删除MOM120下限，改为纯估值Put。

## 固定底仓

- 裸滚袖始终持有0.5倍IM。
- 动量袖资本占50%，内部权重为0/0.5/1，对应0/0.25/0.5倍IM。
- 动量固定为`MA35 / Mom18 / W2.5`，50% Abs20 OFF + 50%静态`Abs20 > 0`。
- 期货、代理贴水、换月、成本、30%保证金缓冲和3%现金收益完全继承v3。

## Put规则

每1倍IM先得到两个目标：

- `q_full`：完整V2目标。绝对轴2.45/2.50/2.60对应1/2/3张；57个月相对轴75%/85%/90%/92.5%对应1/2/3/4张；两轴取较大值；`MOM120 < 0`时最低4张；上限4张。
- `q_valuation`：纯估值目标。只取上述绝对轴和相对轴的较大值，不使用MOM120下限；上限4张。

新路径：

- 裸滚袖：`q_bare = 0.5 × q_full`。
- 动量袖：`q_momentum = 0.5 × momentum_weight × q_valuation`。
- 组合：`q_total = q_bare + q_momentum`，上限4张。

## 比较路径

1. `no_put`：不加Put。
2. `bare_full_put_only`：只有裸滚袖按完整V2配置Put。
3. `both_full_put_v3`：v3旧路径，两袖均使用完整V2 Put。
4. `momentum_valuation_only_put`：本轮新路径；裸滚袖完整V2，动量袖纯估值Put。

除上述差异外，约3个月期限、95%目标行权价、T日信号/T+1收盘执行、月度重置和成本口径保持不变。Call与网格关闭。
