# IM v1.4 q3 成本与周期集中度对抗测试预注册

## 目的

检验 IM v1.3 固定仓在高 IV 时以 3 张 MO 95% Put 替代 1 张 IM，并与核心 Put 3 倍盈利重置联合使用的候选方案，是否能承受更高交易冲击成本，以及是否过度依赖少数卖 Put 周期。

## 固定口径

- 维持 v1.3 的估值分层、120 日绝对动量及防抖、102% 核心/动量 Put 选档。
- 卖 Put 只替代固定 0.5 倍 IM；不引入卖方 MOM120，也不替代动量仓。
- 卖 Put、固定 IM、核心 Put 和对应卖 Call 在同一 T+1 开盘切换；卖 Put 期间暂停卖 Call。
- 卖 Put 采用下一挂牌月 95% Put，权利金衰减 60% 后最多滚至紧接下一挂牌月。
- 真实挂牌层为 2022-07-22 至 2026-08-14；理论延展层为 2015-04-16 至 2026-08-14。
- 每 1 倍期货按 30% 保证金/缓冲计；q3 为每 1 张 IM 对应 3 张 MO Put，使用连续张数研究口径。

## 扫描

1. 所有买入和卖出 MO Put 的单边冲击成本统一重算为 5BP、10BP、20BP；期货保持单边 1BP。
2. 对 5BP 的 q3 联合方案，真实层和理论层分别逐个屏蔽每个原卖 Put 周期的首次准入窗口，完整重跑路由、Call、核心 Put 和组合。
3. 与同成本的“核心 Put 3 倍盈利重置、不卖 Put”比较年化收益、Sharpe 和最大回撤。

## 门槛

- 成本稳健性：真实层和理论层在 5/10/20BP 下，q3 联合方案年化收益均不低于同成本的不卖 Put 方案，且最大回撤恶化不超过 1 个百分点。
- 周期集中度：以逐周期剔除造成的正向年化收益损失计算，最大单周期贡献占全部正向贡献之和不超过 50%。
- 两项门槛必须同时通过，才可作为 1.4 晋级证据；任一失败则保持 v1.3，候选仅保留为研究方向。

## 边界

本测试只产生本地研究工件，不修改生产入口、账本、定时任务，不发送邮件、不部署、不下单。
