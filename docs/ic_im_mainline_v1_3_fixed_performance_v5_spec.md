# IC/IM v1.3 定值绩效 v5 语义一致性修订规格

预注册日期：2026-09-03（Asia/Shanghai）  
状态：研究审计修复；未批准实盘；v1至v4输出保持只读。

## 固定范围与原因

- 完整继承v4的唯一IC Put日程、实际交易层过滤、非有限目标校验、传递依赖哈希与窗口起点口径。
- IC NAV门禁现金日化必须与A股权威实现一致，采用244交易日，而不是252；同时对完整正式期的执行权重、基础NAV和回撤逐日校验。
- 2015-04-16后的IC目标权重未受244修订影响，因此IC/IM规范化`date,ret`字节必须与v3/v4相同；若不同则失败关闭。

## 验收

- IC自2007-01-15起的执行权重、基础NAV、基础回撤与A股权威逐日最大误差不超过1e-12。
- IC/IM定值收益与v4逐日零差异。
- IC Put日程2756个唯一执行日，交易185笔model加95笔real。
- 全部输入、传递代码、规格及固定常量进入SHA-256运行清单。
