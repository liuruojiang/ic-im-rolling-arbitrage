# IC / IM Put 到期方向真实链扫描 v2

日期：2026-08-20（Asia/Shanghai）

## 研究问题

在其他规则完全不变时，Put 的三个月目标日落在两个实际挂牌到期日之间，是否应从“绝对距离最近”改为“目标日之后的最近到期日”，以减少临近到期的时间衰减暴露。

## 候选

- `nearest_absolute`：冻结基准。执行日加3个日历月为目标，选择实际到期日与目标日绝对距离最小的挂牌月份；距离相同时选较晚到期日。
- `on_or_after`：研究候选。存在实际到期日不早于目标日的挂牌月份时，选择其中最早者；不存在时回退 `nearest_absolute`。

不得把 `on_or_after` 解释成固定增加一个合约月，也不得改变 IM Call 的 `rescue_next_listed` 规则。

## 固定不变项

- IC：`real_l190_mom25`，1.90/2.00/2.10 对应25%/50%/75%绝对Delta，MOM120不高于0时最低25%，510500 ETF Put，95%目标行权价，随IC月换重置。
- IM：`reconstructed_valmom_floor3` / `valmom_center_floor3` 的真实链路径，每1倍IM最多3张MO Put，95%目标行权价，月度重置。
- 评估与执行、真实价格、数量取整、期权成本、期货成本、网格、IM Call、30%保证金缓冲与3%现金收益全部沿用冻结来源。
- IC 不含 Call；IM Call 不随本扫描变化。

## 数据与窗口

- IC真实510500 Put：2022-09-19至2026-08-14。
- IM真实MO Put：2022-07-22至2026-08-14。
- 输出 `full / last_10y / last_5y / last_3y / last_1y`；10年和5年窗口早于真实样本时机械截到真实样本起点，并明确记录。

## 强制校验

1. 同次运行包含冻结基准与候选。
2. 基准 Put 日收益与冻结 IC v21、IM v12 输出逐日一致。
3. 用基准 Put 重建完整组合后，与冻结 IC `real_grid_only`、IM `full_put_grid_call` 逐日一致。
4. 候选只能改变到期月及其下游真实价格、Delta数量、Put成本和现金占用；不得改变信号或其他组件。
5. 输出收益、回撤、年化波动、Sharpe、Put成本、平均Put资金占用、换月事件、平均入场剩余天数和选月差异。

## 决策规则

- 不因单一窗口收益更高直接晋升。
- 候选若完整组合全样本和近3年风险收益均不劣，且回撤或成本/收益权衡有实质改善，可进入晋升讨论。
- 若IC与IM方向不一致，分别决策，不强制统一。
- 本扫描是新假设证据，不改写冻结v1；是否晋升由扫描结果和用户后续确认决定。
