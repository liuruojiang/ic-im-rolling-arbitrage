## 1. 研究问题

v4把模型和真实Put期限固定为前月。此前旧代理扫描中的“2m/3m”会随目标到期日匹配交易所已挂牌月份：信号日度更新时，模型2m合约月份变化间隔中位数约28日但单月最多两次，3m间隔中位数约71日且单月最多三次，不能等同于“每个月卖旧买新”。

v6回答两个问题：

1. v4的拒绝结论是否依赖前月Put；
2. 在同一v4日度目标下，强制每月重置的两个月/三个月目标期限，是否提供更好的收益—回撤权衡。

v4正式输出不可覆盖。v6完整复用v4信号，只改变Put期限和月滚执行；所有历史结果已被前版观察，因此v6不是独立OOS，任何通过最多为`watchlist`。

## 2. 冻结信号网格

逐日信号、估值历史、映射和执行目标完全复用v4：

- 历史月末数：84 / 90 / 96；
- 经济风险：PB 25% + ERP 50% + 过去一年股息风险25%；
- 连续映射：0.40/0.80、0.50/0.90、0.60/0.90；目标按10%步长；
- 9个经济候选：`econ_m84_l40_h80`至`econ_m96_l60_h90`；
- 结构对照：`equal4_m90_l50_h90`；
- T日收盘评估，只在T+1开盘调整目标；首日初始化规则不变。

不得在v6内修改估值权重、窗口、映射、日评频率或目标档位。

## 3. 冻结期限与月滚定义

每个v4信号分别测试：

### 3.1 `front_original`

完全复现v4前月执行：使用冻结公共引擎的`tenor="front"`。其模型/真实逐日收益、头寸和成本必须与v4同名候选逐日一致，作为同场期限基线。

### 3.2 `2m_monthly`

- 新开仓或强制月滚日，以执行日 + 2个自然月为目标到期日；
- 在当日已挂牌510500 Put月份中，选择到期日距离目标最近者；距离相同时选择较晚到期；
- 模型执行价重置为当日ETF开盘的85%；真实层选择目标月份中开盘价和成交量均为正的最低流动行权价；
- 每个IC月度到期换仓日开盘强制卖出旧Put并买入新Put，即使挂牌到期月份相同也重置模型执行价/真实合约选择并计双边成本。

### 3.3 `3m_monthly`

与2m完全相同，但目标到期日为执行日 + 3个自然月。

强制月滚日固定为冻结IC基线`roll_from`非空的135个到期换月交易日；模型/真实样本只使用各自区间内日期。月滚在已知日历的当日开盘执行，IC基线仍按其冻结的当日结算换月口径，二者时点差异必须列为限制。

日度目标变更规则保持v4：

- 目标变0时，下一开盘立即平Put；
- 目标比例变化时，在现有合约上按新比例调整；
- 0变正时，不等待月滚日，立即按对应2m/3m目标期限建仓；
- 持仓为正时，强制月滚优先于同日比例调整；真实报价不可执行时顺延，记录延迟。

这不是“三个月持有至到期”。持有至到期、一份Put管理三个IC周期必须另版测试。

## 4. 候选规模与基准

每个期限包含：

- 9个经济候选；
- 1个等权四因子结构对照；
- 永久50%和永久100%引擎有效性基准。

另有每层一个无Put。模型/真实两层共`2 × (1 + 3 × 12) = 74`条路径。

## 5. Put、资本和数据口径

- IC为100%名义；30%保证金/缓冲，70%现金按年化3%；不放大至3.33倍；
- Put市值从现金袖套扣除；IC和Put继续使用冻结的每边1bp成本敏感性；
- 模型Put使用Black-Scholes和冻结波动率代理；真实Put使用第三方日线，要求调整日开盘价和成交量为正；
- 模型样本2015-04-16至2026-08-14；真实样本2022-09-19至2026-08-14；
- 2007估值为官方发布前回溯研究历史；模型Put不是历史可成交价格，真实日线也不是盘口成交保证。

## 6. 强制结果与期限归因

所有74条路径必须生成全样本、最近10年、5年、3年、1年的CAGR和最大回撤；另报开发段2015-04-16至2020-12-31和v4留出段2021-01-04至2026-08-14。

每个信号必须直接比较三个期限：

- CAGR和最大回撤差；
- Put成本、平均Put市值、交易次数；
- 模型与真实平均入场虚值度；
- 月滚成功数、顺延数、最大延迟；
- 合约月份未变化但仍重置的次数；
- 2015事件贡献及2025—2026保险拖累。

期限邻居固定为`front_original ↔ 2m_monthly ↔ 3m_monthly`。

## 7. 判断规则

单个经济候选—期限组合先沿用v4单线门槛：

1. 开发段和v4留出段最大回撤各改善至少3个百分点，CAGR各落后不超过1个百分点；
2. 五个强制窗口至少3个最大回撤改善为正；
3. 全/10年/5年CAGR落后不超过1个百分点，3年/1年落后不超过3个百分点；
4. 模型和真实层各至少20个保护日；
5. 无Put完全匹配冻结IC；永久基准非空；QVIX代理通过；无未来信号或执行泄漏。

稳健通过还必须同时满足：

- 同一信号至少一个相邻期限也通过单线门槛；
- 同一期限至少一个相邻6个月历史窗口、以及一个相邻映射候选通过单线门槛；
- v4信号邻居保护日Jaccard不低于60%、活动目标MAE不超过20个百分点；
- 模型2m/3m永久100%在样本内每个IC月滚日均产生月滚或有明确顺延记录；真实层月滚请求最终完成率至少90%，最大顺延不超过5个交易日。

若无人通过，决定为`keep_default/reject`。若有稳健通过，最多`watchlist`；优先选择通过期限邻居最多、留出段回撤改善最大者，若差异不超过0.1个百分点，依次优先2m、中央90月0.50/0.90、平均保护最低者。完整性或月滚审计失败为`rerun_required/data_sensitive`。
