# IC v1.3 最终组合权利金衰减 50%–80%复核 v1

日期：2026-09-17  
状态：研究预注册；不修改生产、账本、日报或交易规则。

## 目的

复核旧卖Put单腿测试中70%表现较好的结论，在当前完整IC v1.3联合组合中是否仍成立。

## 固定条件

- M+1、95% 510500 Put、等名义数量；最多提前展期一次，新腿重新准入。
- 绝对IV严格高于37.5%；即时估值0/1档加原IC v1.3执行动量许可；不引入卖方MOM120。
- 核心Put三倍盈利兑现；固定核心、动量、动量Put、0.5倍估值网格和季度T-3期货路径保持当前完整组合。
- IC无Call、无灾难保护、无相对IV。
- 所有510500 Put单边成本5BP，期货单边1BP；每1倍期货30%保证金/缓冲，现金年化3%。

## 扫描

权利金衰减50%、60%、70%、80%。真实挂牌层与理论延展层分别报告：

1. 卖Put独立状态机；
2. 完整组合；
3. 相同三倍核心Put兑现但不卖Put的对照；
4. 提前展期次数、周期数与收益风险指标。

## 判定

先检查每档完整组合相对无卖Put对照是否在真实和理论层同时满足：CAGR不低于对照、Sharpe差不低于-0.05、最大回撤绝对值恶化不超过1个百分点。通过者再比较真实/理论CAGR、Sharpe、最大回撤与提前展期次数；不因单一层单一最高收益自动认定“最优”。

## 限制

真实挂牌历史较短，理论层为模型延展。未纳入动态保证金、强平、税费、盘口容量、整数账户张数和显式成交延迟。
