# 中证1000有限滚动窗口双轴估值 v6 预注册规格

冻结日期：2026-08-19  
研究状态：估值本体研究；未批准实盘

## 1. 研究问题

v5已证明，即使2026年校准中近5年权重达60.44%，对全历史绝对分数计算75%/85%/95%加权分位，仍会被旧高估值中枢决定。本版不再扫时间半衰期，而是用有限滚动窗口直接排除过旧环境。

全历史仍用于检验状态稳定性，但当前月份的相对估值门槛只由紧邻的过去N个月末决定。本版仍不读取IM、MO、Put、贴水或策略收益选择模型。

## 2. 冻结数据与绝对轴

- 输入只使用v3冻结的`daily_tier_states.csv.gz`和`monthly_tier_states.csv`，样本2015-10-19至2026-08-17。
- 基础分数继续为`unbounded_median_knot`：PB、ERP和过去一年已实现股息贡献三项固定经济压力的二取三中位数。
- 绝对轴完全复用v3：`<2.45 / 2.45—2.50 / 2.50—2.60 / >=2.60 -> 0/1/2/3档`。
- 最终双轴档位为`max(absolute_tier, rolling_relative_tier)`。相对轴表示近期环境中的高估值风险，不等于跨时代绝对高估。
- 收益字段只报告同窗中证1000价格指数背景，不参与候选选择。

## 3. 月度因果滚动门槛

- 对每个自然月`M`，只能使用日期严格早于`M`首日的月末分数；当月未完整观测不得参与当月门槛。
- 取最近`N`个月末观测；必须有完整`N`个观测才启用相对轴，不做扩展样本或不足窗口的临时计算。
- 门槛在整个自然月内锁定；新月份到来时只移出最旧一个月末并加入上个月末。
- 分位数固定使用NumPy线性插值定义（`method="linear"`）；分数`>=`门槛时进入更高档。
- 任一门槛不严格递增时，该月相对轴不可用并记入失败；绝对轴仍保留。

## 4. 冻结候选

滚动窗口固定为`48 / 60 / 72个月末`：

- 事前唯一主候选：`dual_w60_q758595`；
- 必须的左右邻点：`dual_w48_q758595`、`dual_w72_q758595`；
- 主分档为`75% / 85% / 95%`，校准窗口内累计高估目标约为25%/15%/5%；
- `70% / 80% / 90%`只作放宽诊断，不得晋升。

对每个窗口和分档同时输出`relative_*`和`dual_*`。`absolute_v3`为同批基线。不得看到结果后修改窗口、分位、暖机长度或门槛。

## 5. 强制报告项

对所有候选报告全样本、近10年、5年、3年、1年：

- 日度和月末0/1/2/3档占比、累计档位覆盖、平均档位和已校准占比；
- 非0事件数、最长持续、升/降档、跨两档跳变和年化切换；
- 与绝对轴的精确一致率和平均绝对档差；
- 中证1000价格指数年化、波动、Sharpe和MaxDD背景，语义固定为`underlying_price_index_context_only_no_strategy_return`。

另外输出：

- 2022至今和2025至今的状态分布与月末事件；
- 每个月份的窗口起止、观测数、三个门槛和2022年前观测占比；
- 主候选与48/72月邻点在2022至今的精确档位一致率、线性加权Kappa和非0Jaccard；
- 当前分数、绝对档、相对档、双轴档和当月窗口/门槛。

## 6. 预注册选择门槛

### 6.1 主候选自身

`dual_w60_q758595`必须同时满足：

1. 2022至今非0日度覆盖在12%—45%；累计2档在5%—30%；3档在1%—18%；
2. 2022至今精确1/2/3档占比各至少1%；
3. 2022至今累计1档月末事件至少3个，累计2档至少2个，累计3档至少1个，且至少3个自然年出现非0状态；
4. 2022至今日度年化切换不超过24次；
5. 可用月份中，三个门槛的环比绝对变化中位数均不超过0.05，95%分位均不超过0.25，最大值均不超过0.75；
6. 2026-08主窗口必须恰有60个月末，最大输入日期不晚于2026-07-31，2022年前观测占比不高于10%。

### 6.2 窗口邻点支持

48月和72月邻点必须分别满足主候选门槛1—4，并在2022至今与主候选分别满足：

- 精确档位一致率不低于70%；
- 线性加权Kappa不低于0.60；
- 非0状态Jaccard不低于70%。

### 6.3 决策

- 主候选自身及两个邻点全部通过：`freeze_dual_w60_q758595_for_next_put_layer / wide_stable`；
- 主候选自身通过、但任一邻点失败：`watchlist_finite_window_dual_axis / peak_only`；
- 主候选自身失败：`no_finite_window_valuation_candidate / reject`。

70/80/90系列只作覆盖放宽诊断，无论结果多好都不得替代主候选。

## 7. 因果与完整性

- 每个月度门槛的最大输入日期必须严格早于有效月份；逐月截断重算必须与正式门槛完全一致，未来行使用数为0。
- 每个可用门槛必须恰好使用N个月末；相邻月份窗口应正常只移出/加入各1个观测。
- v3绝对轴逐日奇偶误差必须为0；双轴必须逐日等于`max(absolute, relative)`。
- 日度和月末状态必须使用同一有效月份门槛；候选和五个强制窗口必须完整。
- 本版不含交易执行、手续费、滑点、保证金、现金收益或期权流动性。即使通过，也只允许进入下一层MO Put研究，不批准实盘。
