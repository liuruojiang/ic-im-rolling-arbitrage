# IC Put 污染后重建：第十层成本与逐周期集中度 V1 预注册

## 固定候选

- 按用户确认固定核心买 Put `profit3x`：T 日收盘达到入场权利金 3 倍，最早 T+1 收盘兑现并按当时规则重建。
- 卖 Put 候选采用第九层通过的 `q_delta05`；`q1_notional`继续作为数量基线。
- 卖 Put 其余路径固定为修正后 ETF 单位绝对 IV > 30%、不加卖方 MOM120、M+1、95%、即时估值、无灾难 Put、无相对 IV、持有到期。
- 公平无卖 Put 对照使用相同完整组合、相同核心 Put 3 倍兑现和同档买 Put 成本，只移除卖 Put 路由。
- IC 不含 Call；动量 IC、动量 Put和网格不变。

## 成本压力

- 所有 510500 买 Put 与卖 Put 使用相同单边成本，扫描 `5bp / 10bp / 20bp`；IC 期货仍为单边 1bp，现金年化3%。
- 每档成本完整重跑卖 Put、交割恢复、核心/动量买 Put及组合状态；成本可能改变恢复退出日期，不使用静态收益扣减。
- 5bp 的 q1 与 q_delta05 必须分别逐日复现第九层对应的 3 倍兑现路径。
- 10bp 为主要执行摩擦压力；20bp 仅为极端诊断。

## 周期集中度

- 在 5bp 的 q_delta05 路径上，从每轮卖 Put 入场日起至下一轮入场前一交易日划分互斥周期块；最后一轮延伸到样本末。
- 每次留出一个周期块，将该块完整替换为同成本、同 3 倍兑现的无卖 Put 收益，其他日期保持 q_delta05 候选。
- 输出每轮增量对数收益、绝对贡献占比、留一后 CAGR、Sharpe 与最大回撤。

## 数据与判定

- 真实挂牌层：2022-09-19 至 2026-08-14；理论延展层：2015-04-16 至 2026-08-14。
- 10bp 的 q_delta05 候选在真实与理论层均须满足：CAGR 不低于同成本无卖 Put 对照；Sharpe 不低于对照 0.05 以上；最大回撤绝对值恶化不超过1个百分点；资金可行。
- 5bp逐周期留一后最差 CAGR 不低于同层无卖 Put 对照；任一周期绝对增量贡献不得超过全部周期绝对贡献的50%。
- q1 同成本结果作为数量基线报告，但本层主闸门针对用户继续选择后的 3倍兑现＋q_delta05 候选。
