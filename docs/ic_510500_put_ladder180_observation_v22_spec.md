## 1. 研究问题

v21显示，在MOM120最低25% Delta不变时，估值三级从`2.00/2.10/2.15`下移到`1.90/2.00/2.10`，模型和真实样本的CAGR提高而全样本MaxDD不变。用户提出继续增加一条从1.80开始的观察线。

本版只回答：把三级估值阈值进一步下移至`1.80/1.90/2.00`，是否继续形成更优的收益—回撤交换，以及增量来自哪些历史阶段。不重开已被v21否定的MOM120 50%/75%下限，也不改变Put和执行结构。

重要边界：v6估值本体的均值独立平台从1.80开始，但二取三中位数共同确认平台从1.85开始；二取三1.80最近10年月覆盖34.71%，超过预注册30%上限。因此1.80是结构平台外侧观察点，无论回测结果如何，本版都不能直接把它晋升为实盘线。

## 3. 候选与公式

模型层和真实510500 ETF Put层各跑5条：

1. `no_put`：滚IC加现金；
2. `current_fixed1`：v21当前固定1倍名义控制；
3. `c200_mom25`：估值阈值2.00/2.10/2.15；
4. `l190_mom25`：估值阈值1.90/2.00/2.10；
5. `l180_mom25`：新观察线，估值阈值1.80/1.90/2.00。

三级估值档固定对应交易时25%/50%/75%绝对Delta；`MOM120<=0`提供最低25% Delta。最终目标为：

`target_delta = max(0.25 * valuation_tier, 0.25 * 1[MOM120<=0])`。

MOM120严格沿用中证500全收益指数120交易日绝对收益，不是MA120均线交叉。`l180_mom25`相对`l190_mom25`的边界差异为：

| 二取三中位数 | l180目标 | l190目标 |
| --- | ---: | ---: |
| [1.80, 1.90) | 25% | 0% |
| [1.90, 2.00) | 50% | 25% |
| [2.00, 2.10) | 75% | 50% |
| 其他区间 | 按各自三级规则 | 按各自三级规则 |

## 4. Put、资本、成本和成交

- 日评；T日收盘计算，下一共同交易日收盘执行；样本首日保留冻结初始例外。
- 3个月目标、95%执行价/标的Put，信号持续时随IC逐月卖旧买新，不持有到期。
- Delta只在新开、月换或目标档变化时重算；不做每日Delta再平衡。
- 模型使用冻结Black-Scholes/QVIX代理；真实层使用510500 ETF Put实际收盘反解隐波，失败时才回退冻结QVIX并逐笔标识。
- 1倍IC名义，30%保证金/缓冲，70%现金净年化3%；Put市值扣减计息现金；IC和Put每边1bp。
- 不静默限制Put数量；报告交易后Put市值、所需标的名义、实际Delta漂移和超过100%天数。

## 6. 观察线判定

主比较为`l180_mom25`相对`l190_mom25`；`c200_mom25`用于显示完整下移序列。

1. 若模型和真实全样本CAGR都不低于l190，且全样本MaxDD均不加深，则标记`return_heavy_observation`；
2. 模型五窗口和真实三个可用窗口中，任何窗口MaxDD不得加深超过1个百分点；模型全/10年/5年及真实全样本CAGR不得落后超过1个百分点，3年/1年不得落后超过3个百分点；否则标记`reject_observation`；
3. 若主要增益只来自一个日历年、只来自2026年或只来自模型而不是真实层，则稳定性标记`event_driven`；至少两个分离历史阶段方向一致才可标记`multi_episode_support`；
4. 交易后Put市值须不超过权益70%，收益不得小于等于-100%，模型交易Delta误差不超过`1e-12`、真实不超过2个百分点、真实隐波回退不超过5%；
5. 必须列出l180相对l190新增保护日、只升档不新增保护的日期、年度收益/回撤增量和交易成本增量。

即使达到`return_heavy_observation`，由于1.80低于v6共同结构平台下沿且是用户指定的单一边界点，`selected_variant`仍固定为空，状态保持`RESEARCH_ONLY_NOT_LIVE_APPROVED`。若观察线显著占优，后续也必须另立版本补测1.75/1.80/1.85的结构宽度，不能在本版内追参。
