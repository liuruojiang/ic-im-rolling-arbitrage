# IM v1.3 核心 Put 盈利兑现稳健性复测 v2

预注册日期：2026-09-16。研究专用，不修改生产规则、账本或信号。

## 纠错前提

上一版完整组合回放的真实期权引擎在生成 `replace` 判断后才读取待执行盈利信号，导致真实层盈利兑现实际为 T+2 收盘，而报告误写为 T+1；理论引擎为 T+1。上一版跨层结果因此不得作为正式比较。本版保留旧产物作为失败审计，不覆盖、不删除。

## 固定组合

完整沿用修正后 IM v1.3 反事实组合：0.5倍固定核心、0.5倍现行防抖动量袖、1.6/2.0的0.5倍网格、现行102%核心与动量 Put、IM D10/IV26 Call、季度期货链、每1倍30%缓冲及现金年化3%。恢复认证的2015年早期估值；真实挂牌与理论延展严格分层。

## 候选

- `baseline`：核心 Put 不做盈利兑现；
- `profit2p5x_t1`：T日收盘价达到实际入场权利金2.5倍，T+1收盘兑现并按当日102%、约3个月重新建仓；
- `profit3x_t1`：同上，阈值3倍；
- `profit3p5x_t1`：同上，阈值3.5倍；
- `profit3x_t2`：3倍信号延后一交易日，于T+2收盘执行，用作执行延迟压力。

月度维护优先；目标数量归零按原规则退出；新腿实际成交价成为下一触发基准。盈利信号只可使用T日收盘。动量 Put 不参加盈利兑现。

## 稳健性判定

3倍只能继续保留为研究候选，当且仅当：

1. `profit3x_t1`在真实与理论全期年化均不低于基线；
2. 2.5倍和3.5倍两个邻点在真实与理论全期年化均不低于基线；
3. `profit3x_t2`在真实与理论全期年化均不低于基线；
4. 任一候选最大回撤不得比基线恶化超过1个百分点；
5. 保存真实触发日期、信号至执行交易日数、月度维护冲突和年度归因；真实事件稀少必须单独标注，不能以理论期替代真实证据。

任何一项失败，结论为3倍缺乏稳健性，不晋级生产。即使全部通过，也只能保留研究候选。
