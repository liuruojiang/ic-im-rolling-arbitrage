# IM 估值预测即时择时 + 近3个月最低执行价 Put v2：预注册规格

冻结日期：2026-08-16  
研究状态：预注册研究；未获准实盘

## 1. 修订原因与研究问题

v1 将估值信号只绑定到原永久 Put/IM 月度换仓日，导致已经在月末确认的信号继续等待到 IM 到期及新 `m+3` 合约挂牌后才执行。该执行口径不符合用户“估值变坏后立即买入”的假设；v1 只保留为错误执行诊断，不用于判断即时择时保护是否有效。

v2 只修正执行路径：估值状态在交易日 `T` 收盘确认后，`T+1` 第一个中金所交易日开盘立即买卖 Put；Put 决策和 IM 换月完全解耦。估值模型、零阈值、IM 基线、合约数量、最低执行价和成本不做事后优化。

## 2. 预注册假设

- H1：即时执行 v2 的全样本净年化收益高于错误延迟执行 v1。
- H2：即时执行 v2 在2024年1月初已建立保护，2024年最大回撤应浅于延迟执行 v1；该事件核对用于验证执行修正，不作为重新调参依据。
- H3：相对无保护 IM，同切片 v2 若全样本回撤改善不足8个百分点，则全样本年化收益落后超过1个百分点、或3年/1年落后超过3个百分点，只能归类为观察/诊断。
- H4：即时保护是否优于同执行时点永久保护必须由真实回测决定，不能因为修正了时点而预设结论。

- MO Put 全链：`data/im_monthly_roll_3m_lowest_put_v1/cffex_mo_puts.csv`；使用官方开盘价、结算价、成交量和持仓量。

## 4. 估值信号

信号算法与 v1 相同，但决策直接从每条估值状态产生：

1. 在估值状态日 `T` 收盘后，只使用日期不晚于 `T` 的历史。
2. 对聚合滚动 PE、聚合 PB、`ERP=1/PE-10年国债`、过去一年已实现股息贡献四个特征，在截至 `T` 的历史内重新计算因果百分位。
3. 历史锚点必须满足 `锚点日+3年 <= T`；前瞻全收益终点不得晚于 `T`。
4. 四维百分位均方根距离等权；相似锚点至少间隔12个月，最多8个，至少4个。
5. 历史相似锚点后3年中证1000全收益年化中位数严格小于0时为 `ON`；否则为 `OFF`。阈值固定为0，不扫描。

正式历史决策使用2022-06-30至2026-07-31之间、且能在样本终点前找到 `T+1` 执行日的状态。2026-08-14状态只作为当前研究信号，不进入未来未知价格的回测。

## 5. 即时执行日

- 常规：`T` 日收盘确认信号，`T+1` 第一个 IM/MO 共同交易日使用官方开盘价执行。
- 初始例外：2022-06-30信号产生时 MO 尚未上市；在首个共同交易日2022-07-22执行。为与冻结 IM 基线从当日结算价开始一致，初始 Put 以当日结算价建立，当日不计 Put 盘中损益。
- `OFF -> ON`：`T+1` 开盘立即买入新 Put 组。
- `ON -> OFF`：`T+1` 开盘立即卖出旧 Put。
- `ON -> ON`：`T+1` 开盘卖出旧 Put、同时买入按新状态选出的近3个月 Put。
- `OFF -> OFF`：不持有、不交易 Put。

不得等待 IM 到期、不得等待尚未挂牌的精确 `m+3` 月份，也不得使用 `T+1` 收盘后的估值决定 `T+1` 开盘交易。

## 6. 到期月份、执行价与流动性

每个 `T+1` 执行日：

1. 目标日期固定为 `T + 3个自然月`。
2. 从当日已经挂牌、到期日在执行日之后的 MO Put 月份中，选择实际到期日与目标日期绝对日数距离最小者；若完全并列，选择较晚到期月。
3. 在所选月份中选择数值最低的执行价 Put。
4. 主曲线要求新 Put 官方开盘价严格为正、当日成交量和持仓量均大于0；旧 Put 在退出日也必须有严格为正的官方开盘价。任何条件失败，正式运行终止，不后视改选更高执行价。

预运行只读数据审计显示：50个历史入场全部满足上述条件，目标到期距离为7—15天；49个旧 Put 退出开盘价全部存在，最小退出成交量3、持仓量154。该审计只验证可计算性，不查看策略收益。

## 7. 日度 Put 损益

每1份 IM 名义匹配2份 MO Put，因合约乘数分别为200元/点与100元/点。收益率分母使用前一交易日活动 IM 结算价。

- 普通持有日：`(Put结算_t - Put结算_{t-1}) / IM结算_{t-1}`。
- `ON -> ON` 换仓日：旧 Put 隔夜损益 `(旧Put开盘_t - 旧Put结算_{t-1})`，加新 Put 日内损益 `(新Put结算_t - 新Put开盘_t)`，两者合计除以前一日 IM 结算价。
- `ON -> OFF`：只计旧 Put 隔夜损益至退出开盘。
- `OFF -> ON`：只计新 Put 从买入开盘至当日结算的日内损益。
- 初始2022-07-22按结算价建立，Put 当日损益为0。

最新未完成持仓按2026-08-14官方结算价盯市，不收假设平仓成本。

## 8. 比较线、成本与现金

同一 IM 曲线、日历和费用下展示四条线：

1. 无 Put；
2. 同一 `T+1 open` 月度换仓表下永久持有 Put（正确同执行基线）；
3. 估值即时择时 Put v2；
4. 旧永久 Put v1 作为不同执行表的历史参考，不用于同路径晋升判定。

- IM 成本沿用每边名义1bp。
- 整组2份 Put 每次买或卖按 IM 名义每边1bp；`ON->ON` 或永久月度换仓为2bp。
- 无 Put 时70%净资产按用户情景年化3%计息。
- 有 Put 时可计息权重为 `max(0,70%-Put结算/IM结算)`；Put 本身按市值计入组合资产。
- 不使用30%保证金将方向敞口放大到3.33倍。

## 9. 强制展示与事件核对

全样本、10年、5年、3年、1年统一展示 CAGR 与 MaxDD；不足窗口显示 `N/A`。候选相对无 Put和同执行永久 Put分别展示收益差、回撤改善。另按2022—2026自然年展示。

必须单列：

- 决策数、ON次数、保护日占比、状态切换、Put交易边数和累计成本；
- 每次估值状态日、执行日、目标日期、实际到期日、距离、选中合约、开盘价、流动性与预测中位数；
- 2023-12-29信号、2024-01-02买入、2024-01-22与2024-02-05的实际保护状态和 Put 缓冲；
- 最大回撤峰值、谷底、修复日及最差5个 IM 交易日。

年化按252个交易日，MaxDD由日净值历史峰值计算。

## 10. 当前与3年/5年情景

- 2026-08-14当前走步预测必须与估值 v3 的3年中位数精确核对。
- 当前状态只判断 `ON/OFF`；若相对2026-07-31历史状态未变化，则不虚构新的交易。
- 当前持有合约按 v2 最后一笔历史决策和2026-08-14官方结算价展示。
- 未来情景沿用估值 v3；历史保险成本调整使用 v2“择时+剩余现金”相对“无 Put+70%现金”的全样本相对 CAGR。
- 该调整不含未知未来下跌路径的 Put 赔付，未来保护后 MaxDD 仍为 `N/A`，不得冒充完整预测。

## 11. 完整性与排除

- 全部估值输入 `<= T`，全部类比结果终点 `<= T`，全部常规交易日严格 `> T`。
- 新无 Put 曲线必须与冻结基线逐日一致；旧永久 Put参考必须与冻结 v1 逐日一致。
- 选中 Put 的开盘、结算、退出价格和持有日结算必须完整，`pre_settle` 连续性单列审计。
- 不扫描估值阈值、锚点数、特征权重、到期距离、执行价或执行价格字段。
- 不加入趋势、波动率、隐含波动率或期权价格过滤。
- 不模拟三层重叠、持有到期或动态 Delta；不把官方开盘价视为保证可成交，不计盘口冲击和经纪商附加保证金。
- 本版只做研究审计，不生成或接入自动/人工订单。
