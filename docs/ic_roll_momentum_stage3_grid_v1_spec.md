# IC 分层研究第三层：50:50 + 动态 Put + 独立估值网格 v1（预注册）

## 研究目标

在第二层三条正式路径上只增加当前冻结 IC 估值网格，逐一比较有无网格：

1. `50:50，不加 Put`；
2. `Put 只保护裸滚 50%`；
3. `Put 保护裸滚及实际动量袖`。

本层回答独立网格是否对三种 Put 配置提供稳定增量。Call 继续关闭；不修改动量、Put、网格、成本或资金参数。

## 固定底座与 Put

- 底座继承 `outputs/ic_roll_momentum_stage2_put_v1/daily_nav.csv.gz`。
- 50% 固定裸滚 IC + 50% 动量门控 IC；中证500动量为 `MA110 / Mom24 / W2`，50% `Abs20 OFF` + 50% `Abs20 > 0`。
- Put 三条路径及其执行、调仓、成本、理论/真实数据分层全部保持第二层不变。
- 2015-04-16—2022-09-16 的 Put 为 QVIX/Black-Scholes 理论层；2022-09-19 起为真实 510500ETF Put。网格自身始终使用真实 IC 期货与历史估值分数。

## 固定网格

- 估值分数采用冻结的中证500无界固定经济单位二取三中位数。
- T 日收盘分数 `<= 0.375`，T+1 交易日以当时活跃 IC 官方开盘价新增 1 倍 IC。
- T 日收盘分数 `>= 1.000`，T+1 交易日以当时活跃 IC 官方开盘价退出全部新增仓。
- 网格只有 0/1 倍两个状态，不连续加仓；持仓期间随 IC 逐月换月。
- 网格独立于动量信号运行；动量空仓不阻止网格开仓，也不迫使网格退出。
- 新增网格仓不配置 Put；三条 Put 路径的 Put 名义不得因网格仓变化而变化。

## 收益、成本与资金

- 冻结网格逐日组件取自 `outputs/ic_put_grid_call_combined_v2/daily_candidates.csv.gz` 的 `model_grid_only`：开/平仓日按官方开盘到结算价计算，普通持仓日按前结算到当日结算计算。
- 网格交易成本每边 1bp；网格持仓换月双边 2bp。
- 网格作为独立新增袖，其净增量为 `(1 + grid_gross) × (1 - grid_cost) - 1`，与第二层已含成本的期货及 Put 税前现金收益相加。
- 每 1 倍网格 IC 另占用 30% 保证金/风险缓冲；现金权重为第二层现金权重减 `30% × 网格日终仓位`，剩余现金继续按净年化 3% 计息。
- 若原始现金权重小于 0，正式运行失败，不以隐含借款或裁剪掩盖资金缺口。

## 报告与验证

- 报告全周期、近 10 年、5 年、3 年、1 年及真实 Put 期的年化收益、年化波动、最大回撤、Calmar、网格成本、持仓天数和最大总 IC 名义。
- 每条无网格路径必须逐日精确复现第二层对应路径。
- 冻结网格模型/真实重叠段的仓位、交易、损益、成本和估值分数必须逐日一致，误差不超过 `1e-12`。
- 验证仅有 0/1 倍网格仓、T+1 信号执行、网格与动量独立、Put 目标不随网格变化、现金非负、日期完整且无单日收益小于等于 -100%。
- 保存逐日路径、交易事件、窗口与年度指标、验证、输入哈希及运行清单。

## 研究边界

- 当前冻结网格全周期只有 3 次完整进出、130 个持仓日，事件样本极少；不能只因个别年份改善而认定稳健。
- 本层不测试动量指导网格，也不重新扫描阈值；如需比较独立与动量门控网格，必须另建版本。
- 结果仅为研究候选，不修改冻结 IC/IM V2 主线、Poe 或实盘配置。
