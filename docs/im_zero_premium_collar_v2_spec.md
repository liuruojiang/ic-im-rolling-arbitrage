# IM 权利金差多档领口研究 v2：预注册口径

状态：独立研究候选，不改正式 v1.4-r1 fix4 信号；不代表实际成交。v1 首轮因 T+1 同收盘筛选被独立审计判为诊断，新版本重建，不覆盖 v1 产物。

## 问题与参数

研究“长期持有一倍 IM 以获得贴水，同时按名义等值买虚值 MO Put、卖虚值 MO Call，两腿权利金尽量相抵”的波动、回撤与收益取舍。固定 Put 目标为 T 日指数收盘的 95%；从同月虚值 Call 中选 T 日权利金最接近的合约。仅改变 **T 日已知的两腿毛权利金绝对差上限**：`0.05% / 0.10% / 0.20% / 0.30%` 的同月 IM 收盘名义，以及不设上限的覆盖参考。0.10% 是 v1 历史默认，其他档不自动获准进入正式信号。每档同时生成 `matched_im`、`matched_put`、`matched_call`、`matched_collar`；另生成与同一月度入场时钟的 `all_im`，覆盖全部完整周期。

## 数据与时间

- 使用 v1 所列官方中金所 IM、MO Put/Call 合约级历史数据及中证1000价格指数、月度 IM 期货日程；原始价格指数只用于定义虚值与贴水。截止 2026-08-14，最后完整到期日为 2026-07-17，不把未完成的 2026-08 周期计入绩效。
- T 是上个 IM 合约到期日（首期为 2022-07-22）；T 收盘只用 T 当时可见的期货、指数、MO 收盘价/量/持仓量选约和判断参数档。T 日必须 `指数收盘 > 所选 IM 合约收盘`，否则当期不建领口；`all_im` 仍照常交易。
- T 日选择当前同到期月、正收盘价/成交量/持仓量且行权价低于指数收盘的 Put，目标行权价 95%；再选同月且行权价高于指数收盘的 Call，T 日毛权利金差绝对值最小，并列时选更高 Call 行权价。
- T+1 共同交易日按 T 预选合约的**官方开盘价**买 1 IM、2 MO Put、卖 2 MO Call。只因 T 日信号门槛决定是否入场；T+1 实际价差、是否仍虚值、量仓、开盘价缺失均单独披露。若预选合约 T+1 开盘价缺失或非正，判数据/执行受阻并停止相关数值结论，不事后挑选可交易周期。建仓后按官方每日结算价盯市，至该月到期结算。连续周期之间空档持现金。
- 原始数据没有同步 bid/ask 或盘口容量；官方开盘价仅是三腿非同步成交代理，不保证按该价格成交。`official_open_settle_proxy_not_executable_fill` 必须伴随所有结果。

## 损益与资金

- 1 IM 乘数 200，2 MO 乘数各 100；权利金和损益按人民币统一。期货每边 1bp、每条 MO 腿每边 5bp，均以入场 IM 名义计算。两腿权利金差门槛按**扣成本前**毛额，另报告 T+1 实际毛差、扣入场期权成本净差、差额偏移及相对贴水。
- 每周期以 1 倍 IM 入场名义作为初始资金，30% 留作期货保证金/缓冲，未占用现金年化 3%。期权权利金直接进出现金；期货逐日结算变动进出现金；到期期权现金结算进出现金。卖 Call 保证金用仓库既有的研究近似式估计，日初用前收盘已知价格计提、日末用当日结算价格重估。负可用现金计入资金缺口并按 3% 年化代理融资，不宣称经纪商核验。
- 各档四路径在未入场月份同样持现金，在入场月份共享期货链与日期。`all_im` 为同入场时钟全月持有参考；报告覆盖周期/天数，不能把稀疏路径回撤下降直接说成同持仓风险下降。按真实期货、Put、Call、现金和成本重组总损益及 NAV。

## 结果和验收

- 产出每周期信号/执行日期、合约/行权价、T 与 T+1 权利金差、贴水与到期实际基差、到期偿付上下界、量仓、覆盖原因；逐日金额损益、现金账本、卖 Call 保证金、资金占用、NAV；各档全期、3年、1年窗口与10年/5年不可用说明。
- 逐日检查资金和净值会计恒等式、相同周期基线日期一致、成本进入收益且无成本路径非劣、期权与期货同到期月、T 信号早于 T+1 执行、期权日结算无缺失或未来筛选。成本/可成交性为代理时只给研究诊断结论。
- 本批次所有参数档作为同一次扫描运行；运行后由多个独立 Agent 再次对数据时序、逐笔损益、经济解释/参数稳健性做对抗性复核，通过前不发布确定性绩效结论。扫描不晋级生产。
