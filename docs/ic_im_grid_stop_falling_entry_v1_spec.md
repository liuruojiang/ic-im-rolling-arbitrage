# IC/IM低估网格“停止创新低”入场扫描 v1

预注册日期：2026-09-16。研究专用，不修改1.3正式规则。

## 研究问题

估值首次进入网格准入区后，不立即新增网格仓，而是等待指数连续若干交易日没有再创严格的过去20日新低，再于下一交易日开盘入场，能否改善当前半仓网格的收益回撤结构。

## 固定规则

- IC：估值不高于0.5触发、估值不低于1.0退出，网格0.5倍。
- IM：估值不高于1.6触发、估值不低于2.0退出，网格0.5倍。
- 核心、动量、Put、Call、期货链、成本、30%缓冲和3%现金收益保持来源路径不变。
- 止跌门控只影响空仓后的新买入；买入后完全按原估值上界退出，不因价格趋势减仓或提前退出。
- 当估值离开准入区但尚未确认时，取消等待；下次重新进入低估区重新计数。
- “新低”定义为当日全收益指数收盘严格低于此前20个交易日收盘的最小值。触发日不计入确认日；数据不足20日失败关闭。

## 候选

- `immediate`：当前估值触发后T+1立即入场。
- `wait3`、`wait5`、`wait10`：分别连续3、5、10个交易日没有再创上述新低后，T+1入场。

## 边界

这是网格首次入场的等待条件，不是持续动量策略。真实挂牌与模型/代理时期分别报告；模型IM含事后平均贴水，只作机制压力测试。任何结果不自动改变生产规则。
