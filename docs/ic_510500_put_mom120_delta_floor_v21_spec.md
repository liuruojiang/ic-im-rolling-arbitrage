## 1. 研究问题与术语

v20的三级Delta候选把`MOM120<=0`只设为最低1档，即交易时目标25%绝对Delta。用户提出：趋势已经走坏时，50%或75%保护可能更合理。本版只扫描MOM120触发后的Delta下限，不改变Put期限、执行价、月换、成本和成交时点。

这里的`MOM120`严格沿用冻结定义：

`MOM120(T) = 中证500全收益指数收盘(T) / 收盘(T-120个交易日) - 1`

因此它是120交易日绝对收益，不是“价格跌破120日移动平均线”。边界`MOM120<=0`视为触发。若要研究真正的MA120交叉，必须另立新版本。

“叠加”冻结为取较强者，不做算术相加：

`目标Delta = max(估值档目标Delta, MOM120触发后的Delta下限)`。

例如估值目标25%、MOM下限75%时，最终目标75%，不是100%。

## 3. 候选矩阵

### 3.1 两套估值阶梯

均使用v6“二取三中位数”`unbounded_median_knot`，达到边界即进入高一档：

| 阶梯 | 1档/25% | 2档/50% | 3档/75% |
| --- | ---: | ---: | ---: |
| `l190` | 1.90 | 2.00 | 2.10 |
| `c200` | 2.00 | 2.10 | 2.15 |

`l190`保留用户指出不应淘汰的1.90起点；`c200`是v20原阶梯。二者都必须完整报告，不得按结果删除。

### 3.2 MOM120下限与控制组

模型层和真实期权层各跑11条：

1. `no_put`：滚IC加现金；
2. `current_fixed1`：v20固定1倍名义控制，`c200`任一估值档或`MOM120<=0`时持有1倍标的名义Put；
3. `mom_only_d25`、`mom_only_d50`、`mom_only_d75`：不看估值，只在`MOM120<=0`时把交易时目标Delta设为25%/50%/75%；
4. `l190_mom25`、`l190_mom50`、`l190_mom75`：`l190`估值档目标25%/50%/75%，与对应MOM下限取最大值；
5. `c200_mom25`、`c200_mom50`、`c200_mom75`：`c200`估值档目标25%/50%/75%，与对应MOM下限取最大值。

其中`c200_mom25`必须与v20的`tier_delta255075`逐日、逐笔一致；`no_put`、`current_fixed1`也必须与v20对应路径一致。纯MOM组用于识别：若组合组的改善在纯MOM组中同样出现，则不能把改善归因于估值分档。

## 4. Put、Delta、成本与成交

- 日评；T日收盘计算信号，下一共同交易日收盘执行；样本首日保留冻结引擎的初始状态例外。
- Put固定`3m_monthly_exit_m95`：目标到期月约为执行日后三个月，执行价/标的收盘最接近95%；信号持续时随IC逐月卖旧买新，不持有到期。
- Delta数量只在新开、每月换Put或目标档变化时重算；目标不变时不做每日Delta再平衡。
- 模型层沿用冻结Black-Scholes/QVIX代理；真实层使用510500 ETF Put实际收盘价反解隐波并计算Delta，无法反解时允许冻结QVIX回退且须逐笔标识。
- 真实Delta数量为整数张，逐笔交易时目标误差不得超过2个百分点；模型误差不得超过`1e-12`。
- 1倍IC名义；30%保证金/缓冲，70%现金净年化3%；Put市值从计息现金扣除；IC和Put每边1bp。
- 不静默限制为了达到目标Delta所需的Put张数。须报告交易时新仓保费、持仓市值、标的名义倍数、日度有效Delta及有效Delta超过100%的天数。
- 可实施性资本门槛以“交易后新仓Put市值/组合权益”不超过70%为准；持仓随后因Put升值超过70%单独报告，但不误判为建仓占资失败。

## 6. 预注册判定

### 6.1 MOM下限升级

`mom50`和`mom75`分别与同估值阶梯的`mom25`比较；纯MOM组也分别与`mom_only_d25`比较。升级要进入“稳健候选”须同时满足：

1. 模型和真实全样本MaxDD各改善至少1个百分点；
2. 模型五个窗口至少三个MaxDD改善，真实三个可用窗口至少两个改善；任一窗口MaxDD不得加深超过1个百分点；
3. 模型全/10年/5年及真实全样本CAGR落后不超过1个百分点；模型和真实3年/1年落后不超过3个百分点；
4. 与同层`no_put`相比，全样本MaxDD须改善；CAGR采用同一容忍度；
5. 交易后新仓Put市值不超过权益70%，收益不小于等于-100%，模型/真实交易时Delta误差合格，真实隐波回退不超过5%；
6. 模型MOM触发后执行持有日至少20日，真实至少10日。

若50%和75%均通过，默认选择更低的50%；只有75%相对50%在模型和真实全样本MaxDD都再改善至少1个百分点，且仍满足收益容忍度，才把75%列为优先候选。

### 6.2 估值阶梯与归因

- `l190`和`c200`按相同MOM下限一一比较，但由于1.90/2.00的讨论已经使用2026样本，本版只给“收益偏好/回撤偏好/无显著差异”标签，不据此直接晋升实盘。
- 组合组相对纯MOM组的增量必须单列。如果估值叠加没有带来全样本MaxDD改善或只在单一年份出现，不得宣称估值层有稳健贡献。
- 本版使用与前序研究相同样本，结果不是独立样本外验证；无论通过与否，状态均保持`RESEARCH_ONLY_NOT_LIVE_APPROVED`。
